主机信息

本节介绍系统的主机信息及其配置方法，涵盖以下主题：

  • 主机名

  • 域名

  • IP 地址

  • 别名

主机名

主机名是分配给网络设备（即主机）的标签（名称），用于在特定网络或互联网上区分不同设备。此外，该名称也将显示在命令行提示符中。

set system host-name <hostname>

主机名最多可包含 63 个字符。主机名必须以字母或数字开头和结尾，且中间字符只能为字母、数字或连字符（-）。

默认主机名为 vyos。

域名

域名是分配给计算机网络的标签（名称），因此具有唯一性。VyOS 将域名作为后缀附加到任何未限定的名称之后。例如，若您将域名设置为 example.com，并尝试对未限定名称 crux 执行 ping 操作，则 VyOS 会将该名称解析为 crux.example.com。

set system domain-name <domain>

配置系统域名。域名必须以字母或数字开头和结尾，且中间字符只能为字母、数字或连字符（-）。

静态主机名映射

如何在 以太网接口 上为接口分配 IP 地址。本节介绍如何为本地（即在此 VyOS 实例上）名称解析静态地将 IP 地址映射到主机名。这相当于 VyOS 中的 /etc/hosts 文件条目。

注意

请 不要 手动编辑 /etc/hosts 文件。该文件将在启动时根据本节中的配置自动生成，这意味着您手动所做的所有修改都将丢失。请按如下方式配置静态主机映射。

set system static-host-mapping host-name <hostname> inet <address>

创建一个静态主机名映射，使名称 <hostname> 始终解析为 IP 地址 <address>。

set system static-host-mapping host-name <hostname> alias <alias>

为已配置的主机名 <hostname> 的静态映射创建命名别名 <alias>。因此，通过 set system static-host-mapping host-name <hostname> inet <address> 配置的地址可通过多个名称访问。

每个主机名可指定多个别名。
