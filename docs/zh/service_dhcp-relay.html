DHCP 中继

DHCP 中继代理允许单个 DHCP 服务器为远程子网上的客户端提供服务，从而无需在每个子网上部署单独的服务器。

DHCP 中继代理在一个接口上接收客户端请求，将其作为单播转发至另一网络上的指定服务器，并将服务器的响应返回给原始发起请求的客户端。

VyOS 提供两种独立的 DHCP 中继服务：

  • service dhcp-relay：在 IPv4 客户端与服务器之间中继消息。

  • service dhcpv6-relay：在 IPv6 客户端与服务器之间中继消息。

这两项服务需分别配置，且不共享任何设置。在双协议栈网络中，若 IPv4 和 IPv6 客户端均需使用 DHCP，则必须同时配置两者。

IPv4 中继

配置

set service dhcp-relay listen-interface <interface>

配置一个监听接口，DHCPv4 中继将在该接口上接收客户端广播请求。

重复执行该命令可配置多个监听接口。

注意

为确保提交成功，至少需配置一个 listen-interface 和一个 upstream-interface。

示例：

set service dhcp-relay listen-interface eth1
set service dhcp-relay upstream-interface <interface>

配置一个上游接口，DHCPv4 中继通过该接口将客户端请求转发至 DHCP 服务器。

重复执行该命令可配置多个上游接口。

注意

为确保提交成功，至少需配置一个 listen-interface 和一个 upstream-interface。

示例：

set service dhcp-relay upstream-interface eth2
set service dhcp-relay server <ipv4-address>

配置 DHCPv4 服务器的 IPv4 地址，DHCP 中继将客户端请求转发至该地址。

重复执行该命令可将客户端请求转发至多个 DHCPv4 服务器。

注意

为确保提交成功，至少需配置一个 DHCPv4 服务器。

示例：

set service dhcp-relay server 203.0.113.4
set service dhcp-relay interface <interface>

配置一个参与 DHCPv4 中继的接口。

在此传统命令下配置的接口以双向方式运行：既接收 DHCPv4 客户端广播，又将请求转发至服务器。

警告

该命令已弃用，仅保留以支持现有配置。新部署应使用 listen-interface 和 upstream-interface，二者不可与此命令混用。提交时将显示弃用警告。

注意

回环接口（lo）不被接受为该命令的有效值。

示例：

set service dhcp-relay interface eth1
set service dhcp-relay interface eth2
set service dhcp-relay disable

在不删除其配置的情况下，管理性禁用 DHCPv4 中继服务。

示例：

set service dhcp-relay disable

中继选项

set service dhcp-relay relay-options hop-count <1-255>

配置 DHCPv4 跳数阈值，当转发数据包的跳数达到该值时即被丢弃。

接收到客户端消息的 DHCPv4 中继将跳数设为 0；此后每经过一个 DHCPv4 中继，跳数加 1。当数据包跳数达到所设定的值时，该数据包将被静默丢弃。

默认值为 10。

示例：

set service dhcp-relay relay-options hop-count 4
set service dhcp-relay relay-options max-size <64-1400>

配置添加中继代理信息（Relay Agent Information）选项后，DHCPv4 数据包允许的最大字节数。

若添加该选项后的数据包超过此大小限制，则省略该选项，并直接转发不含该选项的数据包。

默认值为 576。

示例：

set service dhcp-relay relay-options max-size 1400
set service dhcp-relay relay-options relay-agents-packets <append | discard | forward | replace>

配置对已携带中继代理信息（Relay Agent Information）选项的入站 DHCPv4 数据包所应用的策略：

  • append：在保留原有中继代理信息选项的同时，添加本地中继代理信息选项。

  • discard：丢弃携带中继代理信息选项的数据包。

  • forward：原样转发携带原有中继代理信息选项的数据包。

  • replace：移除原有中继代理信息选项，并插入本地中继代理信息选项。

默认值为 forward。

示例：

set service dhcp-relay relay-options relay-agents-packets discard

操作

restart dhcp relay-agent

重启 DHCPv4 中继服务。

示例

以下配置将从 eth1（面向客户端的接口）接收到的 DHCP 客户端请求，经由 eth2（面向服务器的接口）转发至位于 203.0.113.4 的 DHCP 服务器。对于已包含中继代理信息的数据包则予以丢弃，从而确保仅转发直接来自客户端的请求。

set interfaces ethernet eth1 address '192.0.2.1/24'
set interfaces ethernet eth2 address '198.51.100.1/24'
set service dhcp-relay listen-interface 'eth1'
set service dhcp-relay upstream-interface 'eth2'
set service dhcp-relay server '203.0.113.4'
set service dhcp-relay relay-options relay-agents-packets discard

使用已弃用的 interface 语法（仅为向后兼容而保留）的等效配置如下：

set interfaces ethernet eth1 address '192.0.2.1/24'
set interfaces ethernet eth2 address '198.51.100.1/24'
set service dhcp-relay interface 'eth1'
set service dhcp-relay interface 'eth2'
set service dhcp-relay server '203.0.113.4'
set service dhcp-relay relay-options relay-agents-packets discard

IPv6 中继

配置

set service dhcpv6-relay listen-interface <interface>

配置一个监听接口，DHCPv6 中继将在该接口上接收客户端组播请求。

该接口必须已分配全局单播 IPv6 地址。

重复执行该命令可配置多个监听接口。

注意

为确保提交成功，至少需配置一个 listen-interface 和一个 upstream-interface。

示例：

set service dhcpv6-relay listen-interface eth1
set service dhcpv6-relay listen-interface <interface> address <ipv6-address>

配置 DHCPv6 中继用于向 DHCPv6 服务器标识客户端所在网络的 IPv6 地址。

该地址必须是已分配给指定监听接口的非链路本地 IPv6 地址。

若未设置该地址，DHCPv6 中继将使用该监听接口上找到的第一个非链路本地 IPv6 地址。

示例：

set service dhcpv6-relay listen-interface eth1 address 2001:db8:1::1
set service dhcpv6-relay upstream-interface <interface> address <ipv6-address>

配置 DHCPv6 服务器（或另一个中继代理）的 IPv6 地址，DHCPv6 中继将通过指定的上游接口将客户端消息转发至该地址。

重复执行该命令可将客户端消息转发至多个服务器（或中继代理）。

注意

为确保提交成功，每个上游接口至少需配置一个服务器（或中继代理）地址。

示例：

set service dhcpv6-relay upstream-interface eth2 address 2001:db8:2::4
set service dhcpv6-relay disable

在不删除其配置的情况下，管理性禁用 DHCPv6 中继服务。

示例：

set service dhcpv6-relay disable

中继选项

set service dhcpv6-relay max-hop-count <1-255>

配置 DHCPv6 跳数阈值，当转发数据包的跳数达到该值时即被丢弃。

接收到客户端消息的 DHCPv6 中继将跳数设为 0；此后每经过一个 DHCPv6 中继，跳数加 1。当数据包跳数达到所设定的值时，该数据包将被静默丢弃。

默认值为 10。

示例：

set service dhcpv6-relay max-hop-count 4
set service dhcpv6-relay use-interface-id-option

启用在每个 Relay-forward 消息中插入接口 ID（Interface-ID）选项。

无论是否启用此设置，只要中继上配置了多个监听接口，系统将自动插入接口 ID 选项。

示例：

set service dhcpv6-relay use-interface-id-option

操作

restart dhcpv6 relay-agent

重启 DHCPv6 中继服务。

示例

以下配置将从 eth1（面向客户端的接口）接收到的 DHCPv6 客户端请求，经由 eth2（面向服务器的接口）转发至位于 2001:db8:2::4 的 DHCPv6 服务器。

set interfaces ethernet eth1 address '2001:db8:1::1/64'
set interfaces ethernet eth2 address '2001:db8:2::1/64'
set service dhcpv6-relay listen-interface 'eth1'
set service dhcpv6-relay upstream-interface 'eth2' address '2001:db8:2::4'
