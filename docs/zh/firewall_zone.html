基于区域的防火墙

概述

注意

所有在 2023-10-22 之后构建的 VyOS 版本（VyOS 1.4 和 1.5）均支持此功能。

本节提供有关基于区域的防火墙的防火墙配置信息。本节涵盖以下配置命令：

set firewall zone …

如需了解 VyOS 防火墙中通用流量流向的相关信息，请参阅 防火墙。

- set firewall
    * zone
         - custom_zone_name
            + ...

在基于区域的策略中，您将接口分配给区域，并对在区域之间流动的流量应用检查策略。防火墙根据规则对流量执行操作。区域是一组具有相似功能或特性的接口。它建立了网络的安全边界。区域定义了一个边界，在该边界处，系统会对穿越至网络另一区域的流量施加策略限制。

关键要点：

  • 必须先配置区域，然后才能将接口分配给该区域；且一个接口只能分配给一个区域。

  • 区域内接口之间的所有入站和出站流量均可自由流动。

  • 现有策略会影响所有区域之间的流量。

  • 流量无法在某个区域成员接口与任何非区域成员接口之间流动。

  • 您必须定义两个独立的防火墙来定义流量：每个方向各一个。

注意

在 T2199 中，区域配置语法已更改。 区域配置已从 zone-policy zone <name> 迁移至 firewall zone <name>。

配置

作为直接对接口应用策略的替代方案，您可以创建基于区域的防火墙，以便在多个接口属于同一安全区域时简化配置。您无需将规则集应用于接口，而是将其应用于源区域-目的区域对。

您可在 VyOS 知识库 中找到关于基于区域的防火墙的基本介绍， 并在 基于区域的策略示例 中查看示例。

创建基于区域的防火墙需要执行以下步骤：

  1. 定义源区域和目的区域

  2. 定义规则集

  3. 将规则集应用于区域

定义区域

要定义区域，可设置一个包含接口的区域，或将其设置为本地区域。

set firewall zone <name> interface <interface>

将接口指定为区域的成员。

注意

  • 一个接口只能属于一个区域。

  • 一个区域中可以包含多个接口。同一区域内的接口之间的流量遵循区域内过滤策略（默认允许）。

set firewall zone <name> local-zone

将该区域定义为本地区域，用于源自路由器本身或发往路由器本身的流量。

注意

  • 本地区域不能包含任何成员接口

  • 您不能配置多个本地区域

set firewall zone <name> default-action [drop | reject]

修改区域的默认操作，该操作适用于未匹配任何已应用的源区域规则集的目的地流量。

set firewall zone <name> default-log

启用记录匹配该区域默认操作的数据包（默认禁用）。

set firewall zone <name> description

添加有意义的描述。

定义规则集

基于区域的防火墙规则集定义了从 源区域 到 目的区域 的流量。

您可使用以下命令将规则集创建为自定义防火墙链（请参阅防火墙 IPv4/IPv6 章节以获取完整语法）：

  • 对于 IPv4： set firewall ipv4 name <name> ...

  • 对于 IPv6： set firewall ipv6 name <name> ...

为便于识别，建议按格式 <源区域>-<目的区域>-<v4 | v6> 命名规则集。

将规则集应用于区域

定义规则集后，将其应用于源区域和目的区域。配置语法以目的区域为锚点，每个源区域的规则集均列于目的区域之下。

set firewall zone <Destination Zone> from <Source Zone> firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> from <Source Zone> firewall ipv6-name <ipv6-rule-set-name>

您应为每个源区域-目的区域对创建两个规则集。

set firewall zone DMZ from LAN firewall name LAN-DMZ-v4
set firewall zone LAN from DMZ firewall name DMZ-LAN-v4

将默认规则集应用于区域

当某个目的区域对多个源区域共享一个通用规则集，或需要一组复杂的默认策略时，您可以应用一个可选的默认规则集。默认规则集适用于所有未按 IPv4 所述配置规则集的区域。

set firewall zone <Destination Zone> default-firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> default-firewall ipv6-name <ipv6-rule-set-name>

操作模式

show firewall zone-policy

显示区域配置的基本摘要。

vyos@vyos:~$ show firewall zone-policy
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LAN     eth1          WAN          WAN-LAN-v4
eth2
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
show firewall zone-policy zone <zone>

显示特定区域的基本摘要。

vyos@vyos:~$ show firewall zone-policy zone WAN
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
vyos@vyos:~$ show firewall zone-policy zone LOCAL
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
