PPPoE

PPPoE 是一种网络协议，用于将 PPP 帧封装在以太网帧内。 该协议常用于将 ISP 客户端连接至宽带接入服务器。

配置

通用接口配置

set interfaces pppoe <interface> description <description>

为接口配置清晰、具有描述性的别名。

该别名将在 show interfaces 命令及基于 SNMP 的监控工具中显示。

示例：

set interfaces pppoe pppoe0 description '这是一个运行于 VyOS 上的接口。'
set interfaces pppoe <interface> disable

禁用该接口。

该接口将被设置为管理性关闭（A/D）状态。

示例：

set interfaces pppoe pppoe0 disable
set interfaces pppoe <interface> mtu <mtu>

在接口上配置 MTU。

该值定义了接口在不进行分片的情况下所能传输的最大数据包大小（单位：字节）。

示例：

set interfaces pppoe pppoe0 mtu 1600
set interfaces pppoe <interface> vrf <vrf>

将接口分配给特定的 VRF 实例。

另请参阅

有关配置 VRF 的信息，请参阅 VRF 章节。

示例：

set interfaces pppoe pppoe0 vrf red

PPPoE 选项

set interfaces pppoe <interface> access-concentrator <name>

配置 PPPoE 会话的目标接入集中器名称。

在 PPPoE 发现阶段，客户端发送一个 PPPoE 初始化数据包。 多个接入集中器可能响应提供数据包，客户端从中选择一个。

此设置限制客户端仅能与指定的接入集中器建立会话。

set interfaces pppoe <interface> authentication username <username>

配置 PPPoE 会话认证的用户名。

尽管在接口配置中认证是可选的，但大多数 ISP 要求进行认证才能建立连接。

set interfaces pppoe <interface> authentication password <password>

配置 PPPoE 会话认证的密码。

尽管在接口配置中认证是可选的，但大多数 ISP 要求进行认证才能建立连接。

set interfaces pppoe <interface> connect-on-demand

在 PPPoE 接口上启用按需拨号功能。

启用后，系统仅在有流量通过该接口时才建立 PPPoE 连接；若连接失败，则在流量恢复时重新建立连接。

对于按需连接，您还必须配置 idle-timeout（空闲超时）时间，以便在无活动状态持续一段时间后断开会话。

注意

将空闲超时设置为零或不配置该参数，将使连接一旦建立即持续保持激活状态。

默认情况下，PPPoE 连接在启动时建立并持续保持激活状态；若连接失败，则立即重新建立。

set interfaces pppoe <interface> no-default-route

向 PPPoE 服务器请求 IP 地址，但不安装默认路由。

示例：

set interfaces pppoe pppoe0 no-default-route

注意

该命令自 VyOS 1.4 版本起引入，其逻辑与旧版 default-route CLI 选项相反。

set interfaces pppoe <interface> default-route-distance <distance>

配置 PPPoE 服务器提供的默认网关的距离值。

示例：

set interfaces pppoe pppoe0 default-route-distance 220
set interfaces pppoe <interface> mru <mru>

为 PPPoE 接口配置 MRU 值。

该设置指示 pppd 守护进程限制远程对端发送的数据包大小不得超过所配置的 MRU 值。允许的 MRU 取值范围为 128 至 16384 字节。

MRU 值为 296 适用于极慢速链路（TCP/IP 头部占用 40 字节，数据部分占用 256 字节）。

默认 MRU 值为 1492 字节。

注意

使用 IPv6 协议时，MRU 值至少须为 1280 字节。

set interfaces pppoe <interface> idle-timeout <time>

为按需 PPPoE 会话配置空闲超时时间。

该设置定义了在无任何流量的情况下，连接保持激活状态直至被断开的时间长度。

注意

将空闲超时设置为零或不配置该参数，将使连接一旦建立即持续保持激活状态。

set interfaces pppoe <interface> holdoff <time>

为持久性 PPPoE 会话配置重拨延迟时间。

如果持久性会话（已禁用 connect-on-demand）被远端对等体终止或意外中断，路由器将在指定的时间间隔后尝试重新连接。

默认重拨延迟为 30 秒。

set interfaces pppoe <interface> local-address <address>

为 PPPoE 会话配置本地端点 IP 地址。

默认情况下，该 IP 地址由协商确定。

set interfaces pppoe <interface> no-peer-dns

禁用在本地系统上安装通告的 DNS 名称服务器。

set interfaces pppoe <interface> remote-address <address>

为 PPPoE 会话配置远端端点 IP 地址。

默认情况下，该 IP 地址由协商确定。

set interfaces pppoe <interface> service-name <name>

配置 PPPoE 会话的目标接入集中器的服务名称。

默认情况下，PPPoE 接口将连接至任意可用的接入集中器。

set interfaces pppoe <interface> source-interface <source-interface>

为 PPPoE 连接配置底层接口。

每个 PPPoE 连接均建立在某个底层接口之上，该底层接口可以是以太网接口、VIF 或绑定接口。

set interfaces pppoe <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

在指定接口的出站 TCP SYN 数据包中配置所通告的 MSS 值。

通过钳制 TCP SYN 数据包中的 MSS 值，可指示远端对等体不要发送超过指定大小的数据包。这有助于防止路径 MTU 发现（PMTUD）失败时出现连接问题。

以下选项可用：

  • mss：将 MSS 设置为特定的字节数值。

  • clamp-mss-to-pmtu：将 MSS 设置为接口 MTU 减去 40 字节（IPv4 流量：20 字节 IPv4 头部 + 20 字节 TCP 头部）。推荐使用此选项以自动设置合适的值。

注意

该命令自 VyOS 1.4 版本起引入，取代了旧版语法 set firewall options interface <name> adjust-mss <value>。

set interfaces pppoe <interface> ip disable-forwarding

配置接口为主机行为或路由器行为。

若配置此选项，接口将切换为主机模式，并在此接口上禁用 IPv4 转发功能。

set interfaces pppoe <interface> ip source-validation <strict | loose | disable>

根据 RFC 3704 规范，在此接口上使用 RPF 配置源 IP 地址验证。

以下选项可用：

  • strict：检查每个入站数据包的源 IP 地址是否与 FIB 匹配。若该接口并非返回该源地址的最佳路径，则验证失败，数据包将被丢弃。

  • loose：检查每个入站数据包的源 IP 地址是否与 FIB 匹配。若该源 IP 地址无法通过任何接口到达，则验证失败。

  • disable：不执行源 IP 地址验证，所有入站数据包均被接受。

RFC 3704 建议启用 strict 模式以防止 IP 欺骗（例如 DDoS 攻击）。对于非对称路由或其他复杂路由场景，请使用 loose 模式。

IPv6

set interfaces pppoe <interface> ipv6 address autoconf

在此接口上启用通过 SLAAC 分配 IPv6 地址的功能。

set interfaces pppoe <interface> ipv6 adjust-mss <mss | clamp-mss-to-pmtu>

在指定接口的出站 TCP SYN 数据包中配置所通告的 MSS 值。

通过钳制 TCP SYN 数据包中的 MSS 值，可指示远端对等体不要发送超过指定大小的数据包。这有助于防止路径 MTU 发现（PMTUD）失败时出现连接问题。

以下选项可用：

  • mss：将 MSS 设置为特定的字节数值。

  • clamp-mss-to-pmtu：将 MSS 设置为接口 MTU 减去 60 字节（IPv6 流量：40 字节 IPv6 头部 + 20 字节 TCP 头部）。推荐使用此选项以自动设置合适的值。

注意

该命令自 VyOS 1.4 版本起引入，取代了旧版语法 set firewall options interface <name> adjust-mss <value>。

set interfaces pppoe <interface> ipv6 disable-forwarding

配置接口为主机行为或路由器行为。

若配置此选项，接口将切换为主机模式，并在此接口上禁用 IPv6 转发功能。

DHCPv6 前缀委派（PD）

VyOS 支持 RFC 3633 中所述的 DHCPv6 前缀委派（DHCPv6-PD）。大多数为固定网络用户提供原生 IPv6 的 ISP 均支持 DHCPv6-PD。

set interfaces pppoe <interface> dhcpv6-options pd <id> length <length>

为此接口上的 DHCPv6-PD 请求配置特定的前缀长度。

某些 ISP 默认仅提供 /64 前缀。使用此命令可为特定 DHCPv6-PD 请求申请不同的前缀长度，范围从 /32（若您的 ISP 允许）至 /64。<id> 是 DHCPv6-PD 请求的唯一标识符。

默认值为 64。

如需向您的 ISP 申请 /56 前缀，请使用以下命令：

set interfaces pppoe pppoe0 dhcpv6-options pd 0 length 56
set interfaces pppoe <interface> dhcpv6-options pd <id> interface <delegatee> address <address>

为委派接口配置 IPv6 接口标识符（主机部分）。

该值必须为十进制整数。它将附加到委派的前缀和已配置的 SLA ID 后，以构成最终的 IPv6 地址。

默认情况下，主机部分依据父接口的 MAC 地址生成（EUI-64 格式）。

示例：

若 /64 前缀委派至接口 eth8，且您将主机部分配置为 65535，则生成的 IPv6 地址将以 ::ffff 结尾，因为 65535 对应十六进制表示法中的 ffff。

set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth8 address 65534
set interfaces pppoe <interface> dhcpv6-options pd <id> interface <delegatee> sla-id <id>

为委派接口配置 SLA ID 。

该值必须为大于 0 的十进制整数，且符合 SLA ID 的长度要求。该值将转换为十六进制，并附加到委派的前缀后，以构成委派接口的特定子网前缀。

示例：

若 SLA ID 为 1，且委派的前缀为 2001:db8:ffff::/48，则委派接口的子网前缀为 2001:db8:ffff:1::/64。

set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth8 sla-id 1

示例

DSL 上的 PPPoE

配置场景：

  • 您的 ISP DSL 调制解调器连接至 VyOS 路由器的 eth0 接口。

  • 您的 ISP 不要求 VLAN 标记。

  • PPPoE 凭据由您的 ISP 提供。典型用户名格式为 name@host.net，但具体格式可能有所不同。

配置说明：

  • 由于 PPPoE 开销，DSL 的最大 MTU 为 1492。若您正从基于 DHCP 的 ISP（例如标准电缆连接）迁移，需确保 VPN 链路的 MTU 大小相应调整。

  • 若要忽略 ISP 提供的域名服务器并仅使用您静态配置的域名服务器，请将 name-server 选项设置为 none。

  • 接口启用后，默认路由将自动安装。若要更改此行为，请使用 no-default-route CLI 选项。

注意

PPPoE 配置语法在 VyOS 1.2（Crux）版本之后发生变更，并在升级过程中自动迁移。

set interfaces pppoe pppoe0 authentication username 'userid'
set interfaces pppoe pppoe0 authentication password 'secret'
set interfaces pppoe pppoe0 source-interface 'eth0'

通过在防火墙链中创建匹配 pppoe0 接口的规则来保障您的配置安全：

set firewall ipv4 input filter rule 10 inbound-interface name 'pppoe0'
set firewall ipv4 forward filter rule 10 inbound-interface name 'pppoe0'

VLAN 上的 PPPoE

某些 ISP 要求 PPPoE 连接必须建立在 VLAN 接口之上。VyOS 完全支持此类特定拓扑结构。

以下配置通过 VLAN 7 建立 PPPoE 连接，VLAN 7 是德国电信（Deutsche Telekom）的默认 VLAN：

set interfaces pppoe pppoe0 authentication username 'userid'
set interfaces pppoe pppoe0 authentication password 'secret'
set interfaces pppoe pppoe0 source-interface 'eth0.7'

IPv6 DHCPv6 前缀委派

配置场景：

以下配置在 eth1 接口上建立 PPPoE 会话，向 ISP 申请 /56 IPv6 前缀委派，并将该委派中的一部分 /64 子网分配给 eth0 接口。

配置说明：

  • 分配给 eth0 的 IPv6 地址为 <prefix>::1/64。

  • 若您不清楚委派的前缀大小，请从 sla-len 0 开始尝试。

  • 若要在 eth0 链路上通告该前缀，请配置 IPv6 路由器通告（Router Advertisement）。

set interfaces pppoe pppoe0 authentication username vyos
set interfaces pppoe pppoe0 authentication password vyos
set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth0 address '1'
set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth0 sla-id '0'
set interfaces pppoe pppoe0 dhcpv6-options pd 0 length '56'
set interfaces pppoe pppoe0 ipv6 address autoconf
set interfaces pppoe pppoe0 source-interface eth1

set service router-advert interface eth0 prefix ::/64
