IPsec 常规信息

IPsec 概述

IPsec 是用于保护数据的框架。IPsec 通过提供身份验证、IP 网络数据包加密、密钥交换和密钥管理来实现这些目标。VyOS 使用 Strongswan 软件包来实现 IPsec。

认证头 (AH) 定义于 RFC 4302。它使用 IP 头和数据负载创建哈希，并将其附加到数据包前面。此哈希用于验证数据在网络传输过程中未被更改。

封装安全载荷 (ESP) 定义于 RFC 4303。它提供数据的加密和身份验证。

有两种 IPsec 模式：

IPsec 传输模式：在传输模式下，IPSec 头（AH 或 ESP）插入在 IP 头和上层协议头之间。

IPsec 隧道模式：在隧道模式下，原始 IP 数据包被封装在另一个 IP 数据报中，IPsec 头（AH 或 ESP）插入在外层和内层头之间。

IKE（互联网密钥交换）

IKE 协议是 IPsec 安全密钥协商的默认方法。IKE 旨在提供系统的相互身份验证，以及建立共享密钥以创建 IPsec 安全关联 (SA)。安全关联 (SA) 包括连接的所有相关属性，包括使用的加密算法、IPsec 模式、加密密钥以及与通过 VPN 连接传输数据相关的其他参数。

IKEv1

IKEv1 是较旧的版本，至今仍在使用。如今，大多数制造商建议使用 IKEv2 协议。

IKEv1 在以下 RFC 中描述：RFC 2409（IKE）、RFC 3407（IPsec DOI）、RFC 3947（NAT-T）、RFC 3948（ESP 数据包的 UDP 封装）、RFC 3706（DPD）

IKEv1 分两个阶段运行以建立 IKE 和 IPsec SA：

  • 阶段 1 提供 IKE 对等体的相互身份验证和会话密钥的建立。此阶段使用 DH 交换、cookies 和 ID 交换创建 IKE SA。一旦建立 IKE SA，发起者和响应者之间的所有 IKE 通信都受到加密和身份验证完整性检查的保护。IKE 阶段 1 提供两种模式：主模式和激进模式。
    • 主模式 用于站点到站点 VPN 连接。
    • 激进模式 用于远程访问 VPN 连接。
  • 阶段 2 提供使用 ESP 或 AH 保护 IP 数据流量的 IPsec SA 的协商和建立。

IKEv2

IKEv2 在 RFC 7296 中描述。IKEv1 和 IKEv2 之间最大的区别是 IKEv2 比 IKEv1 更简单、更可靠，因为在 VPN 建立期间交换的消息更少，并且具有额外的安全功能。

IKE 身份验证

VyOS 支持 3 种身份验证方法：

  • 预共享密钥：在此方法中，IPsec 隧道的两个对等体必须具有相同的预共享密钥。
  • 数字证书：在此方法中使用 PKI。
  • RSA 密钥：如果在 IKE 策略中使用 RSA 密钥方法，需要确保每个对等体拥有另一个对等体的公钥。

DPD（死对等体检测）

这是一种用于检测 VPN 对等体是否不再活跃的机制。此机制在 VyOS 中的 IKEv1 和 IKEv2 中有不同的算法。DPD 请求作为 ISAKMP R-U-THERE 消息发送，DPD 响应作为 ISAKMP R-U-THERE-ACK 消息发送。在 IKEv1 中，DPD 每隔配置的间隔发送消息。如果在 DPD 超时内未收到对这些数据包的响应，则认为远程对等体不可达。在 IKEv2 中，DPD 每隔配置的间隔发送消息。如果一个请求未得到响应，Strongswan 将执行其重传算法及其定时器。

后量子预共享密钥 (PPK)

后量子预共享密钥有助于在 ML-KEM 等后量子密钥交换算法不可用时为 IPSec 隧道提供一些量子抗性。IKEv2 中 PPK 的使用在 RFC 8784 中描述。

PPK 可以在 VyOS 的 vpn ipsec authentication ppk 配置下进行配置。PPK 需要一个 ID 和一个秘密值。如果 PPK 是成功 IPsec 连接所必需的，则 ID 和秘密必须匹配。秘密可以是纯文本、十六进制值或 Base64 值。默认为纯文本。如果使用其他类型的值，则必须定义秘密类型。

IKE 配置

IKE 属性

VyOS IKE 组有以下选项：

set vpn ipsec ike-group <name> close-action <action>

定义远程对等体意外关闭 CHILD_SA 时要采取的操作：

  • none - 设置为无（默认）
  • trap - 为 CHILD_SA 安装陷阱策略，匹配这些策略的流量将触发获取事件，使守护进程建立所需的 IKE/IPsec SA。
  • start - 尝试立即重新创建 CHILD_SA。

set vpn ipsec ike-group <name> ikev2-reauth

IKE_SA 的重新密钥是否也应重新身份验证对等体。在 IKEv1 中，始终进行重新身份验证。设置此参数可在 IKE 重新密钥期间启用远程主机重新身份验证。

set vpn ipsec ike-group <name> key-exchange

应使用哪个协议来初始化连接。如果未设置，则处理两种协议，连接在发起时使用 IKEv2，但在响应时接受任何协议版本：

  • ikev1 - 使用 IKEv1 进行密钥交换。
  • ikev2 - 使用 IKEv2 进行密钥交换。

set vpn ipsec ike-group <name> lifetime

IKE 生命周期（秒）<0-86400>（默认 28800）。

set vpn ipsec ike-group <name> mode

IKEv1 阶段 1 模式选择：

  • main - 在 IKEv1 协议中使用主模式进行密钥交换（推荐的默认值）。
  • aggressive - 在 IKEv1 协议中使用激进模式进行密钥交换，激进模式比主模式更不安全。

set vpn ipsec ike-group <name> proposal <number> dh-group <dh-group number>

DH 组。默认值为 2。

set vpn ipsec ike-group <name> proposal <number> encryption <encryption>

加密算法。默认值为 aes128。

set vpn ipsec ike-group <name> proposal <number> hash <hash>

哈希算法。默认值为 sha1。

set vpn ipsec ike-group <name> proposal <number> prf <prf>

伪随机函数。

DPD 配置

set vpn ipsec ike-group <name> dead-peer-detection action <action>

DPD 超时时对此 CHILD_SA 执行的操作：

  • trap - 安装陷阱策略，将捕获匹配的流量并尝试按需重新协商隧道。
  • clear - 关闭 CHILD_SA 且不采取进一步操作（默认）。
  • restart - 立即尝试在新的 IKE_SA 下重新协商 CHILD_SA。

set vpn ipsec ike-group <name> dead-peer-detection interval <interval>

保活间隔（秒）<2-86400>（默认 30）。

set vpn ipsec ike-group <name> dead-peer-detection timeout <timeout>

保活超时（秒）<2-86400>（默认 120）仅 IKEv1

ESP 属性

在 VyOS 中，ESP 属性通过 ESP 组指定。可以在单个组中指定多个提案。

set vpn ipsec esp-group <name> compression

启用 IPComp（IP 载荷压缩）协议，允许压缩 IP 数据包的内容。

set vpn ipsec esp-group <name> disable-rekey

不在本地发起 SA 的重新密钥，远程对等体必须在到期前重新密钥。

set vpn ipsec esp-group <name> life-bytes <bytes>

ESP 生命周期（字节）<1024-26843545600000>。IPsec SA 过期前传输的字节数。

set vpn ipsec esp-group <name> life-packets <packets>

ESP 生命周期（数据包）<1000-26843545600000>。IPsec SA 过期前传输的数据包数。

set vpn ipsec esp-group <name> lifetime <timeout>

ESP 生命周期（秒）<30-86400>（默认 3600）。连接的特定实例（用户数据包的加密/身份验证密钥集）应持续多长时间，从成功协商到到期。

set vpn ipsec esp-group <name> mode <mode>

连接类型：

  • tunnel - 隧道模式（默认）。
  • transport - 传输模式。

set vpn ipsec esp-group <name> pfs <dh-group>

是否需要在连接的密钥通道上实现完美前向保密，并定义 PFS 的 Diffie-Hellman 组：

  • enable - 从 IKE 组继承 Diffie-Hellman 组（默认）。
  • disable - 禁用 PFS。
  • <dh-group> - 定义 PFS 的 Diffie-Hellman 组。

set vpn ipsec esp-group <name> proposal <number> encryption <encryption>

加密算法。默认值为 aes128。

set vpn ipsec esp-group <name> proposal <number> hash <hash>

哈希算法。默认值为 sha1。

全局 IPsec 设置

set vpn ipsec interface <name>

用于限制出站 IPsec 策略的接口名称。可以指定多个接口。如果未指定接口，IPsec 策略适用于所有接口。

set vpn ipsec log level <number>

日志级别。默认值为 0。

set vpn ipsec log subsystem <name>

守护进程的子系统。

选项

set vpn ipsec options disable-route-autoinstall

不自动安装到远程网络的路由。

set vpn ipsec options flexvpn

允许 FlexVPN 供应商 ID 载荷（仅 IKEv2）。发送 Cisco FlexVPN 供应商 ID 载荷（仅 IKEv2），这是使 Cisco 品牌设备允许协商本地流量选择器所必需的。

set vpn ipsec options interface <name>

要使用的接口名称。应在其上安装虚拟 IP 地址的接口名称。如果未指定，地址将安装在出站接口上。

set vpn ipsec options virtual-ip

允许安装虚拟 IP 地址。

IKEv2 重传

如果对等体未响应 DPD 数据包，路由器将启动重传程序。使用以下公式计算超时：

relative timeout = timeout * base ^ (attempts-1)

set vpn ipsec options retransmission attempts

在认为对等体处于关闭状态之前的尝试次数。默认值为 5。

set vpn ipsec options retransmission base

指数退避的基数。默认值为 1.8。

set vpn ipsec options retransmission timeout

第一次重传之前的超时时间（秒）。默认值为 4。
