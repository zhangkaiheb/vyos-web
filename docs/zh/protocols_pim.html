PIM

PIM 利用现有的单播路由表进行路径决策，在路由器之间转发组播流量。VyOS 支持 PIM 稀疏模式（PIM-SM）以及 IGMP 第 2 版和第 3 版。

在 PIM-SM 中，来自组播源的流量被转发至RP。组播接收器使用 IGMP 向其本地路由器通告希望接收的组，然后该路由器使用 PIM 通过共享树从 RP 拉取该流量。

一个正常运行的 PIM-SM 部署需要满足以下条件：

  • 在组播路径上的每个接口上启用 PIM。

  • 在 PIM 域内的每台路由器上以完全相同的方式声明 RP 的位置。

  • 在面向组播接收器的接口上启用 IGMP。

配置

PIM-SM

set protocols pim ecmp

为组播流量启用ECMP 路由。

当特定的RPF 查找返回多个等代价下一跳时，启用此功能可将 (S,G) 组播流分布在所有这些下一跳上。

如果未启用 ECMP，PIM 默认仅使用 RPF 查找返回的第一个下一跳。

示例：

set protocols pim ecmp
set protocols pim ecmp rebalance

当 ECMP 下一跳接口发生故障时，自动重新均衡所有 PIM (S,G) 组播流。

当启用 ECMP 后，若 PIM 使用的某个接口发生故障，此功能将强制 PIM 将所有现有 (S,G) 流重新分布到其余等代价接口上。

如果未配置重新均衡，PIM 仅会重新路由那些原本正在使用故障接口的特定流。

示例：

set protocols pim ecmp rebalance
set protocols pim join-prune-interval <1-65535>

配置 PIM 向上游邻居发送 Join/Prune 消息的时间间隔（单位：秒）。

默认间隔为 60 秒。将值设置为低于 60 秒可能对大规模部署的收敛性产生负面影响。

示例：

set protocols pim join-prune-interval 120
set protocols pim keep-alive-timer <1-65535>

配置 (S,G) 组播流状态的保活超时间隔（单位：秒）。

注意

某些硬件无法检测间隔短于 30 秒的流量。对于此类硬件，请确保将该值设置为 31 秒或更高。

示例：

set protocols pim keep-alive-timer 60
set protocols pim packets <1-255>

配置系统在切换至下一任务前，连续处理来自邻居的入站 PIM 数据包的数量。

默认值为 3 个数据包。该命令仅在 PIM 控制数据包数量较多的部署中才有用。

示例：

set protocols pim packets 10
set protocols pim register-accept-list prefix-list <prefix-list>

配置前缀列表以过滤入站 PIM Register 消息。

当 PIM 接收到 Register 数据包时，组播源 IP 地址将与指定的前缀列表进行匹配。若源 IP 地址被允许，则继续执行正常的 PIM 处理；若源 IP 地址被拒绝，则向发送方发送 Register-Stop 消息。

示例：

set protocols pim register-accept-list prefix-list MULTICAST-SOURCES
set protocols pim register-suppress-time <1-65535>

配置第一跳路由器（FHR）抑制发送 PIM Register 消息的持续时间（单位：秒）。

示例：

set protocols pim register-suppress-time 60
set protocols pim rp address <ip-address> group <prefix>

为指定的组播组范围配置汇聚点（RP）。

要使用 PIM，必须配置一个 RP 来接收 Join 消息。VyOS 当前仅支持静态 RP 配置。

<address> 参数定义 RP 的 IP 地址，而 <group> 参数定义该 RP 所服务的组播组范围的前缀。

单个 RP 可以服务多个组范围。重复执行该命令并指定不同的 <group> 前缀，即可将多个范围映射到同一 RP。

示例：

set protocols pim rp address 192.0.2.1 group 239.0.0.0/8
set protocols pim rp keep-alive-timer <1-65535>

配置汇聚点（RP）上 (S,G) 组播流状态的保活超时间隔（单位：秒）。

该值必须至少等于 register-suppression-time；否则，RP 可能在 FHR 发送下一个 Null-Register 消息之前就已超时释放 (S,G) 状态。

当发送 Register-Stop 时，RP 上的 KAT(S,G) 被设置为全局 Keepalive_Period 和 RP_Keepalive_Period 中的最大值。

默认值为 210 秒。

详情请参见RFC 7761 第 4.1 节。

注意

由于某些硬件平台无法检测间隔短于 30 秒的数据流，请确保该值设置为 31 秒或更高。

示例：

set protocols pim rp keep-alive-timer 300
set protocols pim no-v6-secondary

禁用在 PIM Hello 消息中发送 IPv6 次要地址。

默认情况下，PIM Hello 消息包含接口上配置的所有 IPv6 次要地址，以便 PIM 邻居可在 RPF 查找中将其用作 IPv6 下一跳。

示例：

set protocols pim no-v6-secondary
set protocols pim spt-switchover infinity-and-beyond prefix-list <list>

在LHR 上，禁止从共享 (*,G) 树切换至源特定 (S,G) SPT。

可选的 prefix-list 控制受影响的组：由 permit 条目匹配的组保留在共享树上，由 deny 条目匹配的组则按常规方式切换。若未指定前缀列表，则该抑制适用于所有组。

示例：

set protocols pim spt-switchover infinity-and-beyond
set protocols pim spt-switchover infinity-and-beyond prefix-list SHARED-TREE-GROUPS
set protocols pim ssm prefix-list <list>

配置一个前缀列表，其中包含以SSM 模式运行的组播组 IP 地址范围。

示例：

set protocols pim ssm prefix-list SSM-RANGE

接口特定命令

set protocols pim interface <interface> bfd

为在指定接口上发现的每个 PIM 邻居启用BFD。

当 BFD 检测到链路故障时，PIM 邻居关系将被拆除，并移除所有关联的组播 (S,G) 条目。

示例：

set protocols pim interface eth0 bfd
set protocols pim interface <interface> bfd profile <name>

将指定的 BFD 配置文件应用于此 PIM 接口上的 BFD 会话。

示例：

set protocols pim interface eth0 bfd profile fast-failover
set protocols pim interface <interface> dr-priority <1-4294967295>

为指定接口配置DR 优先级。

具有最高接口优先级的路由器将被选举为局域网（LAN）网段的 DR。

示例：

set protocols pim interface eth0 dr-priority 100
set protocols pim interface <interface> hello <1-180>

为指定接口配置 PIM Hello 时间间隔（单位：秒）。

PIM Hello 消息周期性地在接口上发送，用于发现并维护 PIM 邻居关系。保持时间（即在未收到 Hello 消息的情况下判定邻居失效的持续时间）根据 Hello 时间间隔计算得出。

示例：

set protocols pim interface eth0 hello 10
set protocols pim interface <interface> no-bsm

禁用在指定接口上处理 PIM BSM。

示例：

set protocols pim interface eth0 no-bsm
set protocols pim interface <interface> no-unicast-bsm

禁用在此接口上处理单播 PIM BSM。

示例：

set protocols pim interface eth0 no-unicast-bsm
set protocols pim interface <interface> passive

禁用在此接口上发送和接收 PIM 控制数据包。

示例：

set protocols pim interface eth0 passive
set protocols pim interface <interface> source-address <ip-address>

配置 PIM 在指定接口上发送控制消息时所使用的源 IP 地址。

当单个接口上配置了多个 IP 地址时，此命令非常有用。

示例：

set protocols pim interface eth0 source-address 192.0.2.10

IGMP

set protocols pim igmp watermark-warning <1-65535>

基于已加入的 IGMP 组数量配置水位线警告生成机制。

当已加入的 IGMP 组总数达到此指定限制时，路由器将生成一条警告。

示例：

set protocols pim igmp watermark-warning 500

接口特定命令

set protocols pim interface <interface> igmp

在指定接口上启用 IGMP。

示例：

set protocols pim interface eth0 igmp
set protocols pim interface <interface> igmp disable

在不删除现有 IGMP 配置的情况下，管理性地禁用指定接口上的 IGMP。

示例：

set protocols pim interface eth0 igmp disable
set protocols pim interface <interface> igmp join <multicast-address> source-address <IP-address>

配置接口加入特定的 (S,G) 信道。

需同时指定组播 IP 地址（G）和源 IP 地址（S）。每条命令加入一个 (S,G) 信道。若要加入多个共享同一组的信道，请使用不同的 source-address 值重复执行该命令。

示例：

set protocols pim interface eth0 igmp join 232.1.1.100 source-address 192.0.2.50
set protocols pim interface eth0 igmp join 232.1.1.100 source-address 192.0.2.51
set protocols pim interface <interface> igmp query-interval <1-1800>

在指定接口上配置 IGMP 主机查询间隔（单位：秒）。

此设置决定了路由器发送 IGMP 查询的时间间隔，以发现连接网络上哪些组播组存在活跃监听器。

示例：

set protocols pim interface eth1 igmp query-interval 125
set protocols pim interface <interface> igmp query-max-response-time <10-250>

在指定接口上配置 IGMP 最大查询响应时间（单位：十分之一秒）。

该值插入到 IGMP 查询中，指定了主机响应成员报告的最大时限。若在指定窗口内未收到报告，PIM 将假定不再有任何活跃的本地接收器，并可能使关联的 (*,G) 或 (S,G) 状态超时（参见RFC 7761 第 4.1 节）。

示例：

set protocols pim interface eth0 igmp query-max-response-time 50
set protocols pim interface <interface> igmp version <2-3>

在指定接口上配置 IGMP 版本。

默认版本为 3。

示例：

set protocols pim interface eth0 igmp version 2

示例

以下示例演示了一个跨越三台路由器的基本 PIM 稀疏模式（PIM-SM）组播部署，展示了如何在组播域内配置每台路由器的角色。这三台路由器共同构成了一条完整的组播分发路径，从源端到接收端，其中一台路由器充当汇聚点（RP）。

拓扑结构与角色

  • 路由器 1 是LHR。

  • 路由器 3 是RP。

  • 路由器 2 是FHR。

路由器 1：

set interfaces ethernet eth2 address '198.51.100.1/30'
set interfaces ethernet eth1 address '192.0.2.1/24'
set protocols ospf area 0 network '198.51.100.0/30'
set protocols ospf area 0 network '192.0.2.0/24'
set protocols pim interface eth1
set protocols pim interface eth1 igmp
set protocols pim interface eth2
set protocols pim rp address 203.0.113.1 group '224.0.0.0/4'

路由器 3：

set interfaces dummy dum0 address '203.0.113.1/32'
set interfaces ethernet eth0 address '198.51.100.2/30'
set interfaces ethernet eth1 address '198.51.100.5/30'
set protocols ospf area 0 network '198.51.100.0/30'
set protocols ospf area 0 network '203.0.113.1/32'
set protocols ospf area 0 network '198.51.100.4/30'
set protocols pim interface dum0
set protocols pim interface eth0
set protocols pim interface eth1
set protocols pim rp address 203.0.113.1 group '224.0.0.0/4'

路由器 2：

set interfaces ethernet eth1 address '203.0.113.129/25'
set interfaces ethernet eth2 address '198.51.100.6/30'
set protocols ospf area 0 network '203.0.113.128/25'
set protocols ospf area 0 network '198.51.100.4/30'
set protocols pim interface eth1
set protocols pim interface eth2
set protocols pim rp address 203.0.113.1 group '224.0.0.0/4'
