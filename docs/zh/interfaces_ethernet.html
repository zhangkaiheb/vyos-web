以太网

以太网接口（例如，eth0、eth1）表示主机的物理或虚拟网络端口。

它们是最常见的接口类型，作为承载流量穿越局域网（LAN）和广域网（WAN）的基础层，用于配置IP地址、VLAN和隧道等。

配置

通用接口配置

set interfaces ethernet <interface> address <address | dhcp | dhcpv6>

为接口配置一个或多个IP地址。

以下选项可用：

  • address：为接口分配一个或多个IPv4或IPv6地址。例如，对IPv4使用192.0.2.1/24，对IPv6使用2001:db8::1/64。

  • dhcp：接口从同一网络段上的DHCP服务器获取IPv4地址。

  • dhcpv6：接口从同一网络段上的DHCPv6服务器获取IPv6地址。

注意

如果接口通过DHCP获取IPv4地址，并且在获取IP地址前后需要进行特定调整，请使用提供的钩子脚本：

  • /config/scripts/dhcp-client/pre-hooks.d/

  • /config/scripts/dhcp-client/post-hooks.d/

示例：

set interfaces ethernet eth0 address 192.0.2.1/24
set interfaces ethernet eth0 address 2001:db8::1/64
set interfaces ethernet eth0 address dhcp
set interfaces ethernet eth0 address dhcpv6
set interfaces ethernet <interface> description <description>

为接口配置清晰、描述性的别名。

该别名将显示在show interfaces命令及基于SNMP的监控工具中。

示例：

set interfaces ethernet eth0 description '这是一个运行在VyOS上的接口。'
set interfaces ethernet <interface> disable

禁用该接口。

该接口将被设置为管理性关闭（A/D）状态。

示例：

set interfaces ethernet eth0 disable
set interfaces ethernet <interface> disable-flow-control

在接口上禁用以太网流控（IEEE 802.3x暂停帧）。

由IEEE 802.3x标准定义的以太网流控机制，可在网络拥塞时临时停止数据传输，防止丢包。例如，当发送方传输数据的速度超过接收方处理能力时。

禁用以太网流控意味着接口不会向连接设备发出暂停传输信号，而是在过载时直接丢弃数据包。

示例：

set interfaces ethernet eth0 disable-flow-control
set interfaces ethernet <interface> disable-link-detect

禁用接口上的物理链路状态变化检测（例如，拔掉网线时）。

默认情况下，接口会检测物理链路状态变化。

示例：

set interfaces ethernet eth0 disable-link-detect
set interfaces ethernet <interface> mac <xx:xx:xx:xx:xx:xx>

在接口上配置自定义MAC地址。

示例：

set interfaces ethernet eth0 mac '00:53:01:02:03:04'
set interfaces ethernet <interface> mtu <mtu>

在接口上配置MTU值。

该值定义了接口在不进行分片的情况下可传输的最大数据包大小（字节）。

示例：

set interfaces ethernet eth0 mtu 1600
set interfaces ethernet <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

配置在指定接口上向外发送的TCP SYN数据包中通告的 MSS 值。

通过限制TCP SYN数据包中的MSS值，可明确告知远端不要发送大于该尺寸的数据包，从而避免路径MTU发现（PMTUD）失败导致的连接问题。

以下选项可用：

  • mss：将MSS设置为特定字节数值。若需强制执行特定MSS（例如，排查连通性问题或满足特定网络需求），请使用此选项。

  • clamp-mss-to-pmtu：路由器自动计算MSS值，使其等于接口MTU减去40字节（IPv4头部20字节 + TCP头部20字节）。推荐使用此选项自动设置合适值。

set interfaces ethernet <interface> ip arp-cache-timeout

配置ARP条目在学习到IP到MAC地址映射后保持有效的时间长度。

默认持续时间为30秒。

若ARP条目收到上层协议的正向反馈，则其保持有效。

示例：

set interfaces ethernet eth0 ip arp-cache-timeout 180
set interfaces ethernet <interface> ip disable-arp-filter

在此接口上配置ARP过滤功能。

默认行为：内核仅在流量将通过该特定接口路由回ARP请求发送方时，才响应此接口上的ARP请求。

若启用该配置：内核将响应此接口上针对本地主机所配置的任意IP地址的ARP请求，无论该IP地址分配给哪个具体接口，也无论路由表如何。这体现了Linux中“IP地址属于主机而非单个接口”的概念。

示例：

set interfaces ethernet eth0 ip disable-arp-filter
set interfaces ethernet <interface> ip disable-forwarding

配置接口为主机或路由器行为。

若启用该配置，接口将切换至主机模式，且禁用其IPv4转发功能。

示例：

set interfaces ethernet eth0 ip disable-forwarding
set interfaces ethernet <interface> ip enable-directed-broadcast

配置是否转发在此接口上接收到的IP定向广播数据包。

默认行为：IP定向广播数据包将被丢弃。

若启用该配置：IP定向广播数据包将被转发至目标子网内的所有主机，如RFC 1812和RFC 2644所定义。

示例：

set interfaces ethernet eth0 ip enable-directed-broadcast
set interfaces ethernet <interface> ip enable-arp-accept

配置如何处理在此接口上的免费ARP（gratuitous ARP）。

若启用该配置，将根据免费ARP请求或应答，在ARP表中添加IP到MAC地址映射。

注意

若ARP表已包含来自免费ARP的IP地址，其条目将被更新，无论是否启用此设置。

示例：

set interfaces ethernet eth0 ip enable-arp-accept
set interfaces ethernet <interface> ip enable-arp-announce

在此接口的ARP请求中配置源IP地址的选择方式。

默认行为：内核可使用主机拥有的任意IP地址作为此接口上ARP请求的源IP地址。

若启用该配置：内核首先尝试选择与目标IP地址处于同一子网的、配置在该接口上的源IP地址；若不存在此类子网，则内核选择其通常使用的IP地址（即基于路由表到达目标目的地所选的IP地址）。

示例：

set interfaces ethernet eth0 ip enable-arp-announce
set interfaces ethernet <interface> ip enable-arp-ignore

配置在此接口上忽略哪些ARP请求。

默认行为：内核响应针对任何本地IP地址的ARP请求，无论这些IP地址分配给哪个接口。

若启用该配置：内核仅在目标IP地址分配给该特定接口时，才响应ARP请求。

示例：

set interfaces ethernet eth0 ip enable-arp-ignore
set interfaces ethernet <interface> ip enable-proxy-arp

在此接口上配置代理ARP功能。

若启用该配置，路由器（内核）将截获针对非本地IP地址的ARP请求，并以接收请求的接口的MAC地址进行应答。随后发往这些IP地址的数据包将被转发至远程子网中的实际目的地。

示例：

set interfaces ethernet eth0 ip enable-proxy-arp
set interfaces ethernet <interface> ip proxy-arp-pvlan

在接口上配置本地代理ARP功能。

若启用该配置，路由器（内核）将响应此VLAN接口上的ARP请求，即使目标IP地址位于同一子网和接口上。

这用于支持私有VLAN（PVLAN）的网络隔离要求（RFC 3069）。在PVLAN配置中，隔离端口上的主机不允许在二层直接相互通信，但可以与上游路由器通信。

通过以自身MAC地址应答主机间ARP请求，路由器（内核）将主机间流量引导至自身，而非主机之间直接通信。

注意

此命令独立工作，无需在接口上启用标准代理ARP功能。

本地代理ARP也称为：

  • VLAN聚合（RFC 3069）。

  • 私有VLAN（Cisco、Allied Telesyn）。

  • 源端口过滤或端口隔离（Hewlett-Packard）。

  • MAC强制转发（Ericsson）。

set interfaces ethernet <interface> ip source-validation <strict | loose | disable>

按照 RFC 3704 规范，在此接口上使用 RPF 配置源IP地址验证。

以下选项可用：

  • strict：检查每个入站数据包的源IP地址是否与转发表（FIB）匹配。若该接口并非返回该源的最佳路径，则验证失败，数据包被丢弃。

  • loose：检查每个入站数据包的源IP地址是否与转发表（FIB）匹配。若该源IP地址无法通过任何接口到达，则验证失败。

  • disable：不执行源IP地址验证，接受所有入站数据包。

RFC 3704建议启用严格模式以防止IP欺骗（如DDoS攻击）。对于非对称或其他复杂路由场景，请使用宽松模式。

set interfaces ethernet <interface> ipv6 address autoconf

配置接口使用 SLAAC 自动获取IPv6地址，如 RFC 4862 所规定。

IPv6主机在接入IPv6网络时，可通过ICMPv6邻居发现协议的路由器发现消息自动配置自身。首次接入网络时，主机会发送链路本地路由器请求多播请求以获取其配置参数。路由器则以包含网络层配置参数的路由器通告数据包进行响应。

注意

此方法将自动禁用该接口上的IPv6流量转发功能。

示例：

set interfaces ethernet eth0 ipv6 address autoconf
set interfaces ethernet <interface> ipv6 address eui64 <prefix>

配置接口使用 EUI-64 方法为其自身分配IPv6地址，如 RFC 4291 所规定。

示例：

set interfaces ethernet eth0 ipv6 address eui64 2001:db8:beef::/64
set interfaces ethernet <interface> ipv6 address no-default-link-local

禁用为此接口自动分配链路本地IPv6地址的功能。

示例：

set interfaces ethernet eth0 ipv6 address no-default-link-local
set interfaces ethernet <interface> ipv6 disable-forwarding

配置接口为主机或路由器行为。

若启用该配置，接口将切换至主机模式，且禁用其IPv6转发功能。

示例：

set interfaces ethernet eth0 ipv6 disable-forwarding
set interfaces ethernet <interface> ipv6 adjust-mss <mss | clamp-mss-to-pmtu>

配置在指定接口上向外发送的TCP SYN数据包中通告的 MSS 值。

通过限制TCP SYN数据包中的MSS值，可明确告知远端不要发送大于该尺寸的数据包，从而避免路径MTU发现（PMTUD）失败导致的连接问题。

以下选项可用：

  • mss：将MSS设置为特定字节数值。若需强制执行特定MSS（例如，排查连通性问题或满足特定网络需求），请使用此选项。

  • clamp-mss-to-pmtu：路由器计算MSS值，使其等于接口MTU减去60字节（IPv6头部40字节 + TCP头部20字节）。推荐使用此选项自动设置合适值。

set interfaces ethernet <interface> ipv6 accept-dad <0 | 1 | 2>

在接口上配置IPv6 DAD 功能。

以下选项可用：

  • 0：禁用DAD，不执行重复地址检测。

  • 1：启用DAD（默认）。检测重复地址，接口的IPv6操作将继续处理有效的IPv6地址。

  • 2：启用DAD，若发现基于MAC的重复链路本地地址，则禁用该接口上的IPv6操作。

示例：

set interfaces ethernet eth0 ipv6 accept-dad 2
set interfaces ethernet <interface> ipv6 dup-addr-detect-transmits <n>

配置路由器（内核）在该接口上进行IPv6地址分配期间发送的 DAD 消息数量。

默认值为1。

示例：

set interfaces ethernet eth0 ipv6 dup-addr-detect-transmits 5
set interfaces ethernet <interface> vrf <vrf>

将接口分配给特定的 VRF 实例。

另请参阅

有关配置VRF的信息，请参阅VRF章节。

示例：

set interfaces ethernet eth0 vrf red

DHCP(v6)

set interfaces ethernet <interface> dhcp-options client-id <description>

为接口配置DHCP客户端标识符，如 RFC 2131 所规定。

client-id是DHCP客户端发送给DHCP服务器的标识符，用于唯一标识自身以进行IP地址分配。默认情况下，客户端使用其MAC地址。<description>是用户定义的字符串，将作为DHCP客户端标识符发送给DHCP服务器。

示例：

set interfaces ethernet eth0 dhcp-options client-id 'foo-bar'
set interfaces ethernet <interface> dhcp-options host-name <hostname>

为接口配置特定主机名。

DHCP客户端在请求IP地址时，将向DHCP服务器发送该特定主机名，而非真实主机名。

示例：

set interfaces ethernet eth0 dhcp-options host-name 'VyOS'
set interfaces ethernet <interface> dhcp-options vendor-class-id <vendor-id>

配置DHCP客户端在该接口的DHCP请求中包含厂商类标识符。

厂商类标识符是厂商特定的字节字符串，使DHCP服务器能够识别设备，并在某些情况下提供配置选项。

示例：

set interfaces ethernet eth0 dhcp-options vendor-class-id 'VyOS'
set interfaces ethernet <interface> dhcp-options no-default-route

配置DHCP客户端获取IP地址，但忽略DHCP服务器在该接口上提供的任何默认网关。

示例：

set interfaces ethernet eth0 dhcp-options no-default-route
set interfaces ethernet <interface> dhcp-options default-route-distance <distance>

配置从DHCP服务器获取的默认路由在该接口上的距离值。

示例：

set interfaces ethernet eth0 dhcp-options default-route-distance 220
set interfaces ethernet <interface> dhcp-options reject <address>

配置DHCP客户端拒绝DHCP服务器在该接口上提供的特定IP地址或IP地址范围。

当调制解调器启动时分配本地IP地址时，此功能非常有用。要拒绝多个地址，请多次运行此命令并使用不同值。您可以拒绝单个地址（192.168.100.1）或整个子网（192.168.100.0/24）。

示例：

set interfaces ethernet eth0 dhcp-options reject 192.168.100.0/24
set interfaces ethernet <interface> dhcp-options user-class <string>

配置DHCP客户端在该接口的DHCP请求中发送特定用户类标识符。

DHCP服务器可解释此标识符，并据此提供特定配置选项（例如，默认路由）。用户类值通常将具有相似配置需求的DHCP客户端分组（例如，员工、访客或打印机）。

示例：

set interfaces ethernet eth0 dhcp-options user-class VyOS
set interfaces ethernet <interface> dhcpv6-options duid <duid>

为该接口上的DHCPv6客户端配置特定的 DUID 。

DUID是DHCPv6客户端用于从DHCPv6服务器获取IPv6地址的标识符。它由2字节类型字段和最多128字节的可变长度标识符字段组成。标识符部分的格式取决于DUID类型：

  • DUID-LLT：最常见的类型，包括硬件类型、时间戳和MAC地址。

  • DUID-EN：基于厂商的企业编号和厂商分配的唯一标识符。

  • DUID-LL：仅包含MAC地址。

DHCP服务器将DUID与其数据库匹配，并向DHCP客户端提供配置数据（如地址、租约时间、DNS服务器等）。

示例：

set interfaces ethernet eth0 duid '0e:00:00:01:00:01:27:71:db:f0:00:50:56:bf:c5:6d'
set interfaces ethernet <interface> dhcpv6-options no-release

配置DHCP客户端在该接口上停止运行时不发送释放消息。

这有助于保留已分配的地址或前缀。

示例：

set interfaces ethernet eth0 dhcpv6-options no-release
set interfaces ethernet <interface> dhcpv6-options parameters-only

在此接口上启用无状态DHCPv6客户端模式。

在无状态模式下，DHCPv6客户端仅向DHCP服务器请求无状态配置参数（例如DNS服务器地址），而不请求有状态配置（例如IPv6地址或前缀）。

示例：

set interfaces ethernet eth0 dhcpv6-options parameters-only
set interfaces ethernet <interface> dhcpv6-options rapid-commit

在此接口上启用DHCPv6快速提交功能。

启用后，DHCP客户端和服务器跳过协商步骤（Advertise和Request），仅通过两条消息（Solicit和最终Reply）完成DHCPv6配置过程。

示例：

set interfaces ethernet eth0 dhcpv6-options rapid-commit
set interfaces ethernet <interface> dhcpv6-options temporary

配置DHCPv6客户端在该接口上请求临时IPv6地址。

启用后，DHCP客户端不会建立非临时地址身份关联（IA_NA）伙伴关系，因此仅获取临时IPv6地址，不获取永久地址。

示例：

set interfaces ethernet eth0 dhcpv6-options temporary

DHCPv6前缀委派（PD）

VyOS支持RFC 3633中所述的DHCPv6前缀委派（DHCPv6-PD）。大多数为固定网络用户提供原生IPv6服务的ISP均支持DHCPv6-PD。

set interfaces ethernet <interface> dhcpv6-options pd <id> length <length>

为此接口上的DHCPv6-PD请求配置特定前缀长度。

某些ISP默认仅提供/64前缀。使用此命令可为特定DHCPv6-PD请求请求不同的前缀长度，范围从/32（若ISP允许）至/64。<id>是DHCPv6-PD请求的唯一标识符。

默认值为64。

若要向ISP请求/56前缀，请使用：

set interfaces ethernet eth0 dhcpv6-options pd 0 length 56
set interfaces ethernet <interface> dhcpv6-options pd <id> interface <delegatee> address <address>

为委托接口配置IPv6接口标识符（主机部分）。

该值必须为十进制整数。它将附加到委派前缀和配置的SLA ID之后，形成最终IPv6地址。

默认情况下，主机部分基于父接口的MAC地址（EUI-64格式）生成。

示例：

若/64前缀委派给接口eth8，且您将主机部分配置为65535，则生成的IPv6地址将以::ffff结尾，因为65535对应十六进制表示ffff。

set interfaces ethernet eth0 dhcpv6-options pd 0 interface eth8 address 65534
set interfaces ethernet <interface> dhcpv6-options pd <id> interface <delegatee> sla-id <id>

为委托接口配置 SLA ID 。

该值必须为大于0的十进制整数，且符合SLA ID长度要求。它将转换为十六进制，并附加到委派前缀之后，形成委托接口的特定子网前缀。

示例：

若SLA ID为1，且委派前缀为2001:db8:ffff::/48，则委托接口的子网前缀将为2001:db8:ffff:1::/64。

set interfaces ethernet eth0 dhcpv6-options pd 0 interface eth8 sla-id 1
set interfaces ethernet <interface> switchdev

为接口启用 switchdev 模式。

在switchdev模式下，接口将端口间流量交换任务卸载至硬件，绕过主机CPU。这提高了接口的流量处理能力，并降低了其转发延迟。

注意

switchdev模式仅适用于某些物理网络接口，且需要兼容switchdev的驱动程序。

以太网选项

set interfaces ethernet <interface> duplex <auto | full | half>

为接口配置双工模式。

以下双工模式可用：

  • auto：接口与连接设备协商双工模式。

  • full：接口同时发送和接收数据。连接设备也必须设置为全双工，以避免双工不匹配。

  • half：接口一次只能发送或接收数据，不能同时进行。

默认双工模式为auto。

set interfaces ethernet <interface> speed <auto | 10 | 100 | 1000 | 2500 | 5000 | 10000 | 25000 | 40000 | 50000 | 100000>

配置接口速度（单位：Mbit/s）。

以下选项可用：

  • auto：接口与连接设备协商速度。

  • 10, 100, 1000 ...：接口以选定速度运行。连接设备必须设置为相同速度才能建立连接。

默认选项为auto。

set interfaces ethernet <interface> ring-buffer rx <value>

配置接口的接收（RX）环形缓冲区大小。

RX环形缓冲区大小定义了接口在CPU处理之前，可在硬件中排队的入站数据包数量。

较大的值可降低NIC接收网络流量速度快于CPU处理速度时发生丢包的风险，但可能增加延迟；较小的值可降低延迟，但在入站流量突发时增加丢包风险。

要查看特定接口支持的值，请使用：

ethtool -g <interface>
set interfaces ethernet <interface> ring-buffer tx <value>

配置发送（TX）环形缓冲区大小。

TX环形缓冲区大小定义了接口在传输到网络之前，可在硬件中排队的出站数据包数量。

较大的值可降低CPU生成流量速度快于NIC处理速度时发生丢包的风险，但可能增加延迟；较小的值可降低延迟，但在出站流量突发时增加丢包风险。

要查看特定接口支持的值，请使用：

ethtool -g <interface>

中断合并

中断合并是一种通过将多个数据包捆绑为单个中断事件来减少CPU中断负载的机制，而不是为每个数据包到达或传输都中断CPU。

注意

并非所有网络驱动程序或虚拟接口均支持全部合并参数。请使用ethtool --show-coalesce <interface>验证您的硬件和驱动程序支持哪些设置。

基本自适应中断合并

set interfaces ethernet <interface> interrupt-coalescing adaptive-rx
set interfaces ethernet <interface> interrupt-coalescing adaptive-tx

启用自适应中断合并。NIC将根据流量模式自动调整RX/TX中断节奏，以在高吞吐量时降低CPU利用率，同时在低数据包速率下保持低延迟。

基本中断延迟

set interfaces ethernet <interface> interrupt-coalescing rx-usecs <0-16384>
set interfaces ethernet <interface> interrupt-coalescing tx-usecs <0-16384>

设置在接收或传输数据包后生成RX/TX中断的微秒延迟。较小的值降低延迟；较大的值降低CPU负载。

中断帧阈值

set interfaces ethernet <interface> interrupt-coalescing rx-frames <number>
set interfaces ethernet <interface> interrupt-coalescing tx-frames <number>

仅在接收或传输指定数量的数据包后生成RX/TX中断。

IRQ特定中断合并

set interfaces ethernet <interface> interrupt-coalescing rx-usecs-irq <number>
set interfaces ethernet <interface> interrupt-coalescing rx-frames-irq <number>
set interfaces ethernet <interface> interrupt-coalescing tx-usecs-irq <number>
set interfaces ethernet <interface> interrupt-coalescing tx-frames-irq <number>

在驱动程序已处于中断服务（IRQ上下文）时控制中断合并参数。这些设置可在持续负载下实现更精细的中断行为调优。

自适应速率阈值

set interfaces ethernet <interface> interrupt-coalescing pkt-rate-low <number>
set interfaces ethernet <interface> interrupt-coalescing pkt-rate-high <number>

定义自适应中断合并用于在低速率和高速率中断合并配置文件之间切换的数据包速率阈值（每秒数据包数）。

低速率自适应参数

set interfaces ethernet <interface> interrupt-coalescing rx-usecs-low <number>
set interfaces ethernet <interface> interrupt-coalescing rx-frame-low <number>
set interfaces ethernet <interface> interrupt-coalescing tx-usecs-low <number>
set interfaces ethernet <interface> interrupt-coalescing tx-frame-low <number>

当数据包速率低于pkt-rate-low时应用的中断合并参数。通常针对更低延迟进行优化。

高速率自适应参数

set interfaces ethernet <interface> interrupt-coalescing rx-usecs-high <number>
set interfaces ethernet <interface> interrupt-coalescing rx-frame-high <number>
set interfaces ethernet <interface> interrupt-coalescing tx-usecs-high <number>
set interfaces ethernet <interface> interrupt-coalescing tx-frame-high <number>

当数据包速率超过pkt-rate-high时应用的中断合并参数。通常针对最大吞吐量和降低CPU利用率进行优化。

统计与采样

set interfaces ethernet <interface> interrupt-coalescing stats-block-usecs <number>
set interfaces ethernet <interface> interrupt-coalescing sample-interval <number>

控制合并统计信息更新频率以及NIC为自适应合并决策采样流量速率的频率。

完成队列（CQE）模式

set interfaces ethernet <interface> interrupt-coalescing cqe-mode-rx
set interfaces ethernet <interface> interrupt-coalescing cqe-mode-tx

若驱动程序支持，启用RX/TX完成队列条目（CQE）模式。CQE模式可通过优化完成处理，在高速NIC上提升性能。
