CGNAT

CGNAT，也称为大规模 NAT（LSN），是一种由互联网服务提供商（ISP）使用的网络地址转换技术，用于使多个私有 IP 地址共享一个公共 IP 地址。该技术有助于节约有限的 IPv4 地址空间。 100.64.0.0/10 地址块已为运营商级 NAT 预留。

概述

CGNAT 的工作原理是在 ISP 网络内部部署一台 NAT 设备。该设备将客户网络中的私有 IP 地址转换为分配给该 ISP 的有限公共 IP 地址池中的地址。这使得大量客户可以共享较少数量的公共 IP 地址。

并非所有 RFC 6888 要求均在 CGNAT 中实现。

已实现以下 RFC 6888 要求：

  • REQ 2：CGN 必须默认采用“配对式”IP 地址池行为。对于与同一内部 IP 地址关联的所有会话（无论是 TCP、UDP、ICMP、其他协议或混合协议），CGN 必须使用相同的外部 IP 地址映射。

  • REQ 3：CGN 功能不得对外部地址池的大小或连续性施加任何限制。

  • REQ 4：CGN 必须支持按用户限制所分配的外部端口数（或等效地，ICMP 的“标识符”数量）

CGNAT 的优势

  • IPv4 地址节约：CGNAT 通过允许多个客户共享单个公共 IP 地址，缓解了 IPv4 地址耗尽问题。

  • 可扩展性：ISP 可在无需按比例增加公共 IP 地址数量的前提下支持更多客户。

  • 成本效益：降低了获取额外公共 IPv4 地址的相关成本。

注意事项

  • 可追溯性问题：由于多个用户共享同一公共 IP 地址，出于安全和法律目的追踪特定用户可能较为困难。

  • 性能开销：地址转换过程可能引入延迟，并在高负载下造成潜在的性能瓶颈。

  • 应用程序兼容性：某些依赖唯一公共 IP 地址的应用程序和协议可能无法很好地与 CGNAT 协同工作。

  • 端口分配限制：每个公共 IP 地址的端口数量有限，可能被耗尽，从而影响新连接的建立能力。

  • 端口控制协议：未实现 PCP（Port Control Protocol）。

端口计算

在实施 CGNAT 时，确保为每位用户分配足够的端口至关重要。以下总结基于 RFC 6888。

  1. 可用端口总数：

    • 总端口数：65536（0 至 65535）

    • 保留端口：假设有 1024 个端口为知名服务和管理用途而保留。

    • 可用端口数：65536 - 1024 = 64512

  2. 估算每位用户所需端口数：

    • 示例：一个家庭可能需要 1000 个端口，以确保多台设备及多种应用程序运行顺畅。

  3. 计算每公共 IP 地址可支持的用户数：

    • 可用端口数 / 每位用户端口数

    • 64512 / 1000 ≈ 每公共 IP 地址支持 64 位用户

配置

set nat cgnat pool external <pool-name> external-port-range <port-range>

为外部地址池设置外部端口范围，默认范围为 1024-65535。可向同一地址池添加多个条目。

set nat cgnat pool external <pool-name> per-user-limit port <num>

为每位用户单独分配外部源端口限制。默认值为 2000。

set nat cgnat pool external <pool-name> range [address | address range | network] [seq]

设置 CGNAT 地址池的外部 IP 地址范围。 序列号为可选项；若指定，则数值越小表示优先级越高。

set nat cgnat pool internal <pool-name> range [address range | network]

设置 CGNAT 地址池的内部 IP 地址范围。

set nat cgnat rule <num> source pool <internal-pool-name>

设置源地址池规则。

set nat cgnat rule <num> translation pool <external-pool-name>

设置转换地址池规则。

set nat cgnat log-allocation

启用 IP 地址和端口分配日志记录功能。

配置示例

单个外部地址

基本 CGNAT 配置示例： 在以下示例中，我们定义一个名为 ext-1 的外部地址池，其中包含一个外部 IP 地址。

每位用户最多从外部地址池中分配 2000 个端口。

set nat cgnat pool external ext1 external-port-range '1024-65535'
set nat cgnat pool external ext1 per-user-limit port '2000'
set nat cgnat pool external ext1 range '192.0.2.222/32'
set nat cgnat pool internal int1 range '100.64.0.0/28'
set nat cgnat rule 10 source pool 'int1'
set nat cgnat rule 10 translation pool 'ext1'

多个外部地址

set nat cgnat pool external ext1 external-port-range '1024-65535'
set nat cgnat pool external ext1 per-user-limit port '8000'
set nat cgnat pool external ext1 range '192.0.2.1-192.0.2.2'
set nat cgnat pool external ext1 range '203.0.113.253-203.0.113.254'
set nat cgnat pool internal int1 range '100.64.0.1-100.64.0.32'
set nat cgnat rule 10 source pool 'int1'
set nat cgnat rule 10 translation pool 'ext1'

外部地址序列

set nat cgnat pool external ext-01 per-user-limit port '16000'
set nat cgnat pool external ext-01 range 203.0.113.1/32 seq '10'
set nat cgnat pool external ext-01 range 192.0.2.1/32 seq '20'
set nat cgnat pool internal int-01 range '100.64.0.0/29'
set nat cgnat rule 10 source pool 'int-01'
set nat cgnat rule 10 translation pool 'ext-01'
