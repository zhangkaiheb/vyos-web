IPsec 故障排除

本文档提供 IPsec VPN 常见问题的故障排除方法和诊断步骤。

基本诊断命令

VyOS 提供了一系列命令来帮助诊断 IPsec 问题：

查看 IPsec 状态

查看当前 IPsec 隧道和安全关联的状态：

show vpn ipsec status

此命令显示所有 IPsec 隧道的当前状态，包括连接是否建立、SA（安全关联）是否活动等。

查看安全关联

查看详细的 IKE 和 Child SA 信息：

show vpn ipsec sa

输出包含以下信息：

  • IKE SA：IKE 阶段 1 安全关联
  • Child SA：IKE 阶段 2 安全关联（数据隧道）
  • 状态：ESTABLISHED（已建立）、INSTALLED（已安装）等
  • 加密算法：使用的加密和认证算法
  • 流量统计：通过隧道的数据包和字节数

查看 IPsec 配置

查看当前运行的 IPsec 配置：

show vpn ipsec detail

常见问题及解决方案

隧道无法建立

症状：IPsec 隧道状态显示为 "down" 或 "connecting"。

可能原因和解决方案：

  1. 预共享密钥不匹配

    确保两端的预共享密钥完全相同，包括大小写和空格。

    show vpn ipsec site-to-site peer <peer-address>

  2. IKE 提议不匹配

    检查两端的 IKE 组配置是否兼容。加密算法、哈希算法和 Diffie-Hellman 组必须匹配。

    show vpn ipsec ike-group

  3. ESP 提议不匹配

    验证 ESP 组配置是否一致。

    show vpn ipsec esp-group

  4. 防火墙阻止

    确保防火墙允许以下端口通过：

    • UDP 500（IKE）
    • UDP 4500（NAT-T）
    • 协议 50（ESP）

  5. 本地/远端子网配置错误

    检查站点到站点 VPN 的本地子网和远端子网配置是否正确。

隧道建立但不传输数据

症状：IPsec 隧道显示为 "up"，但无法通过隧道传输数据。

可能原因和解决方案：

  1. Child SA 未安装

    检查 Child SA 是否成功安装：

    show vpn ipsec sa

    如果 Child SA 未显示，可能是 ESP 提议不匹配。

  2. 路由问题

    验证路由表是否正确，确保流量能够通过隧道接口：

    show ip route

  3. MTU 问题

    IPsec 会增加数据包开销。如果数据包过大，可能会被丢弃。尝试调整 MTU：

    set interfaces ethernet <interface> mtu 1400

  4. 非对称路由

    确保返回流量也通过 IPsec 隧道，检查策略路由配置。

隧道频繁断开

症状：IPsec 隧道反复建立和断开。

可能原因和解决方案：

  1. DPD（Dead Peer Detection）配置

    检查 DPD 设置是否过于激进：

    show vpn ipsec site-to-site peer <peer-address> dead-peer-detection

    建议的 DPD 设置：

    • interval: 15-30 秒
    • timeout: 30-60 秒
    • action: restart

  2. IKE 重协商失败

    检查 IKE 生命周期设置，确保两端兼容。

  3. NAT 问题

    如果任一端位于 NAT 之后，确保启用了 NAT 穿透（NAT-T）。

认证失败

症状：日志显示认证错误。

可能原因和解决方案：

  1. 预共享密钥错误

    重新配置预共享密钥，确保两端完全匹配。

  2. 证书问题

    如果使用证书认证：

    • 验证证书是否过期
    • 检查证书链是否完整
    • 确认证书主题名称匹配
    • 验证 CA 证书已正确安装

日志和调试

查看 IPsec 日志

查看系统日志中的 IPsec 相关信息：

show log | match charon

或者查看更详细的日志：

tail -f /var/log/syslog | grep charon

启用详细日志

如需更详细的调试信息，可以启用 IPsec 调试日志：

set vpn ipsec logging log-level 3

日志级别说明：

  • 0：仅错误
  • 1：警告
  • 2：信息（默认）
  • 3：调试
  • 4：详细调试
警告：高日志级别会产生大量日志输出，可能影响系统性能。仅在故障排除时临时启用。

常见日志消息

日志消息 含义 解决方案
received INVALID_ID_INFORMATION 身份标识不匹配 检查本地和远端身份配置
no matching proposal found 提议不匹配 检查 IKE/ESP 组配置
authentication failed 认证失败 验证预共享密钥或证书
peer not responding 对等体无响应 检查网络连接和防火墙
SA lifetime expired SA 生命周期到期 正常现象，检查重协商配置

网络抓包

当其他方法无法解决问题时，可以使用 tcpdump 进行网络抓包：

捕获 IKE 流量

tcpdump -i any -n port 500 or port 4500

捕获 ESP 流量

tcpdump -i any -n proto 50

保存抓包文件

tcpdump -i any -n -w /tmp/ipsec.pcap port 500 or port 4500 or proto 50

可以使用 Wireshark 分析保存的 pcap 文件。

重置和重启

重置 IPsec 隧道

重置特定站点的 IPsec 隧道：

reset vpn ipsec site-to-site peer <peer-address>

重启 IPsec 服务

如需重启整个 IPsec 服务：

restart vpn ipsec
警告：重启 IPsec 服务会中断所有活动的 VPN 连接。

性能问题

加密性能测试

测试系统的加密性能：

show vpn ipsec performance

硬件加速

如果支持硬件加密加速，确保已启用：

show vpn ipsec hardware-acceleration
提示：某些 CPU 支持 AES-NI 指令集，可以显著提高 IPsec 性能。使用 lscpu | grep aes 检查是否支持。

联系支持

如果以上步骤无法解决问题，请收集以下信息并联系技术支持：

  1. 完整的配置导出：show configuration commands | match vpn
  2. IPsec 状态输出：show vpn ipsec status
  3. 安全关联信息：show vpn ipsec sa
  4. 系统日志：show log | match charon
  5. 网络抓包文件（如适用）
