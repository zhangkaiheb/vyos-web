IS-IS

中间系统到中间系统（IS-IS）是一种链路状态 IGP，定义于 ISO/IEC 10589、 RFC 1195 和 RFC 5308。它使用 Dijkstra 的 SPF 算法构建网络拓扑数据库（LSDB），并计算到达每个目的地的最短路径。

在 IS-IS 网络中，路由器被称为中间系统（IS）。它们通过 IS-IS 协议与直接相连的邻居交换拓扑信息；该协议的 PDU 直接承载于第 2 层帧中，而非基于 IP 传输。IS-IS 路由器通过一个 NET 进行标识，其长度为 8 至 20 字节（通常为 10 字节）。

IS-IS 与 OSPF 对比

IS-IS 从其他路由器泛洪的链路状态信息中构建 LSDB，并使用 Dijkstra 算法计算路由路径，这与 OSPF 完全相同。 由于两种协议共享相同的链路状态架构，因此它们在路径选择决策上几乎完全一致。鉴于 IS-IS 与 OSPF 的相似性，对比二者路由行为是理解网络在任一 IGP 下响应方式的有效方法。

配置

必需设置

每个 IS-IS 路由器必须配置唯一的 NET，即 CLNS（无连接网络服务）环境下的路由器 ID。 NET 中的 6 字节系统标识符部分必须在整个 IS-IS 路由域内唯一。

set protocols isis net <network-entity-title>

为路由器配置网络实体标题（NET）。

典型的 NET 格式如 49.0001.1921.6800.1002.00。

NET 由以下几部分组成：

  • AFI（49）：IS-IS 通常使用 AFI 值 49 表示私有地址。

  • 区域标识符（0001）：IS-IS 路由域内的区域编号（本例中为区域 1）。

  • 系统标识符（1921.6800.1002）：在 IS-IS 路由域内唯一标识该路由器。我们建议从此路由器的 IP 地址或 MAC 地址派生该值。若从 IPv4 地址（例如 192.168.1.2）构造系统标识符：

    • 为每个八位组补前导零：192.168.1.2 → 192.168.001.002。

    • 将数字重新分组为三个 4 位数字块：192.168.001.002 → 1921.6800.1002。

  • NET 选择器（00）：必须始终为 00，以表示本地系统。

示例：

set protocols isis net 49.0001.1921.6800.1002.00
set protocols isis interface <interface>

在指定接口上启用 IS-IS。

这使路由器能够与直接相连的对等体建立邻接关系。

示例：

set protocols isis interface eth0

IS-IS 全局配置

set protocols isis dynamic-hostname

在路由器上启用动态主机名 TLV 支持（RFC 5301）。

这使路由器能够在 IS-IS 广播中包含其可读性强的系统名称，与其系统 ID 一同发送，以便更轻松地识别对等体。

示例：

set protocols isis dynamic-hostname
set protocols isis level <level-1 | level-1-2 | level-2>

配置路由器运行的 IS-IS 等级：

  • level-1：仅参与 Level-1（区域内）路由。

  • level-1-2：同时参与 Level-1（区域内）和 Level-2（区域间）路由。

  • level-2：仅参与 Level-2（区域间）路由。

示例：

set protocols isis level level-1
set protocols isis lsp-mtu <128-4352>

配置用于生成或接收 IS-IS LSP 的 MTU 大小（字节）。

示例：

set protocols isis lsp-mtu 1400
set protocols isis metric-style <narrow | transition | wide>

配置路由器在生成或处理 IS-IS LSP 时使用的 TLV 格式（度量风格）：

  • narrow：仅生成和处理原始 ISO/IEC 10589 TLV。

  • transition：生成和处理窄型与宽型 TLV 格式。

  • wide：仅生成和处理扩展 TLV。

示例：

set protocols isis metric-style wide
set protocols isis purge-originator

为路由器触发的 IS-IS 清除操作启用 POI （RFC 6232）。

启用后，路由器在每次触发的清除操作中均包含带有其系统 ID 的 POI TLV。这可标识出触发清除操作的 IS。

示例：

set protocols isis purge-originator
set protocols isis set-attached-bit

配置 L1/L2 IS-IS 路由器在其生成的 Level-1 LSP 中设置 ATT（已连接）位 （RFC 3787）。

这向纯 Level-1 路由器发出信号，表明该 L1/L2 路由器具备 Level-2 可达性。

示例：

set protocols isis set-attached-bit
set protocols isis set-overload-bit

配置路由器在其生成的 LSP 中设置 OL（LSP 数据库过载）位 （RFC 3787）。

配置后，其他 IS-IS 路由器将停止通过该路由器转发中转流量，但仍可访问其直连网络。

示例：

set protocols isis set-overload-bit
set protocols isis advertise-high-metrics

配置路由器在其所有 IS-IS 接口上通告高指标值，而忽略各接口上配置的具体指标值。

通告值取决于指标风格：narrow 为 63，wide 为 16777215， transition 为 62。

示例：

set protocols isis advertise-high-metrics
set protocols isis advertise-passive-only

配置路由器仅在其 LSP 中通告被动接口的 IP 前缀。

非被动接口的前缀不会被通告，但这些接口仍可用于建立邻接关系并参与 SPF 计算。

示例：

set protocols isis advertise-passive-only
set protocols isis log-adjacency-changes

配置路由器将 IS-IS 邻接状态变更记录到 syslog。

示例：

set protocols isis log-adjacency-changes
set protocols isis topology <ipv4-multicast | ipv4-mgmt | ipv6-unicast | ipv6-multicast | ipv6-mgmt | ipv6-dstsrc>

为路由器启用额外的 IS-IS 多拓扑功能：

  • ipv4-multicast：IPv4 组播拓扑（MT 3）。

  • ipv4-mgmt：IPv4 管理拓扑（MT 1）。

  • ipv6-unicast：IPv6 单播拓扑（MT 2）。

  • ipv6-multicast：IPv6 组播拓扑（MT 4）。

  • ipv6-mgmt：IPv6 管理拓扑（MT 5）。

  • ipv6-dstsrc：IPv6 目的地址/源地址路由拓扑。

默认的 IPv4 单播拓扑（MT 0）始终存在，无需显式配置。

示例：

set protocols isis topology ipv6-unicast

认证

IS-IS 支持两种全协议范围的密码：

  • area-password：应用于 Level-1 LSP/SNP（在区域内）。

  • domain-password：应用于 Level-2 LSP/SNP（跨 Level-2 骨干网）。

这些密码与每个接口的 password 命令（参见 接口配置）不同。该命令仅对在配置接口上与邻居交换的 Hello（IIH）PDU 进行认证。

set protocols isis area-password plaintext-password <text>

配置用于认证本路由器生成和接收的 Level-1 LSP 和 SNP 的明文密码。

该区域内的所有 Level-1 路由器必须配置相同的密码。

示例：

set protocols isis area-password plaintext-password mysharedsecret
set protocols isis area-password md5 <text>

配置用于认证本路由器生成和接收的 Level-1 LSP 和 SNP 的 HMAC-MD5 密钥。

该区域内的所有 Level-1 路由器必须配置相同的密钥。

注意

对于 area-password 和 domain-password，应配置 plaintext-password 或 md5 之一，但不可同时配置两者。

示例：

set protocols isis area-password md5 mysharedsecret
set protocols isis domain-password plaintext-password <text>

配置用于认证本路由器生成和接收的 Level-2 LSP 和 SNP 的明文密码。

路由域内的所有 Level-2 路由器必须配置相同的密码。

示例：

set protocols isis domain-password plaintext-password mysharedsecret
set protocols isis domain-password md5 <text>

配置用于认证本路由器生成和接收的 Level-2 LSP 和 SNP 的 HMAC-MD5 密钥。

路由域内的所有 Level-2 路由器必须配置相同的密钥。

示例：

set protocols isis domain-password md5 mysharedsecret

默认路由通告

Level-1 IPv4
set protocols isis default-information originate ipv4 level-1

配置路由器生成 IPv4 默认路由（0.0.0.0/0）并在整个 Level-1 区域内本地生成的 LSP 中通告该路由。

注意

此命令要求路由器的 IS-IS 等级设置为 level-1 或 level-1-2。

示例：

set protocols isis default-information originate ipv4 level-1
set protocols isis default-information originate ipv4 level-1 always

配置路由器无条件生成 IPv4 默认路由并在整个 Level-1 区域内通告该路由，即使路由器在其 RIB 中没有默认路由。

注意

此命令要求路由器的 IS-IS 等级设置为 level-1 或 level-1-2。

示例：

set protocols isis default-information originate ipv4 level-1 always
set protocols isis default-information originate ipv4 level-1 metric <0-16777215>

配置 Level-1 通告的 IPv4 默认路由的 IS-IS 指标值。

注意

此命令要求路由器的 IS-IS 等级设置为 level-1 或 level-1-2。

示例：

set protocols isis default-information originate ipv4 level-1 metric 100
set protocols isis default-information originate ipv4 level-1 route-map <name>

将路由映射应用于 Level-1 通告的 IPv4 默认路由。

该路由映射可允许或拒绝通告；若允许，则可修改该路由的指标值。

注意

此命令要求路由器的 IS-IS 等级设置为 level-1 或 level-1-2。

示例：

set protocols isis default-information originate ipv4 level-1 route-map ISIS-DEFAULT

LDP 同步

set protocols isis ldp-sync

为 IS-IS 路由进程启用 LDP IGP 同步 （RFC 5443）。

启用后，所有运行中的 IS-IS 接口自动参与同步，环回接口除外。

注意

要使同步正常工作，路由器上必须已配置并启用 LDP。

示例：

set protocols isis ldp-sync
set protocols isis ldp-sync holddown <0-10000>

配置 IS-IS 在等待 LDP-IGP 同步完成期间，将其任一接口保持在最大指标状态的时间（秒）。

当此时间在某一接口上超时时，即使 LDP-IGP 同步尚未完成，IS-IS 也会恢复该接口的配置指标值。

默认值为 0，表示 IS-IS 将无限期等待。

示例：

set protocols isis ldp-sync holddown 60

接口配置

set protocols isis interface <interface> circuit-type <level-1 | level-1-2 | level-2-only>

配置路由器可在指定接口上建立邻接关系的 IS-IS 等级：

  • level-1：仅允许 Level-1（区域内）邻接关系。

  • level-2-only：仅允许 Level-2（区域间）邻接关系。

  • level-1-2：允许 Level-1（区域内）和 Level-2（区域间）邻接关系。

注意

所选等级必须受路由器 IS-IS 进程支持。

示例：

set protocols isis interface eth0 circuit-type level-1
set protocols isis interface <interface> hello-interval <1-600>

配置在指定接口上连续发送 IS-IS Hello PDU（IIH）的时间间隔（秒）。

示例：

set protocols isis interface eth1 hello-interval 5
set protocols isis interface <interface> hello-multiplier <2-100>

配置应用于 Hello 间隔的乘数，以推导在指定接口上发送的 IS-IS Hello PDU（IIH）中通告的保持时间（Holding Time）。

接收邻居使用通告的保持时间作为其邻接超时时间。若在此时间段内未收到 IIH，则宣告邻接关系失效。

示例：

set protocols isis interface eth1 hello-multiplier 5
set protocols isis interface <interface> hello-padding

在指定接口上启用 IS-IS Hello PDU（IIH）填充，使其达到该接口的完整 MTU （RFC 3719）。

这确保具有不对称 MTU 的邻居无法建立邻接关系。若不启用填充，不对称 MTU 将在邻接建立过程中绕过检测。

示例：

set protocols isis interface eth0 hello-padding
set protocols isis interface <interface> metric <0-16777215>

配置指定接口通告的 IS-IS 指标值（开销）。

SPF 算法使用该值计算到达目的地的最佳路由路径。

有效取值范围取决于配置的指标风格：narrow 将指标限制在 0–63，而 wide 将其扩展至 0–16777215。

默认值为 10。

示例：

set protocols isis interface eth1 metric 100
set protocols isis interface <interface> network point-to-point

将指定接口的 IS-IS 网络类型配置为点对点。

默认网络类型为广播。

注意

相邻接口必须配置为相同的网络类型；否则，邻接关系无法建立。

示例：

set protocols isis interface eth1 network point-to-point
set protocols isis interface <interface> passive

为指定接口启用被动模式。

在被动接口上，路由器既不发送也不处理 IS-IS Hello PDU（IIH），因此不会建立邻接关系。但该接口的 IP 前缀仍会在本路由器的 LSP 中通告。

示例：

set protocols isis interface lo passive
set protocols isis interface <interface> password plaintext-password <text>

为指定接口配置明文认证密码。

该密码包含在接口上发送的 IS-IS Hello（IIH）PDU 中，并在从邻居接收的 IIH PDU 中进行验证。

密码不匹配将阻止邻接关系建立，并拆除已建立的邻接关系。

示例：

set protocols isis interface eth1 password plaintext-password mysharedsecret
set protocols isis interface <interface> password md5 <text>

为指定接口配置 MD5 认证密钥。

该密钥用于生成加密哈希值，该哈希值包含在接口上发送的 IS-IS Hello（IIH）PDU 中，并在从邻居接收的 IIH PDU 中进行验证。

密钥不匹配将阻止邻接关系建立，并拆除已建立的邻接关系。

示例：

set protocols isis interface eth1 password md5 mysharedsecret
set protocols isis interface <interface> priority <0-127>

配置指定接口的 IS-IS DIS 选举优先级。

该优先级用于广播（LAN）网段上的 DIS 选举。通告最高优先级的路由器获胜。

默认优先级为 64。

注意

配置的值仅适用于广播接口，对点对点接口无影响。

示例：

set protocols isis interface eth1 priority 100
set protocols isis interface <interface> psnp-interval <0-127>

配置在指定接口上连续发送 IS-IS PSNP 的时间间隔（秒）。

示例：

set protocols isis interface eth1 psnp-interval 2
set protocols isis interface <interface> no-three-way-handshake

禁用点对点（P2P）邻接关系的三次握手 （RFC 5303）。

三次握手默认启用。

注意

此命令仅适用于点对点接口，对广播接口无影响。

示例：

set protocols isis interface eth1 no-three-way-handshake
set protocols isis interface <interface> ldp-sync disable

在指定 IS-IS 接口上禁用 LDP-IGP 同步。

启用 LDP-IGP 同步后，IS-IS 在 LDP 尚未同步完成时，将在该接口上通告最大指标值。

在该接口上禁用此功能后，IS-IS 将无论 LDP 同步状态如何，均通告配置的指标值。

注意

此命令仅在 IS-IS 路由进程已启用 LDP-IGP 同步时适用。

示例：

set protocols isis interface eth1 ldp-sync disable
set protocols isis interface <interface> ldp-sync holddown <0-10000>

配置 IS-IS 在等待 LDP-IGP 同步完成期间，将指定接口保持在最大指标状态的时间（秒）。

当此时间超时时，IS-IS 将恢复该接口的配置指标值，即使 LDP-IGP 同步尚未完成。

默认值为 0，表示 IS-IS 将无限期等待。

注意

此设置将覆盖为 IS-IS 路由进程配置的 LDP-IGP 同步保持时间。

示例：

set protocols isis interface eth1 ldp-sync holddown 60
set protocols isis interface <interface> bfd profile <profile-name>

将 BFD 配置文件附加到指定接口上的 IS-IS 邻接关系。

配置后，IS-IS 使用命名配置文件描述的 BFD 会话来检测邻接故障。若 BFD 报告会话中断，IS-IS 邻接关系将立即拆除，而非等待 Hello 保持时间超时。

该配置文件本身在 set protocols bfd profile <profile-name> 下配置。

示例：

set protocols isis interface eth1 bfd profile ISIS-FAST

Level-1 快速重路由

set protocols isis interface <interface> fast-reroute lfa level-1 enable

在指定接口上启用 Level-1 LFA 计算。

启用后，IS-IS 为通过该接口到达的每个 Level-1 目的地预先计算备份下一跳。若主下一跳失效，路由器将使用预先计算的备份路径。

示例：

set protocols isis interface eth1 fast-reroute lfa level-1 enable
set protocols isis interface <interface-1> fast-reroute lfa level-1 exclude interface <interface-2>

从指定接口的 Level-1 LFA 备份下一跳选择中排除某接口。

在命令语法中，<interface-1> 标识受保护接口， <interface-2> 标识不得用作 LFA 备份下一跳的接口。

示例：

set protocols isis interface eth1 fast-reroute lfa level-1 exclude interface eth2
set protocols isis interface <interface> fast-reroute remote-lfa level-1 tunnel mpls-ldp

在指定接口上启用基于 MPLS-LDP 隧道的 Level-1 远程 LFA 计算。

当本地 LFA 无法找到无环备用邻居时，远程 LFA 提供备份路径。

若主下一跳失效，路由器将流量发送至 MPLS-LDP 隧道，转发至预先计算的远程 LFA 节点。随后，通过正常的 IS-IS 转发将流量送达目的地。

注意

远程 LFA 要求在同一接口上已配置对应的本地 LFA。

注意

远程 LFA 要求 IS-IS 路由实例中所有潜在的远程 LFA 端点均接受定向 LDP Hello 消息。

示例：

set protocols isis interface eth1 fast-reroute remote-lfa level-1 tunnel mpls-ldp
set protocols isis interface <interface> fast-reroute remote-lfa level-1 maximum-metric <1-16777215>
