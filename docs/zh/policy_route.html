路由 and 路由6 策略

IPv4 route and IPv6 route policies are defined in this section. These route policies can then be associated to interfaces.

规则-设置s

A rule-set is a named collection of rules that 可以 applied to an interface. Each rule is numbered, has an action to apply if the rule is matched, and the ability to specify the criteria to match. 数据 packets go through the rules from 1 - 999999, at the first match the action of the rule 将 executed.

set policy route description
set policy route6 description

Provide a rule-set description.

set policy route default-log
set policy route6 default-log

Option to log packets hitting default-action.

set policy route interface
set policy route6 interface

应用 routing policy to interface

set policy route rule description
set policy route6 rule description

Provide a description for each rule.

set policy route rule log
set policy route6 rule log

Option to enable or disable log matching rule.

匹配ing criteria

There are a lot of matching criteria options available, both for policy route and policy route6. These options are listed in this section.

set policy route rule connection-mark <1-2147483647>
set policy route6 rule connection-mark <1-2147483647>

设置 match criteria based on connection mark.

set policy route rule mark
set policy route6 rule mark

匹配 based on the firewall mark (fwmark), where 可以:

  • <0-2147483647> a single fwmark

  • !<0-2147483647> everything except a single fwmark

  • a range of marks

  • ! everything except the range of marks

注意

When using the set table or set vrf commands the mark settings are ignored and overwritten with a table-specific mark that is set to 0x7FFFFFFF - the id of the table/VRF.

set policy route rule source address
set policy route rule destination address
set policy route6 rule source address
set policy route6 rule destination address

设置 match criteria based on source or destination ipv4|ipv6 address, where 可能:

For ipv4:

  • : IP address to match.

  • : Subnet to match.

  • -: IP range to match.

  • !: 匹配 everything except the specified address.

  • !: 匹配 everything except the specified subnet.

  • !-: 匹配 everything except the specified range.

And for ipv6:

  • : IPv6 address to match.

  • : IPv6 prefix to match.

  • -: IPv6 range to match.

  • !: 匹配 everything except the specified address.

  • !: 匹配 everything except the specified prefix.

  • !-: 匹配 everything except the specified range.

set policy route rule source group
set policy route rule destination group
set policy route6 rule source group
set policy route6 rule destination group

设置 match criteria based on source or destination groups, where 将 the group name/identifier. Prepend character ‘!’ for inverted matching criteria.

set policy route rule destination port
set policy route6 rule destination port

设置 match criteria based on destination port, where could be:

  • : 名称d port (any name in /etc/services, e.g., http).

  • <1-65535>: Numbered port.

  • -: Numbered port range (e.g., 1001-1005).

Multiple destination ports 可以 specified as a comma-separated list. The whole list can also be “negated” using ‘!’. For example: ‘!22,telnet,http,123,1001-1005’

set policy route rule disable
set policy route6 rule disable

Option to disable rule.

set policy route rule dscp
set policy route6 rule dscp
set policy route rule dscp-exclude
set policy route6 rule dscp-exclude

匹配 based on dscp value criteria. Multiple values from 0 to 63 and ranges are supported.

set policy route rule fragment
set policy route6 rule fragment

设置 IP fragment match, where:

  • match-frag: Second and further fragments of fragmented packets.

  • match-non-frag: Head fragments or unfragmented packets.

set policy route rule icmp
set policy route6 rule icmpv6

匹配 based on icmp|icmpv6 code and type.

set policy route rule icmp type-name
set policy route6 rule icmpv6 type-name

匹配 based on icmp|icmpv6 type-name criteria. Use tab for information about what type-name criteria are supported.

set policy route rule ipsec
set policy route6 rule ipsec

设置 IPSec inbound match criteria, where:

  • match-ipsec: match inbound IPsec packets.

  • match-none: match inbound non-IPsec packets.

set policy route rule limit burst <0-4294967295>
set policy route6 rule limit burst <0-4294967295>

设置 maximum number of packets to allow in excess of rate.

set policy route rule limit rate
set policy route6 rule limit rate

设置 maximum average matching rate. 格式 for rate: integer/time_unit, where time_unit 可能 any one of second, minute, hour or day.For example 1/second implies rule to be matched at an average of once per second.

set policy route rule protocol
set policy route6 rule protocol

匹配 a protocol criteria. A protocol number or a name which is defined in: /etc/protocols. Special names are all for all protocols and tcp_udp for tcp and udp based packets. The ! negates the selected protocol.

set policy route rule packet-length
set policy route6 rule packet-length
set policy route rule packet-length-exclude
set policy route6 rule packet-length-exclude

匹配 based on packet length criteria. Multiple values from 1 to 65535 and ranges are supported.

set policy route rule packet-type [broadcast | host | multicast | other]
set policy route6 rule packet-type [broadcast | host | multicast | other]

匹配 based on packet type criteria.

set policy route rule recent count <1-255>
set policy route6 rule recent count <1-255>
set policy route rule recent time <1-4294967295>
set policy route6 rule recent time <1-4294967295>

设置 parameters for matching recently seen sources. This match 可能 used by setting count (source address seen more than <1-255> times) and/or time (source address seen in the last <0-4294967295> seconds).

set policy route rule state
set policy route6 rule state

设置 match criteria based on session state.

set policy route rule tcp flags
set policy route6 rule tcp flags

设置 match criteria based on tcp flags. 允许ed values for TCP flags: SYN ACK FIN RST URG PSH ALL. When specifying more than one flag, flags 应该 comma-separated. For example : value of ‘SYN,!ACK,!FIN,!RST’ will only match packets with the SYN flag set, and the ACK, FIN and RST flags unset.

set policy route rule time monthdays
set policy route6 rule time monthdays
set policy route rule time startdate
set policy route6 rule time startdate
set policy route rule time starttime
set policy route6 rule time starttime
set policy route rule time stopdate
set policy route6 rule time stopdate
set policy route rule time stoptime
set policy route6 rule time stoptime
set policy route rule time weekdays
set policy route6 rule time weekdays
set policy route rule time utc
set policy route6 rule time utc

Time to match the defined rule.

set policy route rule ttl <0-255>

匹配 time to live parameter, where ‘eq’ stands for ‘equal’; ‘gt’ stands for ‘greater than’, and ‘lt’ stands for ‘less than’.

set policy route6 rule hop-limit <0-255>

匹配 hop-limit parameter, where ‘eq’ stands for ‘equal’; ‘gt’ stands for ‘greater than’, and ‘lt’ stands for ‘less than’.

动作

When matching all patterns defined in a rule, then different actions can be made. This includes dropping the packet, modifying certain data, or setting a different routing table.

set policy route rule action drop
set policy route6 rule action drop

设置 rule action to drop.

set policy route rule set connection-mark <1-2147483647>
set policy route6 rule set connection-mark <1-2147483647>

设置 a specific connection mark.

set policy route rule set dscp <0-63>
set policy route6 rule set dscp <0-63>

设置 packet modifications: 数据包 Differentiated 服务s Codepoint (DSCP)

set policy route rule set mark <1-2147483647>
set policy route6 rule set mark <1-2147483647>

设置 a specific packet mark.

set policy route rule set table
set policy route6 rule set table

设置 the routing table to forward packet with.

注意

When using the set table or set vrf commands matching against the mark is not possible, because it gets overwritten with a table-specific mark that is 0x7FFFFFFF - the id of the table/VRF.

set policy route rule set tcp-mss <500-1460>
set policy route6 rule set tcp-mss <500-1460>

设置 packet modifications: Explicitly set TCP Maximum segment size value.

set policy route rule set vrf
set policy route6 rule set vrf

设置 the VRF to forward packet with.

注意

When using the set table or set vrf commands matching against the mark is not possible, because it gets overwritten with a table-specific mark that is 0x7FFFFFFF - the id of the table/VRF.
