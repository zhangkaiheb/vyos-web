防火墙

警告

由于启动时存在竞态条件，所有接口均在防火墙初始化之前完成初始化。这会暂时使系统对所有流量开放，从而带来安全风险。

VyOS 使用 Netfilter。Netfilter 项目为 Linux 内核开发了 iptables 及其后续版本 nftables，以直接处理数据包流。该机制将基于区域的安全概念进行了扩展，允许您在网络接口和驱动程序接收数据包之后、将其发送至目标（例如 Web 服务器或其他设备）之前，在多个阶段对数据进行操作。

VyOS 防火墙中关于数据包流向和术语的主要要点如下：

  • 是否为桥接端口？：根据接收数据包的接口是否属于桥接组，选择相应的处理路径。

如果接收数据包的接口不属于桥接组，则数据包将在IP 层进行处理：

  • 预路由（Prerouting）：路由器在此阶段处理所有数据包，无论其目标地址为何。您可在此阶段执行多种操作，且这些操作也在 VyOS 配置的不同部分中定义。顺序至关重要。适用于此阶段的相关配置包括：

    • 防火墙预路由规则：在 set firewall [ipv4 | ipv6] prerouting raw... 下定义的规则。系统在此部分处理所有规则，且优先于连接跟踪子系统。

    • 连接跟踪忽略规则（Conntrack Ignore）：在 set system conntrack ignore [ipv4 | ipv6] ... 下定义的规则。您也可通过 firewall [ipv4 | ipv6] prerouting ... 配置此部分。出于兼容性考虑，该功能仍受支持，但未来将被弃用。

    • 策略路由（Policy Route）：在 set policy [route | route6] ... 下定义的规则。

    • 目的地址转换（Destination NAT）：在 set [nat | nat66] destination... 下定义的规则。

  • 目标是否为路由器本身？：根据目标 IP 地址选择适当的路径。转发流量继续进入 forward 阶段，而发往路由器自身的流量则继续进入 input 阶段。

  • 输入（Input）：在此阶段过滤和控制发往路由器自身的流量。这是强制执行所有保护路由器安全规则的位置。其中包括在以下位置定义的 IPv4 和 IPv6 过滤规则：

    • set firewall ipv4 input filter ...。

    • set firewall ipv6 input filter ...。

  • 转发（Forward）：在此阶段过滤和控制转发流量。其中包括在以下位置定义的 IPv4 和 IPv6 过滤规则：

    • set firewall ipv4 forward filter ...。

    • set firewall ipv6 forward filter ...。

  • 输出（Output）：在此阶段过滤和控制由路由器自身发起的流量。请注意，此类流量可能源自 VyOS 路由器内部进程（如 NTP）发起的新连接，或源自路由器通过 input 阶段从外部接收的流量所生成的响应（例如，对 SSH 登录尝试的响应）。其中包括 IPv4 和 IPv6 规则，且适用两个不同配置部分：

    • 输出预路由（Output Prerouting）：set firewall [ipv4 | ipv6] output raw ...。如 Prerouting 所述，系统在此部分处理规则，且优先于连接跟踪子系统。

    • 输出过滤（Output Filter）：set firewall [ipv4 | ipv6] output filter ...。

  • 后路由（Postrouting）：与 Prerouting 类似，您可在本阶段执行多种操作，这些操作在 VyOS 配置的不同部分中定义。其中包括：

    • 源地址转换（Source NAT）：在 set [nat | nat66] source... 下定义的规则。

如果接收数据包的接口属于桥接组，则数据包将在桥接层（Bridge Layer）进行处理：

  • 预路由（桥接）（Prerouting (Bridge)）：桥接组在此阶段处理其接收到的所有数据包，无论其目标地址为何。首先，您可在此处应用过滤器，或配置忽略连接跟踪系统的规则。适用的相关配置如下：

    • set firewall bridge prerouting filter ...。

  • 转发（桥接）（Forward (Bridge)）：在此阶段过滤和控制经桥接组转发的流量：

    • set firewall bridge forward filter ...。

  • 输入（桥接）（Input (Bridge)）：在此阶段过滤和控制发往桥接组自身的流量：

    • set firewall bridge input filter ...。

  • 输出（桥接）（Output (Bridge)）：在此阶段过滤和控制由桥接组自身发起的流量：

    • set firewall bridge output filter ...。

以下是 VyOS 防火墙 CLI 子命令及其对应文档页面的列表：

set firewall bridge …

配置桥接层流量的桥接防火墙规则。 详细信息请参阅“桥接防火墙配置”页面。

set firewall flowtable …

配置防火墙流表（flowtables），用于有状态连接跟踪及相应规则。 详细信息请参阅“流表防火墙配置”页面。

set firewall global-options …

配置全局防火墙选项，例如 all-ping、broadcast-ping、 syn-cookies 及其他系统级防火墙设置。 详细信息请参阅“全局防火墙选项”页面。

set firewall group …

通过创建可复用的地址组、网络组、接口组、MAC 地址组、端口组和域名组来组织防火墙规则。在多条规则中使用这些组，可简化配置与维护工作。 详细信息请参阅“防火墙组”页面。

set firewall ipv4 …

配置 IPv4 专用防火墙规则。 详细信息请参阅“IPv4 防火墙配置”页面。

set firewall ipv6 …

配置 IPv6 专用防火墙规则。 详细信息请参阅“IPv6 防火墙配置”页面。

set firewall zone …

配置基于区域的防火墙策略，以控制不同网络区域之间的流量。 详细信息请参阅“基于区域的防火墙配置”页面。

基于区域的防火墙

  • 基于区域的防火墙

在基于区域的防火墙中，引入了一种新概念。除标准的入站和出站流量流之外，“本地流（local flow）”还支持源自并目的地为路由器自身的流量。这意味着您必须额外配置规则以保护防火墙免受网络攻击，而不仅限于已有的入站和出站规则。

有关如何使用基于区域的防火墙配置 VyOS，请参阅 基于区域的防火墙配置。
