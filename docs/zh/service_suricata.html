Suricata

Suricata 是一个开源的网络威胁检测引擎，通过将实时流量与一组规则（也称为特征码）进行匹配，实现入侵检测（IDS）、内联式入侵防御（IPS）以及网络安全监控（NSM）。每个事件均以 EVE 事件日志形式记录，并采用 JSON 格式。

VyOS 将 Suricata 集成为一项受管服务，可通过 service suricata 进行配置。当提交配置时，VyOS 将根据这些设置生成 Suricata 配置并启动该服务。

在 service suricata 下，您可以配置以下内容：

  • 被监控接口：一个或多个 Suricata 用于捕获流量的接口。

  • 地址组：IPv4/IPv6 地址或前缀的命名列表，在 Suricata 规则中替代字面 IP 地址使用。

  • 端口组：端口或端口范围的命名列表，在 Suricata 规则中替代字面端口号使用。

  • EVE 日志：目标（常规文件或 syslog）、文件名或路径，以及要记录的事件类型。

规则需单独通过在操作模式下运行 update suricata 命令获取。在执行此命令之前，该服务没有任何规则可用于匹配。

注意

仅当至少定义了一个接口、一个地址组和一个端口组时，Suricata 配置才可提交成功；否则提交将失败。

配置

被监控接口

使用以下命令配置 Suricata 监控的接口。

set service suricata interface <interface>

配置 Suricata 用于捕获和检查流量的接口。

重复执行该命令可监控多个接口。为确保提交成功，必须至少配置一个接口。

示例：

set service suricata interface eth1

地址组

使用以下命令配置地址组。

注意

组名称必须仅包含小写字母、数字或连字符。

注意

Suricata 规则引用了一组约定俗成的组名称，例如 home-net、external-net、http-servers 等。允许定义非标准名称的组，但预装的规则不会引用该组。典型的地址组包括：

  • home-net：Suricata 应视为内部网络的网段（例如 192.0.2.0/24 和 2001:db8::/32）。

  • external-net：除 home-net 外的所有网络。

  • http-servers、sql-servers、dns-servers：分别运行对应服务的主机。

set service suricata address-group <name> address <address>

将 IPv4 或 IPv6 地址或前缀配置为指定地址组的成员。

<address> 可接受 IPv4 或 IPv6 地址、IPv4 或 IPv6 前缀，或在前述任一形式前添加 ! 以排除其匹配。

重复执行该命令可向同一组添加更多地址或前缀。

示例：

set service suricata address-group home-net address 192.0.2.0/24
set service suricata address-group home-net address 2001:db8::/32
set service suricata address-group home-net address !192.0.2.5
set service suricata address-group <name> group <name>

将另一个地址组配置为指定地址组的成员。

在被引用的组名前添加 ! 可排除该组所有成员。被引用的组必须在提交时已定义，且组间循环引用将被拒绝。

重复执行该命令可向同一父组添加更多子组。

示例：

set service suricata address-group home-net address 192.0.2.0/24
set service suricata address-group external-net group !home-net

端口组

使用以下命令配置端口组。

注意

组名称必须仅包含小写字母、数字或连字符。

注意

Suricata 规则引用了一组约定俗成的端口组名称，例如 http-ports、ssh-ports、oracle-ports、shellcode-ports 等。允许定义非标准名称的端口组，但预装的规则不会引用该组。典型的端口组包括：

  • http-ports：HTTP 服务运行的端口。

  • ssh-ports：SSH 服务监听的端口。

  • oracle-ports：Oracle 数据库服务使用的端口。

  • shellcode-ports：由 shellcode 检测规则检查的端口。

set service suricata port-group <name> port <port>

将端口或端口范围配置为指定端口组的成员。

<port> 可接受单个端口（1–65535）、以 start-end 形式表示的数值范围（例如 1001-1005），或在前述任一形式前添加 ! 以排除其匹配。

重复执行该命令可向同一组添加更多端口或端口范围。

示例：

set service suricata port-group http-ports port 80
set service suricata port-group http-ports port 443
set service suricata port-group http-ports port 8000-8999
set service suricata port-group http-ports port !8080
set service suricata port-group <name> group <name>

将另一个端口组配置为指定端口组的成员。

在被引用的组名前添加 ! 可排除该组所有成员的匹配。被引用的组必须在提交时已定义，且组间循环引用将被拒绝。

重复执行该命令可向同一父组添加多个子组。

示例：

set service suricata port-group http-ports port 80
set service suricata port-group shellcode-ports group !http-ports

EVE 日志

使用以下命令配置 EVE 日志。

set service suricata log eve filename <filename>

配置 Suricata EVE 日志的文件名或路径。

仅含文件名（例如 eve.json）会将日志置于 Suricata 默认日志目录 /var/log/suricata/ 中；绝对路径将被直接使用。

默认值为 eve.json。

示例：

set service suricata log eve filename eve.json
set service suricata log eve filename /var/log/custom/suricata-eve.json
set service suricata log eve filetype <regular | syslog>

配置 Suricata EVE 日志的目标：

  • regular：将 EVE 日志写入 set service suricata log eve filename 指定的文件中。

  • syslog：将 EVE 日志发送至 syslog。

默认值为 regular。

示例：

set service suricata log eve filetype syslog
set service suricata log eve type <type>

配置要记录的 EVE 事件类型。

可接受的值：

  • 通用事件类型：alert、anomaly、drop、files、flow、netflow。

  • 按协议划分的事件类型：http、http2、dns、tls、smtp、ftp、smb、ssh、dhcp、tftp、nfs、rdp、sip、snmp、ikev2、krb5、dcerpc、dnp3、rfb、mqtt。

重复执行该命令可记录多种事件类型。

示例：

set service suricata log eve type alert
set service suricata log eve type flow
set service suricata log eve type http

操作

update suricata

使用 suricata-update 获取当前规则集，并重启 Suricata 服务以加载新规则。

若未配置 service suricata，该命令将输出错误消息并退出。

示例：

update suricata
restart suricata

重启 Suricata 服务。

若该服务尚未配置（即不存在 service suricata 配置），或正处于配置提交过程中，该命令将打印错误消息并退出。

示例：

restart suricata
