VTI（虚拟隧道接口）

VTI 允许您在公共基础设施（例如互联网）之上，在私有网络或主机之间创建安全、加密的隧道。它们与底层 IPsec 隧道协同工作，后者负责封装和加密，而 VTI 则仅作为路由接口使用。

配置

通用接口配置

set interfaces vti <interface> address <address>

配置一个或多个接口 IP 地址。

<address> 支持 CIDR 表示法的 IPv4 和 IPv6 地址。例如，IPv4 使用 192.0.2.1/24，IPv6 使用 2001:db8::1/64。

示例：

set interfaces vti vti0 address 192.0.2.1/24
set interfaces vti vti0 address 2001:db8::1/64
set interfaces vti <interface> description <description>

为接口配置清晰、描述性的别名。

该别名将显示在 show interfaces 命令以及基于 SNMP 的监控工具中。

示例：

set interfaces vti vti0 description '这是一个运行在 VyOS 上的接口。'
set interfaces vti <interface> disable

禁用该接口。

该接口将被设置为管理性关闭（A/D）状态。

示例：

set interfaces vti vti0 disable
set interfaces vti <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

配置在指定接口上发出的 TCP SYN 数据包中通告的 MSS 值。

通过限制 TCP SYN 数据包中的 MSS 值，可明确告知远端不要发送大于该尺寸的数据包。这可以防止路径 MTU 发现（PMTUD）失败时出现连接问题。

以下选项可用：

  • mss： 将 MSS 设置为特定字节数值。当需要强制执行特定 MSS（例如排查连通性问题或满足特定网络要求）时，请使用此选项。

  • clamp-mss-to-pmtu： 路由器自动计算 MSS 值，即接口 MTU 减去 40 字节（IPv4 流量：20 字节 IPv4 头部 + 20 字节 TCP 头部）。建议使用此选项以自动设置正确值。

set interfaces vti <interface> ip arp-cache-timeout

配置 ARP 条目在学习到本接口上的 IP 到 MAC 地址映射后保持有效的时间长度。

默认持续时间为 30 秒。

如果 ARP 条目从上层协议接收到正向反馈，则其保持有效。

示例：

set interfaces vti vti0 ip arp-cache-timeout 180
set interfaces vti <interface> ip disable-arp-filter

配置本接口上的 ARP 过滤。

默认行为： 内核仅在流量将通过该特定接口路由回 ARP 请求发送方时，才响应本接口上的 ARP 请求。

若已配置： 内核将响应本接口上针对本地主机所配置的任意 IP 地址的 ARP 请求，而不论该 IP 地址分配给哪个具体接口，也不论路由表如何。这体现了 Linux 的概念：IP 地址属于主机，而非单个接口。

示例：

set interfaces vti vti0 ip disable-arp-filter
set interfaces vti <interface> ip disable-forwarding

配置接口的主机或路由器行为。

若已配置，接口将切换为主机模式，并在该接口上禁用 IPv4 转发。

示例：

set interfaces vti vti0 ip disable-forwarding
set interfaces vti <interface> ip enable-directed-broadcast

配置是否转发在本接口上接收到的 IP 定向广播数据包。

默认行为： IP 定向广播数据包将被丢弃。

若已配置： IP 定向广播数据包将根据 RFC 1812 和 RFC 2644 的定义，转发至目标子网上的所有主机。

示例：

set interfaces vti vti0 ip enable-directed-broadcast
set interfaces vti <interface> ip enable-arp-accept

配置本接口上对免费 ARP 的处理方式。

若已配置，将根据免费 ARP 请求或应答，在 ARP 表中添加 IP 到 MAC 地址映射。

注意

如果 ARP 表中已存在来自免费 ARP 的 IP 地址，则无论是否启用此设置，其条目都将被更新。

示例：

set interfaces vti vti0 ip enable-arp-accept
set interfaces vti <interface> ip enable-arp-announce

配置本接口上 ARP 请求的源 IP 地址选择方式。

默认行为： 内核可在本接口的 ARP 请求中使用主机拥有的任意 IP 地址作为源 IP 地址。

若已配置： 内核首先尝试选择一个配置在本接口上且与目标 IP 地址处于同一子网的源 IP 地址；若不存在此类子网，则内核选择其通常使用的 IP 地址（依据路由表到达目标目的地）。

示例：

set interfaces vti vti0 ip enable-arp-announce
set interfaces vti <interface> ip enable-arp-ignore

配置本接口上将忽略哪些 ARP 请求。

默认行为： 内核将响应任何本地 IP 地址的 ARP 请求，而不论这些地址分配给了哪个接口。

若已配置： 内核仅在目标 IP 地址分配给本特定接口时才响应 ARP 请求。

示例：

set interfaces vti vti0 ip enable-arp-ignore
set interfaces vti <interface> ip enable-proxy-arp

配置本接口上的代理 ARP。

若已配置，路由器（内核）将截获针对非本地 IP 地址的 ARP 请求，并以接收请求的接口的 MAC 地址进行应答。后续发往这些 IP 地址的数据包将被转发至远程子网上的实际目的地。

示例：

set interfaces vti vti0 ip enable-proxy-arp
set interfaces vti <interface> ip proxy-arp-pvlan

在接口上配置本地代理 ARP。

若已配置，路由器（内核）即使目标 IP 地址位于同一子网和接口上，也会响应本 VLAN 接口上的 ARP 请求。

此功能用于支持私有 VLAN（PVLAN）的网络隔离需求（RFC 3069）。在 PVLAN 配置中，隔离端口上的主机在二层不允许直接相互通信，但可与上游路由器通信。

通过以其自身 MAC 地址应答主机间 ARP 请求，路由器（内核）将主机间流量引导至自身，而非在主机间直接传输。

注意

此命令独立工作，无需在接口上启用标准代理 ARP。

本地代理 ARP 也称为：

  • VLAN 聚合（RFC 3069）。

  • 私有 VLAN（Cisco、Allied Telesyn）。

  • 源端口过滤或端口隔离（Hewlett-Packard）。

  • MAC 强制转发（Ericsson）。

set interfaces vti <interface> ip source-validation <strict | loose | disable>

按照 RFC 3704 的规定，使用 RPF 在此接口上配置源 IP 地址验证。

以下选项可用：

  • strict： 检查每个入站数据包的源 IP 地址是否与转发表（FIB）匹配。若该接口并非返回该源地址的最佳路径，则验证失败，数据包被丢弃。

  • loose： 检查每个入站数据包的源 IP 地址是否与 FIB 匹配。若源 IP 地址无法通过任何接口到达，则验证失败。

  • disable： 不执行源 IP 地址验证，接受所有入站数据包。

RFC 3704 建议启用严格模式以防止 IP 欺骗（如 DDoS 攻击）。对于非对称或其他复杂路由场景，请使用宽松模式。

set interfaces vti <interface> ipv6 address autoconf

按照 RFC 4862 的规定，配置接口使用 SLAAC 自动获取 IPv6 地址。

IPv6 主机在连接到 IPv6 网络时，可通过 ICMPv6 路由器发现消息利用邻居发现协议自动配置自身。主机首次连接到网络时，会发送链路本地路由器请求组播请求以获取其配置参数。路由器则以包含网络层配置参数的路由器通告数据包进行响应。

注意

此方法将自动禁用接口上的 IPv6 流量转发。

示例：

set interfaces vti vti0 ipv6 address autoconf
set interfaces vti <interface> ipv6 address eui64 <prefix>

按照 RFC 4291 的规定，配置接口使用 EUI-64 方法为其自身分配 IPv6 地址。

示例：

set interfaces vti vti0 ipv6 address eui64 2001:db8:beef::/64
set interfaces vti <interface> ipv6 address no-default-link-local

禁用为此接口自动分配链路本地 IPv6 地址。

示例：

set interfaces vti vti0 ipv6 address no-default-link-local
set interfaces vti <interface> ipv6 disable-forwarding

配置接口的主机或路由器行为。

若已配置，接口将切换为主机模式，并在该接口上禁用 IPv6 转发。

示例：

set interfaces vti vti0 ipv6 disable-forwarding
set interfaces vti <interface> ipv6 adjust-mss <mss | clamp-mss-to-pmtu>

配置在指定接口上发出的 TCP SYN 数据包中通告的 MSS 值。

通过限制 TCP SYN 数据包中的 MSS 值，可明确告知远端不要发送大于该尺寸的数据包。这可以防止路径 MTU 发现（PMTUD）失败时出现连接问题。

以下选项可用：

  • mss： 将 MSS 设置为特定字节数值。使用此选项可强制执行特定 MSS，例如排查连通性问题或满足特定网络要求。

  • clamp-mss-to-pmtu： 路由器计算 MSS 值为接口 MTU 减去 60 字节（IPv6 流量：40 字节 IPv6 头部 + 20 字节 TCP 头部）。建议使用此选项以自动设置正确值。

set interfaces vti <interface> ipv6 accept-dad <0 | 1 | 2>

在接口上配置 IPv6 DAD 功能。

以下选项可用：

  • 0： 禁用 DAD。不执行重复地址检测。

  • 1： 启用 DAD（默认）。检测重复地址。接口的 IPv6 操作将继续处理有效的 IPv6 地址。

  • 2： 启用 DAD；若发现基于 MAC 的重复链路本地地址，则禁用本接口上的 IPv6 操作。

示例：

set interfaces vti vti0 ipv6 accept-dad 2
set interfaces vti <interface> ipv6 dup-addr-detect-transmits <n>

配置路由器（内核）在本接口上执行 IPv6 地址分配期间发送的 DAD 消息数量。

默认值为 1。

示例：

set interfaces vti vti0 ipv6 dup-addr-detect-transmits 5
set interfaces vti <interface> mtu <mtu>

在接口上配置 MTU。

该值定义了接口在不分片情况下可传输的最大数据包大小（字节）。

示例：

set interfaces vti vti0 mtu 1600
set interfaces vti <interface> mirror egress <monitor-interface>

配置将指定 VTI 的出站流量镜像至指定的监控接口。

set interfaces vti <interface> mirror ingress <monitor-interface>

配置将指定 VTI 的入站流量镜像至指定的监控接口。

set interfaces vti <interface> redirect <interface>

启用将入站数据包重定向至指定接口。

set interfaces vti <interface> vrf <vrf>

将接口分配给特定的 VRF 实例。

另请参阅

有关配置 VRF 的信息，请参阅 VRF 章节。

示例：

set interfaces vti vti0 vrf red

操作

show interfaces vti <vtiX>

显示指定 VTI 的运行状态和流量统计信息。

show interfaces vti <vtiX> brief

显示指定 VTI 的简要运行状态摘要。

示例

配置 VTI

为 VTI 分配 IPv4 和 IPv6 地址，并附带简短描述：

set interfaces vti vti0 address 192.168.2.249/30
set interfaces vti vti0 address 2001:db8:2::249/64
set interfaces vti vti0 description "Description"

生成的配置：

vyos@vyos# show interfaces vti
vti vti0 {
    address 192.168.2.249/30
    address 2001:db8:2::249/64
    description "Description"
}

警告

在使用 VTI 配置站点到站点 IPsec 时，请确保禁用路由自动安装功能。

set vpn ipsec options disable-route-autoinstall

有关 IPsec 和 VTI 问题以及 disable-route-autoinstall 选项的更多信息，请参阅： https://blog.vyos.io/vyos-1-dot-2-0-development-news-in-july.

该问题的根本原因是：VTI 隧道要求其流量选择器设置为 0.0.0.0/0 才能使流量匹配隧道，尽管路由决策基于 netfilter 标记。除非显式禁用路由插入，否则 strongSWAN 会错误地通过 VTI 对等地址插入一条默认路由，导致所有流量被错误路由。
