SNMP

SNMP 是一种互联网标准协议，用于收集和组织 IP 网络上受管设备的信息，并修改这些信息以改变设备行为。通常支持 SNMP 的设备包括电缆调制解调器、路由器、交换机、服务器、工作站、打印机等。

SNMP 广泛应用于网络管理中的网络监控。SNMP 将管理数据以变量形式暴露在受管系统上，这些变量按管理信息库（MIB）组织，用于描述系统状态和配置。这些变量随后可由管理应用程序远程查询（在某些情况下还可被操作）。

SNMP 已开发并部署了三个重要版本：SNMPv1 是该协议的原始版本；较新版本 SNMPv2c 和 SNMPv3 在性能、灵活性和安全性方面均有改进。

SNMP 是互联网工程任务组（IETF）定义的互联网协议套件的一个组成部分。它包含一套网络管理标准，包括应用层协议、数据库模式以及一组数据对象。

概述与基本概念

在典型的 SNMP 使用场景中，一台或多台称为“管理器”的管理计算机负责监控或管理计算机网络中的一组主机或设备。每个受管系统均运行一个称为“代理”的软件组件，该组件通过 SNMP 向管理器报告信息。

一个受 SNMP 管理的网络由三个关键组件构成：

  • 受管设备

  • 代理 — 运行于受管设备上的软件

  • 网络管理站（NMS）— 运行于管理器上的软件

受管设备是实现 SNMP 接口的网络节点，该接口允许单向（只读）或双向（读写）访问节点特定信息。受管设备与 NMS 交换节点特定信息。有时也称作网络单元，受管设备可以是任何类型的设备，包括但不限于路由器、接入服务器、交换机、电缆调制解调器、网桥、集线器、IP 电话、IP 视频摄像头、计算机主机及打印机。

代理是一种驻留在受管设备上的网络管理软件模块。代理具备对管理信息的本地认知能力，并将该信息转换为 SNMP 特定格式，或从 SNMP 特定格式进行反向转换。

网络管理站执行监控和控制受管设备的应用程序。NMS 提供网络管理所需的大部分处理能力和内存资源。在任一受管网络中，可存在一个或多个 NMS。

注意

VyOS SNMP 同时支持 IPv4 和 IPv6。

SNMP 协议版本

VyOS 本身支持 SNMPv2（第 2 版）和 SNMPv3（第 3 版），其中推荐使用 SNMPv3，因其具有更完善的安全性（可选的身份验证和加密功能）。

SNMPv2

SNMPv2 是原始且最常用的版本。对于客户端授权，SNMP 使用“团体”（community）的概念。团体的授权级别可设为只读（这是最常见的情形）或读写（此选项在 VyOS 中未被积极使用）。

SNMP 可同步或异步工作。在同步通信中，监控系统定期向路由器发起查询；在异步通信中，路由器向“陷阱”（trap，即监控主机）发送通知。

SNMPv2 不支持除客户端源地址外的任何身份验证机制，因此您应指定获准监控路由器的客户端地址。请注意，SNMPv2 不支持任何加密，所有数据均以明文方式传输。

示例

# 定义一个团体
set service snmp community routers authorization ro

# 允许整个网络进行监控访问
set service snmp community routers network 192.0.2.0/24
set service snmp community routers network 2001::db8:ffff:eeee::/64

# 允许特定地址进行监控访问
set service snmp community routers client 203.0.113.10
set service snmp community routers client 203.0.113.20

# 定义可选的路由器信息
set service snmp location "英国，伦敦"
set service snmp contact "[email protected]"

# 若需异步通信，则设置陷阱目标
set service snmp trap-target 203.0.113.10

# 仅监听特定 IP 地址（端口默认为 161）
set service snmp listen-address 172.16.254.36 port 161
set service snmp listen-address 2001:db8::f00::1

SNMPv3

SNMPv3（SNMP 协议第 3 版）引入了大量此前版本所缺失的安全相关特性。安全性曾是 SNMP v3 之前各版本的最大弱点。SNMP 第 1 版和第 2 版的身份验证仅相当于在管理器与代理之间以明文方式传输密码（即团体字符串）。每个 SNMPv3 消息均包含安全参数，这些参数被编码为八位字节串。这些安全参数的具体含义取决于所采用的安全模型。

SNMPv3 的安全方法旨在实现以下目标：

  • 保密性 — 对数据包进行加密，防止未经授权的来源窃听。

  • 完整性 — 确保数据包在传输过程中未被篡改，并可选地提供数据包重放保护机制。

  • 身份验证 — 验证消息是否源自有效来源。

示例

  • 让 SNMP 守护进程仅监听 IP 地址 192.0.2.1

  • 配置名为 “vyos” 的新 SNMP 用户，密码为 “vyos12345678”

  • 新用户将使用 SHA/AES 进行身份验证和隐私保护

set service snmp listen-address 192.0.2.1
set service snmp location 'VyOS 数据中心'
set service snmp v3 engineid '000000000000000000000002'
set service snmp v3 group default mode 'ro'
set service snmp v3 group default view 'default'
set service snmp v3 user vyos auth plaintext-password 'vyos12345678'
set service snmp v3 user vyos auth type 'sha'
set service snmp v3 user vyos group 'default'
set service snmp v3 user vyos privacy plaintext-password 'vyos12345678'
set service snmp v3 user vyos privacy type 'aes'
set service snmp v3 view default oid 1

提交后，明文密码将被哈希化并存储于您的配置中。最终生成的 CLI 配置如下所示：

vyos@vyos# show service snmp

 }

     engineid 000000000000000000000002
     group default {
         mode ro
         view default
     }
     user vyos {
         auth {
             encrypted-password 4e52fe55fd011c9c51ae2c65f4b78ca93dcafdfe
             type sha
         }
         group default
         privacy {
             encrypted-password 4e52fe55fd011c9c51ae2c65f4b78ca93dcafdfe

         }

         }
     }
 }

您可在任意基于 Linux 的系统上测试 SNMPv3 功能，只需运行以下命令：snmpwalk -v 3 -u vyos -a SHA -A vyos12345678 -x AES -X vyos12345678 -l authPriv 192.0.2.1 .1

VyOS MIB

所有 SNMP MIB 均位于 VyOS 每个镜像的以下路径中：/usr/share/snmp/mibs/

一旦启用了 SSH 服务，您即可使用 SCP 下载这些文件，例如：

scp -r vyos@your_router:/usr/share/snmp/mibs /your_folder/mibs

SNMP 扩展

为扩展 SNMP 代理的功能，可在每次调用代理时执行自定义脚本。这可通过使用 arbitrary extensioncommands 实现。第一步当然是创建一个功能完备的脚本，然后通过命令 scp your_script.sh vyos@your_router:/config/user-data 将其上传至您的 VyOS 实例。脚本上传完成后，需通过以下命令进行配置。

set service snmp script-extensions extension-name my-extension script your_script.sh
commit

当调用 OID .1.3.6.1.4.1.8072.1.3.2.3.1.1.4.116.101.115.116 时，其返回值即为该扩展脚本的输出结果。

root@vyos:/home/vyos# snmpwalk -v2c  -c public 127.0.0.1 nsExtendOutput1
NET-SNMP-EXTEND-MIB::nsExtendOutput1Line."my-extension" = STRING: hello
NET-SNMP-EXTEND-MIB::nsExtendOutputFull."my-extension" = STRING: hello
NET-SNMP-EXTEND-MIB::nsExtendOutNumLines."my-extension" = INTEGER: 1
NET-SNMP-EXTEND-MIB::nsExtendResult."my-extension" = INTEGER: 0

SolarWinds

若您恰好使用 SolarWinds Orion 作为 NMS，还可使用设备模板管理功能。VyOS 的模板可轻松导入。

请使用以下内容创建一个名为 VyOS-1.3.6.1.4.1.44641.ConfigMgmt-Commands 的文件：

<Configuration-Management Device="VyOS" SystemOID="1.3.6.1.4.1.44641">
    <Commands>
        <Command Name="Reset" Value="set terminal width 0${CRLF}set terminal length 0"/>
        <Command Name="Reboot" Value="reboot${CRLF}Yes"/>
        <Command Name="EnterConfigMode" Value="configure"/>
        <Command Name="ExitConfigMode" Value="commit${CRLF}exit"/>
        <Command Name="DownloadConfig" Value="show configuration commands"/>
        <Command Name="SaveConfig" Value="commit${CRLF}save"/>
        <Command Name="Version" Value="show version"/>
        <Command Name="MenuBased" Value="False"/>
        <Command Name="VirtualPrompt" Value=":~"/>
    </Commands>
</Configuration-Management>
