SSTP 客户端

SSTP 通过 SSL/TLS 通道传输 PPP 流量，利用密钥协商、加密和流量完整性检查提供传输层安全性。SSL/TLS 默认使用 TCP 端口 443（该端口可更改），因此 SSTP 几乎能够穿透所有防火墙和代理服务器，但经过身份验证的 Web 代理除外。

注意

VyOS 内置了 SSTP 服务器。更多信息，请参阅 SSTP 服务器。

配置

通用接口配置

set interfaces sstpc <interface> description <description>

为接口配置清晰、描述性强的别名。

该别名将显示在 show interfaces 命令以及基于 SNMP 的监控工具中。

示例：

set interfaces sstpc sstpc0 description '这是运行在 VyOS 上的一个接口。'
set interfaces sstpc <interface> disable

禁用该接口。

该接口将被设置为管理性关闭（A/D）状态。

示例：

set interfaces sstpc sstpc0 disable
set interfaces sstpc <interface> mtu <mtu>

在接口上配置 MTU。

该值定义了接口在不进行分片的情况下所能传输的最大数据包大小（以字节为单位）。

示例：

set interfaces sstpc sstpc0 mtu 1600
set interfaces sstpc <interface> vrf <vrf>

将接口分配给特定的 VRF 实例。

另请参阅

有关配置 VRF 的信息，请参阅 VRF 章节。

示例：

set interfaces sstpc sstpc0 vrf red

SSTP 客户端选项

set interfaces sstpc <interface> no-default-route

向 SSTP 服务器请求 IP 地址，但不安装默认路由。

示例：

set interfaces sstpc sstpc0 no-default-route

注意

该命令自 VyOS 1.4 版本起引入，其逻辑与旧版 default-route CLI 选项相反。

set interfaces sstpc <interface> default-route-distance <distance>

配置由 SSTP 服务器提供的默认网关的距离值。

示例：

set interfaces sstpc sstpc0 default-route-distance 220
set interfaces sstpc <interface> no-peer-dns

禁用在本地系统上安装通告的 DNS 服务器地址。

set interfaces sstpc <interface> server <address>

为客户端连接配置远程 SSTP 服务器地址。

该地址可以是 IP 地址或 FQDN。

set interfaces sstpc <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

在指定接口的出站 TCP SYN 数据包中配置所通告的 MSS 值。

通过在 TCP SYN 数据包中限制 MSS 值，可指示对端不要发送大于指定大小的数据包。当 PMTUD 失败时，这有助于防止连接问题。

以下选项可用：

  • mss：将 MSS 设置为特定的字节数值。

  • clamp-mss-to-pmtu：将 MSS 设置为接口 MTU 减去 40 字节（IPv4 流量：20 字节 IPv4 报头 + 20 字节 TCP 报头）。建议使用此选项以自动设置合适的值。

注意

该命令自 VyOS 1.4 版本起引入，替代了旧语法 set firewall options interface <name> adjust-mss <value>。

set interfaces sstpc <interface> ip disable-forwarding

配置接口为主机行为或路由器行为。

若启用该配置，接口将切换至主机模式，并在此接口上禁用 IPv4 转发功能。

set interfaces sstpc <interface> ip source-validation <strict | loose | disable>

根据 RFC 3704 中规定的 RPF 机制，在此接口上配置源 IP 地址验证。

以下选项可用：

  • strict：每个入站数据包的源 IP 地址均与 FIB 进行比对。若该接口并非返回该源地址的最佳路径，则验证失败，数据包将被丢弃。

  • loose：每个入站数据包的源 IP 地址均与 FIB 进行比对。若该源 IP 地址无法通过任何接口到达，则验证失败。

  • disable：不执行源 IP 地址验证，接受所有入站数据包。

RFC 3704 建议启用 strict 模式以防止 IP 欺骗（例如 DDoS 攻击）。对于非对称路由或其他复杂路由场景，请使用 loose 模式。

连接/断开连接

disconnect interface <interface>

断开指定接口的连接。

connect interface <interface>

在指定接口上启动会话。
