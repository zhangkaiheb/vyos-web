Babel

Babel 协议为有线和无线网状网络提供健壮且高效的路由功能。默认情况下，Babel 在有线链路上使用跳数度量，在无线链路上使用期望传输次数（ETX）的变体。管理员可配置 Babel 以支持射频多样性、自动计算链路延迟，并将该延迟纳入路由度量中。RFC 8966 定义了 Babel 协议。

Babel 是一种双栈协议。单个 Babel 实例可同时路由 IPv4 和 IPv6 流量。

常规配置

VyOS 不需要执行特定命令来启动 Babel 进程。当您配置首个启用 Babel 的接口时，系统会自动启动路由进程。

set protocols babel interface <interface>

在指定接口上启用 Babel 路由功能。

系统将立即开始在此接口上发送和接收 Babel 数据包。

可选配置

set protocols babel parameters diversity

为 Babel 进程启用射频频段多样性路由功能。

对于包含大量无线节点的网络，强烈建议启用此功能。

注意

启用多样性路由后，还应配置 diversity-factor 和 channel 参数。

set protocols babel parameters diversity-factor <1-256>

配置多样性路由的乘法因子，单位为 1/256。

较小的乘法因子会在路由选择中赋予多样性更高的权重。默认值为 256，即禁用多样性路由。对于配备多个独立无线电设备的节点，应配置为 128 或更小的值。

set protocols babel parameters resend-delay <20-655340>

配置系统重发重要请求或更新前的延迟时间（毫秒）。

默认值为 2000 毫秒。

set protocols babel parameters smoothing-half-life <0-65534>

配置用于实现迟滞效应的平滑算法的时间常数（秒）。

较大的值可减少路由振荡，但会略微增加收敛时间。值为 0 将禁用迟滞效应，适用于有线网络。默认值为 4 秒。

接口配置

set protocols babel interface <interface> type <auto|wired|wireless>

为启用 Babel 的接口配置网络类型。

可从以下选项中选择：

  • auto：Babel 自动检测接口为有线还是无线类型。

  • wired：Babel 启用针对有线接口的优化功能。

  • wireless：Babel 禁用仅适用于有线接口的优化功能。指定 wireless 总是正确的，但可能导致收敛速度变慢及路由流量增加。

set protocols babel interface <interface> split-horizon <default|disable|enable>

为指定接口配置水平分割路由行为。

可使用以下选项之一：

  • default：Babel 自动在有线接口上启用水平分割，在无线接口上禁用水平分割。

  • enable：Babel 在该接口上启用水平分割。此优化仅适用于对称、可传递（有线）网络。

  • disable：Babel 在该接口上禁用水平分割。禁用水平分割始终安全且正确。

set protocols babel interface <interface> hello-interval <20-655340>

配置在指定接口上发送 Hello 消息的间隔时间（毫秒）。

在有线链路上，Babel 可在两个 Hello 间隔内检测到链路故障；在无线链路上，链路质量在每个间隔内重新估算。默认值为 4000 毫秒。

set protocols babel interface <interface> update-interval <20-655340>

配置在指定接口上发送路由更新的间隔时间（毫秒）。

由于 Babel 广泛使用触发式更新，因此可在丢包率极低的可靠链路上增大此值。默认值为 20000 毫秒。

set protocols babel interface <interface> rxcost <1-65534>

配置指定接口的基础接收开销。

Babel 根据所配置的网络类型应用该值：

  • wired：该值为向邻接路由器通告的路由开销。

  • wireless：该值为用于计算 ETX（期望传输次数）接收开销的乘数。

默认值为 256。

set protocols babel interface <interface> rtt-decay <1-256>

配置 RTT 样本指数移动平均值的衰减因子，单位为 1/256。

较大值会更快地舍弃旧样本。默认值为 42。

set protocols babel interface <interface> rtt-min <1-65535>

配置邻居开销开始增加时的最小 RTT（毫秒）。

额外开销与 (rtt - rtt-min) 呈线性关系。默认值为 10 毫秒。

set protocols babel interface <interface> rtt-max <1-65535>

配置邻居开销停止增加时的最大 RTT（毫秒）。

默认值为 120 毫秒。

set protocols babel interface <interface> max-rtt-penalty <0-65535>

配置当 RTT 达到或超过 rtt-max 时，添加至邻居的最大开销。

将此值设为 0 将禁用基于 RTT 的开销。默认值为 150。

set protocols babel interface <interface> enable-timestamps

配置为每个 Hello 和 IHU 消息添加时间戳，以计算 RTT 值。

建议在隧道接口上启用时间戳功能。

set protocols babel interface <interface> channel <1-254|interfering|noninterfering>

配置多样性路由为指定接口使用的信道标识符。

接口根据分配的信道标识符相互干扰：

  • 1–254：该接口与共享相同信道编号的其他接口以及配置为 interfering 的接口相互干扰。

  • interfering：该接口与所有其他接口相互干扰，但配置为 noninterfering 的接口除外。

  • noninterfering：该接口仅与自身相互干扰。

重分发配置

set protocols babel redistribute <ipv4|ipv6> <route source>

配置将来自指定路由源的路由信息重分发至 Babel 进程。

可用的路由源如下：

  • ipv4： bgp、connected、eigrp、isis、kernel、nhrp、ospf、rip、static

  • ipv6： bgp、connected、eigrp、isis、kernel、nhrp、ospfv3、ripng、static

set protocols babel distribute-list <ipv4|ipv6> access-list <in|out> <number>

使用访问控制列表（ACL）配置全局 Babel 路由过滤。

指定访问控制列表的应用方向：

  • in：过滤入站路由。

  • out：过滤出站路由。

set protocols babel distribute-list <ipv4|ipv6> interface <interface> access-list <in|out> <number>

使用访问控制列表（ACL）在指定接口上配置 Babel 路由过滤。

指定访问控制列表的应用方向：

  • in：过滤入站路由。

  • out：过滤出站路由。

set protocols babel distribute-list <ipv4|ipv6> prefix-list <in|out> <name>

使用前缀列表配置全局 Babel 路由过滤。

指定前缀列表的应用方向：

  • in：过滤入站路由。

  • out：过滤出站路由。

set protocols babel distribute-list <ipv4|ipv6> interface <interface> prefix-list <in|out> <name>

使用前缀列表在指定接口上配置 Babel 路由过滤。

指定前缀列表的应用方向：

  • in：过滤入站路由。

  • out：过滤出站路由。

配置示例

基础双节点 Babel 网络

目标：以下示例通过 eth0 接口连接两台路由器（节点 1 和节点 2），并使用 Babel 路由协议向彼此通告（重分发）各路由器本地配置的网络（以环回地址表示）。

节点 1：

# 配置环回接口（本地网络）和物理接口（eth0）地址
set interfaces loopback lo address 10.1.1.1/32
set interfaces loopback lo address fd12:3456:dead:beef::1/128
set interfaces ethernet eth0 address 192.168.1.1/24

# 在物理链路上启用 Babel
set protocols babel interface eth0 type wired

# 指示 Babel 通告（重分发）本地配置的网络
set protocols babel redistribute ipv4 connected
set protocols babel redistribute ipv6 connected

节点 2：

# 配置环回接口（本地网络）和物理接口（eth0）地址
set interfaces loopback lo address 10.2.2.2/32
set interfaces loopback lo address fd12:3456:beef:dead::2/128
set interfaces ethernet eth0 address 192.168.1.2/24

# 在物理链路上启用 Babel
set protocols babel interface eth0 type wired

# 指示 Babel 通告（重分发）本地配置的网络
set protocols babel redistribute ipv4 connected
set protocols babel redistribute ipv6 connected
