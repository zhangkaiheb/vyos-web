SSH

SSH 是一种加密网络协议，用于在不安全的网络上安全地运行网络服务。SSH 的标准 TCP 端口为 22。最广为人知的应用示例是用户远程登录计算机系统。

SSH 在客户端-服务器架构中，通过在 SSH 客户端应用程序与 SSH 服务器之间建立连接，在不安全的网络上提供安全通道。常见应用包括远程命令行登录和远程命令执行，但任何网络服务均可使用 SSH 进行保护。协议规范将 SSH 分为两个主要版本，即 SSH-1 和 SSH-2。

该协议最显著的应用是访问类 Unix 操作系统上的 Shell 账户，但在 Windows 上也有一定范围的使用。2015 年，微软宣布将在未来版本中原生支持 SSH。

SSH 的设计初衷是替代 Telnet 以及 Berkeley rlogin、rsh 和 rexec 等不安全的远程 Shell 协议。这些协议以明文形式传输信息（尤其是密码），因此容易被数据包分析技术截获和泄露。SSH 所采用的加密机制旨在为不安全网络（例如互联网）上的数据提供机密性和完整性保障。

注意

VyOS 1.1 支持以 root 用户身份登录。由于 VyOS 1.2 实施了更严格的安全策略，此功能已被移除。

配置

set service ssh port <port>

启用 SSH 仅需指定 SSH 监听的端口号 <port>。默认情况下，SSH 运行于端口 22。

set service ssh listen-address <address>

指定 SSH 服务器的 IPv4/IPv6 监听地址。可定义多个地址。

set service ssh cipher <cipher>

定义 SSH 连接所允许使用的加密算法。可指定多个允许的加密算法，多次使用该命令即可启用多个算法。

支持的加密算法列表：3des-cbc、aes128-cbc、aes192-cbc、 aes256-cbc、aes128-ctr、aes192-ctr、aes256-ctr、 aes128-gcm@openssh.com、aes256-gcm@openssh.com、 chacha20-poly1305@openssh.com

set service ssh disable-password-authentication

禁用基于密码的身份验证，仅允许通过 SSH 密钥登录。此举可增强安全性！

set service ssh fido pin-required

要求 FIDO2 密钥证明用户已通过验证（例如输入 PIN 码）。

set service ssh fido touch-required

要求 FIDO2 密钥证明用户物理存在。

VyOS 支持使用 OpenSSH 生成的基于 FIDO2 的密钥进行 SSH 身份验证。OpenSSH 支持两种 FIDO2 密钥类型：ed25519-sk、ecdsa-sk

通用的基于 FIDO2 的 SSH 密钥生成示例：

ssh-keygen -t ecdsa-sk -O verify-required -C "fido2-ssh-key"
密钥生成过程中，OpenSSH 将执行以下操作：

  • 请求用户确认（例如物理触摸或确认操作）

  • 如认证器支持，可选择性地请求用户验证（PIN 码）

  • 创建本地密钥句柄文件及对应的公钥文件（.pub）

私钥材料永远不会离开认证器设备。

VyOS 配置示例：

# 在客户端系统上生成 FIDO2 SSH 密钥
# 将公钥复制到 VyOS 实例
set system login user vyos authentication public-keys fido key '<public-key>'
set system login user vyos authentication public-keys fido type '[email protected]'
set service ssh fido touch-required

现在可使用以下命令登录系统：ssh -i ~/.ssh/id_fido_key vyos@192.0.2.1

set service ssh disable-host-validation

禁用通过反向 DNS 查询进行的主机验证——当无法执行反向查询时，可加快登录速度。

set service ssh mac <mac>

指定可用的 MAC 算法。MAC 算法在协议版本 2 中用于数据完整性保护。可通过多次执行该命令来指定多个算法，每次指定一个算法。

支持的 MAC 算法列表：hmac-md5、hmac-md5-96、hmac-ripemd160、 hmac-sha1、hmac-sha1-96、hmac-sha2-256、hmac-sha2-512、 umac-64@openssh.com、umac-128@openssh.com、 hmac-md5-etm@openssh.com、hmac-md5-96-etm@openssh.com、 hmac-ripemd160-etm@openssh.com、hmac-sha1-etm@openssh.com、 hmac-sha1-96-etm@openssh.com、hmac-sha2-256-etm@openssh.com、 hmac-sha2-512-etm@openssh.com、umac-64-etm@openssh.com、 umac-128-etm@openssh.com

set service ssh access-control <allow | deny> <group | user> <name>

添加访问控制指令以允许或拒绝特定用户和用户组。指令按如下优先级顺序处理：deny-users、 allow-users、deny-groups 和 allow-groups。

set service ssh client-keepalive-interval <interval>

指定保活消息超时间隔（单位：秒）。

set service ssh key-exchange <kex>

指定允许的 KEX 算法。

支持的算法列表：diffie-hellman-group1-sha1、 diffie-hellman-group14-sha1、diffie-hellman-group14-sha256、 diffie-hellman-group16-sha512、diffie-hellman-group18-sha512、 diffie-hellman-group-exchange-sha1、 diffie-hellman-group-exchange-sha256、 ecdh-sha2-nistp256、ecdh-sha2-nistp384、ecdh-sha2-nistp521、 curve25519-sha256 和 curve25519-sha256@libssh.org。

set service ssh loglevel <quiet | fatal | error | info | verbose>

设置 sshd 日志级别。默认值为 info。

set service ssh vrf <name>

指定 VRF 实例的名称。

set service ssh pubkey-accepted-algorithm <name>

指定接受用于公钥身份验证的签名算法

支持的算法列表：ssh-ed25519、 ssh-ed25519-cert-v01@openssh.com、sk-ssh-ed25519@openssh.com、 sk-ssh-ed25519-cert-v01@openssh.com、ecdsa-sha2-nistp256、 ecdsa-sha2-nistp256-cert-v01@openssh.com、ecdsa-sha2-nistp384、 ecdsa-sha2-nistp384-cert-v01@openssh.com、ecdsa-sha2-nistp521、 ecdsa-sha2-nistp521-cert-v01@openssh.com、 sk-ecdsa-sha2-nistp256@openssh.com、 sk-ecdsa-sha2-nistp256-cert-v01@openssh.com、 webauthn-sk-ecdsa-sha2-nistp256@openssh.com、 ssh-dss、ssh-dss-cert-v01@openssh.com、ssh-rsa、 ssh-rsa-cert-v01@openssh.com、rsa-sha2-256、 rsa-sha2-256-cert-v01@openssh.com、rsa-sha2-512、 rsa-sha2-512-cert-v01@openssh.com

set service ssh trusted-user-ca <name>

指定作为证书颁发机构（CA）并用于验证用户证书的 OpenSSH 密钥对的名称。

您可通过 PKI 子系统添加该 OpenSSH 密钥对。

示例：

# 生成作为 CA 的密钥对
$ ssh-keygen -f vyos-ssh-ca.key

# 为用户 vyos_testca 生成密钥
$ ssh-keygen -f vyos_testca  -C "[email protected]"

# 对用户 vyos_testca 的公钥进行签名，并插入主体名称：vyos、vyos_testca
# 密钥有效期为两周，到期后密钥将不可用
$ ssh-keygen -s vyos-ssh-ca.key -I [email protected] -n vyos,vyos_testca -V +2w vyos_testca.pub

$ set system login user vyos_testca
$ set pki openssh test_ca public key AAAAB3N.....
$ set pki openssh test_ca public type ssh-rsa
$ set service ssh trusted-user-ca test_ca

现在可使用以下命令登录系统：ssh -i vyos_testca vyos_testca@vyos.test.com

动态防护

防止针对 SSH 的暴力破解攻击。日志消息将逐行解析，识别特定模式。若检测到攻击行为（例如数秒内发生多次登录失败），则阻止攻击源 IP 地址。被阻止的 IP 地址将在设定的时间间隔后自动解除封锁。

set service ssh dynamic-protection

启用 ssh 动态防护功能。

set service ssh dynamic-protection allow-from <address | prefix>

地址和网络白名单。始终允许来自这些系统的入站连接。

set service ssh dynamic-protection block-time <sec>

阻止源 IP 地址的持续时间（单位：秒）。后续封锁时间按 1.5 倍递增。默认值为 120。

set service ssh dynamic-protection detect-time <sec>

在重置其计分前记录源 IP 地址的持续时间（单位：秒）。默认值为 1800。

set service ssh dynamic-protection threshold <sec>

当源 IP 地址累积攻击得分超过阈值时，将其封锁。默认值为 30。

操作

restart ssh

重启 SSH 守护进程。当前会话不受影响，仅后台守护进程被重启。

generate ssh server-key

重新生成 SSH 用于保护连接的公钥/私钥对。

注意

客户端已保存的 known_hosts 文件需要更新，因为公钥已发生变化。

generate ssh client-key /path/to/private_key

重新生成一个已知的公钥/私钥文件，可用于连接其他服务（例如 RPKI 缓存）。

示例：

vyos@vyos:~$ generate ssh client-key /config/auth/id_rsa_rpki

Your public key has been saved in /config/auth/id_rsa_rpki.pub.

The key's randomart image is:

|          ..o    |
|       . o.o.. o.|

|        = o *.o.o|
|       o * +.o+.+|

将创建两个新文件：/config/auth/id_rsa_rpki 和 /config/auth/id_rsa_rpki.pub。

generate public-key-command user <username> path <location>

生成用于添加公钥的配置模式命令，以实现 基于密钥的身份验证。 <location> 可为本地路径，也可为指向远程文件的 URL。

支持的远程协议包括 FTP、FTPS、HTTP、HTTPS、SCP/SFTP 和 TFTP。

示例：

alyssa@vyos:~$ generate public-key-command user alyssa path sftp://example.net/home/alyssa/.ssh/id_rsa.pub
# 若要将此密钥作为嵌入式密钥添加，请运行以下命令：
configure
set system login user alyssa authentication public-keys [email protected] key AAA...
set system login user alyssa authentication public-keys [email protected] type ssh-rsa
commit
save
exit

ben@vyos:~$ generate public-key-command user ben path ~/.ssh/id_rsa.pub
# 若要将此密钥作为嵌入式密钥添加，请运行以下命令：
configure
set system login user ben authentication public-keys ben@vyos key AAA...
set system login user ben authentication public-keys ben@vyos type ssh-dss
commit
save
exit
show log ssh

显示 SSH 服务器日志。

monitor log ssh

实时跟踪 SSH 服务器日志。

show log ssh dynamic-protection

显示 SSH 动态防护日志。

monitor log ssh dynamic-protection

实时跟踪 SSH 动态防护日志。

show ssh dynamic-protection

显示当前被 SSH 动态防护功能封锁的 IP 地址列表。

show ssh fingerprints

显示 SSH 服务器公钥指纹。

show ssh fingerprints ascii

显示 SSH 服务器公钥指纹，包括可视化的 ASCII 艺术表示形式。
