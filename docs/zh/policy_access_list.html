访问控制列表（ACL）策略

过滤功能用于路由信息的输入和输出方向。一旦定义了过滤规则，即可在任一方向上应用该规则。VyOS 通过访问控制列表（ACL）和前缀列表（prefix list）实现过滤功能。

基本过滤可通过 access-list 和 access-list6 实现。

配置

访问控制列表（ACL）

set policy access-list <acl_number>

该命令创建一个新的访问控制列表策略，其中 <acl_number> 必须为 1 至 2699 之间的数字。

set policy access-list <acl_number> description <text>

为访问控制列表设置描述信息。

set policy access-list <acl_number> rule <1-65535> action <permit|deny>

该命令在访问控制列表中创建一条新规则，并定义其动作。

set policy access-list <acl_number> rule <1-65535> <destination|source> <any|host|inverse-mask|network>

该命令定义访问控制列表规则的匹配参数。匹配条件可应用于目的地址或源地址参数：

  • any：匹配任意 IP 地址。

  • host：匹配单个主机的 IP 地址。

  • inverse-mask：匹配网络/子网掩码（需同时指定 network 参数）。

  • network：匹配网络/子网掩码（需同时指定 inverse-mask 参数）。

IPv6 访问控制列表

基本过滤功能也可应用于 IPv6 流量。

set policy access-list6 <text>

该命令创建一个新的 IPv6 访问控制列表，由 <text> 标识。

set policy access-list6 <text> description <text>

为 IPv6 访问控制列表设置描述信息。

set policy access-list6 <text> rule <1-65535> action <permit|deny>

该命令在 IPv6 访问控制列表中创建一条新规则，并定义其动作。

set policy access-list6 <text> rule <1-65535> source <any|exact-match|network>

该命令定义 IPv6 访问控制列表规则的匹配参数。匹配条件可应用于源地址参数：

  • any：匹配任意 IPv6 地址。

  • exact-match：精确匹配网络前缀。

  • network：匹配网络/前缀长度（需同时指定 inverse-match 参数；注意：access-list6 中无 inverse-match 选项）
