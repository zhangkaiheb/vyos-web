路由 Map 策略

路由 map is a powerful command, that gives network administrators a very useful and flexible tool for traffic manipulation.

配置

路由 Map

set policy route-map

This command creates a new route-map policy, identified by .

set policy route-map description

设置 description for the route-map policy.

set policy route-map rule <1-65535> action

设置 action for the route-map policy.

set policy route-map rule <1-65535> call

Call another route-map policy on match.

set policy route-map rule <1-65535> continue <1-65535>

Jump to a different rule in this route-map on a match.

set policy route-map rule <1-65535> description

设置 description for the rule in the route-map policy.

set policy route-map rule <1-65535> match as-path

BGP as-path list to match.

set policy route-map rule <1-65535> match community community-list

BGP community-list to match.

set policy route-map rule <1-65535> match community exact-match

设置 BGP community-list to exactly match.

set policy route-map rule <1-65535> match extcommunity

BGP extended community to match.

set policy route-map rule <1-65535> match interface

First hop interface of a route to match.

set policy route-map rule <1-65535> match ip address access-list <1-2699>

IP address of route to match, based on access-list.

set policy route-map rule <1-65535> match ip address prefix-list

IP address of route to match, based on prefix-list.

set policy route-map rule <1-65535> match ip address prefix-len <0-32>

IP address of route to match, based on specified prefix-length. 注意 that this 可以 used for kernel routes only. Do not apply to the routes of dynamic routing protocols (e.g. BGP, RIP, OSFP), as this can lead to unexpected results..

set policy route-map rule <1-65535> match ip nexthop access-list <1-2699>

IP next-hop of route to match, based on access-list.

set policy route-map rule <1-65535> match ip nexthop address

IP next-hop of route to match, based on ip address.

set policy route-map rule <1-65535> match ip nexthop prefix-len <0-32>

IP next-hop of route to match, based on prefix length.

set policy route-map rule <1-65535> match ip nexthop prefix-list

IP next-hop of route to match, based on prefix-list.

set policy route-map rule <1-65535> match ip nexthop type

IP next-hop of route to match, based on type.

set policy route-map rule <1-65535> match ip route-source access-list <1-2699>

IP route source of route to match, based on access-list.

set policy route-map rule <1-65535> match ip route-source prefix-list

IP route source of route to match, based on prefix-list.

set policy route-map rule <1-65535> match ipv6 address access-list

IPv6 address of route to match, based on IPv6 access-list.

set policy route-map rule <1-65535> match ipv6 address prefix-list

IPv6 address of route to match, based on IPv6 prefix-list.

set policy route-map rule <1-65535> match ipv6 address prefix-len <0-128>

IPv6 address of route to match, based on specified prefix-length. 注意 that this 可以 used for kernel routes only. Do not apply to the routes of dynamic routing protocols (e.g. BGP, RIP, OSFP), as this can lead to unexpected results..

set policy route-map rule <1-65535> match ipv6 nexthop

Nexthop IPv6 address to match.

set policy route-map rule <1-65535> match large-community large-community-list

匹配 BGP large communities.

set policy route-map rule <1-65535> match local-preference <0-4294967295>

匹配 local preference.

set policy route-map rule <1-65535> match metric <1-65535>

匹配 route metric.

set policy route-map rule <1-65535> match origin

Boarder 网关 协议 (BGP) origin code to match.

set policy route-map rule <1-65535> match peer

Peer IP address to match.

set policy route-map rule <1-65535> match protocol
源 protocol to match.

  • babel - Babel routing protocol (Babel)

  • bgp - Border 网关 协议 (BGP)

  • connected - 连接ed routes (directly attached subnet or host)

  • isis - Intermediate 系统 to Intermediate 系统 (IS-IS)

  • kernel - Kernel routes

  • ospf - Open Shortest 路径 First (OSPFv2)

  • ospfv3 - Open Shortest 路径 First (IPv6) (OSPFv3)

  • rip - 路由 信息rmation 协议 (RIP)

  • ripng - 路由 信息rmation 协议 next-generation (IPv6) (RIPng)

  • static - Statically configured routes

  • table - Non-main Kernel 路由 表

  • vnc - Virtual 网络 Control (VNC)

set policy route-map rule <1-65535> match rpki

匹配 RPKI validation result.

set policy route-map rule <1-65535> match source-vrf

源 VRF to match.

set policy route-map rule <1-65535> match tag <1-65535>

路由 tag to match.

set policy route-map rule <1-65535> on-match goto <1-65535>

Exit policy on match: go to rule <1-65535>

set policy route-map rule <1-65535> on-match next

Exit policy on match: go to next sequence number.

set policy route-map rule <1-65535> set aggregator <1-4294967295|x.x.x.x>

BGP aggregator attribute: AS number or IP address of an aggregation.

set policy route-map rule <1-65535> set as-path exclude <1-4294967295 | all>

丢弃 AS-NUMBER from the BGP AS path.

If all is specified, remove all AS numbers from the AS_PATH of the BGP path’s NLRI.

set policy route-map rule <1-65535> set as-path prepend <1-4294967295>

Prepend the given string of AS numbers to the AS_PATH of the BGP path’s NLRI.

set policy route-map rule <1-65535> set as-path prepend-last-as

Prepend the existing last AS number (the leftmost ASN) to the AS_PATH.

set policy route-map rule <1-65535> set atomic-aggregate

BGP atomic aggregate attribute.

set policy route-map rule <1-65535> set community

添加 or replace BGP community attribute in format <0-65535:0-65535> or from well-known community list

set policy route-map rule <1-65535> set community none

删除 all BGP communities

set policy route-map rule <1-65535> set community delete

删除 BGP communities matching the community-list.

set policy route-map rule <1-65535> set large-community

添加 or replace BGP large-community attribute in format <0-4294967295:0-4294967295:0-4294967295>

set policy route-map rule <1-65535> set large-community none

删除 all BGP large-communities

set policy route-map rule <1-65535> set large-community delete

删除 BGP communities matching the large-community-list.

set policy route-map rule <1-65535> set extcommunity bandwidth <1-25600|cumulative|num-multipaths>

设置 extcommunity bandwidth

set policy route-map rule <1-65535> set extcommunity bandwidth-non-transitive

The link bandwidth extended community is encoded as non-transitive

set policy route-map rule <1-65535> set extcommunity rt

设置 route target value in format <0-65535:0-4294967295> or .

set policy route-map rule <1-65535> set extcommunity soo

设置 site of origin value in format <0-65535:0-4294967295> or .

set policy route-map rule <1-65535> set extcommunity none

清除 all BGP extcommunities.

set policy route-map rule <1-65535> set distance <0-255>

Locally significant administrative distance.

set policy route-map rule <1-65535> set ip-next-hop

Nexthop IP address.

set policy route-map rule <1-65535> set ip-next-hop unchanged

设置 the next-hop as unchanged. Pass through the route-map without changing its value

set policy route-map rule <1-65535> set ip-next-hop peer-address

设置 the BGP nexthop address to the address of the peer. For an incoming route-map this means the ip address of our peer is used. For an outgoing route-map this means the ip address of our self 用于 establish the peering with our neighbor.

set policy route-map rule <1-65535> set ipv6-next-hop

Nexthop IPv6 address.

set policy route-map rule <1-65535> set ipv6-next-hop peer-address

设置 the BGP nexthop address to the address of the peer. For an incoming route-map this means the ip address of our peer is used. For an outgoing route-map this means the ip address of our self 用于 establish the peering with our neighbor.

set policy route-map rule <1-65535> set ipv6-next-hop prefer-global

For Incoming and 导入 路由-maps if we receive a v6 global and v6 LL address for the route, then prefer to use the global address as the nexthop.

set policy route-map rule <1-65535> set local-preference <0-4294967295>

设置 BGP local preference attribute.

set policy route-map rule <1-65535> set metric <+/-metric|0-4294967295|rtt|+rtt|-rtt>

设置 the route metric. When used with BGP, set the BGP attribute MED to a specific value. Use +/- to add or subtract the specified value to/from the existing/MED. Use rtt to set the MED to the round trip time or +rtt/-rtt to add/subtract the round trip time to/from the MED.

set policy route-map rule <1-65535> set metric-type

设置 OSPF external metric-type.

set policy route-map rule <1-65535> set origin

设置 BGP origin code.

set policy route-map rule <1-65535> set originator-id

设置 BGP originator ID attribute.

set policy route-map rule <1-65535> set src

设置 source IP/IPv6 address for route.

set policy route-map rule <1-65535> set table <1-200>

设置 prefixes to table.

set policy route-map rule <1-65535> set tag <1-65535>

设置 tag value for routing protocol.

set policy route-map rule <1-65535> set weight <0-4294967295>

设置 BGP weight attribute
