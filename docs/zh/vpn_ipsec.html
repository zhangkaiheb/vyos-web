IPsec 概述

IPsec 是用于保护数据的框架。IPsec 通过提供身份验证、IP 网络数据包加密、密钥交换和密钥管理来实现这些目标。VyOS 使用 Strongswan 软件包来实现 IPsec。

认证头 (AH) 定义于 RFC 4302。它使用 IP 头和数据负载创建哈希，并将其附加到数据包前面。此哈希用于验证数据在网络传输过程中未被更改。

封装安全载荷 (ESP) 定义于 RFC 4303。它提供数据的加密和身份验证。

有两种 IPsec 模式：

IPsec 传输模式：在传输模式下，IPSec 头（AH 或 ESP）插入在 IP 头和上层协议头之间。

IPsec 隧道模式：在隧道模式下，原始 IP 数据包被封装在另一个 IP 数据报中，IPsec 头（AH 或 ESP）插入在外层和内层头之间。

IKE（互联网密钥交换）

IKE 协议是 IPsec 安全密钥协商的默认方法。IKE 旨在提供系统的相互身份验证，以及建立共享密钥以创建 IPsec 安全关联 (SA)。安全关联 (SA) 包括连接的所有相关属性，包括使用的加密算法、IPsec 模式、加密密钥以及与通过 VPN 连接传输数据相关的其他参数。

IKEv1

IKEv1 是较旧的版本，至今仍在使用。如今，大多数制造商建议使用 IKEv2 协议。

IKEv1 在以下 RFC 中描述：RFC 2409（IKE）、RFC 3407（IPsec DOI）、RFC 3947（NAT-T）、RFC 3948（ESP 数据包的 UDP 封装）、RFC 3706（DPD）

IKEv1 分两个阶段运行以建立 IKE 和 IPsec SA：

  • 阶段 1 提供 IKE 对等体的相互身份验证和会话密钥的建立。此阶段使用 DH 交换、cookies 和 ID 交换创建 IKE SA。一旦建立 IKE SA，发起者和响应者之间的所有 IKE 通信都受到加密和身份验证完整性检查的保护。IKE 阶段 1 提供两种模式：主模式和激进模式。
    • 主模式 用于站点到站点 VPN 连接。
    • 激进模式 用于远程访问 VPN 连接。
  • 阶段 2 提供使用 ESP 或 AH 保护 IP 数据流量的 IPsec SA 的协商和建立。

IKEv2

IKEv2 在 RFC 7296 中描述。IKEv1 和 IKEv2 之间最大的区别是 IKEv2 比 IKEv1 更简单、更可靠，因为在 VPN 建立期间交换的消息更少，并且具有额外的安全功能。

IKE 身份验证

VyOS 支持 3 种身份验证方法：

  • 预共享密钥：在此方法中，IPsec 隧道的两个对等体必须具有相同的预共享密钥。
  • 数字证书：在此方法中使用 PKI。
  • RSA 密钥：如果在 IKE 策略中使用 RSA 密钥方法，需要确保每个对等体拥有另一个对等体的公钥。

DPD（死对等体检测）

这是一种用于检测 VPN 对等体是否不再活跃的机制。此机制在 VyOS 中的 IKEv1 和 IKEv2 中有不同的算法。DPD 请求作为 ISAKMP R-U-THERE 消息发送，DPD 响应作为 ISAKMP R-U-THERE-ACK 消息发送。在 IKEv1 中，DPD 每隔配置的间隔发送消息。如果在 DPD 超时内未收到对这些数据包的响应，则认为远程对等体不可达。在 IKEv2 中，DPD 每隔配置的间隔发送消息。如果一个请求未得到响应，Strongswan 将执行其重传算法及其定时器。

后量子预共享密钥 (PPK)

后量子预共享密钥有助于在 ML-KEM 等后量子密钥交换算法不可用时为 IPSec 隧道提供一些量子抗性。IKEv2 中 PPK 的使用在 RFC 8784 中描述。

PPK 可以在 VyOS 的 vpn ipsec authentication ppk 配置下进行配置。PPK 需要一个 ID 和一个秘密值。如果 PPK 是成功 IPsec 连接所必需的，则 ID 和秘密必须匹配。秘密可以是纯文本、十六进制值或 Base64 值。默认为纯文本。如果使用其他类型的值，则必须定义秘密类型。

IKE 配置

IKE 属性

VyOS IKE 组有以下选项：

set vpn ipsec ike-group <name> close-action <action>

定义远程对等体意外关闭 CHILD_SA 时要采取的操作：

  • none - 设置为无（默认）
  • trap - 为 CHILD_SA 安装陷阱策略，匹配这些策略的流量将触发获取事件，使守护进程建立所需的 IKE/IPsec SA。
  • start - 尝试立即重新创建 CHILD_SA。

set vpn ipsec ike-group <name> ikev2-reauth

IKE_SA 的重新密钥是否也应重新身份验证对等体。在 IKEv1 中，始终进行重新身份验证。设置此参数可在 IKE 重新密钥期间启用远程主机重新身份验证。

set vpn ipsec ike-group <name> key-exchange

应使用哪个协议来初始化连接。如果未设置，则处理两种协议，连接在发起时使用 IKEv2，但在响应时接受任何协议版本：

  • ikev1 - 使用 IKEv1 进行密钥交换。
  • ikev2 - 使用 IKEv2 进行密钥交换。

set vpn ipsec ike-group <name> lifetime

IKE 生命周期（秒）<0-86400>（默认 28800）。

set vpn ipsec ike-group <name> mode

IKEv1 阶段 1 模式选择：

  • main - 在 IKEv1 协议中使用主模式进行密钥交换（推荐的默认值）。
  • aggressive - 在 IKEv1 协议中使用激进模式进行密钥交换，激进模式比主模式更不安全。

set vpn ipsec ike-group <name> proposal <number> dh-group <dh-group number>

DH 组。默认值为 2。

set vpn ipsec ike-group <name> proposal <number> encryption <encryption>

加密算法。默认值为 aes128。

set vpn ipsec ike-group <name> proposal <number> hash <hash>

哈希算法。默认值为 sha1。

set vpn ipsec ike-group <name> proposal <number> prf <prf>

伪随机函数。

DPD 配置

set vpn ipsec ike-group <name> dead-peer-detection action <action>

DPD 超时时对此 CHILD_SA 执行的操作：

  • trap - 安装陷阱策略，将捕获匹配的流量并尝试按需重新协商隧道。
  • clear - 关闭 CHILD_SA 且不采取进一步操作（默认）。
  • restart - 立即尝试在新的 IKE_SA 下重新协商 CHILD_SA。

set vpn ipsec ike-group <name> dead-peer-detection interval <interval>

保活间隔（秒）<2-86400>（默认 30）。

set vpn ipsec ike-group <name> dead-peer-detection timeout <timeout>

保活超时（秒）<2-86400>（默认 120）仅 IKEv1

ESP 属性

在 VyOS 中，ESP 属性通过 ESP 组指定。可以在单个组中指定多个提案。

set vpn ipsec esp-group <name> compression

启用 IPComp（IP 载荷压缩）协议，允许压缩 IP 数据包的内容。

set vpn ipsec esp-group <name> disable-rekey

不在本地发起 SA 的重新密钥，远程对等体必须在到期前重新密钥。

set vpn ipsec esp-group <name> life-bytes <bytes>

ESP 生命周期（字节）<1024-26843545600000>。IPsec SA 过期前传输的字节数。

set vpn ipsec esp-group <name> life-packets <packets>

ESP 生命周期（数据包）<1000-26843545600000>。IPsec SA 过期前传输的数据包数。

set vpn ipsec esp-group <name> lifetime <timeout>

ESP 生命周期（秒）<30-86400>（默认 3600）。连接的特定实例（用户数据包的加密/身份验证密钥集）应持续多长时间，从成功协商到到期。

set vpn ipsec esp-group <name> mode <mode>

连接类型：

  • tunnel - 隧道模式（默认）。
  • transport - 传输模式。

set vpn ipsec esp-group <name> pfs <dh-group>

是否需要在连接的密钥通道上实现完美前向保密，并定义 PFS 的 Diffie-Hellman 组：

  • enable - 从 IKE 组继承 Diffie-Hellman 组（默认）。
  • disable - 禁用 PFS。
  • <dh-group> - 定义 PFS 的 Diffie-Hellman 组。

set vpn ipsec esp-group <name> proposal <number> encryption <encryption>

加密算法。默认值为 aes128。

set vpn ipsec esp-group <name> proposal <number> hash <hash>

哈希算法。默认值为 sha1。

全局 IPsec 设置

set vpn ipsec interface <name>

用于限制出站 IPsec 策略的接口名称。可以指定多个接口。如果未指定接口，IPsec 策略适用于所有接口。

set vpn ipsec log level <number>

日志级别。默认值为 0。

set vpn ipsec log subsystem <name>

守护进程的子系统。

选项

set vpn ipsec options disable-route-autoinstall

不自动安装到远程网络的路由。

set vpn ipsec options flexvpn

允许 FlexVPN 供应商 ID 载荷（仅 IKEv2）。发送 Cisco FlexVPN 供应商 ID 载荷（仅 IKEv2），这是使 Cisco 品牌设备允许协商本地流量选择器所必需的。

set vpn ipsec options interface <name>

要使用的接口名称。应在其上安装虚拟 IP 地址的接口名称。如果未指定，地址将安装在出站接口上。

set vpn ipsec options virtual-ip

允许安装虚拟 IP 地址。

IKEv2 重传

如果对等体未响应 DPD 数据包，路由器将启动重传程序。使用以下公式计算超时：

relative timeout = timeout * base ^ (attempts-1)

set vpn ipsec options retransmission attempts

在认为对等体处于关闭状态之前的尝试次数。默认值为 5。

set vpn ipsec options retransmission base

指数退避的基数。默认值为 1.8。

set vpn ipsec options retransmission timeout

第一次重传之前的超时时间（秒）。默认值为 4。

使用默认值，数据包按以下方式重传：

IPsec 站点到站点 VPN 类型

VyOS 支持两种类型的 IPsec VPN：基于策略的 IPsec VPN 和基于路由的 IPsec VPN。

基于策略的 VPN

基于策略的 VPN 基于静态配置的策略。每个策略创建独立的 IPSec SA。匹配这些 SA 的流量将被加密并定向到远程对等体。

基于路由的 VPN

基于路由的 VPN 基于通过虚拟隧道接口 (VTI) 传递的安全流量。这种类型的 IPsec VPN 允许使用路由协议。

站点到站点 VPN 配置

需要匹配的协商参数

阶段 1
  • IKE 版本
  • 身份验证
  • 加密
  • 哈希
  • PRF
  • 生命周期
注意：Strongswan 建议在两个对等体上使用相同的生命周期值
阶段 2
  • 加密
  • 哈希
  • PFS
  • 模式（隧道或传输）

  • SA 中的远程和本地网络必须在两个对等体上兼容

站点到站点 VPN 的配置步骤

以下示例显示了参与 IPsec VPN 的一台路由器的配置。

隧道信息：

  • 阶段 1：
    • 加密：AES256
    • 哈希：SHA256
    • PRF：SHA256
    • DH：14
    • 生命周期：28800
  • 阶段 2：
    • IPsec 模式：隧道
    • 加密：AES256
    • 哈希：SHA256
    • PFS：继承自 DH 阶段 1
    • 生命周期：3600
  • 如果使用基于策略的 VPN
    • 远程网络为 192.168.50.0/24。本地网络为 192.168.10.0/24
  • 如果使用基于路由的 VPN
    • VTI 接口的 IP 为 10.0.0.1/30
注意：我们不建议对同一对等体同时使用基于策略的 VPN 和基于路由的 VPN 配置。

1. 配置 ike-group（IKE 阶段 1）

set vpn ipsec ike-group IKE close-action 'start'
set vpn ipsec ike-group IKE key-exchange 'ikev1'
set vpn ipsec ike-group IKE lifetime '28800'
set vpn ipsec ike-group IKE proposal 10 dh-group '14'
set vpn ipsec ike-group IKE proposal 10 encryption 'aes256'
set vpn ipsec ike-group IKE proposal 10 hash 'sha256'
set vpn ipsec ike-group IKE proposal 10 prf 'prfsha256'

2. 配置 ESP-group（IKE 阶段 2）

set vpn ipsec esp-group ESP lifetime '3600'
set vpn ipsec esp-group ESP mode 'tunnel'
set vpn ipsec esp-group ESP pfs 'enable'
set vpn ipsec esp-group ESP proposal 10 encryption 'aes256'
set vpn ipsec esp-group ESP proposal 10 hash 'sha256'

3. 指定接口 eth0 的公共 IP 地址

set vpn ipsec ipsec-interfaces interface eth0

4. 配置站点到站点对等体

基于策略的 VPN 配置：

set vpn ipsec site-to-site peer 203.0.113.2 authentication mode 'pre-shared-secret'
set vpn ipsec site-to-site peer 203.0.113.2 authentication id '192.0.2.1'
set vpn ipsec site-to-site peer 203.0.113.2 authentication remote-id '203.0.113.2'
set vpn ipsec site-to-site peer 203.0.113.2 connection-type 'respond'
set vpn ipsec site-to-site peer 203.0.113.2 default-esp-group 'ESP'
set vpn ipsec site-to-site peer 203.0.113.2 ike-group 'IKE'
set vpn ipsec site-to-site peer 203.0.113.2 local-address '192.0.2.1'
set vpn ipsec site-to-site peer 203.0.113.2 tunnel 1 local prefix '192.168.10.0/24'
set vpn ipsec site-to-site peer 203.0.113.2 tunnel 1 remote prefix '192.168.50.0/24'

基于路由的 VPN 配置：

set interfaces vti vti0 address '10.0.0.1/30'
set interfaces vti vti0 description 'VPN VTI interface'

set vpn ipsec site-to-site peer 203.0.113.2 authentication mode 'pre-shared-secret'
set vpn ipsec site-to-site peer 203.0.113.2 authentication id '192.0.2.1'
set vpn ipsec site-to-site peer 203.0.113.2 authentication remote-id '203.0.113.2'
set vpn ipsec site-to-site peer 203.0.113.2 connection-type 'respond'
set vpn ipsec site-to-site peer 203.0.113.2 default-esp-group 'ESP'
set vpn ipsec site-to-site peer 203.0.113.2 ike-group 'IKE'
set vpn ipsec site-to-site peer 203.0.113.2 local-address '192.0.2.1'
set vpn ipsec site-to-site peer 203.0.113.2 vti bind to 'vti0'
set vpn ipsec site-to-site peer 203.0.113.2 vti esp-group 'ESP'

远程访问 VPN 概述

远程访问 VPN 允许远程用户通过 IPsec 隧道安全地连接到公司网络。VyOS 支持多种远程访问 VPN 配置方式，包括基于预共享密钥、证书和 EAP 的身份验证。

远程访问 VPN 类型

基于预共享密钥的远程访问

最简单的远程访问配置方式，每个远程用户使用相同的预共享密钥进行身份验证。适用于小型部署或测试环境。

基于证书的远程访问

使用 X.509 证书进行身份验证，提供更高的安全性。每个用户可以拥有自己的证书，便于管理和撤销。

基于 EAP 的远程访问

可扩展身份验证协议 (EAP) 允许使用 RADIUS 服务器进行用户身份验证。支持多种 EAP 方法，如 EAP-MSCHAPv2、EAP-TLS 等。

配置远程访问 VPN

基本配置步骤

1. 配置 IKE 和 ESP 组

set vpn ipsec ike-group IKE-RA lifetime '28800'
set vpn ipsec ike-group IKE-RA proposal 1 encryption 'aes256'
set vpn ipsec ike-group IKE-RA proposal 1 hash 'sha256'
set vpn ipsec ike-group IKE-RA proposal 1 dh-group '14'

set vpn ipsec esp-group ESP-RA lifetime '3600'
set vpn ipsec esp-group ESP-RA proposal 1 encryption 'aes256'
set vpn ipsec esp-group ESP-RA proposal 1 hash 'sha256'

2. 配置 IP 地址池

set vpn ipsec remote-access connection RA pool 'RA-POOL'
set vpn ipsec remote-access connection RA pool RA-POOL prefix '100.64.0.0/24'
set vpn ipsec remote-access connection RA pool RA-POOL name-server '192.0.2.53'

3. 配置远程访问连接

set vpn ipsec remote-access connection RA authentication local-id '192.0.2.1'
set vpn ipsec remote-access connection RA authentication server-mode 'x509'
set vpn ipsec remote-access connection RA authentication x509 certificate 'ipsec-cert'

set vpn ipsec remote-access connection RA remote-access-interface 'ppp0'
set vpn ipsec remote-access connection RA ike-group 'IKE-RA'
set vpn ipsec remote-access connection RA default-esp-group 'ESP-RA'

基于 EAP-RADIUS 的配置

使用 RADIUS 服务器进行用户身份验证：

set vpn ipsec remote-access connection RA authentication client-mode 'eap-radius'
set vpn ipsec remote-access connection RA eap-radius server 1 address '192.0.2.100'
set vpn ipsec remote-access connection RA eap-radius server 1 key 'testing123'

set vpn ipsec remote-access connection RA pool RA-POOL name-server '192.0.2.53'
set vpn ipsec remote-access connection RA pool RA-POOL prefix '100.64.0.0/24'

基于预共享密钥的配置

适用于简单的远程访问场景：

set vpn ipsec remote-access connection RA authentication mode 'pre-shared-secret'
set vpn ipsec remote-access connection RA authentication id '192.0.2.1'
set vpn ipsec remote-access connection RA authentication local-id '192.0.2.1'

set vpn ipsec remote-access connection RA remote-access-interface 'ppp0'
set vpn ipsec remote-access connection RA ike-group 'IKE-RA'
set vpn ipsec remote-access connection RA default-esp-group 'ESP-RA'

set vpn ipsec remote-access connection RA pool RA-POOL prefix '100.64.0.0/24'

远程访问接口配置

远程访问 VPN 使用虚拟 PPP 接口。需要指定远程访问接口：

set interfaces ppp ppp0 description 'Remote Access VPN Interface'
set vpn ipsec remote-access connection RA remote-access-interface 'ppp0'

客户端配置示例

Windows 客户端

Windows 内置的 VPN 客户端支持 IKEv2 和 L2TP/IPsec。配置步骤：

  1. 打开"设置" > "网络和 Internet" > "VPN"
  2. 点击"添加 VPN 连接"
  3. 填写 VPN 提供程序名称、服务器名称或地址
  4. 选择 VPN 类型（IKEv2 或 L2TP/IPsec）
  5. 输入身份验证信息（用户名/密码或证书）

Linux 客户端

Linux 用户可以使用 NetworkManager 或命令行工具配置 IPsec VPN：

# 使用 strongswan 客户端
sudo apt install strongswan strongswan-pki libcharon-extra-plugins

# 配置 /etc/ipsec.conf
conn vyos-ra
    right=192.0.2.1
    rightid=@192.0.2.1
    rightsubnet=0.0.0.0/0
    left=%defaultroute
    leftid=user@example.com
    eap_identity=user@example.com
    auto=start

macOS 客户端

macOS 内置支持 IKEv2 VPN：

  1. 打开"系统偏好设置" > "网络"
  2. 点击"+"添加新连接
  3. 选择接口为"VPN"，类型为"IKEv2"
  4. 填写服务器地址和远程 ID
  5. 配置身份验证方法

移动设备

iOS 和 Android 设备都内置支持 IKEv2 VPN：

  • iOS: 设置 > 通用 > VPN 与网络 > 添加 VPN 配置
  • Android: 设置 > 网络与互联网 > VPN > 添加 VPN 配置文件

故障排除

常见问题

  • 连接失败：检查 IKE 和 ESP 参数是否匹配，验证预共享密钥或证书是否正确
  • 身份验证失败：确认 RADIUS 服务器配置正确，检查用户凭据
  • 无法获取 IP 地址：验证 IP 地址池配置，确保有足够的可用地址
  • 连接不稳定：检查 DPD 设置，调整生命周期参数

输出包含以下信息：

  • IKE SA：IKE 阶段 1 安全关联
  • Child SA：IKE 阶段 2 安全关联（数据隧道）
  • 状态：ESTABLISHED（已建立）、INSTALLED（已安装）等
  • 加密算法：使用的加密和认证算法
  • 流量统计：通过隧道的数据包和字节数

查看 IPsec 配置

查看当前运行的 IPsec 配置：

show vpn ipsec detail

常见问题及解决方案

隧道无法建立

症状：IPsec 隧道状态显示为 "down" 或 "connecting"。

可能原因和解决方案：

  1. 预共享密钥不匹配

    确保两端的预共享密钥完全相同，包括大小写和空格。

    show vpn ipsec site-to-site peer <peer-address>

  2. IKE 提议不匹配

    检查两端的 IKE 组配置是否兼容。加密算法、哈希算法和 Diffie-Hellman 组必须匹配。

    show vpn ipsec ike-group

  3. ESP 提议不匹配

    验证 ESP 组配置是否一致。

    show vpn ipsec esp-group

  4. 防火墙阻止

    确保防火墙允许以下端口通过：

    • UDP 500（IKE）
    • UDP 4500（NAT-T）
    • 协议 50（ESP）

  5. 本地/远端子网配置错误

    检查站点到站点 VPN 的本地子网和远端子网配置是否正确。

隧道建立但不传输数据

症状：IPsec 隧道显示为 "up"，但无法通过隧道传输数据。

可能原因和解决方案：

  1. Child SA 未安装

    检查 Child SA 是否成功安装：

    show vpn ipsec sa

    如果 Child SA 未显示，可能是 ESP 提议不匹配。

  2. 路由问题

    验证路由表是否正确，确保流量能够通过隧道接口：

    show ip route

  3. MTU 问题

    IPsec 会增加数据包开销。如果数据包过大，可能会被丢弃。尝试调整 MTU：

    set interfaces ethernet <interface> mtu 1400

  4. 非对称路由

    确保返回流量也通过 IPsec 隧道，检查策略路由配置。

隧道频繁断开

症状：IPsec 隧道反复建立和断开。

可能原因和解决方案：

  1. DPD（Dead Peer Detection）配置

    检查 DPD 设置是否过于激进：

    show vpn ipsec site-to-site peer <peer-address> dead-peer-detection

    建议的 DPD 设置：

    • interval: 15-30 秒
    • timeout: 30-60 秒
    • action: restart

  2. IKE 重协商失败

    检查 IKE 生命周期设置，确保两端兼容。

  3. NAT 问题

    如果任一端位于 NAT 之后，确保启用了 NAT 穿透（NAT-T）。

认证失败

症状：日志显示认证错误。

可能原因和解决方案：

  1. 预共享密钥错误

    重新配置预共享密钥，确保两端完全匹配。

  2. 证书问题

    如果使用证书认证：

    • 验证证书是否过期
    • 检查证书链是否完整
    • 确认证书主题名称匹配
    • 验证 CA 证书已正确安装

日志和调试

查看 IPsec 日志

查看系统日志中的 IPsec 相关信息：

show log | match charon

或者查看更详细的日志：

tail -f /var/log/syslog | grep charon

启用详细日志

如需更详细的调试信息，可以启用 IPsec 调试日志：

set vpn ipsec logging log-level 3

日志级别说明：

  • 0：仅错误
  • 1：警告
  • 2：信息（默认）
  • 3：调试
  • 4：详细调试
警告：高日志级别会产生大量日志输出，可能影响系统性能。仅在故障排除时临时启用。

常见日志消息

日志消息 含义 解决方案
received INVALID_ID_INFORMATION 身份标识不匹配 检查本地和远端身份配置
no matching proposal found 提议不匹配 检查 IKE/ESP 组配置
authentication failed 认证失败 验证预共享密钥或证书
peer not responding 对等体无响应 检查网络连接和防火墙
SA lifetime expired SA 生命周期到期 正常现象，检查重协商配置

网络抓包

当其他方法无法解决问题时，可以使用 tcpdump 进行网络抓包：

捕获 IKE 流量

tcpdump -i any -n port 500 or port 4500

捕获 ESP 流量

tcpdump -i any -n proto 50

保存抓包文件

tcpdump -i any -n -w /tmp/ipsec.pcap port 500 or port 4500 or proto 50

可以使用 Wireshark 分析保存的 pcap 文件。

重置和重启

重置 IPsec 隧道

重置特定站点的 IPsec 隧道：

reset vpn ipsec site-to-site peer <peer-address>

重启 IPsec 服务

如需重启整个 IPsec 服务：

restart vpn ipsec
警告：重启 IPsec 服务会中断所有活动的 VPN 连接。

性能问题

加密性能测试

测试系统的加密性能：

show vpn ipsec performance

硬件加速

如果支持硬件加密加速，确保已启用：

show vpn ipsec hardware-acceleration
提示：某些 CPU 支持 AES-NI 指令集，可以显著提高 IPsec 性能。使用 lscpu | grep aes 检查是否支持。
