链路层发现协议（LLDP）

LLDP 是互联网协议套件中一种与厂商无关的链路层协议，网络设备使用该协议在 IEEE 802 局域网（主要是有线以太网）上广播其身份、能力及邻居信息。该协议由 IEEE 正式称为“站点和媒体访问控制连接性发现”，定义于 IEEE 802.1AB 和 IEEE 802.3-2012 第 6 章第 79 节。

LLDP 执行的功能类似于若干专有协议，例如：CDP、FDP、NDP 和 LLTD。

通过 LLDP 获取的信息存储在设备中作为 MIB，并可依据 RFC 2922 中规定的 SNMP 进行查询。可通过遍历主机并查询该数据库来发现启用 LLDP 的网络拓扑结构。可检索的信息包括：

  • 系统名称和描述

  • 端口名称和描述

  • VLAN 名称

  • IP 管理地址

  • 系统能力（交换、路由等）

  • MAC/PHY 信息

  • MDI 供电能力

  • 链路聚合

配置

set service lldp

启用 LLDP 服务

set service lldp management-address <address>

定义通过 LLDP 传输的 IPv4/IPv6 管理地址。可定义多个地址。仅传输与系统相连的地址。

set service lldp interface <interface>

在指定的 <interface> 接口上启用 LLDP 信息传输。此处也可使用 all，从而在所有接口上启用 LLDP。

set service lldp interface <interface> mode [disable|rx-tx|rx|tx]

配置指定端口的管理状态。

默认情况下，所有端口均配置为 rx-tx 模式，即既可接收也可发送 LLDP 帧。

在 rx 模式下，端口不会发送任何帧；在 tx 模式下，端口不会接收任何帧；在 disabled 模式下，不发送任何帧且丢弃所有入站帧。

set service lldp snmp

启用对 LLDP 数据库的 SNMP 查询

set service lldp legacy-protocols <cdp|edp|fdp|sonmp>

在此 LLDP 实例上启用指定的旧版协议。旧版协议包括：

  • cdp — 监听思科路由器/交换机的 CDP

  • edp — 监听 Extreme 路由器/交换机的 EDP

  • fdp — 监听 Foundry 路由器/交换机的 FDP

  • sonmp — 监听北电路由器/交换机的 SONMP

show lldp neighbors

显示通过 LLDP 发现的所有邻居的信息。
