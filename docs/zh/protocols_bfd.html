BFD

BFD is a network protocol that detects communication failures between two connected routing devices in mere milliseconds — far faster than traditional routing protocols. BFD does not route traffic itself. Instead, it provides rapid failure detection for other protocols, such as BGP, OSPF, and static routes.

BFD is described and extended by the following RFCs: RFC 5880, RFC 5881 and RFC 5883.

How BFD works

BFD establishes a session between two peers and exchanges rapid UDP control packets at a negotiated interval (e.g., 300 ms between consecutive packets). If a peer doesn’t receive these packets within the detection time (the negotiated interval multiplied by a detection multiplier), BFD assumes a connection failure and notifies the routing protocols.

配置

set protocols bfd peer

Configure the IPv4 or IPv6 address of the BFD peer.

You can configure multiple BFD peers by specifying a different IP address for each neighbor you want to monitor.

注意

For IPv6 peers, you must configure a source IP address or interface.

示例:

set protocols bfd peer 198.51.100.33
set protocols bfd peer
echo-mode

Enable BFD echo transmission mode for the peer at the specified IP address.

示例:

set protocols bfd peer 198.51.100.33 echo-mode
set protocols bfd peer
multihop

Configure the peer at the specified IP address as a multi-hop neighbor.

注意

For BFD multi-hop peers, you must configure a local source IP address.

示例:

set protocols bfd peer 198.51.100.33 multihop
set protocols bfd peer 198.51.100.33 source address 198.51.100.1
set protocols bfd peer
source address

Configure the source IP address for the BFD session with the peer at the specified IP address.

注意

Configuring a source IP address or interface is mandatory for IPv6 BFD peers.

示例:

set protocols bfd peer 198.51.100.33 source address 198.51.100.1
set protocols bfd peer
source interface

Configure the source interface for the BFD session with the peer at the specified IP address.

注意

Configuring a source IP address or interface is mandatory for IPv6 BFD peers.

示例:

set protocols bfd peer 2001:db8::2 source interface eth0
set protocols bfd peer
interval echo-interval <10-60000>

Configure the minimum interval, in milliseconds, at which the local system can receive echo packets from the peer at the specified IP address.

示例:

set protocols bfd peer 198.51.100.33 interval echo-interval 50
set protocols bfd peer
interval multiplier <2-255>

Configure the detection multiplier for the peer at the specified IP address.

BFD multiplies the negotiated interval by this value to calculate the detection time — the period after which it declares the session down if no control packets arrive.

示例:

set protocols bfd peer 192.0.2.1 interval multiplier 3
set protocols bfd peer
interval receive <10-60000>

Configure the interval, in milliseconds, at which the local system can receive BFD control packets from the peer at the specified IP address.

示例:

set protocols bfd peer 192.0.2.1 interval receive 300
set protocols bfd peer
interval transmit <10-60000>

Configure the interval, in milliseconds, at which you want the local system to transmit BFD control packets to the peer at the specified IP address.

示例:

set protocols bfd peer 192.0.2.1 interval transmit 300
set protocols bfd peer
shutdown

Disable the BFD session with the peer at the specified IP address.

示例:

set protocols bfd peer 198.51.100.33 shutdown
set protocols bfd peer
minimum-ttl <1-254>

Configure the minimum TTL value that incoming BFD control packets must have to be accepted from the peer at the specified IP address.

BFD discards any packet whose TTL is below this threshold.

注意

This setting applies only to multi-hop sessions.

示例:

set protocols bfd peer 192.0.2.1 minimum-ttl 250
set protocols bfd peer
passive

Configure the BFD session with the peer at the specified IP address to operate in passive mode.

In passive mode, the local system does not initiate the BFD session. Instead, it waits to receive the first BFD control packet from the remote peer.

注意

At least one of the two peers must remain in active mode for the session to establish. If both peers are passive, neither will initiate, and the session never establishes.

示例:

set protocols bfd peer 198.51.100.33 passive
set protocols bfd peer
profile

应用 settings from a designated BFD profile to the peer at the specified IP address.

示例:

set protocols bfd peer 192.0.2.1 profile datacenter-fast
set protocols bfd peer
vrf

绑定 the BFD session with the peer at the specified IP address to a specific VRF instance.

示例:

set protocols bfd peer 192.0.2.1 vrf customer-a

Enable BFD in BGP

set protocols bgp neighbor bfd

Enable BFD failure detection for the BGP session with the neighbor at the specified IP address.

示例:

set protocols bgp neighbor 192.0.2.1 bfd
set protocols bgp peer-group bfd

Enable BFD failure detection for all neighbors in the specified BGP peer group.

示例:

set protocols bgp peer-group INTERNAL-PEERS bfd

Enable BFD in OSPF

set protocols ospf interface bfd

Enable BFD failure detection for OSPF neighbors discovered on the specified interface.

When OSPF forms an adjacency with a neighbor on this interface, it requests BFD to establish a session with that neighbor.

示例:

set protocols ospf interface eth0 bfd
set protocols ospfv3 interface bfd

Enable BFD failure detection for OSPFv3 neighbors discovered on the specified interface.

When OSPFv3 forms an adjacency with a neighbor on this interface, it requests BFD to establish a session with that neighbor.

示例:

set protocols ospfv3 interface eth0 bfd

Enable BFD in IS-IS

set protocols isis interface bfd

Enable BFD failure detection for IS-IS neighbors discovered on the specified interface.

When IS-IS forms an adjacency with a neighbor on this interface, it requests BFD to establish a session with that neighbor.

示例:

set protocols isis interface eth0 bfd

BFD static route monitoring

A monitored static route is present in the RIB only when the BFD session is up. If the session goes down, the route is removed.

set protocols static route next-hop
bfd profile

Configure BFD failure detection for a single-hop static route.

BFD uses the next-hop IP address as the BFD peer IP address and applies settings from the specified BFD profile.

示例:

set protocols static route 10.0.0.0/24 next-hop 192.0.2.1 bfd profile datacenter-fast
set protocols static route next-hop
bfd multi-hop source-address

Configure BFD failure detection for a multi-hop static route.

BFD uses the next-hop IP address as the BFD peer IP address and the multi-hop source IP address as the local source IP for outgoing BFD packets.

示例:

set protocols static route 10.0.0.0/24 next-hop 198.51.100.33 bfd multi-hop source-address 198.51.100.1
set protocols static route6 next-hop
bfd profile

Configure BFD failure detection for a single-hop IPv6 static route.

BFD uses the next-hop IPv6 address as the BFD peer IPv6 address and applies settings from the specified BFD profile.

示例:

set protocols static route6 2001:db8:1::/64 next-hop 2001:db8::1 bfd profile datacenter-fast
set protocols static route6 next-hop
bfd multi-hop source-address

Configure BFD failure detection for a multi-hop IPv6 static route.

BFD uses the next-hop IPv6 address as the BFD peer IPv6 address and the multi-hop source IPv6 address as the local source IPv6 address for outgoing BFD packets.

示例:

set protocols static route6 2001:db8:1::/64 next-hop 2001:db8:100::33 bfd multi-hop source-address 2001:db8::1
