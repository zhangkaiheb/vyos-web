系统 DNS

警告

如果您正在为管理目的配置 VRF，则目前无法强制系统 DNS 流量经由特定 VRF。

本节介绍如何在系统上配置 DNS，具体包括：

  • DNS 名称服务器

  • 域名搜索顺序

DNS 名称服务器

set system name-server <address>

使用此命令指定系统用于 DNS 查询的 DNS 服务器。可添加多个 DNS 服务器，但需逐个配置。同时支持 IPv4 和 IPv6 地址。

示例

在此示例中，使用了若干 OpenNIC 服务器，包括两个 IPv4 地址和两个 IPv6 地址：

set system name-server 176.9.37.132
set system name-server 195.10.195.195
set system name-server 2a01:4f8:161:3441::1
set system name-server 2a00:f826:8:2::195

域名搜索顺序

为使系统能够解析并补全未限定的主机名，可定义一个域名列表，系统将按该列表顺序执行域名搜索。

set system domain-search <domain>

使用此命令逐个定义域名，以便系统用其补全未限定的主机名。最多支持 6 个条目。

注意

域名可包含字母、数字、连字符和句点，最大长度为 253 个字符。

示例

系统被配置为按以下顺序尝试域名补全：vyos.io（第一）、vyos.net（第二）和 vyos.network（最后）：

set system domain-search vyos.io
set system domain-search vyos.net
set system domain-search vyos.network
