HTTP API

VyOS 提供 HTTP API。您可以使用该 API 执行操作模式命令，或更改、删除配置。该 API 同时支持 REST API 和 GraphQL API。

有关 REST API 请求示例、端点及身份验证详情，请参阅 VyOS API。

注意

如果未为该服务配置 PKI 证书，VyOS 将自动创建一个自签名证书。此方式不建议用于生产环境。

配置

HTTPS 监听器

set service https listen-address <address>

配置 HTTPS 监听器接受入站连接的本地 IPv4 或 IPv6 地址。

该 IP 地址必须已分配给本地接口。重复执行该命令可配置多个 IP 地址。

当未设置该参数时，监听器将在所有本地 IP 地址上接受入站连接。

示例：

set service https listen-address 192.0.2.1
set service https listen-address 2001:db8::1
set service https port <1-65535>

配置 HTTPS 监听器接受入站连接的 TCP 端口。

默认值为 443。

注意

若所选端口已被其他服务占用，则提交配置将失败。

示例：

set service https port 8443
set service https vrf <name>

将 HTTPS 监听器绑定到指定的 VRF 实例。

该 VRF 必须已在 set vrf name <name> 下完成配置。

示例：

set service https vrf mgmt
set service https allow-client address <address>

将 HTTPS API 端点的访问权限限制为指定的 IPv4 或 IPv6 地址或前缀。

重复执行该命令可允许多个 IP 地址或前缀。

当未设置该参数时，API 将接受来自任意 IP 地址的连接。

示例：

set service https allow-client address 192.0.2.0/24
set service https allow-client address 2001:db8::/32
set service https enable-http-redirect

启用将入站 HTTP 请求（端口 80）重定向至 HTTPS 的功能。

重定向将流量发送至默认 HTTPS 端口（443）。若您已更改 HTTPS 端口，则重定向将无法生效。

示例：

set service https enable-http-redirect
set service https request-body-size-limit <1-256>

配置监听器所接受的 HTTP 请求体的最大大小（单位：MB）。

超出此限制的请求将被拒绝。

默认值为 1。

示例：

set service https request-body-size-limit 10

TLS

set service https tls-version <1.2 | 1.3>

为 HTTPS 监听器启用特定 TLS 协议版本。

重复执行该命令可启用多个协议版本。

默认情况下，TLS 1.2 和 TLS 1.3 均已启用。

示例：

set service https tls-version 1.3
set service https certificates certificate <name>

将 PKI 子系统中的 TLS 证书绑定至 HTTPS 监听器。

该证书必须已在 set pki certificate <name> 下定义，并同时包含证书和私钥。

示例：

set service https certificates certificate my-server-cert
set service https certificates ca-certificate <name>

将 PKI 子系统中的 CA 证书绑定至 HTTPS 监听器。

该 CA 必须已在 set pki ca <name> 下定义。CA 证书将附加至 TLS 证书，以在 TLS 握手期间向客户端提供完整证书链。

示例：

set service https certificates ca-certificate my-internal-ca
set service https certificates dh-params <name>

从 PKI 子系统中选择 Diffie-Hellman 参数供 HTTPS 监听器使用。

该参数必须已在 set pki dh <name> 下定义，且密钥长度至少为 2048 位。这些参数将被 TLS 1.2 中的 DHE 密码套件使用。TLS 1.3 不使用这些参数。

示例：

set service https certificates dh-params my-dh-2048

API 身份验证

set service https api keys id <name> key <apikey>

配置 HTTP API 密钥，用于对 REST 请求进行身份验证；对于 GraphQL 请求，除非已将 GraphQL 切换为 JWT 令牌身份验证，否则也使用该密钥进行身份验证。

该密钥以明文形式指定，并授予对 API 的完全访问权限。

至少需配置一个密钥才能使用 REST API。若启用了 JWT 令牌身份验证，GraphQL 可无需密钥运行。

示例：

set service https api keys id MY-HTTPS-API-ID key 'MY-HTTPS-API-PLAINTEXT-KEY'

REST

set service https api rest

启用 REST API，以便通过 HTTPS 管理 VyOS。

示例：

set service https api rest
set service https api rest strict

当目标配置路径不存在时，拒绝针对 /configure 端点的删除请求。

若未启用此标志，此类请求将静默成功。

示例：

set service https api rest strict
set service https api rest debug

当 API 配置请求失败时，在 systemd 日志中记录详细的错误消息。

若未启用此标志，则仅记录简短的错误消息。

示例：

set service https api rest debug

GraphQL

set service https api graphql introspection

启用 GraphQL 模式内省功能。

经身份验证的客户端随后可查询该端点以获取完整模式。默认情况下该功能处于禁用状态，出于安全考虑，生产环境中通常保持禁用。

示例：

set service https api graphql introspection
set service https api graphql authentication type <key | token>

配置 GraphQL 请求的身份验证类型：

  • key：使用在 service https api keys 中配置的 API 密钥。

  • token：使用 JWT 令牌。

默认值为 key。

示例：

set service https api graphql authentication type token
set service https api graphql authentication expiration <60-31536000>

配置 JWT 令牌的有效期（单位：秒）。

默认值为 3600。

示例：

set service https api graphql authentication expiration 86400
set service https api graphql authentication secret-length <16-65535>

配置用于签署 JWT 令牌的共享密钥长度（单位：字节）。

默认值为 32。

示例：

set service https api graphql authentication secret-length 64
set service https api graphql cors allow-origin <origin>

配置允许通过 CORS 在浏览器中读取 GraphQL API 响应的网站（来源）。

重复执行该命令可允许多个来源。

示例：

set service https api graphql cors allow-origin https://app.example.com

示例

使 REST API 正常工作的最小配置要求启用 REST 功能并至少配置一个 API 密钥：

set service https api keys id MY-HTTPS-API-ID key MY-HTTPS-API-PLAINTEXT-KEY
set service https api rest
