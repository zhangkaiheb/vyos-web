任务调度器

任务调度器允许您按指定时间表执行任务。它基于 UNIX cron 实现。

注意

所有通过此方式执行的脚本均以 root 用户身份运行——这可能存在危险。结合命令脚本编写功能，可用于自动化（重新）配置。

set system task-scheduler task <task> interval <interval>

指定 <task> 的执行时间间隔。该间隔以数字形式指定，并需附加以下后缀之一：

  • none —— 以分钟为单位的执行间隔

  • m —— 以分钟为单位的执行间隔

  • h —— 以小时为单位的执行间隔

  • d —— 以天为单位的执行间隔

注意

若省略后缀，则默认单位为分钟。

set system task-scheduler task <task> crontab-spec <spec>

以标准 cron 时间格式设置执行时间。<spec> 值为 30 */6 * * * 表示在每 6 小时的第 30 分钟执行 <task>。

set system task-scheduler task <task> executable path <path>

指定当执行 <task> 时所运行脚本的绝对路径 <path>。

set system task-scheduler task <task> executable arguments <args>

传递给可执行文件的参数。
