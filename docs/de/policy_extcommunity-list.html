BGP - Erweiterte Gemeinschaftsliste

VyOS bietet Befehle für die Filterung und Manipulation von BGP-Datenverkehr an: extcommunity-list ist einer davon.

Konfiguration

policy extcommunity-list

set policy extcommunity-list <text>

Erstellt eine extcommunity-list-Richtlinie mit dem Namen <text>.

set policy extcommunity-list <text> description <text>

Legt eine Beschreibung für die extcommunity-list-Richtlinie fest.

set policy extcommunity-list <text> rule <1-65535> action <permit|deny>

Legt das Verhalten fest, wenn Einträge mit dieser Regel übereinstimmen.

set policy extcommunity-list <text> rule <1-65535> description <text>

Legt eine Beschreibung für die Regel fest.

set policy extcommunity-list <text> rule <1-65535> regex <text>

Regulärer Ausdruck, um mit einer erweiterten Gemeinschaftsliste abzugleichen, wobei Text folgendes sein könnte:

  • <aa:nn:nn>: Regulärer Ausdruck für eine erweiterte Gemeinschaftsliste.

  • <rt aa:nn:nn>: Regulärer Ausdruck für Route Target.

  • <soo aa:nn:nn>: Regulärer Ausdruck für Site of Origin.
