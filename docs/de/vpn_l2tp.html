L2TP

VyOS verwendet accel-ppp, um L2TP-Server-Funktionen bereitzustellen. Es kann mit lokaler Authentifizierung oder einem angeschlossenen RADIUS-Server verwendet werden.

L2TP-Server konfigurieren

set vpn l2tp remote-access authentication mode local
set vpn l2tp remote-access authentication local-users username test password 'test'
set vpn l2tp remote-access client-ip-pool L2TP-POOL range 192.168.255.2-192.168.255.254
set vpn l2tp remote-access default-pool 'L2TP-POOL'
set vpn l2tp remote-access outside-address 192.0.2.2
set vpn l2tp remote-access gateway-address 192.168.255.1
set vpn l2tp remote-access authentication mode <local | radius>

Legt den Authentifizierungsbackend fest. Der konfigurierte Authentifizierungsbackend wird für alle Abfragen verwendet.

  • radius: Alle Authentifizierungsanfragen werden durch einen konfigurierten RADIUS-Server verarbeitet.

  • local: Alle Authentifizierungsanfragen werden lokal verarbeitet.

set vpn l2tp remote-access authentication local-users username <user> password <pass>

Erstellt einen <user> für die lokale Authentifizierung auf diesem System. Das Passwort des Benutzers wird auf <pass> gesetzt.

set vpn l2tp remote-access client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Verwenden Sie diesen Befehl, um die erste IP-Adresse eines Adresspools zu definieren, der an L2TP-Clients vergeben wird. Wenn die Notation x.x.x.x-x.x.x.x verwendet wird, muss sie innerhalb eines /24-Subnets liegen. Wenn die Notation x.x.x.x/x verwendet wird, besteht die Möglichkeit, Host/Netzmaske anzugeben.

set vpn l2tp remote-access default-pool <POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des Standard-Adresspools zu definieren.

set vpn l2tp remote-access gateway-address <gateway>

Gibt eine einzelne <gateway> IP-Adresse an, die als lokale Adresse der PPP-Schnittstellen verwendet wird.

IPsec konfigurieren

set vpn ipsec interface eth0
set vpn l2tp remote-access ipsec-settings authentication mode pre-shared-secret
set vpn l2tp remote-access ipsec-settings authentication pre-shared-secret secret
set vpn ipsec interface <INTERFACE>

Verwenden Sie diesen Befehl, um die IPsec-Schnittstelle zu definieren.

set vpn l2tp remote-access ipsec-settings authentication mode <pre-shared-secret | x509>

Legt den Modus für die IPsec-Authentifizierung zwischen VyOS und L2TP-Clients fest.

set vpn l2tp remote-access ipsec-settings authentication pre-shared-secret <secret>

Legt einen vordefinierten gemeinsamen Geheimnistext fest.

Wenn auf Ihrer externen Schnittstelle eine lokale Firewall-Richtlinie aktiviert ist, müssen Sie die folgenden Ports erlauben:

  • UDP-Port 500 (IKE)

  • IP-Protokollnummer 50 (ESP)

  • UDP-Port 1701 für IPsec

Außerdem müssen die folgenden für NAT-Traversierung erlaubt werden (wenn der VPN-Client NAT detektiert, wird ESP in UDP für NAT-Traversierung gekapselt):

  • UDP-Port 4500 (NAT-T)

Beispiel:

set firewall ipv4 name OUTSIDE-LOCAL rule 40 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 40 protocol 'esp'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 destination port '500'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 protocol 'udp'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 destination port '4500'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 protocol 'udp'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 destination port '1701'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 ipsec 'match-ipsec'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 protocol 'udp'

Um den Zugriff von VPN-Clients über Ihre externe Adresse zu ermöglichen, ist eine NAT-Regel erforderlich:

set nat source rule 110 outbound-interface name 'eth0'
set nat source rule 110 source address '192.168.255.0/24'
set nat source rule 110 translation address masquerade

RADIUS-Authentifizierung konfigurieren

Um RADIUS-basierte Authentifizierung zu aktivieren, muss der Authentifizierungsmodus innerhalb der Konfiguration geändert werden. Vorhandene Einstellungen wie lokale Benutzer existieren weiterhin in der Konfiguration, jedoch werden sie nicht verwendet, wenn der Modus von local auf radius geändert wurde. Sobald der Modus wieder auf local geändert wird, werden alle lokalen Konten erneut verwendet.

set vpn l2tp remote-access authentication mode radius
set vpn l2tp remote-access authentication radius server <server> key <secret>

Konfiguriert den RADIUS <server> und seinen erforderlichen gemeinsamen <secret> für die Kommunikation mit dem RADIUS-Server.

Da der RADIUS-Server ein einziger Ausfallpunkt sein kann, können mehrere RADIUS-Server eingerichtet werden und werden anschließend nacheinander verwendet. Zum Beispiel:

set vpn l2tp remote-access authentication radius server 10.0.0.1 key 'foo'
set vpn l2tp remote-access authentication radius server 10.0.0.2 key 'foo'

Hinweis

Einige RADIUS-Server verwenden eine Zugriffssteuerungsliste, die Anfragen erlaubt oder ablehnt, stellen Sie sicher, dass Ihr VyOS-Router zur erlaubten Client-Liste hinzugefügt wird.

RADIUS-Quelladresse

Wenn Sie OSPF als Ihren IGP verwenden, verwenden Sie die am nächsten am RADIUS-Server angeschlossene Schnittstelle. Sie können alle ausgehenden RADIUS-Anfragen an eine einzelne Quell-IP-Adresse binden, z. B. die Loopback-Schnittstelle.

set vpn l2tp remote-access authentication radius source-address <address>

Quell-IPv4-Adresse, die bei allen RADIUS-Server-Abfragen verwendet wird.

Hinweis

Die source-address muss so konfiguriert werden, dass sie einer Schnittstelle entspricht. Best Practice wäre eine Loopback- oder Dummy-Schnittstelle.

Erweiterte RADIUS-Optionen

set vpn l2tp remote-access authentication radius server <server> port <port>

Konfiguriert den RADIUS <server> und seinen erforderlichen Port für Authentifizierungsanfragen.

set vpn l2tp remote-access authentication radius server <server> fail-time <time>

Markiert den RADIUS-Server für diese gegebene <time> Sekunden als offline.

set vpn l2tp remote-access authentication radius server <server> disable

Deaktiviert diesen RADIUS-Server vorübergehend.

set vpn l2tp remote-access authentication radius acct-timeout <timeout>

Zeitlimit zum Warten auf Antwort für Interim-Update-Pakete. (Standardwert 3 Sekunden)

set vpn l2tp remote-access authentication radius dynamic-author server <address>

Gibt die IP-Adresse für den Dynamic Authorization Extension Server (DM/CoA) an. Diese IP muss auf irgendeiner VyOS-Schnittstelle existieren oder es kann 0.0.0.0 sein.

set vpn l2tp remote-access authentication radius dynamic-author port <port>

UDP-Port für Dynamic Authorization Extension Server (DM/CoA)

set vpn l2tp remote-access authentication radius dynamic-author key <secret>

Geheimnis für Dynamic Authorization Extension Server (DM/CoA)

set vpn l2tp remote-access authentication radius max-try <number>

Maximale Anzahl Versuche, Access-Request/Accounting-Request-Anfragen zu senden

set vpn l2tp remote-access authentication radius timeout <timeout>

Zeitlimit zum Warten auf Antwort vom Server (Sekunden)

set vpn l2tp remote-access authentication radius nas-identifier <identifier>

Wert, der an den RADIUS-Server im NAS-Identifier-Attribut gesendet wird und in DM/CoA-Anfragen übereinstimmen muss.

set vpn l2tp remote-access authentication radius nas-ip-address <address>

Wert, der an den RADIUS-Server im NAS-IP-Address-Attribut gesendet wird und in DM/CoA-Anfragen übereinstimmen muss. Auch DM/CoA-Server bindet sich an diese Adresse.

set vpn l2tp remote-access authentication radius source-address <address>

Quell-IPv4-Adresse, die bei allen RADIUS-Server-Abfragen verwendet wird.

set vpn l2tp remote-access authentication radius rate-limit attribute <attribute>

Gibt an, welches RADIUS-Server-Attribut die Rate-Limit-Information enthält. Das Standardattribut ist Filter-Id.

Hinweis

Wenn Sie ein benutzerdefiniertes RADIUS-Attribut festlegen, müssen Sie es auf beiden Dictionaries auf dem RADIUS-Server und Client definieren.

set vpn l2tp remote-access authentication radius rate-limit enable

Ermöglicht Bandbreitensteuerung über RADIUS.

set vpn l2tp remote-access authentication radius rate-limit vendor

Gibt das Herstellerdictionary an. Dieses Dictionary muss in /usr/share/accel-ppp/radius vorhanden sein.

Empfangene RADIUS-Attribute haben Priorität gegenüber Parametern, die innerhalb der CLI-Konfiguration definiert sind, siehe unten für weitere Informationen.

Client-IP-Adressen durch RADIUS zuweisen

Wenn der RADIUS-Server das Attribut Framed-IP-Address sendet, wird diese IP-Adresse dem Client zugewiesen und der Parameter default-pool innerhalb der CLI-Konfiguration wird ignoriert.

Wenn der RADIUS-Server das Attribut Framed-Pool sendet, wird die IP-Adresse aus einem vordefinierten IP-Pool zugewiesen, dessen Name dem Attributwert entspricht.

Wenn der RADIUS-Server das Attribut Stateful-IPv6-Address-Pool sendet, wird die IPv6-Adresse aus einem vordefinierten IPv6-Pool prefix zugewiesen, dessen Name dem Attributwert entspricht.

Wenn der RADIUS-Server das Attribut Delegated-IPv6-Prefix-Pool sendet, wird ein IPv6-Delegationspräfix aus einem vordefinierten IPv6-Pool delegate zugewiesen, dessen Name dem Attributwert entspricht.

Hinweis

Stateful-IPv6-Address-Pool und Delegated-IPv6-Prefix-Pool sind in RFC6911 definiert. Wenn sie in Ihrem RADIUS-Server nicht definiert sind, fügen Sie neue Dictionary hinzu.

Die Schnittstelle des Clients kann über einen RADIUS Access-Accept-Paket in einen VRF-Kontext versetzt werden oder über RADIUS CoA geändert werden. Accel-VRF-Name wird dafür verwendet. Dies ist ein benutzerdefiniertes ACCEL-PPP-Attribut. Definieren Sie es auf Ihrem RADIUS-Server.

Benennung der Clientschnittstellen durch RADIUS ändern

Wenn der RADIUS-Server das Attribut NAS-Port-Id verwendet, werden die PPP-Tunnel umbenannt.

Hinweis

Der Wert des Attributs NAS-Port-Id muss weniger als 16 Zeichen lang sein, andernfalls wird die Schnittstelle nicht umbenannt.

LNS (L2TP Network Server) konfigurieren

LNS werden oft verwendet, um sich mit einem LAC (L2TP Access Concentrator) zu verbinden.

set vpn l2tp remote-access lns host-name <hostname>

Wird an den Client (LAC) im Host-Name-Attribut gesendet

set vpn l2tp remote-access lns shared-secret <secret>

Tunnel-Passwort, das zur Authentifizierung des Clients (LAC) verwendet wird

Um die Verwendung von LNS zu erklären, folgen Sie unserem Blueprint PPPoE über L2TP.

IPv6

set vpn l2tp remote-access ppp-options ipv6 <require | prefer | allow | deny>

Legt die Präferenz für die IPv6-Verhandlung fest.

  • require - IPv6-Verhandlung erfordern

  • prefer - Client nach IPv6-Verhandlung fragen, nicht fehlschlagen, wenn er ablehnt

  • allow - IPv6 nur dann verhandeln, wenn der Client darum bittet (Standardwert)

  • deny - IPv6 nicht verhandeln (Standardwert)

set vpn l2tp remote-access client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Verwenden Sie diesen Befehl, um den IPv6-Adresspool zu setzen, aus dem ein L2TP-Client eine IPv6-Präfix von Ihrer definierten Länge (Maske) erhält, um das L2TP-Endgerät auf ihrer Seite zu beenden. Die Maske kann zwischen 48 und 128 Bit lang sein, der Standardwert ist 64.

set vpn l2tp remote-access client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Verwenden Sie diesen Befehl, um DHCPv6 Prefix Delegation (RFC3633) auf L2TP zu konfigurieren. Sie müssen Ihren IPv6-Pool und die Länge des Delegationspräfixes festlegen. Aus dem definierten IPv6-Pool geben Sie Netzwerke der definierten Länge (Delegationspräfix) aus. Die Länge des Delegationspräfixes kann zwischen 32 und 64 Bit lang sein.

set vpn l2tp remote-access default-ipv6-pool <IPv6-POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des Standard-IPv6-Adresspools zu definieren.

set vpn l2tp remote-access ppp-options ipv6 allow
set vpn l2tp remote-access client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn l2tp remote-access client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn l2tp remote-access default-ipv6-pool IPv6-POOL

Erweiterte IPv6-Optionen

set vpn l2tp remote-access ppp-options ipv6-accept-peer-interface-id

Peer-Interface-Identifikator akzeptieren. Standardmäßig ist dies nicht definiert.

set vpn l2tp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Legt fest, ob ein fester oder zufälliger Interface-Identifikator für IPv6 verwendet wird. Der Standard ist fest.

  • random - Zufälliger Interface-Identifikator für IPv6

  • x:x:x:x - Interface-Identifikator für IPv6 angeben

set vpn l2tp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Legt den Peer-Interface-Identifikator für IPv6 fest. Der Standard ist fest.

  • random - Zufälliger Interface-Identifikator für IPv6

  • x:x:x:x - Interface-Identifikator für IPv6 angeben

  • ipv4-addr - Interface-Identifikator aus IPv4-Adresse berechnen.

  • calling-sid - Interface-Identifikator aus calling-station-id berechnen.

Skripting

set vpn l2tp remote-access extended-scripts on-change <path_to_script>

Skript, das ausgeführt wird, wenn die Sitzungsschnittstelle durch RADIUS CoA-Behandlung geändert wird

set vpn l2tp remote-access extended-scripts on-down <path_to_script>

Skript, das ausgeführt wird, wenn die Sitzungsschnittstelle beendet wird

set vpn l2tp remote-access extended-scripts on-pre-up <path_to_script>

Skript, das vor dem Hochfahren der Sitzungsschnittstelle ausgeführt wird

set vpn l2tp remote-access extended-scripts on-up <path_to_script>

Skript, das ausgeführt wird, wenn die Sitzungsschnittstelle vollständig konfiguriert und gestartet ist

Erweiterte Optionen

Erweiterte Authentifizierungs-Optionen

set vpn l2tp remote-access authentication local-users username <user> disable

Deaktiviert das <user> Konto.

set vpn l2tp remote-access authentication local-users username <user> static-ip <address>

Weist eine statische IP-Adresse dem <user> Konto zu.

set vpn l2tp remote-access authentication local-users username <user> rate-limit download <bandwidth>

Limitiert die Download-Bandbreite für <user> auf <bandwidth> kbit/s.

set vpn l2tp remote-access authentication local-users username <user> rate-limit upload <bandwidth>

Limitiert die Upload-Bandbreite für <user> auf <bandwidth> kbit/s

set vpn l2tp remote-access authentication protocols <pap | chap | mschap | mschap-v2>

Verlangt, dass der Peer sich mit einem der folgenden Protokolle authentifiziert: pap, chap, mschap, mschap-v2.

Erweiterte Client-IP-Pool-Optionen

set vpn l2tp remote-access client-ip-pool <POOL-NAME> next-pool <NEXT-POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des nächsten Adresspools zu definieren.

Erweiterte PPP-Optionen

set vpn l2tp remote-access ppp-options disable-ccp

Deaktiviert das Compression Control Protocol (CCP). CCP ist standardmäßig aktiviert.

set vpn l2tp remote-access ppp-options interface-cache <number>

Legt die Anzahl der zu cachenden Schnittstellen fest. Dies verhindert, dass Schnittstellen gelöscht werden, sobald die entsprechende Sitzung zerstört wird. Stattdessen werden Schnittstellen für spätere Verwendung in neuen Sitzungen gecached. Dies sollte die Rate der Erstellung/Löschung von Schnittstellen auf Kernel-Ebene reduzieren. Der Standardwert ist 0.

set vpn l2tp remote-access ppp-options ipv4 <require | prefer | allow | deny>

Legt die Präferenz für die IPv4-Verhandlung fest.

  • require - IPv4-Verhandlung erfordern

  • prefer - Client nach IPv4-Verhandlung fragen, nicht fehlschlagen, wenn er ablehnt

  • allow - IPv4 nur dann verhandeln, wenn der Client darum bittet (Standardwert)

  • deny - IPv4 nicht verhandeln

set vpn l2tp remote-access ppp-options lcp-echo-failure <number>

Definiert die maximale Anzahl <number> unbeantworteter Echo-Anfragen. Bei Erreichen des Werts <number> wird die Sitzung zurückgesetzt. Der Standardwert ist 3.

set vpn l2tp remote-access ppp-options lcp-echo-interval <interval>

Wenn dieser Option angegeben und größer als 0, sendet das PPP-Modul LCP Echo-Anfragen alle <interval> Sekunden. Der Standardwert ist 30.

set vpn l2tp remote-access ppp-options lcp-echo-timeout

Gibt die Zeit in Sekunden an, um auf beliebige Peer-Aktivität zu warten. Wenn diese Option angegeben wird, wird adaptive LCP Echo-Funktion aktiviert und „lcp-echo-failure“ wird nicht verwendet. Der Standardwert ist 0.

set vpn l2tp remote-access ppp-options min-mtu <number>

Definiert das minimale akzeptable MTU. Wenn ein Client versucht, ein MTU zu verhandeln, das kleiner als dieses ist, wird es NAKed und getrennt, wenn es ein größeres MTU ablehnt. Der Standardwert ist 100.

set vpn l2tp remote-access ppp-options mppe <require | prefer | deny>

Legt die MPPE-Verhandlungspräferenz fest.

  • require - Client nach MPPE fragen, falls er ablehnt, Verbindung trennen

  • prefer - Client nach MPPE fragen, falls er ablehnt, nicht fehlschlagen. (Standardwert)

  • deny - MPPE ablehnen

Standardverhalten - Client nicht nach MPPE fragen, aber erlauben, wenn der Client will. Bitte beachten Sie, dass RADIUS diesen Parameter mit dem MS-MPPE-Encryption-Policy-Attribut überschreiben kann.

set vpn l2tp remote-access ppp-options mru <number>

Definiert das bevorzugte MRU. Standardmäßig ist es nicht definiert.

Erweiterte globale Optionen

set vpn l2tp remote-access description <description>

Setzen Sie die Beschreibung.

set vpn l2tp remote-access limits burst <value>

Burst-Zahl

set vpn l2tp remote-access limits connection-limit <value>

Maximale akzeptierte Verbindungsraten (z. B. 1/min, 60/sec)

set vpn l2tp remote-access limits timeout <value>

Timeout in Sekunden

set vpn l2tp remote-access mtu

Maximum Transmission Unit (MTU) (Standardwert: 1436)

set vpn l2tp remote-access max-concurrent-sessions

Maximale Anzahl gleichzeitiger Sitzungsstartversuche

set vpn l2tp remote-access name-server <address>

Die verbundenen Clients sollten <address> als DNS-Server verwenden. Dieser Befehl akzeptiert sowohl IPv4- als auch IPv6-Adressen. Bis zu zwei Nameserver können für IPv4, bis zu drei für IPv6 konfiguriert werden.

set vpn l2tp remote-access shaper fwmark <1-2147483647>

Match-Firewall-Mark-Wert

set vpn l2tp remote-access snmp master-agent

SNMP aktivieren

set vpn l2tp remote-access wins-server <address>

Windows Internet Name Service (WINS)-Server, die an den Client weitergeleitet werden
