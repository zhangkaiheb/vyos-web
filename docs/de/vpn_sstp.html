SSTP Server

SSTP ist eine Form des VPN-Tunnels, der ein Mittel zur Transport von PPP-Datenverkehr über einen SSL/TLS-Kanal bietet. SSL/TLS bietet Sicherheit auf Transportebene mit Schlüsselvereinbarung, Verschlüsselung und Integritätsprüfung des Datenverkehrs. Die Verwendung von SSL/TLS über TCP-Port 443 ermöglicht es SSTP, fast durch alle Firewalls und Proxyserver zu passieren, ausgenommen authentifizierte Web-Proxyserver.

SSTP ist für Linux, BSD und Windows verfügbar.

VyOS verwendet accel-ppp, um die SSTP-Server-Funktion bereitzustellen. Wir unterstützen sowohl lokale als auch RADIUS-Authentifizierung.

Da SSTP PPP über einen SSL/TLS-Kanal bereitstellt, wird entweder ein öffentlich signiertes Zertifikat oder ein privates PKI benötigt.

Konfigurieren des SSTP-Servers

Zertifikate

Verwenden Sie unser Dokumentationskapitel - PKI, um CA- und Serverzertifikate zu generieren und zu installieren

vyos@vyos:~$ generate pki ca install CA

vyos@vyos:~$ generate pki certificate sign CA install Server

Konfiguration

set vpn sstp authentication local-users username test password 'test'
set vpn sstp authentication mode 'local'
set vpn sstp client-ip-pool SSTP-POOL range '10.0.0.2-10.0.0.100'
set vpn sstp default-pool 'SSTP-POOL'
set vpn sstp gateway-address '10.0.0.1'
set vpn sstp ssl ca-certificate 'CA1'
set vpn sstp ssl certificate 'Server'
set vpn sstp authentication mode <local | radius>

Legen Sie den Authentifizierungsbackend fest. Der konfigurierte Authentifizierungsbackend wird für alle Abfragen verwendet.

  • radius: Alle Authentifizierungsanfragen werden durch einen konfigurierten RADIUS-Server verarbeitet.

  • local: Alle Authentifizierungsanfragen werden lokal verarbeitet.

set vpn sstp authentication local-users username <user> password <pass>

Erstellen Sie einen <user> für die lokale Authentifizierung auf diesem System. Das Passwort des Benutzers wird auf <pass> gesetzt.

set vpn sstp client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Verwenden Sie diesen Befehl, um den ersten IP-Adressbereich eines Adresspools zu definieren, der an SSTP-Clients vergeben wird. Wenn die Notation x.x.x.x-x.x.x.x verwendet wird, muss sie innerhalb eines /24-Subnetzes liegen. Wenn die Notation x.x.x.x/x verwendet wird, besteht die Möglichkeit, Host/Netzmaske zu setzen.

set vpn sstp default-pool <POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des Standardadresspools zu definieren.

set vpn sstp gateway-address <gateway>

Gibt eine einzelne <gateway> IP-Adresse an, die als lokale Adresse der PPP-Schnittstellen verwendet werden soll.

set vpn sstp ssl ca-certificate <file>

Name des installierten Zertifizierungsstellenzertifikats.

set vpn sstp ssl certificate <file>

Name des installierten Serverzertifikats.

Konfigurieren der RADIUS-Authentifizierung

Um die RADIUS-basierte Authentifizierung zu aktivieren, muss der Authentifizierungsmodus innerhalb der Konfiguration geändert werden. Vorherige Einstellungen wie lokale Benutzer existieren weiterhin in der Konfiguration, jedoch werden sie nicht verwendet, wenn der Modus vom lokalen zum RADIUS-Modus geändert wurde. Sobald er wieder auf lokal geändert wird, werden alle lokalen Konten erneut verwendet.

set vpn sstp authentication mode radius
set vpn sstp authentication radius server <server> key <secret>

Konfigurieren Sie den RADIUS <server> und seinen erforderlichen gemeinsamen <secret> für die Kommunikation mit dem RADIUS-Server.

Da der RADIUS-Server ein einzelner Ausfallpunkt ist, können mehrere RADIUS-Server eingerichtet werden und nacheinander verwendet werden. Zum Beispiel:

set vpn sstp authentication radius server 10.0.0.1 key 'foo'
set vpn sstp authentication radius server 10.0.0.2 key 'foo'

Hinweis

Einige RADIUS-Server verwenden eine Zugriffsliste, die Anfragen erlaubt oder verweigert, stellen Sie sicher, dass Ihr VyOS-Router zur erlaubten Clientliste hinzugefügt wird.

RADIUS-Quelladresse

Wenn Sie OSPF als Ihren IGP verwenden, verwenden Sie die Schnittstelle, die am nächsten am RADIUS-Server liegt. Sie können alle ausgehenden RADIUS-Anfragen an eine einzelne Quell-IP binden, z. B. die Loopback-Schnittstelle.

set vpn sstp authentication radius source-address <address>

Quell-IPv4-Adresse, die bei allen RADIUS-Server-Abfragen verwendet wird.

Hinweis

Die source-address muss so konfiguriert sein, dass sie einer Schnittstelle entspricht. Best Practice wäre eine Loopback- oder Dummy-Schnittstelle.

Erweiterte RADIUS-Optionen

set vpn sstp authentication radius server <server> port <port>

Konfigurieren Sie den RADIUS <server> und seinen erforderlichen Port für Authentifizierungsanfragen.

set vpn sstp authentication radius server <server> fail-time <time>

Markieren Sie den RADIUS-Server für diese gegebene <time> Sekunden als offline.

set vpn sstp authentication radius server <server> disable

Temporär deaktivieren Sie diesen RADIUS-Server.

set vpn sstp authentication radius acct-timeout <timeout>

Zeitlimit, um Antwort auf Interim-Update-Pakete zu warten. (Standard 3 Sekunden)

set vpn sstp authentication radius dynamic-author server <address>

Gibt die IP-Adresse des Dynamic Authorization Extension Servers (DM/CoA) an. Diese IP muss auf irgendeiner VyOS-Schnittstelle vorhanden sein oder kann 0.0.0.0 sein.

set vpn sstp authentication radius dynamic-author port <port>

UDP-Port für Dynamic Authorization Extension Server (DM/CoA)

set vpn sstp authentication radius dynamic-author key <secret>

Geheimnis für Dynamic Authorization Extension Server (DM/CoA)

set vpn sstp authentication radius max-try <number>

Maximale Anzahl von Versuchen, um Access-Request/Accounting-Request-Anfragen zu senden

set vpn sstp authentication radius timeout <timeout>

Zeitlimit, um Antwort vom Server zu warten (Sekunden)

set vpn sstp authentication radius nas-identifier <identifier>

Wert, der an den RADIUS-Server im NAS-Identifier-Attribut gesendet wird und in DM/CoA-Anfragen übereinstimmen muss.

set vpn sstp authentication radius nas-ip-address <address>

Wert, der an den RADIUS-Server im NAS-IP-Address-Attribut gesendet wird und in DM/CoA-Anfragen übereinstimmen muss. Auch DM/CoA-Server bindet sich an diese Adresse.

set vpn sstp authentication radius source-address <address>

Quell-IPv4-Adresse, die bei allen RADIUS-Server-Abfragen verwendet wird.

set vpn sstp authentication radius rate-limit attribute <attribute>

Bestimmt, welches RADIUS-Serverattribut die Rate-Limit-Information enthält. Das Standardattribut ist Filter-Id.

Hinweis

Wenn Sie ein benutzerdefiniertes RADIUS-Attribut festlegen, müssen Sie es auf beiden Seiten des RADIUS-Servers und Clients definieren.

set vpn sstp authentication radius rate-limit enable

Ermöglicht Bandbreitensteuerung über RADIUS.

set vpn sstp authentication radius rate-limit vendor

Bestimmt das Herstellerdictionary. Dieses Dictionary muss im /usr/share/accel-ppp/radius vorhanden sein.

Empfangene RADIUS-Attribute haben Priorität vor Parametern, die innerhalb der CLI-Konfiguration definiert sind, siehe Erklärung unten.

Client-IP-Adressen durch RADIUS zuweisen

Wenn der RADIUS-Server das Attribut Framed-IP-Address sendet, wird diese IP-Adresse dem Client zugewiesen und das Option default-pool innerhalb der CLI-Konfiguration wird ignoriert.

Wenn der RADIUS-Server das Attribut Framed-Pool sendet, wird die IP-Adresse aus einem vordefinierten IP-Pool zugewiesen, dessen Name dem Attributwert entspricht.

Wenn der RADIUS-Server das Attribut Stateful-IPv6-Address-Pool sendet, wird die IPv6-Adresse aus einem vordefinierten IPv6-Pool prefix zugewiesen, dessen Name dem Attributwert entspricht.

Wenn der RADIUS-Server das Attribut Delegated-IPv6-Prefix-Pool sendet, wird ein IPv6-Delegationspräfix aus einem vordefinierten IPv6-Pool delegate zugewiesen, dessen Name dem Attributwert entspricht.

Hinweis

Stateful-IPv6-Address-Pool und Delegated-IPv6-Prefix-Pool sind in RFC6911 definiert. Wenn sie in Ihrem RADIUS-Server nicht definiert sind, fügen Sie neue Dictionary hinzu.

Der Client-Interface kann über einen RADIUS Access-Accept-Paket in einen VRF-Kontext versetzt werden oder über RADIUS CoA geändert werden. Accel-VRF-Name wird dafür verwendet. Dies ist ein benutzerdefiniertes ACCEL-PPP-Attribut. Definieren Sie es in Ihrem RADIUS-Server.

Client-Interfaces durch RADIUS umbenennen

Wenn der RADIUS-Server das Attribut NAS-Port-Id verwendet, werden die PPP-Tunnel umbenannt.

Hinweis

Der Wert des Attributs NAS-Port-Id muss weniger als 16 Zeichen sein, andernfalls wird die Schnittstelle nicht umbenannt.

IPv6

set vpn sstp ppp-options ipv6 <require | prefer | allow | deny>

Gibt die Präferenz für die IPv6-Verhandlung an.

  • require - Erfordert IPv6-Verhandlung

  • prefer - Fragt den Client nach IPv6-Verhandlung an, scheitert nicht, wenn er ablehnt

  • allow - Verhandeln Sie IPv6 nur, wenn der Client darum bittet

  • deny - IPv6 nicht verhandeln (Standardwert)

set vpn sstp client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Verwenden Sie diesen Befehl, um den IPv6-Adresspool zu setzen, aus dem ein SSTP-Client eine IPv6-Präfix von Ihrer definierten Länge (Maske) erhält, um den SSTP-Endpunkt auf ihrer Seite zu beenden. Die Maske kann zwischen 48 und 128 Bit lang sein, der Standardwert ist 64.

set vpn sstp client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Verwenden Sie diesen Befehl, um DHCPv6 Prefix Delegation (RFC3633) auf SSTP zu konfigurieren. Sie müssen Ihren IPv6-Pool und die Länge des Delegationspräfixes festlegen. Aus dem definierten IPv6-Pool geben Sie Netzwerke der definierten Länge (Delegationspräfix) aus. Die Länge des Delegationspräfixes kann zwischen 32 und 64 Bit lang sein.

set vpn sstp default-ipv6-pool <IPv6-POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des Standard-IPv6-Adresspools zu definieren.

set vpn sstp ppp-options ipv6 allow
set vpn sstp client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn sstp client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn sstp default-ipv6-pool IPv6-POOL

Erweiterte IPv6-Optionen

set vpn sstp ppp-options ipv6-accept-peer-interface-id

Peer-Interface-Identifikator akzeptieren. Standardmäßig ist dies nicht definiert.

set vpn sstp ppp-options ipv6-interface-id <random | x:x:x:x>

Gibt an, ob ein fester oder zufälliger Interface-Identifikator für IPv6 verwendet wird. Der Standard ist fest.

  • random - Zufälliger Interface-Identifikator für IPv6

  • x:x:x:x - Geben Sie den Interface-Identifikator für IPv6 an

set vpn sstp ppp-options ipv6-interface-id <random | x:x:x:x>

Gibt den Peer-Interface-Identifikator für IPv6 an. Der Standard ist fest.

  • random - Zufälliger Interface-Identifikator für IPv6

  • x:x:x:x - Geben Sie den Interface-Identifikator für IPv6 an

  • ipv4-addr - Berechnen Sie den Interface-Identifikator aus der IPv4-Adresse.

  • calling-sid - Berechnen Sie den Interface-Identifikator aus dem calling-station-id.

Skripting

set vpn sstp extended-scripts on-change <path_to_script>

Skript, das ausgeführt wird, wenn die Sitzungsschnittstelle durch RADIUS CoA geändert wird

set vpn sstp extended-scripts on-down <path_to_script>

Skript, das ausgeführt wird, wenn die Sitzungsschnittstelle beendet wird

set vpn sstp extended-scripts on-pre-up <path_to_script>

Skript, das vor dem Hochfahren der Sitzungsschnittstelle ausgeführt wird

set vpn sstp extended-scripts on-up <path_to_script>

Skript, das ausgeführt wird, wenn die Sitzungsschnittstelle vollständig konfiguriert und gestartet wurde

Erweiterte Optionen

Erweiterte Authentifizierungs-Optionen

set vpn sstp authentication local-users username <user> disable

Deaktivieren Sie das <user> Konto.

set vpn sstp authentication local-users username <user> static-ip <address>

Weisen Sie eine statische IP-Adresse dem <user> Konto zu.

set vpn sstp authentication local-users username <user> rate-limit download <bandwidth>

Limitieren Sie die Download-Bandbreite für <user> auf <bandwidth> kbit/s.

set vpn sstp authentication local-users username <user> rate-limit upload <bandwidth>

Limitieren Sie die Upload-Bandbreite für <user> auf <bandwidth> kbit/s.

set vpn sstp authentication protocols <pap | chap | mschap | mschap-v2>

Fordern Sie den Peers auf, sich mit einem der folgenden Protokolle zu authentifizieren: pap, chap, mschap, mschap-v2.

Erweiterte Client-IP-Pool-Optionen

set vpn sstp client-ip-pool <POOL-NAME> next-pool <NEXT-POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des nächsten Adresspools zu definieren.

Erweiterte PPP-Optionen

set vpn sstp ppp-options disable-ccp

Deaktivieren Sie das Compression Control Protocol (CCP). CCP ist standardmäßig aktiviert.

set vpn sstp ppp-options interface-cache <number>

Gibt die Anzahl der Schnittstellen an, die zwischengespeichert werden. Dies verhindert, dass Schnittstellen gelöscht werden, sobald die entsprechende Sitzung zerstört wird. Stattdessen werden Schnittstellen für spätere Verwendung in neuen Sitzungen zwischengespeichert. Dies sollte die Rate der Kernel-Erstellung/Löschung von Schnittstellen reduzieren. Der Standardwert ist 0.

set vpn sstp ppp-options ipv4 <require | prefer | allow | deny>

Gibt die Präferenz für die IPv4-Verhandlung an.

  • require - Erfordert IPv4-Verhandlung

  • prefer - Fragt den Client nach IPv4-Verhandlung an, scheitert nicht, wenn er ablehnt

  • allow - Verhandeln Sie IPv4 nur, wenn der Client darum bittet (Standardwert)

  • deny - IPv4 nicht verhandeln

set vpn sstp ppp-options lcp-echo-failure <number>

Definiert die maximale <number> Anzahl unbeantworteter Echoanfragen. Bei Erreichen des Werts <number> wird die Sitzung zurückgesetzt. Der Standardwert ist 3.

set vpn sstp ppp-options lcp-echo-interval <interval>

Wenn dieser Option angegeben und größer als 0 ist, sendet das PPP-Modul LCP Echo-Anfragen alle <interval> Sekunden. Der Standardwert ist 30.

set vpn sstp ppp-options lcp-echo-timeout

Gibt die Zeit in Sekunden an, um auf jede Peersaktivität zu warten. Wenn diese Option angegeben wird, schaltet sie adaptive LCP Echo-Funktion ein und „lcp-echo-failure“ wird nicht verwendet. Der Standardwert ist 0.

set vpn sstp ppp-options min-mtu <number>

Definiert die minimale akzeptable MTU. Wenn ein Client versucht, eine MTU zu verhandeln, die kleiner ist als diese, wird sie NAKed und getrennt, wenn sie eine größere MTU ablehnt. Der Standardwert ist 100.

set vpn sstp ppp-options mppe <require | prefer | deny>

Gibt die MPPE-Verhandlungspräferenz an.

  • require - Fragt den Client nach MPPE an, falls er ablehnt, trennen Sie die Verbindung

  • prefer - Fragt den Client nach MPPE an, falls er ablehnt, nicht fehlschlagen. (Standardwert)

  • deny - MPPE ablehnen

Standardverhalten - fragen Sie den Client nicht nach MPPE, aber erlauben Sie es, wenn der Client es möchte. Beachten Sie, dass RADIUS dieses Option durch das MS-MPPE-Encryption-Policy-Attribut überschreiben kann.

set vpn sstp ppp-options mru <number>

Definiert die bevorzugte MRU. Standardmäßig ist sie nicht definiert.

Erweiterte globale Optionen

set vpn sstp description <description>

Setzen Sie die Beschreibung.

set vpn sstp limits burst <value>

Burst-Zahl

set vpn sstp limits connection-limit <value>

Maximale akzeptierte Verbindungsrate (z. B. 1/min, 60/sec)

set vpn sstp limits timeout <value>

Timeout in Sekunden

set vpn sstp mtu

Maximum Transmission Unit (MTU) (Standard: 1500)

set vpn sstp max-concurrent-sessions

Maximale Anzahl gleichzeitiger Sitzungsstartversuche

set vpn sstp name-server <address>

Verwenden Sie <address> als DNS-Server für verbundene Clients. Dieser Befehl akzeptiert sowohl IPv4- als auch IPv6-Adressen. Bis zu zwei Nameserver können für IPv4 konfiguriert werden, bis zu drei für IPv6.

set vpn sstp shaper fwmark <1-2147483647>

Match Firewall Mark Wert

set vpn sstp snmp master-agent

SNMP aktivieren

set vpn sstp wins-server <address>

Windows Internet Name Service (WINS)-Server, die an den Client weitergeleitet werden

set vpn sstp host-name <hostname>

Wenn dieser Option gegeben wird, werden nur SSTP-Verbindungen zu dem angegebenen Host und mit dem gleichen TLS SNI zugelassen.

Konfigurieren des SSTP-Clients

Nachdem Sie Ihren SSTP-Server eingerichtet haben, kommt die Zeit für einige grundlegende Tests. Der Linux-Client, der für die Tests verwendet wird, heißt sstpc. sstpc benötigt eine PPP-Konfigurations-/Peers-Datei.

Wenn Sie ein selbstsigniertes Zertifikat verwenden, vergessen Sie nicht, die CA auf der Clientseite zu installieren.

Die folgende PPP-Konfiguration testet MSCHAP-v2:

$ cat /etc/ppp/peers/vyos
usepeerdns
#require-mppe
#require-pap
require-mschap-v2
noauth
lock
refuse-pap
refuse-eap
refuse-chap
refuse-mschap
#refuse-mschap-v2
nobsdcomp
nodeflate
debug

Sie können nun mit dem folgenden Befehl „dialen“: sstpc --log-level 4 --log-stderr --user vyos --password vyos vpn.example.com -- call vyos.
