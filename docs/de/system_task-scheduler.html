Aufgabenplaner

Der Aufgabenplaner ermöglicht es Ihnen, Aufgaben zu einem bestimmten Zeitplan auszuführen. Er verwendet UNIX cron.

Hinweis

Alle Skripte, die auf diese Weise ausgeführt werden, werden als Root-Benutzer ausgeführt - dies kann gefährlich sein. Zusammen mit Befehlsscripting kann dies zur Automatisierung (wiederholten) Konfiguration verwendet werden.

set system task-scheduler task <task> interval <interval>

Geben Sie den Zeitraum an, in dem <task> ausgeführt werden soll. Der Zeitraum wird als Zahl mit einem der folgenden Suffixes angegeben:

  • none - Ausführungsintervall in Minuten

  • m - Ausführungsintervall in Minuten

  • h - Ausführungsintervall in Stunden

  • d - Ausführungsintervall in Tagen

Hinweis

Wenn das Suffix fehlt, werden Minuten impliziert.

set system task-scheduler task <task> crontab-spec <spec>

Legen Sie die Ausführungszeit im üblichen Cron-Zeitformat fest. Ein Cron-<spec> von 30 */6 * * * führt <task> um 30 Minuten nach jeder 6. Stunde aus.

set system task-scheduler task <task> executable path <path>

Geben Sie den absoluten <path> des Skripts an, das ausgeführt wird, wenn <task> ausgeführt wird.

set system task-scheduler task <task> executable arguments <args>

Argumente, die an das ausführbare Programm übergeben werden.
