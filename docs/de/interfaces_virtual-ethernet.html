Virtual Ethernet

Virtual Ethernet (veth) interfaces are software-based interfaces that operate in pairs, creating a tunnel between each other. Traffic transmitted into one interface of the pair (e.g., veth0) is delivered directly to its peer interface (e.g., veth1).

Veth interfaces are commonly used to connect network namespaces or VRFs, but they can also function as standalone virtual network interfaces.

Hinweis

Veth interfaces must be created in pairs, where each interface acts as the peer of the other.

Konfiguration

Gemeinsame Schnittstellenkonfiguration

set interfaces virtual-ethernet <interface> address <address | dhcp | dhcpv6>

Konfigurieren Sie die Schnittstelle mit einer oder mehreren IP-Adressen.

Die folgenden Optionen sind verfügbar:

  • address: Weisen Sie der Schnittstelle eine oder mehrere IPv4- oder IPv6-Adressen zu. Zum Beispiel verwenden Sie 192.0.2.1/24 für IPv4 oder 2001:db8::1/64 für IPv6.

  • dhcp: Die Schnittstelle erhält eine IPv4-Adresse von einem DHCP-Server im gleichen Netzsegment.

  • dhcpv6: Die Schnittstelle erhält eine IPv6-Adresse von einem DHCPv6-Server im gleichen Netzsegment.

Hinweis

Wenn die Schnittstelle eine IPv4-Adresse über DHCP erhält und spezifische Anpassungen vor/ nach Erhalt der IP-Adresse erforderlich sind, verwenden Sie die bereitgestellten Hook-Skripte:

  • /config/scripts/dhcp-client/pre-hooks.d/

  • /config/scripts/dhcp-client/post-hooks.d/

Beispiel:

set interfaces virtual-ethernet veth0 address 192.0.2.1/24
set interfaces virtual-ethernet veth0 address 2001:db8::1/64
set interfaces virtual-ethernet veth0 address dhcp
set interfaces virtual-ethernet veth0 address dhcpv6
set interfaces virtual-ethernet <interface> description <description>

Konfigurieren Sie eine klare, beschreibende Alias für die Schnittstelle.

Dieser Alias erscheint im Befehl show interfaces und in SNMP-basierten Überwachungstools.

Beispiel:

set interfaces virtual-ethernet veth0 description 'This is an interface running on VyOS.'

VLAN

Reguläre VLANs (802.1q)

IEEE 802.1q, oft als Dot1q bezeichnet, ist der Industriestandard für die Implementierung von VLANs auf Ethernet-Netzwerken. Es definiert VLAN-Tags für Ethernet-Frames und legt Verfahren für Brücken und Switches fest. Der Standard enthält auch Qualitäts-of-Service-Priorisierung (IEEE 802.1p) und definiert das Generische Attributregistrierungsprotokoll.

VLAN-konforme Netzsegments (d.h. IEEE 802.1q konform) verwenden VLAN-Tags. Wenn ein Frame in ein solches Segment eingeht, wird ein Tag hinzugefügt, um die VLAN-Zugehörigkeit anzugeben. Jeder Frame kann nur einem VLAN angehören. Wenn ein Frame ohne Tag eingeht, wird angenommen, dass er dem Standard-VLAN angehört.

IEEE 802.1, ein Arbeitskreis der IEEE 802-Standardskommission, hat den Standard entwickelt und verfeinert ihn weiter. Eine bemerkenswerte Überarbeitung ist 802.1Q-2014, die IEEE 802.1aq (Shortest Path Bridging) und viel von IEEE 802.1d integriert.

In VyOS werden 802.1q VLAN-Schnittstellen als virtuelle Subschnittstellen dargestellt, die als vif bezeichnet werden.

set interfaces virtual-ethernet <interface> vif <vlan-id>

Konfigurieren Sie eine VLAN-Schnittstelle mit einer eindeutigen VLAN-ID.

VLAN-ID identifiziert ein bestimmtes VLAN und reicht von 0 bis 4094.

Sie können mehrere VLAN-Schnittstellen auf einer physischen Schnittstelle konfigurieren.

Hinweis

Nur 802.1Q-getaggte Pakete werden auf Ethernet vifs akzeptiert.

set interfaces virtual-ethernet <interface> vif <vlan-id> address <address | dhcp | dhcpv6>

Konfigurieren Sie die Schnittstelle mit einer oder mehreren IP-Adressen.

Die folgenden Optionen sind verfügbar:

  • address: Weisen Sie der Schnittstelle eine oder mehrere IPv4- oder IPv6-Adressen zu. Zum Beispiel verwenden Sie 192.0.2.1/24 für IPv4 oder 2001:db8::1/64 für IPv6.

  • dhcp: Die Schnittstelle erhält eine IPv4-Adresse von einem DHCP-Server im gleichen Netzsegment.

  • dhcpv6: Die Schnittstelle erhält eine IPv6-Adresse von einem DHCPv6-Server im gleichen Netzsegment.

Hinweis

Wenn die Schnittstelle eine IPv4-Adresse über DHCP erhält und spezifische Anpassungen vor/ nach Erhalt der IP-Adresse erforderlich sind, verwenden Sie die bereitgestellten Hook-Skripte:

  • /config/scripts/dhcp-client/pre-hooks.d/

  • /config/scripts/dhcp-client/post-hooks.d/

Beispiel:

set interfaces virtual-ethernet veth0 vif 10 address 192.0.2.1/24
set interfaces virtual-ethernet veth0 vif 10 address 2001:db8::1/64
set interfaces virtual-ethernet veth0 vif 10 address dhcp
set interfaces virtual-ethernet veth0 vif 10 address dhcpv6
set interfaces virtual-ethernet <interface> vif <vlan-id> description <description>

Konfigurieren Sie eine klare, beschreibende Alias für die Schnittstelle.

Dieser Alias erscheint im Befehl show interfaces und in SNMP-basierten Überwachungstools.

Beispiel:

set interfaces virtual-ethernet veth0 vif 10 description 'This is an interface running on VyOS.'
set interfaces virtual-ethernet <interface> vif <vlan-id> disable

Deaktivieren Sie die Schnittstelle.

Die Schnittstelle wird auf den administrativ heruntergefahrenen Zustand (A/D) gesetzt.

Beispiel:

set interfaces virtual-ethernet veth0 vif 10 disable
set interfaces virtual-ethernet <interface> vif <vlan-id> disable-link-detect
