SSTP Client

SSTP transportiert PPP-Datenverkehr über eine SSL/TLS-Verbindung und bietet Transportebene Sicherheit durch Schlüsselvereinbarung, Verschlüsselung und Prüfung der Datenintegrität. Die Verwendung von SSL/TLS über TCP-Port 443 (standardmäßig, dieser Port kann geändert werden) ermöglicht es SSTP, fast alle Firewalls und Proxyserver zu passieren, mit Ausnahme authentifizierter Web-Proxys.

Hinweis

VyOS enthält einen integrierten SSTP-Server. Für weitere Informationen siehe SSTP Server.

Konfiguration

Allgemeine Schnittstellenkonfiguration

set interfaces sstpc <interface> description <description>

Konfigurieren Sie einen klaren, beschreibenden Alias für die Schnittstelle.

Dieser Alias erscheint im Befehl show interfaces und in SNMP-basierten Überwachungstools.

Beispiel:

set interfaces sstpc sstpc0 description 'This is an interface running on VyOS.'
set interfaces sstpc <interface> disable

Schalten Sie die Schnittstelle aus.

Die Schnittstelle wird auf den administrativ heruntergefahrenen (A/D) Zustand gesetzt.

Beispiel:

set interfaces sstpc sstpc0 disable
set interfaces sstpc <interface> mtu <mtu>

Konfigurieren Sie das MTU auf der Schnittstelle.

Dieser Wert definiert die größte Paketgröße in Bytes, die die Schnittstelle ohne Fragmentierung überträgt.

Beispiel:

set interfaces sstpc sstpc0 mtu 1600
set interfaces sstpc <interface> vrf <vrf>

Weisen Sie die Schnittstelle einer bestimmten VRF Instanz zu.

Siehe auch

Für Informationen zur Konfiguration einer VRF siehe den Abschnitt VRF.

Beispiel:

set interfaces sstpc sstpc0 vrf red

SSTP Client Optionen

set interfaces sstpc <interface> no-default-route

Einen IP-Adressantrag beim SSTP-Server ohne Installation einer Standardroute anfordern.

Beispiel:

set interfaces sstpc sstpc0 no-default-route

Hinweis

Eingeführt in VyOS 1.4, invertiert dieser Befehl die Logik des ehemaligen default-route CLI-Option.

set interfaces sstpc <interface> default-route-distance <distance>

Konfigurieren Sie die Entfernung für den Standardgateway, der vom SSTP-Server bereitgestellt wird.

Beispiel:

set interfaces sstpc sstpc0 default-route-distance 220
set interfaces sstpc <interface> no-peer-dns

Deaktivieren Sie die Installation der angegebenen DNS-Nameserver auf dem lokalen System.

set interfaces sstpc <interface> server <address>

Konfigurieren Sie die Remote-SSTP-Server-Adresse für die Clientverbindung.

Die Adresse kann entweder eine IP-Adresse oder ein FQDN sein.

set interfaces sstpc <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

Konfigurieren Sie das MSS , das in ausgehenden TCP SYN-Paketen auf der angegebenen Schnittstelle angeboten wird.

Durch das Einschränken des MSS-Werts in TCP SYN-Paketen weisen Sie die andere Seite an, keine Pakete größer als die angegebene Größe zu senden. Dies hilft, Verbindungsprobleme zu vermeiden, wenn PMTUD fehlschlägt.

Die folgenden Optionen sind verfügbar:

  • mss: Legt das MSS auf einen spezifischen Wert in Bytes fest.

  • clamp-mss-to-pmtu: Legt das MSS auf das MTU der Schnittstelle minus 40 Bytes für IPv4-Traffic (20 Bytes für den IPv4-Header und 20 Bytes für den TCP-Header) fest. Diese Option wird empfohlen, um den richtigen Wert automatisch einzustellen.

Hinweis

Eingeführt in VyOS 1.4, ersetzt dieser Befehl die ältere Syntax set firewall options interface <name> adjust-mss <value>.

set interfaces sstpc <interface> ip disable-forwarding

Konfigurieren Sie die Schnittstelle für Host- oder Router-Verhalten.

Wenn konfiguriert, wechselt die Schnittstelle in den Hostmodus und wird IPv4-Forwarding deaktiviert.

set interfaces sstpc <interface> ip source-validation <strict | loose | disable>

Konfigurieren Sie die Quell-IP-Adressenprüfung mithilfe von RPF auf dieser Schnittstelle gemäß RFC 3704.

Die folgenden Optionen sind verfügbar:

  • strict: Die Quell-IP-Adresse jedes eingehenden Pakets wird gegen die FIB überprüft. Wenn die Schnittstelle nicht der beste Weg zurück zu dieser Quelle ist, schlägt die Validierung fehl und das Paket wird gelöscht.

  • loose: Die Quell-IP-Adresse jedes eingehenden Pakets wird gegen die FIB überprüft. Wenn die Quell-IP-Adresse durch irgendeine Schnittstelle nicht erreichbar ist, schlägt die Validierung fehl.

  • disable: Es wird keine Quell-IP-Adressenprüfung durchgeführt. Alle eingehenden Pakete werden akzeptiert.

RFC 3704 empfiehlt, den strict-Modus zu aktivieren, um IP-Spoofing, wie z. B. DDoS-Angriffe, zu verhindern. Für asynchrone oder andere komplexe Routing-Szenarien verwenden Sie den loose-Modus.

Verbinden/Trennen

disconnect interface <interface>

Die angegebene Schnittstelle trennen.

connect interface <interface>

Session auf der angegebenen Schnittstelle initiieren.
