LLDP

LLDP ist ein herstellerneutraler Link-Layer-Protokoll im Internet-Protokoll-Suite, das von Netzwerkgeräten verwendet wird, um ihre Identität, Fähigkeiten und Nachbarn auf einem IEEE 802-Local-Area-Network, hauptsächlich kabelgebundenen Ethernet, zu bewerben. Das Protokoll wird offiziell vom IEEE als Station and Media Access Control Connectivity Discovery bezeichnet, wie in IEEE 802.1AB und IEEE 802.3-2012 Abschnitt 6 Klammer 79 festgelegt.

LLDP erfüllt Funktionen, die dem mehreren proprietären Protokollen ähnlich sind, wie z.B. CDP, FDP, NDP und LLTD.

Informationen, die mit LLDP gesammelt werden, werden im Gerät als MIB gespeichert und können mit SNMP abgefragt werden, wie in RFC 2922 spezifiziert. Die Topologie eines LLDP-fähigen Netzwerks kann durch Crawling der Hosts und Abfragen dieser Datenbank entdeckt werden. Informationen, die abgerufen werden können, umfassen:

  • Systemname und Beschreibung

  • Portname und Beschreibung

  • VLAN-Name

  • IP-Verwaltungsadresse

  • Systemfähigkeiten (Switching, Routing usw.)

  • MAC/PHY-Informationen

  • MDI-Strom

  • Link-Aggregation

Konfiguration

set service lldp

LLDP-Dienst aktivieren

set service lldp management-address <address>

Definieren Sie die IPv4/IPv6-Verwaltungsadresse, die über LLDP übertragen wird. Mehrere Adressen können definiert werden. Nur Adressen, die mit dem System verbunden sind, werden übertragen.

set service lldp interface <interface>

Aktivieren Sie die Übertragung von LLDP-Informationen auf dem gegebenen <interface>. Sie können auch sagen all hier, damit LLDP auf jedem Interface eingeschaltet wird.

set service lldp interface <interface> mode [disable|rx-tx|rx|tx]

Konfigurieren Sie den administrativen Status des gegebenen Ports.

Standardmäßig sind alle Ports auf rx-tx-Modus konfiguriert. Dies bedeutet, dass sie LLDP-Frames empfangen und senden können.

Im rx-Modus senden sie keine Frames. Im tx-Modus empfangen sie keine Frames. Im deaktivierten Modus werden keine Frames gesendet und alle eingehenden Frames werden verworfen.

set service lldp snmp

SNMP-Abfragen der LLDP-Datenbank aktivieren

set service lldp legacy-protocols <cdp|edp|fdp|sonmp>

Das gegebene Legacy-Protokoll auf diesem LLDP-Instanz aktivieren. Legacy-Protokolle umfassen:

  • cdp - CDP für Cisco-Router/Switches abhören

  • edp - EDP für Extreme-Router/Switches abhören

  • fdp - FDP für Foundry-Router/Switches abhören

  • sonmp - SONMP für Nortel-Router/Switches abhören

show lldp neighbors

Zeigt Informationen über alle über LLDP entdeckten Nachbarn an.
