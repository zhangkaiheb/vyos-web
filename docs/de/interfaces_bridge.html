Brücke

VyOS-Brücken verbinden Ethernet-Segmente, indem sie mehrere Schnittstellen in eine einzelne Brückenschnittstelle gruppieren, die als virtueller Software-Switch fungiert. Im Gegensatz zu Routern, die den Datenverkehr basierend auf Layer-3-IP-Adressen weiterleiten, arbeiten Brücken auf Layer 2 und leiten den Datenverkehr basierend auf MAC-Adressen weiter. Auf Layer 2 sind Brücken protokollunabhängig und leiten alle Ethernet-kapselten Datenverkehrsdaten transparent weiter, ob es sich um IPv4, IPv6 oder spezialisierte industrielle Protokolle handelt.

Diese Implementierung verwendet das Linux-Brückensubsystem, um einen Teil des ANSI/IEEE 802.1d-Standards für transparente Brücken und MAC-Adresstermittlung zu unterstützen.

Hinweis

STP ist in VyOS standardmäßig deaktiviert und muss bei Bedarf explizit aktiviert werden. Siehe STP-Konfiguration für Details.

Konfiguration

Gemeinsame Schnittstellenkonfiguration

set interfaces bridge <interface> address <address | dhcp | dhcpv6>

Konfigurieren Sie die Schnittstelle mit einer oder mehreren IP-Adressen.

Die folgenden Optionen sind verfügbar:

  • address: Weisen Sie der Schnittstelle eine oder mehrere IPv4- oder IPv6-Adressen zu. Zum Beispiel verwenden Sie 192.0.2.1/24 für IPv4 oder 2001:db8::1/64 für IPv6.

  • dhcp: Die Schnittstelle erhält eine IPv4-Adresse von einem DHCP-Server im gleichen Netzwerksegment.

  • dhcpv6: Die Schnittstelle erhält eine IPv6-Adresse von einem DHCPv6-Server im gleichen Netzwerksegment.

Hinweis

Wenn die Schnittstelle eine IPv4-Adresse über DHCP erhält und spezifische Anpassungen vor/ nach der Erhaltung der IP-Adresse erforderlich sind, verwenden Sie die bereitgestellten Hook-Skripte:

  • /config/scripts/dhcp-client/pre-hooks.d/

  • /config/scripts/dhcp-client/post-hooks.d/

Beispiel:

set interfaces bridge br0 address 192.0.2.1/24
set interfaces bridge br0 address 2001:db8::1/64
set interfaces bridge br0 address dhcp
set interfaces bridge br0 address dhcpv6
set interfaces bridge <interface> description <description>

Konfigurieren Sie ein klares, beschreibendes Alias für die Schnittstelle.

Dieses Alias erscheint im Befehl show interfaces und in SNMP-basierten Überwachungstools.

Beispiel:

set interfaces bridge br0 description 'This is an interface running on VyOS.'
set interfaces bridge <interface> disable

Deaktivieren Sie die Schnittstelle.

Die Schnittstelle wird auf den administrativ heruntergefahrenen Zustand (A/D) gesetzt.

Beispiel:

set interfaces bridge br0 disable
set interfaces bridge <interface> disable-flow-control

Deaktivieren Sie die Ethernet-Flusssteuerung (IEEE 802.3x Pause-Frames) auf der Schnittstelle.
