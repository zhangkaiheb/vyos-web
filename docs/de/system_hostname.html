Hostinformation

Dieser Abschnitt beschreibt die Hostinformationen des Systems und wie sie konfiguriert werden können. Er umfasst folgende Themen:

  • Hostname

  • Domain

  • IP-Adresse

  • Alias

Hostname

Ein Hostname ist das Etikett (Name), das einem Netzwerkgerät (einem Host) auf einem Netzwerk zugewiesen wird und dazu verwendet wird, ein Gerät von anderen Geräten auf bestimmten Netzwerken oder über das Internet zu unterscheiden. Andererseits wird dies der Name sein, der im Befehlszeilenprompt erscheint.

set system host-name <hostname>

Der Hostname kann bis zu 63 Zeichen lang sein. Ein Hostname muss mit einem Buchstaben oder einer Ziffer beginnen und enden und darf als innere Zeichen nur Buchstaben, Ziffern oder Bindestriche enthalten.

Der Standardhostname lautet vyos.

Domain-Name

Ein Domainname ist das Etikett (Name), das einem Computernetzwerk zugewiesen wird und daher eindeutig ist. VyOS fügt den Domainnamen als Suffix an jeden unqualifizierten Namen an. Zum Beispiel, wenn Sie den Domainnamen example.com festlegen und Sie den unqualifizierten Namen crux pingen, dann qualifiziert VyOS den Namen zu crux.example.com.

set system domain-name <domain>

Konfigurieren Sie den System-Domainnamen. Ein Domainname muss mit einem Buchstaben oder einer Ziffer beginnen und enden und darf als innere Zeichen nur Buchstaben, Ziffern oder Bindestriche enthalten.

Statische Hostnamenzuordnung

Wie eine IP-Adresse einem Interface in Ethernet zugewiesen wird. Dieser Abschnitt zeigt, wie man eine IP-Adresse statisch einem Hostnamen für lokale (also auf diesem VyOS-System) Namensauflösung zuordnet. Dies ist das Äquivalent zu Einträgen in der Datei /etc/hosts in VyOS.

Hinweis

Ändern Sie /etc/hosts nicht manuell. Diese Datei wird bei jedem Boot automatisch neu generiert basierend auf den Einstellungen in diesem Abschnitt, was bedeutet, dass alle manuellen Änderungen verloren gehen. Stattdessen konfigurieren Sie statische Hostnamenzuordnungen wie folgt.

set system static-host-mapping host-name <hostname> inet <address>

Erstellen Sie eine statische Hostnamenzuordnung, die den Namen <hostname> immer auf die IP-Adresse <address> auflöst.

set system static-host-mapping host-name <hostname> alias <alias>

Erstellen Sie einen benannten <alias> für die konfigurierte statische Zuordnung für <hostname>. Somit kann die als set system static-host-mapping host-name <hostname> inet <address> konfigurierte Adresse über mehrere Namen erreicht werden.

Pro Hostname können mehrere Aliasse angegeben werden.
