Präfixlistenrichtlinie

Präfixlisten bieten das mächtigste Prüfmechanismus basierend auf Präfixen. Neben der Zugriffsliste-Funktion hat die ip prefix-list eine Spezifikation des Präfixlängenbereichs.

Wenn keine ip prefix list angegeben wird, wirkt sie als erlauben. Wenn die ip prefix list definiert ist und kein Treffer gefunden wird, wird die Standardverweigerung angewandt.

Präfixfilterung kann mit prefix-list und prefix-list6 durchgeführt werden.

Konfiguration

IPv4 Präfixlisten (prefix-list)

set policy prefix-list <text>

Dieser Befehl erstellt eine neue Präfixlistenrichtlinie, identifiziert durch <text>.

set policy prefix-list <text> description <text>

Legt eine Beschreibung für die Präfixlistenrichtlinie fest.

set policy prefix-list <text> rule <1-65535> action <permit|deny>

Dieser Befehl erstellt eine neue Regel in der Präfixliste und definiert eine Aktion.

set policy prefix-list <text> rule <1-65535> description <text>

Legt eine Beschreibung für die Regel in der Präfixliste fest.

set policy prefix-list <text> rule <1-65535> prefix <x.x.x.x/x>

Präfix, das abgeglichen werden soll.

set policy prefix-list <text> rule <1-65535> ge <0-32>

Netzmaske größer als Länge.

set policy prefix-list <text> rule <1-65535> le <0-32>

Netzmaske kleiner als Länge

Beispiel: IPv4 Präfixlisten (prefix-list)

Dieses Beispiel erstellt eine IPv4 Präfixliste namens PL4-EXAMPLE-NAME, definiert 3 Regeln mit jeweils einem Präfix und passt le (kleiner/gleich) /32 an.

set policy prefix-list PL4-EXAMPLE-NAME rule 10 action ‘permit’
set policy prefix-list PL4-EXAMPLE-NAME rule 10 le ‘32’
set policy prefix-list PL4-EXAMPLE-NAME rule 10 prefix ‘192.0.2.0/24’
set policy prefix-list PL4-EXAMPLE-NAME rule 20 action ‘permit’
set policy prefix-list PL4-EXAMPLE-NAME rule 20 le ‘32’
set policy prefix-list PL4-EXAMPLE-NAME rule 20 prefix ‘198.51.100.0/24’
set policy prefix-list PL4-EXAMPLE-NAME rule 30 action ‘permit’
set policy prefix-list PL4-EXAMPLE-NAME rule 30 le ‘32’
set policy prefix-list PL4-EXAMPLE-NAME rule 30 prefix ‘203.0.113.0/24’

IPv6 Präfixlisten (prefix-list6)

set policy prefix-list6 <text>

Dieser Befehl erstellt eine neue IPv6 Präfixlistenrichtlinie, identifiziert durch <text>.

set policy prefix-list6 <text> description <text>

Legt eine Beschreibung für die IPv6 Präfixlistenrichtlinie fest.

set policy prefix-list6 <text> rule <1-65535> action <permit|deny>

Dieser Befehl erstellt eine neue Regel in der IPv6 Präfixliste und definiert eine Aktion.

set policy prefix-list6 <text> rule <1-65535> description <text>

Legt eine Beschreibung für die Regel in der IPv6 Präfixliste fest.

set policy prefix-list6 <text> rule <1-65535> prefix <h:h:h:h:h:h:h:h/x>

IPv6 Präfix.

set policy prefix-list6 <text> rule <1-65535> ge <0-128>

Netzmaske größer als Länge.

set policy prefix-list6 <text> rule <1-65535> le <0-128>

Netzmaske kleiner als Länge

Beispiel: IPv6 Präfixlisten (prefix-list6)

Dieses Beispiel erstellt eine IPv6 Präfixliste6 namens PL6-EXAMPLE-NAME, definiert 3 Regeln mit jeweils einem Präfix und passt le (kleiner/gleich) /128 an.

set policy prefix-list6 PL6-EXAMPLE-NAME rule 10 action ‘permit’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 10 le ‘128’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 10 prefix ‘2001:db8:0:0::/64’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 20 action ‘permit’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 20 le ‘128’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 20 prefix ‘2001:db8:0:1::/64’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 30 action ‘permit’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 30 le ‘128’
set policy prefix-list6 PL6-EXAMPLE-NAME rule 30 prefix ‘2001:db8:0:2::/64’
