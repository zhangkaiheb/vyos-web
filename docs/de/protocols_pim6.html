PIMv6

VyOS unterstützt IPv6-Multicast-Routing durch PIMv6 und MLD Versionen 1 und 2.

PIMv6 funktioniert ähnlich wie seine IPv4-Vorgänger: Es verwendet die vorhandene unicast-IPv6-Routentabelle für Pfadentscheidungen, und der Verkehr von Multicast-Quellen wird zum einem RP weitergeleitet. IPv6-Multicast-Empfänger verwenden MLD, um ihre lokalen Router darüber zu informieren, welche Gruppen sie empfangen möchten, und der Router verwendet PIMv6, um diesen Verkehr über einen gemeinsamen Verteilungsbaum vom RP abzuholen.

Eine funktionierende PIMv6-Bereitstellung erfordert:

  • PIMv6 auf jedem Schnittstellen aktiviert, das an der IPv6-Multicast-Weiterleitung beteiligt ist.

  • Die Position des Rendezvous Points (RP) identisch auf jedem Router im PIMv6-Bereich deklariert.

  • MLD auf Schnittstellen aktiviert, die gegenüber Multicast-Empfängern liegen.

Basisbefehle

Verwenden Sie die folgenden Befehle für eine grundlegende PIMv6-Konfiguration.

set protocols pim6 interface <interface-name>

PIMv6 auf der angegebenen PIMv6-Schnittstelle aktivieren.

Dieser Befehl aktiviert auch MLD, sodass der Router MLD-Anfragen und Berichte von IPv6-Multicast-Empfängern verarbeiten kann.

Beispiel:

set protocols pim6 interface eth0
set protocols pim6 interface <interface-name> mld disable

MLD auf der angegebenen PIMv6-Schnittstelle deaktivieren.

Dieser Befehl schaltet die MLD-Verarbeitung an der Schnittstelle aus, während PIMv6 aktiv bleibt.

Beispiel:

set protocols pim6 interface eth0 mld disable

Anpassungsbefehle

Sie können auch Multicast mit den folgenden Befehlen anpassen.

set protocols pim6 interface <interface-name> mld interval <1-65535>

Konfigurieren Sie das MLD-Abfrageintervall in Sekunden auf der angegebenen Schnittstelle.

Diese Einstellung bestimmt, wie oft der Router MLD-Abfragen sendet, um herauszufinden, welche IPv6-Multicastgruppen aktive Empfänger auf dem angeschlossenen Netzwerk haben.

Der Standardwert beträgt 125 Sekunden.

Beispiel:

set protocols pim6 interface eth0 mld interval 100
set protocols pim6 interface <interface-name> mld join <multicast-address>

Konfigurieren Sie die Schnittstelle, um einer bestimmten IPv6-Multicastgruppe beizutreten.

Beispiel:

set protocols pim6 interface eth0 mld join ff0e::db8:0:1234
set protocols pim6 interface <interface-name> mld join <multicast-address> source <source-address>

Konfigurieren Sie die Schnittstelle, um einer bestimmten (S,G)-Kanal beizutreten.

Ein Kanal wird durch die Kombination einer Quell-IPv6-Adresse (S) und einer Multicast-IPv6-Adresse (G) identifiziert.

Beispiel:

set protocols pim6 interface eth0 mld join ff3e::1234 source 2001:db8::1
set protocols pim6 interface <interface-name> mld last-member-query-count <1-255>

Konfigurieren Sie die Anzahl der MLD-Last Listener Queries, die der Router auf der angegebenen Schnittstelle nachdem ein Empfänger eine Multicastgruppe verlässt, sendet.

Der Standardwert ist 2.

Beispiel:

set protocols pim6 interface eth0 mld last-member-query-count 3
set protocols pim6 interface <interface-name> mld last-member-query-interval <100-6553500>

Konfigurieren Sie das MLD Last Listener Query Intervall in Millisekunden auf der angegebenen Schnittstelle.

Diese Einstellung bestimmt, wie lange der Router zwischen Last Listener Queries wartet.

Der Standardwert beträgt 1000 Millisekunden.

Beispiel:

set protocols pim6 interface eth0 mld last-member-query-interval 500
set protocols pim6 interface <interface-name> mld max-response-time <100-6553500>

Konfigurieren Sie die maximale Antwortverzögerung von MLD in Millisekunden auf der angegebenen Schnittstelle.

Dieser Wert wird in MLD-Abfragen eingefügt und gibt an, wie lange Hosts Zeit haben, um mit einer Mitgliedschaftsmeldung zu antworten. Wenn innerhalb des festgelegten Zeitfensters keine Meldung empfangen wird, geht PIMv6 davon aus, dass es keine aktiven lokalen Empfänger mehr gibt und möglicherweise den zugehörigen (*,G) oder (S,G) Zustand ablaufen lässt.

Beispiel:

set protocols pim6 interface eth0 mld max-response-time 5000
set protocols pim6 interface <interface-name> mld version <1-2>

Konfigurieren Sie die MLD-Version auf der angegebenen Schnittstelle.

Die Standardversion ist 2.

Beispiel:

set protocols pim6 interface eth0 mld version 1

Konfigurationsbeispiel

Um PIMv6 auf den Schnittstellen eth0 und eth1 zu aktivieren (was auch MLD automatisch aktiviert, sodass der Router MLD-Abfragen und Berichte von verbundenen IPv6-Multicast-Empfängern verarbeiten kann):

set protocols pim6 interface eth0
set protocols pim6 interface eth1

Die folgende Konfiguration schließt explizit die IPv6-Multicastgruppe ff0e::db8:0:1234 auf der Schnittstelle eth0 und den (S,G)-Kanal (2001:db8::1, ff3e::5678) auf der Schnittstelle eth1 an:

set protocols pim6 interface eth0 mld join ff0e::db8:0:1234
set protocols pim6 interface eth1 mld join ff3e::5678 source 2001:db8::1
