Global Options Firewall Konfiguration

Übersicht

Einige Firewall-Einstellungen sind global und wirken sich auf das gesamte System aus. Dieser Abschnitt gibt Informationen über diese globalen Optionen, die Sie mit dem VyOS CLI konfigurieren können.

Konfigurationsbefehle, die in diesem Abschnitt behandelt werden:

set firewall global-options …

Konfiguration

set firewall global-options all-ping [enable | disable]

Standardmäßig antwortet VyOS auf einen ICMP Echo Request-Paket, der für es selbst bestimmt ist, es sei denn, Ihre Firewall verhindert dies.

Sie können Firewall-Regeln festlegen, um ICMP in, out oder lokal zu akzeptieren, abzulehnen oder zu blockieren. Sie können auch den Befehl firewall global-options all-ping verwenden. Dieser Befehl betrifft nur lokale Verkehr (Pakete, die für Ihr VyOS-System bestimmt sind), nicht IN oder OUT-Verkehr.

Hinweis

firewall global-options all-ping betrifft nur lokalen Verkehr und verhält sich immer am strengsten

set firewall global-options all-ping enable

Wenn Sie diesen Befehl setzen, antwortet VyOS auf jeden ICMP Echo Request, der an sich selbst gerichtet ist, aber diese Antwort erfolgt nur, wenn keine andere Regel lokale Echo-Anfragen blockiert oder ablehnt. Bei Konflikt antwortet VyOS nicht auf ICMP Echo Anfragen.

set firewall global-options all-ping disable

Wenn Sie diesen Befehl setzen, antwortet VyOS auf keine ICMP Echo Anfragen, die an sich selbst gerichtet sind, unabhängig davon, wo sie herkommen oder welche spezifischen Regeln sie akzeptieren.

set firewall global-options apply-to-bridged-traffic [ipv4 | ipv6]

Anwenden von IPv4 oder IPv6 Firewall-Regeln auf gebondeten Verkehr.

set firewall global-options broadcast-ping [enable | disable]

Aktivieren oder Deaktivieren der Antwort auf ICMP Broadcast-Nachrichten. Das System ändert den folgenden Parameter:

  • net.ipv4.icmp_echo_ignore_broadcasts

set firewall global-options ip-src-route [enable | disable]
set firewall global-options ipv6-src-route [enable | disable]

Legen Sie fest, ob VyOS Pakete mit einer Quellroute akzeptiert. Die folgenden sysctl-Parameter werden geändert:

  • net.ipv4.conf.all.accept_source_route

  • net.ipv6.conf.all.accept_source_route

set firewall global-options receive-redirects [enable | disable]
set firewall global-options ipv6-receive-redirects [enable | disable]

VyOS darf ICMPv4 und ICMPv6 Redirect-Nachrichten empfangen. Die folgenden sysctl-Parameter werden geändert:

  • net.ipv4.conf.all.accept_redirects

  • net.ipv6.conf.all.accept_redirects

set firewall global-options send-redirects [enable | disable]

VyOS darf ICMPv4 Redirect-Nachrichten senden. Der folgende sysctl-Parameter wird geändert:

  • net.ipv4.conf.all.send_redirects

set firewall global-options log-martians [enable | disable]

VyOS darf martian IPv4-Pakete protokollieren. Der folgende sysctl-Parameter wird geändert:

  • net.ipv4.conf.all.log_martians

set firewall global-options source-validation [strict | loose | disable]

Einstellung des IPv4-Quellen-Validierungsmodus. Der folgende sysctl-Parameter wird geändert:

  • net.ipv4.conf.all.rp_filter

set firewall global-options syn-cookies [enable | disable]

VyOS darf IPv4 TCP SYN Cookies verwenden. Der folgende sysctl-Parameter wird geändert:

  • net.ipv4.tcp_syncookies

set firewall global-options twa-hazards-protection [enable | disable]

Aktivieren oder Deaktivieren der VyOS RFC 1337 Konformität. Der folgende sysctl-Parameter wird geändert:

  • net.ipv4.tcp_rfc1337

set firewall global-options state-policy established action [accept | drop | reject]
set firewall global-options state-policy established log
set firewall global-options state-policy established log-level [emerg | alert | crit | err | warn | notice | info | debug]

Setzen Sie die globale Einstellung für eine etablierte Verbindung.

set firewall global-options state-policy invalid action [accept | drop | reject]
set firewall global-options state-policy invalid log
set firewall global-options state-policy invalid log-level [emerg | alert | crit | err | warn | notice | info | debug]

Setzen Sie die globale Einstellung für ungültige Pakete.

set firewall global-options state-policy related action [accept | drop | reject]
set firewall global-options state-policy related log
set firewall global-options state-policy related log-level [emerg | alert | crit | err | warn | notice | info | debug]

Setzen Sie die globale Einstellung für verwandte Verbindungen.

VyOS unterstützt das Festlegen von Timeout-Werten für Verbindungen nach Verbindungsart. Sie können Timeout-Werte für allgemeine Verbindungen, ICMP-Verbindungen, UDP-Verbindungen oder TCP-Verbindungen in verschiedenen Zuständen festlegen.

set firewall global-options timeout icmp <1-21474836>
set firewall global-options timeout other <1-21474836>
set firewall global-options timeout tcp close <1-21474836>
set firewall global-options timeout tcp close-wait <1-21474836>
set firewall global-options timeout tcp established <1-21474836>
set firewall global-options timeout tcp fin-wait <1-21474836>
set firewall global-options timeout tcp last-ack <1-21474836>
set firewall global-options timeout tcp syn-recv <1-21474836>
set firewall global-options timeout tcp syn-sent <1-21474836>
set firewall global-options timeout tcp time-wait <1-21474836>
set firewall global-options timeout udp other <1-21474836>
set firewall global-options timeout udp stream <1-21474836>

Setzen Sie den Timeout in Sekunden für ein Protokoll oder einen Zustand.
