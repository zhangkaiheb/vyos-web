System DNS

Warnung

Wenn Sie einen VRF für Verwaltungszwecke konfigurieren, gibt es derzeit keine Möglichkeit, den System-DNS-Verkehr über einen bestimmten VRF zu leiten.

Dieser Abschnitt beschreibt die Konfiguration von DNS auf dem System, nämlich:

  • DNS-Name-Server

  • Domänen-Suchreihenfolge

DNS-Name-Server

set system name-server <address>

Verwenden Sie diesen Befehl, um einen DNS-Server für das System anzugeben, der für DNS-Abfragen verwendet werden soll. Es können mehrere DNS-Server hinzugefügt werden, wobei jeweils nur einer gleichzeitig konfiguriert wird. Sowohl IPv4- als auch IPv6-Adressen werden unterstützt.

Beispiel

In diesem Beispiel werden einige OpenNIC-Server verwendet, zwei IPv4-Adressen und zwei IPv6-Adressen:

set system name-server 176.9.37.132
set system name-server 195.10.195.195
set system name-server 2a01:4f8:161:3441::1
set system name-server 2a00:f826:8:2::195

Domänen-Suchreihenfolge

Um das System dazu zu bringen, unvollständige Hostnamen zu verwenden und zu vervollständigen, kann eine Liste definiert werden, die für Domänensuchen verwendet wird.

set system domain-search <domain>

Verwenden Sie diesen Befehl, um Domänen einzeln zu definieren, damit das System sie verwendet, um unvollständige Hostnamen zu vervollständigen. Maximal: 6 Einträge.

Hinweis

Domänennamen können Buchstaben, Zahlen, Bindestriche und Punkte enthalten, mit einer maximalen Länge von 253 Zeichen.

Beispiel

Das System ist so konfiguriert, dass es die Domänenvervollständigung in folgender Reihenfolge versucht: vyos.io (erster), vyos.net (zweiter) und vyos.network (letzter):

set system domain-search vyos.io
set system domain-search vyos.net
set system domain-search vyos.network
