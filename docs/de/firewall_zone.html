Zone-basiertes Firewall

Übersicht

Hinweis

Alle VyOS-Versionen, die nach dem 22.10.2023 (VyOS 1.4 und 1.5) gebaut wurden, unterstützen diese Funktion.

Dieser Abschnitt enthält Informationen zur Firewall-Konfiguration für das zone-basierte Firewall. Dieser Abschnitt umfasst folgende Konfigurationsbefehle:

set firewall zone …

Um mehr über den allgemeinen Datenverkehr in VyOS-Firewalls zu erfahren, siehe Firewall.

- set firewall
    * zone
         - custom_zone_name
            + ...

In der zonenbasierten Richtlinie weisen Sie Schnittstellen zu Zonen zu und wenden Inspektion Richtlinien auf den Datenverkehr zwischen Zonen an. Das Firewall verarbeitet den Datenverkehr nach Regeln. Eine Zone ist eine Gruppe von Schnittstellen mit ähnlichen Funktionen oder Merkmalen. Sie definiert die Sicherheitsgrenzen eines Netzwerks. Eine Zone definiert eine Grenze, bei der das System den Datenverkehr politischen Einschränkungen unterwirft, wenn er in ein anderes Gebiet des Netzwerks übergeht.

Wichtige Punkte:

  • Eine Zone muss vor dem Zuweisen einer Schnittstelle konfiguriert werden, und Sie können einer Schnittstelle nur eine einzelne Zone zuweisen.

  • Der gesamte Datenverkehr zu und von einer Schnittstelle innerhalb einer Zone fließt frei.

  • Bestehende Richtlinien wirken sich auf den gesamten Datenverkehr zwischen Zonen aus.

  • Datenverkehr kann nicht zwischen einer Schnittstelle, die Mitglied einer Zone ist, und jeder anderen Schnittstelle fließen, die kein Mitglied der Zone ist.

  • Sie müssen zwei separate Firewalls definieren, um den Datenverkehr zu definieren: einen für jede Richtung.

Hinweis

In T2199 wurde die Syntax der Zoneneinstellungen geändert. Die Zoneneinstellung wurde von zone-policy zone <name> auf firewall zone <name> verlegt.

Konfiguration

Als Alternative dazu, Richtlinien direkt auf eine Schnittstelle anzuwenden, können Sie ein zonenbasiertes Firewall erstellen, um die Konfiguration zu vereinfachen, wenn mehrere Schnittstellen zur gleichen Sicherheitszone gehören. Anstatt Regel-Sets auf Schnittstellen anzuwenden, wenden Sie sie auf Quell-Ziel-Zonen-Paare an.

Sie finden eine grundlegende Einführung in zonenbasierte Firewalls im VyOS Knowledge Base, und ein Beispiel unter Zone-Policy-Beispiel.

Die folgenden Schritte sind erforderlich, um ein zonenbasiertes Firewall zu erstellen:

  1. Definieren Sie sowohl die Quell- als auch die Zielzone

  2. Definieren Sie das Regel-Set

  3. Wenden Sie das Regel-Set auf die Zonen an

Zone definieren

Um eine Zone zu definieren, richten Sie entweder eine mit Schnittstellen ein oder als lokale Zone.

set firewall zone <name> interface <interface>

Weisen Sie Schnittstellen als Mitglied einer Zone zu.

Hinweis

  • Eine Schnittstelle kann nur Mitglied einer einzigen Zone sein.

  • Sie können mehrere Schnittstellen in einer Zone haben. Der Datenverkehr zwischen Schnittstellen in derselben Zone folgt der intra-Zonen-Filter-Richtlinie (zugelassen per Default).

set firewall zone <name> local-zone

Definieren Sie die Zone als lokale Zone für den Datenverkehr, der vom Router selbst stammt oder für den Router bestimmt ist.

Hinweis

  • Eine lokale Zone kann keine Mitgliedsschnittstellen haben

  • Sie können keine mehreren lokalen Zonen haben

set firewall zone <name> default-action [drop | reject]

Ändern Sie die Standardaktion der Zone, die auf den Datenverkehr angewandt wird, der für diese Zone bestimmt ist und keine der Quell-Zonen-Regel-Sets trifft.

set firewall zone <name> default-log

Enable logging of packets that match this zone’s default-action (disabled by default).

set firewall zone <name> description

Fügen Sie eine sinnvolle Beschreibung hinzu.

Definieren eines Regel-Sets

Zonenbasierte Firewall-Regel-Sets definieren den Datenverkehr von einer Quell-Zone zu einer Ziel-Zone.

Sie erstellen Regel-Sets als benutzerdefinierte Firewall-Kette mit den unten stehenden Befehlen (Referenzieren Sie die Firewall IPv4/IPv6 Abschnitte für die vollständige Syntax):

  • Für IPv4: set firewall ipv4 name <name> ...

  • Für IPv6: set firewall ipv6 name <name> ...

Es ist hilfreich, die Regel-Sets im Format <Quell-Zone>-<Ziel-Zone>-<v4 | v6> zu benennen, um sie leicht identifizierbar zu machen.

Anwenden eines Regel-Sets auf eine Zone

Nachdem Sie ein Regel-Set definiert haben, wenden Sie es auf die Quell- und Zielzonen an. Die Konfigurationsyntax bezieht sich auf die Zielzone, mit jedem der Quell-Zonen-Regel-Sets gegen die Zielzone gelistet.

set firewall zone <Destination Zone> from <Source Zone> firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> from <Source Zone> firewall ipv6-name <ipv6-rule-set-name>

Sie sollten für jedes Quell-Ziel-Zonen-Paar zwei Regel-Sets erstellen.

set firewall zone DMZ from LAN firewall name LAN-DMZ-v4
set firewall zone LAN from DMZ firewall name DMZ-LAN-v4

Anwenden eines Standard-Regel-Sets auf eine Zone

Wenn eine Zielzone einen gemeinsamen Regel-Satz für mehrere Quellzonen hat, oder wenn Sie eine komplexe Reihe von Standardrichtlinien benötigen, können Sie ein optionales Standard-Regel-Satz anwenden. Der Standard-Regel-Satz gilt für alle Zonen, die keinen Regel-Satz gemäß IPv4 konfiguriert haben.

set firewall zone <Destination Zone> default-firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> default-firewall ipv6-name <ipv6-rule-set-name>

Betriebsmodus

show firewall zone-policy

Zeigt eine grundlegende Zusammenfassung der Zoneneinstellungen an.

vyos@vyos:~$ show firewall zone-policy
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LAN     eth1          WAN          WAN-LAN-v4
eth2
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
show firewall zone-policy zone <zone>

Zeigt eine grundlegende Zusammenfassung einer bestimmten Zone an.

vyos@vyos:~$ show firewall zone-policy zone WAN
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
vyos@vyos:~$ show firewall zone-policy zone LOCAL
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
