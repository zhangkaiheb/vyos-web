Conntrack

VyOS kann so konfiguriert werden, dass es Verbindungen mithilfe des Verbindungsverfolgungssubsystems verfolgt. Die Verbindungsverfolgung wird aktiv, sobald entweder ein stateful Firewall oder NAT konfiguriert wird.

Konfigurieren

set system conntrack table-size <1-50000000>

Die Verbindungsverfolgungstabelle enthält einen Eintrag für jede Verbindung, die vom System verfolgt wird.

set system conntrack expect-table-size <1-50000000>

Die Verbindungsverfolgungserwartungstabelle enthält einen Eintrag für jede erwartete Verbindung, die mit einer vorhandenen Verbindung verbunden ist. Diese werden normalerweise von „Verbindungsverfolgungs-Helfer“-Modulen wie FTP verwendet. Die Standardgröße der Erwartungstabelle beträgt 2048 Einträge.

set system conntrack hash-size <1-50000000>

Legen Sie die Größe der Hash-Tabelle fest. Die Verbindungsverfolgungshash-Tabelle macht das Suchen in der Verbindungsverfolgungstabelle schneller. Die Hash-Tabelle verwendet „Buckets“, um Einträge in der Verbindungsverfolgungstabelle zu speichern.

set system conntrack modules ftp
set system conntrack modules h323
set system conntrack modules nfs
set system conntrack modules pptp
set system conntrack modules sip
set system conntrack modules sqlnet
set system conntrack modules tftp

Konfigurieren Sie die Protokollhilfsmodule für die Verbindungsverfolgung. Alle Module sind standardmäßig aktiviert.

Verwenden Sie delete system conntrack modules, um alle Module zu deaktivieren.
Oder beispielsweise ftp, delete system conntrack modules ftp.
set system conntrack tcp half-open-connections <1-21474836>

Legen Sie die maximale Anzahl von TCP-Half-Open-Verbindungen fest.

set system conntrack tcp loose <enable | disable>

Richtlinie zur Verfolgung bereits hergestellter Verbindungen.

set system conntrack tcp max-retrans <1-2147483647>

Legen Sie die Anzahl der maximalen TCP-Wiederholversuche fest.

Conntrack-Zeitüberschreitungen

Sie können benutzerdefinierte Zeitüberschreitungszeiten definieren, um eine bestimmte Teilmenge von Verbindungen anzuwenden, basierend auf einem Paket- und Flussselektor. Dazu müssen Sie eine Regel erstellen, die den Paket- und Flussselektor definiert.

set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> description <test>

Setzen Sie eine Regelbeschreibung.

set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> destination address <ip-address>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> source address <ip-address>

Legen Sie eine Ziel- und/oder Quelladresse fest. Akzeptierte Eingabe für ipv4:

set system conntrack timeout custom ipv4 rule <1-999999> [source | destination] address
Mögliche Ergänzungen:
   <x.x.x.x>            IPv4-Adresse zum Abgleich
   <x.x.x.x/x>          IPv4-Präfix zum Abgleich
   <x.x.x.x>-<x.x.x.x>  IPv4-Adressbereich zum Abgleich
   !<x.x.x.x>           Alles außer der angegebenen Adresse abgleichen
   !<x.x.x.x/x>         Alles außer dem angegebenen Präfix abgleichen
   !<x.x.x.x>-<x.x.x.x> Alles außer dem angegebenen Bereich abgleichen

set system conntrack timeout custom ipv6 rule <1-999999> [source | destination] address
Mögliche Ergänzungen:
   <h:h:h:h:h:h:h:h>    IP-Adresse zum Abgleich
   <h:h:h:h:h:h:h:h/x>  Subnetz zum Abgleich
   <h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>
                        IP-Bereich zum Abgleich
   !<h:h:h:h:h:h:h:h>   Alles außer der angegebenen Adresse abgleichen
   !<h:h:h:h:h:h:h:h/x> Alles außer dem angegebenen Präfix abgleichen
   !<h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>
                        Alles außer dem angegebenen Bereich abgleichen
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> destination port <value>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> source port <value>

Legen Sie eine Ziel- und/oder Quellport fest. Akzeptierte Eingabe:

<Portname>    Benannter Port (beliebiger Name in /etc/services, z. B. http)
<1-65535>      Nummerierter Port
<start>-<end>  Nummerierter Portbereich (z. B. 1001-1005)

Mehrere Zielports können als Komma-getrennte Liste angegeben werden. Die gesamte Liste kann auch mit '!' negiert werden. Zum Beispiel: !22,telnet,http,123,1001-1005`

set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp close <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp close-wait <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp established <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp fin-wait <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp last-ack <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp syn-recv <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp syn-sent <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp time-wait <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol udp replied <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol udp unreplied <1-21474836>

Legen Sie die Zeitüberschreitung in Sekunden für ein Protokoll oder einen Zustand in einer benutzerdefinierten Regel fest.

Conntrack-Ignore-Regeln

Hinweis

Wichtiger Hinweis zu Conntrack-Ignore-Regeln: Ab vyos-1.5-rolling-202406120020 können Ignore-Regeln in set firewall [ipv4 | ipv6] prerouting raw ... definiert werden. Es wird erwartet, dass in Zukunft die Conntrack-Ignore-Regeln entfernt werden.

Benutzerdefinierte Ignore-Regeln, basierend auf einem Paket- und Flussselektor.

set system conntrack ignore [ipv4 | ipv6] rule <1-999999> description <text>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> destination address <ip-address>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> destination port <port>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> inbound-interface <interface>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> protocol <protocol>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> source address <ip-address>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> source port <port>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> tcp flags [not] <text>

Erlaubte Werte für TCP-Flags: ack, cwr, ecn, fin, psh, rst, syn und urg. Mehrere Werte werden unterstützt, und für umgekehrte Auswahl verwenden Sie not, wie im Beispiel gezeigt.

Conntrack-Log

set system conntrack log event destroy
set system conntrack log event new
set system conntrack log event update

Protokollieren Sie Verbindungsverfolgungsereignisse pro Typ.

set system conntrack log event destroy icmp
set system conntrack log event destroy other
set system conntrack log event destroy tcp
set system conntrack log event destroy udp
set system conntrack log event new icmp
set system conntrack log event new other
set system conntrack log event new tcp
set system conntrack log event new udp
set system conntrack log event update icmp
set system conntrack log event update other
set system conntrack log event update tcp
set system conntrack log event update udp

Protokollieren Sie Verbindungsverfolgungsereignisse pro Protokoll.

set system conntrack log timestamp

Flussbasierte Zeitsammlung aktivieren.

set system conntrack log queue-size <100-999999>

Verwalten Sie die interne Warteschlangengröße, Standardgröße ist 4096 Ereignisse.

set system conntrack log log-level <info | debug>
