Zugriffslistenrichtlinie

Filterung wird sowohl für die Eingabe als auch für die Ausgabe der Routinginformationen verwendet. Sobald die Filterung definiert ist, kann sie in beliebiger Richtung angewandt werden. VyOS ermöglicht die Filterung mit ACLs und Präfixlisten.

Grundlegende Filterung kann mit access-list und access-list6 durchgeführt werden.

Konfiguration

Zugriffslisten

set policy access-list <acl_number>

Dieser Befehl erstellt die neue Zugriffslistenrichtlinie, wobei <acl_number> eine Zahl von 1 bis 2699 sein muss.

set policy access-list <acl_number> description <text>

Legt eine Beschreibung für die Zugriffsliste fest.

set policy access-list <acl_number> rule <1-65535> action <permit|deny>

Dieser Befehl erstellt eine neue Regel in der Zugriffsliste und definiert eine Aktion.

set policy access-list <acl_number> rule <1-65535> <destination|source> <any|host|inverse-mask|network>

Dieser Befehl definiert die Übereinstimmungskriterien für die Zugriffslistenregel. Die Übereinstimmungskriterien können auf Ziel- oder Quellparameter angewandt werden:

  • any: jede IP-Adresse, um zu übereinstimmen.

  • host: eine einzelne Host-IP-Adresse, um zu übereinstimmen.

  • inverse-match: Netzwerk/Netzmaske, um zu übereinstimmen (erfordert, dass das Netzwerk definiert wird).

  • network: Netzwerk/Netzmaske, um zu übereinstimmen (erfordert, dass inverse-match definiert wird).

IPv6-Zugriffsliste

Grundlegende Filterung kann auch auf IPv6-Datenverkehr angewandt werden.

set policy access-list6 <text>

Dieser Befehl erstellt die neue IPv6-Zugriffsliste, identifiziert durch <text>

set policy access-list6 <text> description <text>

Legt eine Beschreibung für die IPv6-Zugriffsliste fest.

set policy access-list6 <text> rule <1-65535> action <permit|deny>

Dieser Befehl erstellt eine neue Regel in der IPv6-Zugriffsliste und definiert eine Aktion.

set policy access-list6 <text> rule <1-65535> source <any|exact-match|network>

Dieser Befehl definiert die Übereinstimmungskriterien für die IPv6-Zugriffslistenregel. Die Übereinstimmungskriterien können auf Quellparameter angewandt werden:

  • any: jede IPv6-Adresse, um zu übereinstimmen.

  • exact-match: genaue Übereinstimmung der Netzwerkpräfixe.

  • network: Netzwerk/Netzmaske, um zu übereinstimmen (erfordert, dass inverse-match definiert wird) Fehler, keine invert-match-Option in access-list6
