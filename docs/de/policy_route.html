Route und Route6 Richtlinien

IPv4-Route- und IPv6-Route-Richtlinien werden in diesem Abschnitt definiert. Diese Routenrichtlinien können dann an Schnittstellen angehängt werden.

Regel-Sammlungen

Eine Regel-Sammlung ist eine benannte Sammlung von Regeln, die auf eine Schnittstelle angewandt werden können. Jede Regel ist nummeriert, hat eine Aktion, die ausgeführt wird, wenn die Regel übereinstimmt, und die Fähigkeit, die Kriterien für die Übereinstimmung anzugeben. Datenpakete durchlaufen die Regeln von 1 bis 999999, bei der ersten Übereinstimmung wird die Aktion der Regel ausgeführt.

set policy route <name> description <text>
set policy route6 <name> description <text>

Geben Sie eine Beschreibung für die Regel-Sammlung an.

set policy route <name> default-log
set policy route6 <name> default-log

Option zum Protokollieren von Paketen, die die Standardaktion treffen.

set policy route <name> interface <interface>
set policy route6 <name> interface <interface>

Routenrichtlinie auf Schnittstelle anwenden

set policy route <name> rule <n> description <text>
set policy route6 <name> rule <n> description <text>

Geben Sie eine Beschreibung für jede Regel an.

set policy route <name> rule <n> log <enable|disable>
set policy route6 <name> rule <n> log <enable|disable>

Option, um das Protokollieren der passenden Regel zu aktivieren oder zu deaktivieren.

Übereinstimmungskriterien

Es gibt viele Übereinstimmungskriterien, sowohl für policy route als auch für policy route6. Diese Optionen sind in diesem Abschnitt aufgelistet.

set policy route <name> rule <n> connection-mark <1-2147483647>
set policy route6 <name> rule <n> connection-mark <1-2147483647>

Legen Sie die Übereinstimmungskriterien basierend auf dem Verbindungsmark fest.

set policy route <name> rule <n> mark <match_criteria>
set policy route6 <name> rule <n> mark <match_criteria>

Übereinstimmung basierend auf dem Firewall-Mark (fwmark), wobei <match_criteria> folgendes sein kann:

  • <0-2147483647> ein einzelner fwmark

  • !<0-2147483647> alles außer einem einzelnen fwmark

  • <start-end> ein Bereich von Markierungen

  • !<start-end> alles außer dem Bereich der Markierungen

Hinweis

Wenn die Befehle set table oder set vrf verwendet werden, werden die Mark-Einstellungen ignoriert und mit einer tabellenspezifischen Mark überschrieben, die auf 0x7FFFFFFF gesetzt ist - die ID der Tabelle/VRF.

set policy route <name> rule <n> source address <match_criteria>
set policy route <name> rule <n> destination address <match_criteria>
set policy route6 <name> rule <n> source address <match_criteria>
set policy route6 <name> rule <n> destination address <match_criteria>

Legen Sie Übereinstimmungskriterien basierend auf Quell- oder Ziel-ipv4|ipv6-Adresse fest, wobei <match_criteria> folgendes sein könnte:

Für ipv4:

  • <x.x.x.x>: IP-Adresse zur Übereinstimmung.

  • <x.x.x.x/x>: Subnetz zur Übereinstimmung.

  • <x.x.x.x>-<x.x.x.x>: IP-Bereich zur Übereinstimmung.

  • !<x.x.x.x>: Übereinstimmung mit allem außer der angegebenen Adresse.

  • !<x.x.x.x/x>: Übereinstimmung mit allem außer dem angegebenen Subnetz.

  • !<x.x.x.x>-<x.x.x.x>: Übereinstimmung mit allem außer dem angegebenen Bereich.

Und für ipv6:

  • <h:h:h:h:h:h:h:h>: IPv6-Adresse zur Übereinstimmung.

  • <h:h:h:h:h:h:h:h/x>: IPv6-Präfix zur Übereinstimmung.

  • <h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>: IPv6-Bereich zur Übereinstimmung.

  • !<h:h:h:h:h:h:h:h>: Übereinstimmung mit allem außer der angegebenen Adresse.

  • !<h:h:h:h:h:h:h:h/x>: Übereinstimmung mit allem außer dem angegebenen Präfix.

  • !<h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>: Übereinstimmung mit allem außer dem angegebenen Bereich.

set policy route <name> rule <n> source group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route <name> rule <n> destination group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route6 <name> rule <n> source group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route6 <name> rule <n> destination group <address-group|domain-group|mac-group|network-group|port-group> <text>

Legen Sie Übereinstimmungskriterien basierend auf Quell- oder Zielgruppen fest, wobei <text> der Gruppenname/Identifikator ist. Ein '!' am Anfang invertiert das Kriterium.

set policy route <name> rule <n> destination port <match_criteria>
set policy route6 <name> rule <n> destination port <match_criteria>

Legen Sie Übereinstimmungskriterien basierend auf Zielport fest, wobei <match_criteria> folgendes sein könnte:

  • <Portname>: Benannter Port (jeder Name in /etc/services, z. B. http).

  • <1-65535>: Nummerierter Port.

  • <start>-<end>: Nummerierter Portbereich (z. B. 1001-1005).

Mehrere Zielports können als Komma-Liste angegeben werden. Die gesamte Liste kann auch mit '!' negiert werden. Zum Beispiel: '!22,telnet,http,123,1001-1005'

set policy route <name> rule <n> disable
set policy route6 <name> rule <n> disable

Option, um die Regel zu deaktivieren.

set policy route <name> rule <n> dscp <text>
set policy route6 <name> rule <n> dscp <text>
set policy route <name> rule <n> dscp-exclude <text>
set policy route6 <name> rule <n> dscp-exclude <text>

Übereinstimmung basierend auf DSCP-Wertkriterien. Mehrere Werte von 0 bis 63 und Bereiche sind unterstützt.

set policy route <name> rule <n> fragment <match-grag|match-non-frag>
set policy route6 <name> rule <n> fragment <match-grag|match-non-frag>

Setzen Sie IP-Fragment-Übereinstimmung, wobei:

  • match-frag: Zweite und weitere Fragmente von fragmentierten Paketen.

  • match-non-frag: Kopffragmente oder unfragmentierte Pakete.

set policy route <name> rule <n> icmp <code | type>
set policy route6 <name> rule <n> icmpv6 <code | type>

Übereinstimmung basierend auf icmp|icmpv6 Code und Typ.

set policy route <name> rule <n> icmp type-name <text>
set policy route6 <name> rule <n> icmpv6 type-name <text>

Übereinstimmung basierend auf icmp|icmpv6 type-name-Kriterien. Nutzen Sie die Tab-Taste, um Informationen über unterstützte type-name-Kriterien zu erhalten.

set policy route <name> rule <n> ipsec <match-ipsec|match-none>
set policy route6 <name> rule <n> ipsec <match-ipsec|match-none>

Setzen Sie IPSec-Eingangskriterien, wobei:

  • match-ipsec: Match eingehende IPSec-Pakete.

  • match-none: Match eingehende nicht-IPSec-Pakete.

set policy route <name> rule <n> limit burst <0-4294967295>
set policy route6 <name> rule <n> limit burst <0-4294967295>

Setzen Sie die maximale Anzahl von Paketen, die über die Rate hinaus erlaubt werden.

set policy route <name> rule <n> limit rate <text>
set policy route6 <name> rule <n> limit rate <text>

Setzen Sie die maximale Durchschnittsübereinstimmungsrate. Format für Rate: Ganzzahl/Zeiteinheit, wobei Zeiteinheit eine der folgenden sein kann: Sekunde, Minute, Stunde oder Tag. Zum Beispiel 1/Sekunde bedeutet, dass die Regel im Durchschnitt einmal pro Sekunde übereinstimmt.

set policy route <name> rule <n> protocol <text | 0-255 | tcp_udp | all >
set policy route6 <name> rule <n> protocol <text | 0-255 | tcp_udp | all >

Übereinstimmung eines Protokollkriteriums. Eine Protokollnummer oder ein Name, der in /etc/protocols definiert ist. Spezielle Namen sind all für alle Protokolle und tcp_udp für TCP- und UDP-basierte Pakete. Das ! negiert das ausgewählte Protokoll.

set policy route <name> rule <n> packet-length <text>
set policy route6 <name> rule <n> packet-length <text>
set policy route <name> rule <n> packet-length-exclude <text>
set policy route6 <name> rule <n> packet-length-exclude <text>

Übereinstimmung basierend auf Paketlängenkriterien. Mehrere Werte von 1 bis 65535 und Bereiche sind unterstützt.

set policy route <name> rule <n> packet-type [broadcast | host | multicast | other]
set policy route6 <name> rule <n> packet-type [broadcast | host | multicast | other]

Übereinstimmung basierend auf Pakettypkriterien.

set policy route <name> rule <n> recent count <1-255>
set policy route6 <name> rule <n> recent count <1-255>
set policy route <name> rule <n> recent time <1-4294967295>
set policy route6 <name> rule <n> recent time <1-4294967295>

Setzen Sie Parameter für die Übereinstimmung mit kürzlich gesehenen Quellen. Dieses Match kann verwendet werden, indem man count (Quelladresse wurde mehr als <1-255> Mal gesehen) und/oder time (Quelladresse wurde in den letzten <0-4294967295> Sekunden gesehen) setzt.

set policy route <name> rule <n> state <established | invalid | new | related>
set policy route6 <name> rule <n> state <established | invalid | new | related>

Setzen Sie Übereinstimmungskriterien basierend auf Sitzungsstatus.

set policy route <name> rule <n> tcp flags <text>
set policy route6 <name> rule <n> tcp flags <text>

Setzen Sie Übereinstimmungskriterien basierend auf TCP-Flags. Erlaubte Werte für TCP-Flags: SYN ACK FIN RST URG PSH ALL. Wenn mehr als ein Flag angegeben wird, sollten Flags durch Kommas getrennt werden. Zum Beispiel: Wert von „SYN,!ACK,!FIN,!RST“ passt nur auf Pakete mit dem SYN-Flag, und die Flags ACK, FIN und RST sind nicht gesetzt.

set policy route <name> rule <n> time monthdays <text>
set policy route6 <name> rule <n> time monthdays <text>
set policy route <name> rule <n> time startdate <text>
set policy route6 <name> rule <n> time startdate <text>
set policy route <name> rule <n> time starttime <text>
set policy route6 <name> rule <n> time starttime <text>
set policy route <name> rule <n> time stopdate <text>
set policy route6 <name> rule <n> time stopdate <text>
set policy route <name> rule <n> time stoptime <text>
set policy route6 <name> rule <n> time stoptime <text>
set policy route <name> rule <n> time weekdays <text>
set policy route6 <name> rule <n> time weekdays <text>
set policy route <name> rule <n> time utc
set policy route6 <name> rule <n> time utc

Zeit, um die definierte Regel zu matchen.

set policy route rule <n> ttl <eq | gt | lt> <0-255>

Match Time to live Parameter, wobei 'eq' für 'equal' steht; 'gt' steht für 'greater than', und 'lt' steht für 'less than'.

set policy route6 rule <n> hop-limit <eq | gt | lt> <0-255>

Match Hop-Limit Parameter, wobei 'eq' für 'equal' steht; 'gt' steht für 'greater than', und 'lt' steht für 'less than'.

Aktionen

Wenn alle Muster, die in einer Regel definiert sind, übereinstimmen, können verschiedene Aktionen durchgeführt werden. Dies beinhaltet das Löschen des Pakets, das Ändern bestimmter Daten oder das Festlegen einer anderen Routing-Tabelle.

set policy route <name> rule <n> action drop
set policy route6 <name> rule <n> action drop

Setzen Sie die Regel-Aktion auf Drop.

set policy route <name> rule <n> set connection-mark <1-2147483647>
set policy route6 <name> rule <n> set connection-mark <1-2147483647>

Setzen Sie einen spezifischen Verbindungs-Mark.

set policy route <name> rule <n> set dscp <0-63>
set policy route6 <name> rule <n> set dscp <0-63>

Setzen Sie Paketmodifikationen: Packet Differentiated Services Codepoint (DSCP)

set policy route <name> rule <n> set mark <1-2147483647>
set policy route6 <name> rule <n> set mark <1-2147483647>

Setzen Sie einen spezifischen Paket-Mark.

set policy route <name> rule <n> set table <main | 1-200>
set policy route6 <name> rule <n> set table <main | 1-200>

Setzen Sie die Routing-Tabelle, um das Paket weiterzuleiten.

Hinweis

Wenn die Befehle set table oder set vrf verwendet werden, ist es nicht möglich, gegen den Mark zu matchen, weil dieser mit einem tabellenspezifischen Mark überschrieben wird, der 0x7FFFFFFF - die ID der Tabelle/VRF ist.

set policy route <name> rule <n> set tcp-mss <500-1460>
set policy route6 <name> rule <n> set tcp-mss <500-1460>

Setzen Sie Paketmodifikationen: Explizit setzen Sie den TCP Maximum Segment Size Wert.

set policy route <name> rule <n> set vrf <default | text >
set policy route6 <name> rule <n> set vrf <default | text >

Setzen Sie die VRF, um das Paket weiterzuleiten.

Hinweis

Wenn die Befehle set table oder set vrf verwendet werden, ist es nicht möglich, gegen den Mark zu matchen, weil dieser mit einem tabellenspezifischen Mark überschrieben wird, der 0x7FFFFFFF - die ID der Tabelle/VRF ist.
