PPTP-Server

Das Point-to-Point Tunneling Protocol (PPTP) wurde in VyOS nur für die Rückwärtskompatibilität implementiert. PPTP hat viele bekannte Sicherheitsprobleme und Sie sollten eine der vielen anderen neuen VPN-Implementierungen verwenden.

PPTP Server konfigurieren

set vpn pptp remote-access authentication mode local
set vpn pptp remote-access authentication local-users username test password 'test'
set vpn pptp remote-access client-ip-pool PPTP-POOL range 192.168.255.2-192.168.255.254
set vpn pptp remote-access default-pool 'PPTP-POOL'
set vpn pptp remote-access outside-address 192.0.2.2
set vpn pptp remote-access gateway-address 192.168.255.1
set vpn pptp remote-access authentication mode <local | radius>

Legen Sie den Authentifizierungsbackend fest. Der konfigurierte Authentifizierungsbackend wird für alle Abfragen verwendet.

  • radius: Alle Authentifizierungsanfragen werden von einem konfigurierten RADIUS-Server verarbeitet.

  • local: Alle Authentifizierungsanfragen werden lokal verarbeitet.

  • noauth: Authentifizierung deaktiviert.

set vpn pptp remote-access authentication local-users username <user> password <pass>

Erstellen Sie einen <user> für die lokale Authentifizierung auf diesem System. Das Passwort des Benutzers wird auf <pass> gesetzt.

set vpn pptp remote-access client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Verwenden Sie diesen Befehl, um das erste IP-Adresspool-Element zu definieren, das an PPTP-Clients vergeben wird. Wenn die Notation x.x.x.x-x.x.x.x verwendet wird, muss sie innerhalb eines /24-Subnetzes liegen. Wenn die Notation x.x.x.x/x verwendet wird, besteht die Möglichkeit, Host/Netzmaske zu setzen.

set vpn pptp remote-access default-pool <POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des Standard-IP-Adresspools zu definieren.

set vpn pptp remote-access gateway-address <gateway>

Gibt eine einzelne <gateway> IP-Adresse an, die als lokale Adresse der PPP-Schnittstellen verwendet werden soll.

Radius-Authentifizierung konfigurieren

Um die Radius-basierte Authentifizierung zu aktivieren, muss der Authentifizierungsmodus innerhalb der Konfiguration geändert werden. Vorherige Einstellungen wie lokale Benutzer existieren weiterhin in der Konfiguration, jedoch werden sie nicht verwendet, wenn der Modus von local auf radius geändert wurde. Sobald er wieder auf local geändert wird, verwendet er erneut alle lokalen Konten.

set vpn pptp remote-access authentication mode radius
set vpn pptp remote-access authentication radius server <server> key <secret>

Konfigurieren Sie den RADIUS <server> und seinen erforderlichen gemeinsamen <secret> für die Kommunikation mit dem RADIUS-Server.

Da der RADIUS-Server ein einzelner Ausfallpunkt ist, können mehrere RADIUS-Server eingerichtet werden und werden anschließend verwendet. Zum Beispiel:

set vpn pptp remote-access authentication radius server 10.0.0.1 key 'foo'
set vpn pptp remote-access authentication radius server 10.0.0.2 key 'foo'

Hinweis

Einige RADIUS-Server verwenden eine Zugriffsliste, die Anfragen erlaubt oder verweigert, stellen Sie sicher, dass Ihr VyOS-Router zur Liste der erlaubten Client-Listen hinzugefügt wird.

RADIUS-Quelladresse

Wenn Sie OSPF als IGP verwenden, wird immer die nächstgelegene Schnittstelle verwendet, die mit dem RADIUS-Server verbunden ist. Sie können alle ausgehenden RADIUS-Anfragen an eine einzelne Quell-IP-Adresse binden, z. B. die Loopback-Schnittstelle.

set vpn pptp remote-access authentication radius source-address <address>

Quell-IPv4-Adresse, die bei allen RADIUS-Serverabfragen verwendet wird.

Hinweis

Einige RADIUS-Server verwenden eine Zugriffsliste, die Anfragen erlaubt oder verweigert, stellen Sie sicher, dass Ihr VyOS-Router zur Liste der erlaubten Client-Listen hinzugefügt wird.

Erweiterte RADIUS-Optionen

set vpn pptp remote-access authentication radius server <server> port <port>

Konfigurieren Sie den RADIUS <server> und seinen erforderlichen Port für Authentifizierungsanfragen.

set vpn pptp remote-access authentication radius server <server> fail-time <time>

Markieren Sie den RADIUS-Server für diese gegebene <time> Sekunde als offline.

set vpn pptp remote-access authentication radius server <server> disable

Deaktivieren Sie diesen RADIUS-Server vorübergehend.

set vpn pptp remote-access authentication radius acct-timeout <timeout>

Zeitlimit, um auf Antwort für Interim-Update-Pakete zu warten. (Standardwert 3 Sekunden)

set vpn pptp remote-access authentication radius dynamic-author server <address>

Gibt die IP-Adresse des Dynamic Authorization Extension Servers (DM/CoA) an. Diese IP muss auf einer beliebigen VyOS-Schnittstelle vorhanden sein oder es kann 0.0.0.0 sein.

set vpn pptp remote-access authentication radius dynamic-author port <port>

UDP-Port für den Dynamic Authorization Extension Server (DM/CoA)

set vpn pptp remote-access authentication radius dynamic-author key <secret>

Geheimnis für den Dynamic Authorization Extension Server (DM/CoA)

set vpn pptp remote-access authentication radius max-try <number>

Maximale Anzahl von Versuchen, um Access-Request/Accounting-Request-Anfragen zu senden

set vpn pptp remote-access authentication radius timeout <timeout>

Zeitlimit, um auf eine Antwort vom Server zu warten (Sekunden)

set vpn pptp remote-access authentication radius nas-identifier <identifier>

Wert, der an den RADIUS-Server im NAS-Identifier-Attribut gesendet wird und in DM/CoA-Anfragen übereinstimmen muss.

set vpn pptp remote-access authentication radius nas-ip-address <address>

Wert, der an den RADIUS-Server im NAS-IP-Address-Attribut gesendet wird und in DM/CoA-Anfragen übereinstimmen muss. Der DM/CoA-Server bindet auch an diese Adresse.

set vpn pptp remote-access authentication radius source-address <address>

Quell-IPv4-Adresse, die bei allen RADIUS-Serverabfragen verwendet wird.

set vpn pptp remote-access authentication radius rate-limit attribute <attribute>

Gibt an, welches RADIUS-Serverattribut den Rate-Limit-Informationen entspricht. Das Standardattribut ist Filter-Id.

Hinweis

Wenn Sie ein benutzerdefiniertes RADIUS-Attribut festlegen, müssen Sie es auf beiden Seiten in den Dictionaries des RADIUS-Servers und Clients definieren.

set vpn pptp remote-access authentication radius rate-limit enable

Ermöglicht Bandbreitensteuerung über RADIUS.

set vpn pptp remote-access authentication radius rate-limit vendor

Gibt das Herstellerdictionary an, das Dictionary muss sich in /usr/share/accel-ppp/radius befinden.

Empfangene RADIUS-Attribute haben eine höhere Priorität als Parameter, die innerhalb der CLI-Konfiguration definiert sind, siehe die Erklärung unten.

Client-IP-Adressen durch RADIUS zuweisen

Wenn der RADIUS-Server das Attribut Framed-IP-Address sendet, wird diese IP-Adresse dem Client zugewiesen und der Option default-pool innerhalb der CLI-Konfiguration wird ignoriert.

Wenn der RADIUS-Server das Attribut Framed-Pool sendet, wird die IP-Adresse aus einem vordefinierten IP-Pool zugewiesen, dessen Name dem Attributwert entspricht.

Wenn der RADIUS-Server das Attribut Stateful-IPv6-Address-Pool sendet, wird die IPv6-Adresse aus einem vordefinierten IPv6-Pool prefix zugewiesen, dessen Name dem Attributwert entspricht.

Wenn der RADIUS-Server das Attribut Delegated-IPv6-Prefix-Pool sendet, wird der IPv6-Deligation-Präfix aus einem vordefinierten IPv6-Pool delegate zugewiesen, dessen Name dem Attributwert entspricht.

Hinweis

Stateful-IPv6-Address-Pool und Delegated-IPv6-Prefix-Pool sind in RFC6911 definiert. Wenn sie in Ihrem RADIUS-Server nicht definiert sind, fügen Sie neue Dictionary hinzu.

Der Benutzeroberflächenschnittstelle kann über einen RADIUS Access-Accept-Paket in den VRF-Kontext gestellt werden oder über RADIUS CoA geändert werden. Accel-VRF-Name wird für diese Zwecke verwendet. Es handelt sich um ein benutzerdefiniertes ACCEL-PPP-Attribut. Definieren Sie es in Ihrem RADIUS-Server.

Client-Schnittstellen durch RADIUS umbenennen

Wenn der RADIUS-Server das Attribut NAS-Port-Id verwendet, werden die pp-Tunnel umbenannt.

Hinweis

Der Wert des Attributs NAS-Port-Id muss weniger als 16 Zeichen lang sein, andernfalls wird die Schnittstelle nicht umbenannt.

IPv6

set vpn pptp remote-access ppp-options ipv6 <require | prefer | allow | deny>

Gibt die Präferenz für die IPv6-Verhandlung an.

  • require - IPv6-Verhandlung erfordern

  • prefer - Client nach IPv6-Verhandlung fragen, nicht fehlschlagen, wenn er ablehnt

  • allow - IPv6 nur dann verhandeln, wenn der Client darum bittet (Standardwert)

  • deny - IPv6 nicht verhandeln

set vpn pptp remote-access client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Verwenden Sie diesen Befehl, um das IPv6-Adresspool festzulegen, aus dem ein PPTP-Client eine IPv6-Präfix Ihrer definierten Länge (Maske) erhält, um den PPTP-Endpunkt auf ihrer Seite zu beenden. Die Maske kann von 48 bis 128 Bit eingestellt werden, der Standardwert ist 64.

set vpn pptp remote-access client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Verwenden Sie diesen Befehl, um DHCPv6 Prefix Delegation (RFC3633) auf PPTP zu konfigurieren. Sie müssen Ihr IPv6-Pool und die Länge des Delegation-Präfixes festlegen. Von dem definierten IPv6-Pool geben Sie Netzwerke der definierten Länge (Delegation-Präfix) aus. Die Länge des Delegation-Präfixes kann von 32 bis 64 Bit eingestellt werden.

set vpn pptp remote-access default-ipv6-pool <IPv6-POOL-NAME>

Verwenden Sie diesen Befehl, um den Namen des Standard-IPv6-Adresspools zu definieren.

set vpn pptp remote-access ppp-options ipv6 allow
set vpn pptp remote-access client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn pptp remote-access client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn pptp remote-access default-ipv6-pool IPv6-POOL

Erweiterte IPv6-Optionen

set vpn pptp remote-access ppp-options ipv6-accept-peer-interface-id

Peer-Interface-Identifikator akzeptieren. Standardmäßig ist dies nicht definiert.

set vpn pptp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Gibt einen festen oder zufälligen Interface-Identifikator für IPv6 an. Standardmäßig ist es fest.

  • random - Zufälliger Interface-Identifikator für IPv6

  • x:x:x:x - Geben Sie den Interface-Identifikator für IPv6 an

set vpn pptp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Gibt den Peer-Interface-Identifikator für IPv6 an. Standardmäßig ist es fest.

  • random - Zufälliger Interface-Identifikator für IPv6

  • x:x:x:x - Geben Sie den Interface-Identifikator für IPv6 an

  • ipv4-addr - Berechnen Sie den Interface-Identifikator aus der IPv4-Adresse.

  • calling-sid - Berechnen Sie den Interface-Identifikator aus calling-station-id.

Erweiterte PPP-Optionen

set vpn pptp remote-access ppp-options disable-ccp

Deaktivieren Sie das Compression Control Protocol (CCP). CCP ist standardmäßig aktiviert.

set vpn pptp remote-access ppp-options interface-cache <number>

Gibt die Anzahl der Schnittstellen an, die im Cache gehalten werden. Das bedeutet, dass die Schnittstelle nicht nach entsprechender Sitzung zerstört wird, sondern in den Cache platziert und später für neue Sitzungen wieder verwendet wird. Dies sollte die Rate der Kernel-Ebene Schnittstellen-Erstellung/Löschung reduzieren. Der Standardwert ist 0.

set vpn pptp remote-access ppp-options ipv4 <require | prefer | allow | deny>

Gibt die Präferenz für die IPv4-Verhandlung an.

  • require - IPv4-Verhandlung erfordern

  • prefer - Client nach IPv4-Verhandlung fragen, nicht fehlschlagen, wenn er ablehnt

  • allow - IPv4 nur dann verhandeln, wenn der Client darum bittet (Standardwert)

  • deny - IPv4 nicht verhandeln

set vpn pptp remote-access ppp-options lcp-echo-failure <number>

Definiert die maximale Anzahl <number> unbeantworteter Echoanfragen. Bei Erreichen des Werts <number> wird die Sitzung zurückgesetzt. Der Standardwert ist 3.

set vpn pptp remote-access ppp-options lcp-echo-interval <interval>

Wenn dieser Option angegeben und größer als 0 ist, sendet das PPP-Modul LCP-Pings der Echoanfrage alle <interval> Sekunden. Der Standardwert ist 30.

set vpn pptp remote-access ppp-options lcp-echo-timeout

Gibt die Zeit in Sekunden an, um auf jede Peer-Aktivität zu warten. Wenn diese Option angegeben wird, wird adaptive lcp echo-Funktion aktiviert und „lcp-echo-failure“ wird nicht verwendet. Der Standardwert ist 0.

set vpn pptp remote-access ppp-options min-mtu <number>

Definiert die minimale akzeptable MTU. Wenn der Client versucht, weniger als die angegebene MTU zu verhandeln, wird es NAKed oder getrennt, wenn es größere MTU ablehnt. Der Standardwert ist 100.

set vpn pptp remote-access ppp-options mppe <require | prefer | deny>

Gibt die MPPE-Verhandlungspräferenz an.

  • require - Client nach MPPE fragen, wenn er ablehnt, Verbindung trennen

  • prefer - Client nach MPPE fragen, wenn er ablehnt, nicht fehlschlagen. (Standardwert)

  • deny - MPPE ablehnen

Standardverhalten - Client nicht nach MPPE fragen, aber erlauben, wenn Client möchte. Bitte beachten Sie, dass RADIUS diesen Wert durch das MS-MPPE-Encryption-Policy-Attribut überschreiben kann.

set vpn pptp remote-access ppp-options mru <number>

Definiert das bevorzugte MRU. Standardmäßig ist es nicht definiert.
