DHCP-Server

VyOS verwendet den Kea DHCP-Server für die Zuweisung von IPv4- und IPv6-Adressen.

IPv4-Server

Die Netzwerktopologie wird durch shared-network-name und Subnetzdeklarationen definiert. Der DHCP-Dienst kann mehrere gemeinsame Netzwerke bedienen, wobei jedes gemeinsame Netzwerk 1 oder mehrere Subnetze haben kann. Jedes Subnetz muss auf einem Interface vorhanden sein. Ein Bereich kann innerhalb eines Subnetzes deklariert werden, um einen Pool dynamischer Adressen zu definieren. Mehrere Bereiche können definiert werden und können Löcher enthalten. Statische Zuordnungen können eingerichtet werden, um „statische“ Adressen an Clients basierend auf deren MAC-Adresse zuzuweisen.

Die folgenden DHCP-Optionen gelten für ein ganzes gemeinsames Netzwerk. Alle Subnetze erben diese Werte, es sei denn, die gleiche Option ist lokal festgelegt.

Gibt das Client-Subnetzmaske gemäß RFC 950 an. Wenn nicht gesetzt, wird die Subnetzdeklaration verwendet (DHCP Option 1).

set service dhcp-server shared-network-name <name> option default-router <address>

IP-Adresse des Standardrouters (DHCP Option 3).

set service dhcp-server shared-network-name <name> option domain-name <domain-name>

Der domain-name-Parameter sollte der Domänenname sein, der dem Hostnamen des Clients angehängt wird, um einen vollständigen Domänennamen (FQDN) zu bilden (DHCP Option 15).

Dies ist der Konfigurationsparameter für die gesamte gemeinsame Netzwerkkonfiguration. Alle Subnetze erben diesen Konfigurationswert, sofern nicht lokal festgelegt.

set service dhcp-server shared-network-name <name> option domain-search <domain-name>

These settings can be configured on the global level and overridden on the scope level, i.e. for individual shared networks or subnets. See examples below.

set service dhcp-server dynamic-dns-update send-updates <enable | disable>

If set to enable on global level, updates for all scopes will be enabled, except if explicitly set to disable on the scope level. If set to disable, updates will only be sent for scopes, where send-updates is explicitly set to enable.

This model is followed for a few behavioral settings below: if the option is not set, the setting is inherited from the parent scope. You can override the parent scope setting by setting the option explicitly.

set service dhcp-server dynamic-dns-update override-no-update <enable | disable>

VyOS will ignore client request not to update DNS records and send DDNS update requests regardless.

set service dhcp-server dynamic-dns-update override-client-update <enable | disable>

VyOS will override client DDNS request settings and always update both forward and reverse DNS records.

set service dhcp-server dynamic-dns-update update-on-renew <enable | disable>

Issue DDNS update requests on DHCP lease renew. In busy networks this may generate a lot of traffic.

TSIG keys definition

This is the global list of TSIG keys for DDNS updates. They need to be specified by the name in the DNS domain definitions.

set service dhcp-server dynamic-dns-update tsig-key <key-name> algorithm <algorithm>

Sets the algorithm for the TSIG key. Supported algorithms are hmac-md5, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384, hmac-sha512

set service dhcp-server dynamic-dns-update tsig-key <key-name> secret <key-secret>

base64-encoded TSIG key secret value

DNS domains definition

This is global configuration of DNS servers for the updatable forward and reverse DNS domains. For every domain multiple DNS servers can be specified.

set service dhcp-server dynamic-dns-update [forward|reverse]-domain <domain-name> key-name <tsig-key-name>

TSIG key used for the domain.

set service dhcp-server dynamic-dns-update [forward|reverse]-domain <domain-name> dns-server <number> address <ip-address>

IP address of the DNS server.

set service dhcp-server dynamic-dns-update [forward|reverse]-domain <domain-name> dns-server <number> port <port>

UDP port of the DNS server. 53 is the default.

Example:

Global configuration you will most likely want:

set service dhcp-server dynamic-dns-update send-updates enable
set service dhcp-server dynamic-dns-update conflict-resolution enable

Override the above configuration for a shared network NET1:

set service dhcp-server shared-network-name 'NET1' dynamic-dns-update replace-client-name when-not-present
set service dhcp-server shared-network-name 'NET1' dynamic-dns-update generated-prefix ip
