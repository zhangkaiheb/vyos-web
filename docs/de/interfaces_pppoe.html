PPPoE

PPPoE ist ein Netzwerkprotokoll, das PPP-Frames innerhalb von Ethernet-Frames kapselt. Es wird häufig verwendet, um ISP-Clients mit einem Breitband-Zugangs-Server zu verbinden.

Konfiguration

Gemeinsame Schnittstellenkonfiguration

set interfaces pppoe <interface> description <description>

Konfigurieren Sie einen klaren, beschreibenden Alias für die Schnittstelle.

Dieser Alias erscheint im Befehl show interfaces und in SNMP-basierten Überwachungstools.

Beispiel:

set interfaces pppoe pppoe0 description 'This is an interface running on VyOS.'
set interfaces pppoe <interface> disable

Schalten Sie die Schnittstelle aus.

Die Schnittstelle wird auf den administrativ heruntergefahrenen (A/D) Zustand gesetzt.

Beispiel:

set interfaces pppoe pppoe0 disable
set interfaces pppoe <interface> mtu <mtu>

Konfigurieren Sie das MTU auf der Schnittstelle.

Der Wert definiert die größte Paketgröße in Bytes, die die Schnittstelle ohne Fragmentierung überträgt.

Beispiel:

set interfaces pppoe pppoe0 mtu 1600
set interfaces pppoe <interface> vrf <vrf>

Weisen Sie die Schnittstelle einer bestimmten VRF Instanz zu.

Siehe auch

Für Informationen zur Konfiguration einer VRF siehe den Abschnitt VRF.

Beispiel:

set interfaces pppoe pppoe0 vrf red

PPPoE-Optionen

set interfaces pppoe <interface> access-concentrator <name>

Konfigurieren Sie den Namen des Ziel-Zugangs-Konzentrators für die PPPoE-Sitzung.

Während des PPPoE-Entdeckungsprozesses sendet der Client ein PPPoE-Initiierungs-Paket. Mehrere Zugangs-Konzentratoren können mit Angebotspaketen antworten, und der Client wählt eines davon aus.

Diese Einstellung beschränkt den Client darauf, nur mit dem angegebenen Zugangs-Konzentratoren Sitzungen zu erstellen.

set interfaces pppoe <interface> authentication username <username>

Konfigurieren Sie den Benutzernamen für die PPPoE-Sitzungsauthentifizierung.

Obwohl die Authentifizierung optional in der Schnittstellenkonfiguration ist, benötigen die meisten ISPs sie, um eine Verbindung herzustellen.

set interfaces pppoe <interface> authentication password <password>

Konfigurieren Sie das Passwort für die PPPoE-Sitzungsauthentifizierung.

Obwohl die Authentifizierung optional in der Schnittstellenkonfiguration ist, benötigen die meisten ISPs sie, um eine Verbindung herzustellen.

set interfaces pppoe <interface> connect-on-demand

Enable dial-on-demand auf der PPPoE-Schnittstelle.

Wenn aktiviert, stellt das System eine PPPoE-Verbindung nur dann her, wenn Daten durch die Schnittstelle fließen. Wenn die Verbindung fehlschlägt, wird sie wiederhergestellt, sobald der Datenverkehr wieder beginnt.

Für bedarfsgesteuerte Verbindungen müssen Sie außerdem eine idle-timeout-Periode konfigurieren, um die Sitzung nach Inaktivität zu trennen.

Hinweis

Das Festlegen des idle timeout auf Null oder das Nichtkonfigurieren behält die Verbindung aktiv, sobald sie hergestellt wurde.

Standardmäßig wird die PPPoE-Verbindung beim Start hergestellt und bleibt kontinuierlich aktiv; falls die Verbindung fehlschlägt, wird sie sofort wiederhergestellt.

set interfaces pppoe <interface> no-default-route

Anfordern Sie eine IP-Adresse vom PPPoE-Server ohne Installation einer Standardroute.

Beispiel:

set interfaces pppoe pppoe0 no-default-route

Hinweis

Eingeführt in VyOS 1.4, invertiert dieser Befehl die Logik des ehemaligen default-route CLI-Option.

set interfaces pppoe <interface> default-route-distance <distance>

Konfigurieren Sie die Distanz für den Standardgateway, der vom PPPoE-Server bereitgestellt wird.

Beispiel:

set interfaces pppoe pppoe0 default-route-distance 220
set interfaces pppoe <interface> mru <mru>

Konfigurieren Sie das MRU für die PPPoE-Schnittstelle.

Diese Einstellung weist den pppd-Dienst an, den entfernten Peer daran zu hindern, Pakete größer als das konfigurierte MRU zu senden. Erlaubte MRU-Werte liegen zwischen 128 und 16384 Bytes.

Ein MRU von 296 ist für sehr langsamen Links (40 Bytes für das TCP/IP-Header und 256 Bytes für Daten) geeignet.

Das Standard-MRU beträgt 1492 Bytes.

Hinweis

Bei Verwendung des IPv6-Protokolls muss das MRU mindestens 1280 Bytes betragen.

set interfaces pppoe <interface> idle-timeout <time>

Konfigurieren Sie den Inaktivitätszeitraum für bedarfsgesteuerte PPPoE-Sitzungen.

Diese Einstellung definiert, wie lange die Verbindung aktiv bleibt, ohne dass Datenfluss stattfindet, bevor sie getrennt wird.

Hinweis

Das Festlegen des Inaktivitätszeitraums auf Null oder das Nichtkonfigurieren behält die Verbindung aktiv, sobald sie hergestellt wurde.

set interfaces pppoe <interface> holdoff <time>

Konfigurieren Sie die Wartezeit für dauerhafte PPPoE-Sitzungen.

Wenn eine dauerhafte Sitzung (mit connect-on-demand deaktiviert) vom Remote-Partner beendet wird oder unerwartet abbricht, wartet der Router die angegebene Intervallzeit, bevor er versucht, sich erneut zu verbinden.

Die Standardwartezeit beträgt 30 Sekunden.

set interfaces pppoe <interface> local-address <address>

Konfigurieren Sie die lokale Endpunktkennung für PPPoE-Sitzungen.

Standardmäßig wird diese IP-Adresse vereinbart.

set interfaces pppoe <interface> no-peer-dns

Deaktivieren Sie die Installation der von der lokalen Systemwerbung angegebenen DNS-Nameserver.

set interfaces pppoe <interface> remote-address <address>

Konfigurieren Sie die entfernte Endpunktkennung für PPPoE-Sitzungen.

Standardmäßig wird diese IP-Adresse vereinbart.

set interfaces pppoe <interface> service-name <name>

Konfigurieren Sie den Dienstnamen des Ziel-Zugangs-Konzentrators für die PPPoE-Sitzung.

Standardmäßig verbindet die PPPoE-Schnittstelle mit jedem verfügbaren Zugangs-Konzentratoren.

set interfaces pppoe <interface> source-interface <source-interface>

Konfigurieren Sie die zugrunde liegende Schnittstelle für die PPPoE-Verbindung.

Jede PPPoE-Verbindung wird über eine zugrunde liegende Schnittstelle hergestellt, die eine Ethernet-Schnittstelle, ein VIF oder eine Bonding-Schnittstelle sein kann.

set interfaces pppoe <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

Konfigurieren Sie das MSS im ausgehenden TCP SYN-Paket auf der angegebenen Schnittstelle.

Durch das Begrenzen des MSS-Werts in TCP SYN-Paketen instruieren Sie den Remote-Partner, keine Pakete größer als die angegebene Größe zu senden. Dies hilft, Verbindungsprobleme zu vermeiden, falls PMTUD fehlschlägt.

Die folgenden Optionen sind verfügbar:

  • mss: Setzt das MSS auf einen spezifischen Wert in Bytes.

  • clamp-mss-to-pmtu: Setzt das MSS auf das MTU der Schnittstelle minus 40 Bytes für IPv4-Datenverkehr (20 Bytes für das IPv4-Header und 20 Bytes für das TCP-Header). Diese Option wird empfohlen, um den richtigen Wert automatisch zu setzen.

Hinweis

Ab VyOS 1.4 wurde dieser Befehl eingeführt und ersetzt die ältere Syntax set firewall options interface <name> adjust-mss <value>.

set interfaces pppoe <interface> ip disable-forwarding

Konfigurieren Sie die Schnittstelle für Host- oder Router-Verhalten.

Wenn konfiguriert, wechselt die Schnittstelle in Hostmodus und wird IPv4-Weiterleitung deaktiviert.

set interfaces pppoe <interface> ip source-validation <strict | loose | disable>

Konfigurieren Sie die Quell-IP-Adressen-Validierung mit RPF auf dieser Schnittstelle, wie in RFC 3704 beschrieben.

Die folgenden Optionen sind verfügbar:

  • strict: Jedes eingehende Paket wird anhand des FIB überprüft. Wenn die Schnittstelle nicht der beste Weg zurück zu diesem Quell-IP-Adress ist, schlägt die Validierung fehl und das Paket wird gelöscht.

  • loose: Jedes eingehende Paket wird anhand des FIB überprüft. Wenn die Quell-IP-Adresse über keine Schnittstelle erreichbar ist, schlägt die Validierung fehl.

  • disable: Keine Quell-IP-Adressen-Validierung wird durchgeführt. Alle eingehenden Pakete werden akzeptiert.

RFC 3704 empfiehlt, den strict-Modus zu aktivieren, um IP-Spoofing, wie z. B. DDoS-Angriffe, zu verhindern. Für asynchrone oder komplexe Routing-Szenarien verwenden Sie den loose-Modus.

IPv6

set interfaces pppoe <interface> ipv6 address autoconf

IPv6-Adresszuweisung über SLAAC auf dieser Schnittstelle aktivieren.

set interfaces pppoe <interface> ipv6 adjust-mss <mss | clamp-mss-to-pmtu>

Konfigurieren Sie das MSS im ausgehenden TCP SYN-Paket auf der angegebenen Schnittstelle.

Durch das Begrenzen des MSS-Werts in TCP SYN-Paketen instruieren Sie den Remote-Partner, keine Pakete größer als die angegebene Größe zu senden. Dies hilft, Verbindungsprobleme zu vermeiden, falls PMTUD fehlschlägt.

Die folgenden Optionen sind verfügbar:

  • mss: Setzt das MSS auf einen spezifischen Wert in Bytes.

  • clamp-mss-to-pmtu: Setzt das MSS auf das MTU der Schnittstelle minus 60 Bytes für IPv6-Datenverkehr (40 Bytes für das IPv6-Header und 20 Bytes für das TCP-Header). Diese Option wird empfohlen, um den richtigen Wert automatisch zu setzen.

Hinweis

Ab VyOS 1.4 wurde dieser Befehl eingeführt und ersetzt die ältere Syntax set firewall options interface <name> adjust-mss <value>.

set interfaces pppoe <interface> ipv6 disable-forwarding

Konfigurieren Sie die Schnittstelle für Host- oder Router-Verhalten.

Wenn konfiguriert, wechselt die Schnittstelle in Hostmodus und wird IPv6-Weiterleitung deaktiviert.

DHCPv6 Prefix Delegation (PD)

VyOS unterstützt DHCPv6 Prefix Delegation (DHCPv6-PD), wie in RFC 3633 beschrieben. DHCPv6-PD wird von den meisten ISPs unterstützt, die native IPv6 für Verbraucher auf festen Netzwerken anbieten.

set interfaces pppoe <interface> dhcpv6-options pd <id> length <length>

Konfigurieren Sie eine spezifische Präfixlänge für DHCPv6-PD-Anfragen auf dieser Schnittstelle.

Einige ISPs bieten standardmäßig nur ein /64-Präfix an. Verwenden Sie diesen Befehl, um eine andere Präfixlänge für eine spezifische DHCPv6-PD-Anfrage anzufordern, die von /32 (wenn von Ihrem ISP erlaubt) bis /64 reicht. <id> ist ein einzigartiger Bezeichner für die DHCPv6-PD-Anfrage.

Der Standardwert ist 64.

Um ein /56-Präfix von Ihrem ISP anzufordern, verwenden Sie:

set interfaces pppoe pppoe0 dhcpv6-options pd 0 length 56
set interfaces pppoe <interface> dhcpv6-options pd <id> interface <delegatee> address <address>

Konfigurieren Sie den IPv6-Schnittstellen-Identifier (Host-Anteil) für die delegatee-Schnittstelle.

Der Wert muss eine Dezimalzahl sein. Er wird dem delegierten Präfix und dem konfigurierten SLA ID angehängt, um die endgültige IPv6-Adresse zu bilden.

Standardmäßig wird der Host-Anteil basierend auf der MAC-Adresse der Elternschnittstelle generiert (EUI-64-Format).

Beispiel:

Wenn ein /64-Präfix an die Schnittstelle eth8 delegiert wird und Sie den Host-Anteil als 65535 konfigurieren, endet die resultierende IPv6-Adresse mit ::ffff, da 65535 hexadezimal ffff entspricht.

set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth8 address 65534
set interfaces pppoe <interface> dhcpv6-options pd <id> interface <delegatee> sla-id <id>

Konfigurieren Sie den SLA ID für die delegatee-Schnittstelle.

Der Wert muss eine Dezimalzahl sein, größer als 0 und in die Länge der SLA IDs passt. Er wird in Hexadezimal umgewandelt und an das delegierte Präfix angehängt, um das spezifische Subnetzpräfix für die delegatee-Schnittstelle zu bilden.

Beispiel:

Wenn SLA ID 1 ist und das delegierte Präfix 2001:db8:ffff::/48 ist, wird das resultierende Subnetzpräfix für die delegatee-Schnittstelle 2001:db8:ffff:1::/64 sein.

set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth8 sla-id 1

Beispiel

PPPoE über DSL

Konfigurations-Szenario:

  • Ihr ISP's DSL-Modem ist an die eth0 Schnittstelle Ihres VyOS-Routers angeschlossen.

  • Ihr ISP benötigt keine VLAN-Beschilderung.

  • PPPoE-Anmeldeinformationen werden von Ihrem ISP bereitgestellt. Das typische Benutzernamensformat ist name@host.net, obwohl dies variieren kann.

Konfigurationsnotizen:

  • Das maximale MTU-Größe für DSL beträgt 1492, wegen PPPoE-Overhead. Wenn Sie von einem DHCP-basierten ISP wechseln (z. B. ein Standard-Kabelanschluss), stellen Sie sicher, dass VPN-Verbindungen entsprechend angepasst werden.

  • Um ISP-bereitgestellte Nameserver zu ignorieren und nur Ihre statisch konfigurierten zu verwenden, setzen Sie die name-server Option auf none.

  • Ein Standardroute wird automatisch installiert, sobald die Schnittstelle aktiviert ist. Um dieses Verhalten zu ändern, verwenden Sie die no-default-route CLI-Option.

Hinweis

Die PPPoE-Konfigurationsyntax hat sich nach VyOS 1.2 (Crux) geändert und wird während eines Upgrades automatisch migriert.

set interfaces pppoe pppoe0 authentication username 'userid'
set interfaces pppoe pppoe0 authentication password 'secret'
set interfaces pppoe pppoe0 source-interface 'eth0'

Schützen Sie Ihre Einrichtung, indem Sie Regeln erstellen, die die pppoe0 Schnittstelle in den Firewall-Chains abgleichen:

set firewall ipv4 input filter rule 10 inbound-interface name 'pppoe0'
set firewall ipv4 forward filter rule 10 inbound-interface name 'pppoe0'

PPPoE über VLAN

Einige ISPs erfordern, dass PPPoE-Verbindungen über eine VLAN-Schnittstelle hergestellt werden. Dieses spezifische Topologie wird vollständig von VyOS unterstützt.

Die folgende Konfiguration stellt die PPPoE-Verbindung über VLAN 7 her, was das Standard-VLAN für Deutsche Telekom ist:

set interfaces pppoe pppoe0 authentication username 'userid'
set interfaces pppoe pppoe0 authentication password 'secret'
set interfaces pppoe pppoe0 source-interface 'eth0.7'

IPv6 DHCPv6 Präfixdelegation

Konfigurations-Szenario:

Die folgende Konfiguration stellt eine PPPoE-Sitzung auf der eth1 Schnittstelle her, fordert ein /56 IPv6-Präfixdelegations von der ISP an und weist ein /64 Subnetz aus dieser Delegation der eth0 Schnittstelle zu.

Konfigurationsnotizen:

  • Die IPv6-Adresse, die der eth0 Schnittstelle zugewiesen wird, ist <prefix>::1/64.

  • Wenn Sie Ihren delegierten Präfix-Größe nicht kennen, beginnen Sie mit sla-len 0.

  • Um das Präfix auf der eth0 Verbindung zu bewerben, konfigurieren Sie IPv6 Router Advertisement.

set interfaces pppoe pppoe0 authentication username vyos
set interfaces pppoe pppoe0 authentication password vyos
set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth0 address '1'
set interfaces pppoe pppoe0 dhcpv6-options pd 0 interface eth0 sla-id '0'
set interfaces pppoe pppoe0 dhcpv6-options pd 0 length '56'
set interfaces pppoe pppoe0 ipv6 address autoconf
set interfaces pppoe pppoe0 source-interface eth1

set service router-advert interface eth0 prefix ::/64
