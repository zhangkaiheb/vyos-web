Politik

Policen werden zum Filtern und Verkehrsmanagement verwendet. Mit Policen können Netzwerkadministratoren den Verkehr entsprechend ihren Anforderungen filtern und behandeln.

Es könnte eine breite Palette an Routing-Policen geben. Einige Beispiele sind unten aufgelistet:

  • Verkehr basierend auf Quell-/Zieladresse filtern.

  • Einen bestimmten Metrik-Wert für Routen festlegen, die von einem bestimmten Nachbarn gelernt wurden.

  • Einige Attribute (wie AS PATH oder Community-Wert) für angebotene Routen an Nachbarn festlegen.

  • Eine spezifische Routing-Protokoll-Routen über ein anderes Routing-Protokoll vorziehen, das auf demselben Router läuft.

In VyOS werden Policen mithilfe von FRR-Filtern und Route-Maps implementiert. Detaillierte Informationen zu FRR finden Sie unter http://docs.frrouting.org/
