Route Map Richtlinie

Route map ist ein leistungsstarker Befehl, der Netzwerkadministratoren ein sehr nützliches und flexibles Werkzeug für die Verkehrsmanipulation bietet.

Konfiguration

Route Map

set policy route-map <text>

Dieser Befehl erstellt eine neue Route-Map-Richtlinie, identifiziert durch <text>.

set policy route-map <text> description <text>

Legen Sie eine Beschreibung für die Route-Map-Richtlinie fest.

set policy route-map <text> rule <1-65535> action <permit|deny>

Legen Sie die Aktion für die Route-Map-Richtlinie fest.

set policy route-map <text> rule <1-65535> call <text>

Rufen Sie eine andere Route-Map-Richtlinie auf, wenn ein Treffer vorliegt.

set policy route-map <text> rule <1-65535> continue <1-65535>

Wechseln Sie zu einer anderen Regel in dieser Route-Map bei einem Treffer.

set policy route-map <text> rule <1-65535> description <text>

Legen Sie eine Beschreibung für die Regel in der Route-Map-Richtlinie fest.

set policy route-map <text> rule <1-65535> match as-path <text>

BGP as-path-Liste zum Abgleichen.

set policy route-map <text> rule <1-65535> match community community-list <text>

BGP community-list zum Abgleichen.

set policy route-map <text> rule <1-65535> match community exact-match

Legen Sie die BGP community-list auf exakten Abgleich fest.

set policy route-map <text> rule <1-65535> match extcommunity <text>

BGP erweiterte Community zum Abgleichen.

set policy route-map <text> rule <1-65535> match interface <text>

Erster Hop-Interface einer Route zum Abgleichen.

set policy route-map <text> rule <1-65535> match ip address access-list <1-2699>

IP-Adresse einer Route zum Abgleichen, basierend auf der Zugriffsliste.

set policy route-map <text> rule <1-65535> match ip address prefix-list <text>

IP-Adresse einer Route zum Abgleichen, basierend auf der Präfixliste.

set policy route-map <text> rule <1-65535> match ip address prefix-len <0-32>

IP-Adresse einer Route zum Abgleichen, basierend auf der angegebenen Präfixlänge. Hinweis: Dies kann nur für Kernel-Wege verwendet werden. Wenden Sie dies nicht auf Wege dynamischer Routing-Protokolle (z. B. BGP, RIP, OSFP) an, da dies zu unerwarteten Ergebnissen führen kann.

set policy route-map <text> rule <1-65535> match ip nexthop access-list <1-2699>

IP-Nächste-Hop-Adresse einer Route zum Abgleichen, basierend auf der Zugriffsliste.

set policy route-map <text> rule <1-65535> match ip nexthop address <x.x.x.x>

IP-Nächste-Hop-Adresse einer Route zum Abgleichen, basierend auf der IP-Adresse.

set policy route-map <text> rule <1-65535> match ip nexthop prefix-len <0-32>

IP-Nächste-Hop-Adresse einer Route zum Abgleichen, basierend auf der Präfixlänge.

set policy route-map <text> rule <1-65535> match ip nexthop prefix-list <text>

IP-Nächste-Hop-Adresse einer Route zum Abgleichen, basierend auf der Präfixliste.

set policy route-map <text> rule <1-65535> match ip nexthop type <blackhole>

IP-Nächste-Hop-Adresse einer Route zum Abgleichen, basierend auf dem Typ.

set policy route-map <text> rule <1-65535> match ip route-source access-list <1-2699>

IP-Quellweg einer Route zum Abgleichen, basierend auf der Zugriffsliste.

set policy route-map <text> rule <1-65535> match ip route-source prefix-list <text>

IP-Quellweg einer Route zum Abgleichen, basierend auf der Präfixliste.

set policy route-map <text> rule <1-65535> match ipv6 address access-list <text>

IPv6-Adresse einer Route zum Abgleichen, basierend auf der IPv6-Zugriffsliste.

set policy route-map <text> rule <1-65535> match ipv6 address prefix-list <text>

IPv6-Adresse einer Route zum Abgleichen, basierend auf der IPv6-Präfixliste.

set policy route-map <text> rule <1-65535> match ipv6 address prefix-len <0-128>

IPv6-Adresse einer Route zum Abgleichen, basierend auf der angegebenen Präfixlänge. Hinweis: Dies kann nur für Kernel-Wege verwendet werden. Wenden Sie dies nicht auf Wege dynamischer Routing-Protokolle (z. B. BGP, RIP, OSFP) an, da dies zu unerwarteten Ergebnissen führen kann.

set policy route-map <text> rule <1-65535> match ipv6 nexthop <h:h:h:h:h:h:h:h>

Nächste-Hop-IPv6-Adresse zum Abgleichen.

set policy route-map <text> rule <1-65535> match large-community large-community-list <text>

Abgleich von BGP großen Communities.

set policy route-map <text> rule <1-65535> match local-preference <0-4294967295>

Abgleich der lokalen Präferenz.

set policy route-map <text> rule <1-65535> match metric <1-65535>

Abgleich des Routen-Metrics.

set policy route-map <text> rule <1-65535> match origin <egp|igp|incomplete>

Border Gateway Protocol (BGP) Ursprungscode zum Abgleichen.

set policy route-map <text> rule <1-65535> match peer <x.x.x.x>

Peer-IP-Adresse zum Abgleichen.

set policy route-map <text> rule <1-65535> match protocol <protocol>
Quellprotokoll zum Abgleichen.

  • babel - Babel-Routing-Protokoll (Babel)

  • bgp - Border Gateway Protocol (BGP)

  • connected - Verbundene Routen (direkt angeschlossenes Subnetz oder Host)

  • isis - Intermediate System to Intermediate System (IS-IS)

  • kernel - Kernel-Routen

  • ospf - Open Shortest Path First (OSPFv2)

  • ospfv3 - Open Shortest Path First (IPv6) (OSPFv3)

  • rip - Routing Information Protocol (RIP)

  • ripng - Routing Information Protocol next-generation (IPv6) (RIPng)

  • static - Statisch konfigurierte Routen

  • table - Nicht-Haupt-Kernel-Routing-Tabelle

  • vnc - Virtual Network Control (VNC)

set policy route-map <text> rule <1-65535> match rpki <invalid|notfound|valid>

Abgleich des RPKI-Validierungsergebnisses.

set policy route-map <text> rule <1-65535> match source-vrf <text>

Quell-VRF zum Abgleichen.

set policy route-map <text> rule <1-65535> match tag <1-65535>

Route-Tag zum Abgleichen.

set policy route-map <text> rule <1-65535> on-match goto <1-65535>

Ausgangsrichtlinie bei Übereinstimmung: gehen Sie zur Regel <1-65535>

set policy route-map <text> rule <1-65535> on-match next

Ausgangsrichtlinie bei Übereinstimmung: gehen Sie zur nächsten Sequenznummer.

set policy route-map <text> rule <1-65535> set aggregator <as|ip> <1-4294967295|x.x.x.x>

BGP-Aggregator-Attribut: AS-Nummer oder IP-Adresse eines Aggregats.

set policy route-map <text> rule <1-65535> set as-path exclude <1-4294967295 | all>

Entfernen Sie AS-Nummer aus dem BGP AS-Pfad.

Wenn all angegeben wird, entfernen Sie alle AS-Nummern aus dem AS_PATH des BGP Pfad NLRI.

set policy route-map <text> rule <1-65535> set as-path prepend <1-4294967295>

Das gegebene String von AS-Nummern am Anfang des AS_PATH des BGP Pfad NLRI anhängen.

set policy route-map <text> rule <1-65535> set as-path prepend-last-as <n>

Hängen Sie die vorhandene letzte AS-Nummer (die linke AS-Nummer) an das AS_PATH an.

set policy route-map <text> rule <1-65535> set atomic-aggregate

BGP atomares Aggregat-Attribut.

set policy route-map <text> rule <1-65535> set community <add|replace> <community>

Fügen Sie oder ersetzen Sie das BGP Community-Attribut im Format <0-65535:0-65535> oder aus einer bekannten Community-Liste

set policy route-map <text> rule <1-65535> set community none

Löschen Sie alle BGP-Communities

set policy route-map <text> rule <1-65535> set community delete <text>

Löschen Sie BGP-Communities, die mit der Community-Liste übereinstimmen.

set policy route-map <text> rule <1-65535> set large-community <add|replace> <GA:LDP1:LDP2>

Fügen Sie oder ersetzen Sie das BGP große Community-Attribut im Format <0-4294967295:0-4294967295:0-4294967295>

set policy route-map <text> rule <1-65535> set large-community none

Löschen Sie alle BGP große Communities

set policy route-map <text> rule <1-65535> set large-community delete <text>

Löschen Sie BGP-Communities, die mit der großen Community-Liste übereinstimmen.

set policy route-map <text> rule <1-65535> set extcommunity bandwidth <1-25600|cumulative|num-multipaths>

Setzen Sie die externe Community-Bandbreite

set policy route-map <text> rule <1-65535> set extcommunity bandwidth-non-transitive

Die Link-Bandbreite erweiterte Community wird als nicht übertragbar codiert

set policy route-map <text> rule <1-65535> set extcommunity rt <text>

Setzen Sie den Route Target-Wert im Format <0-65535:0-4294967295> oder <IP:0-65535>.

set policy route-map <text> rule <1-65535> set extcommunity soo <text>

Setzen Sie den Site of Origin-Wert im Format <0-65535:0-4294967295> oder <IP:0-65535>.

set policy route-map <text> rule <1-65535> set extcommunity none

Löschen Sie alle BGP extcommunities.

set policy route-map <text> rule <1-65535> set distance <0-255>

Lokal signifikante administrativ Entfernung.

set policy route-map <text> rule <1-65535> set ip-next-hop <x.x.x.x>

Nächste-Hop-IP-Adresse.

set policy route-map <text> rule <1-65535> set ip-next-hop unchanged

Setzen Sie den Nächsten Hop als unverändert. Durchlaufen Sie die Route-Map ohne seinen Wert zu ändern

set policy route-map <text> rule <1-65535> set ip-next-hop peer-address

Setzen Sie die BGP Nächste-Hop-Adresse auf die Adresse des Peers. Für eine eingehende Route-Map bedeutet dies, dass die IP-Adresse unseres Peers verwendet wird. Für eine ausgehende Route-Map bedeutet dies, dass die IP-Adresse unseres selbst verwendet wird, um das Peering mit unserem Nachbarn herzustellen.

set policy route-map <text> rule <1-65535> set ipv6-next-hop <global|local> <h:h:h:h:h:h:h:h>

Nächste-Hop-IPv6-Adresse.

set policy route-map <text> rule <1-65535> set ipv6-next-hop peer-address

Setzen Sie die BGP Nächste-Hop-Adresse auf die Adresse des Peers. Für eine eingehende Route-Map bedeutet dies, dass die IP-Adresse unseres Peers verwendet wird. Für eine ausgehende Route-Map bedeutet dies, dass die IP-Adresse unseres selbst verwendet wird, um das Peering mit unserem Nachbarn herzustellen.

set policy route-map <text> rule <1-65535> set ipv6-next-hop prefer-global

Für eingehende und Import-Route-Maps, wenn wir eine v6 globale und v6 LL Adresse für den Weg empfangen, bevorzugen Sie, die globale Adresse als Nächste-Hop zu verwenden.

set policy route-map <text> rule <1-65535> set local-preference <0-4294967295>

Setzen Sie das BGP lokale Präferenzattribut.

set policy route-map <text> rule <1-65535> set metric <+/-metric|0-4294967295|rtt|+rtt|-rtt>

Setzen Sie den Routen-Metric. Wenn mit BGP verwendet, setzen Sie das BGP Attribut MED auf einen bestimmten Wert. Verwenden Sie +/-, um den angegebenen Wert zu addieren oder zu subtrahieren. Verwenden Sie rtt, um die MED auf die Round-Trip-Time zu setzen oder +rtt/-rtt, um die Round-Trip-Time zum/ab dem MED zu addieren/subtrahieren.

set policy route-map <text> rule <1-65535> set metric-type <type-1|type-2>

Setzen Sie den OSPF externen Metric-Type.

set policy route-map <text> rule <1-65535> set origin <igp|egp|incomplete>

Setzen Sie den BGP Ursprungscode.

set policy route-map <text> rule <1-65535> set originator-id <x.x.x.x>

Setzen Sie das BGP Originator-ID-Attribut.

set policy route-map <text> rule <1-65535> set src <x.x.x.x|h:h:h:h:h:h:h:h>

Setzen Sie die Quell-IP/IPv6-Adresse für den Weg.

set policy route-map <text> rule <1-65535> set table <1-200>

Setzen Sie Präfixe in Tabelle.

set policy route-map <text> rule <1-65535> set tag <1-65535>

Setzen Sie den Tag-Wert für das Routing-Protokoll.

set policy route-map <text> rule <1-65535> set weight <0-4294967295>

Setzen Sie das BGP Weight-Attribut
