BFD

BFD est un protocole réseau qui détecte les échecs de communication entre deux appareils de routage connectés en quelques millisecondes — bien plus rapidement que les protocoles de routage traditionnels. BFD ne route pas le trafic lui-même. Il fournit plutôt une détection rapide des pannes pour d'autres protocoles, tels que BGP, OSPF, et les routes statiques.

BFD est décrit et étendu par les RFCs suivantes : RFC 5880, RFC 5881 et RFC 5883.

Comment fonctionne BFD

BFD établit une session entre deux pairs et échange des paquets de contrôle UDP rapides à un intervalle négocié (par exemple, 300 ms entre les paquets consécutifs). Si un pair ne reçoit pas ces paquets dans le délai de détection (l'intervalle négocié multiplié par un multiplicateur de détection), BFD suppose une panne de connexion et informe les protocoles de routage.

Configuration

set protocols bfd peer <address>

Configurez l'adresse IPv4 ou IPv6 du pair BFD.

Vous pouvez configurer plusieurs pairs BFD en spécifiant une adresse IP différente pour chaque voisin que vous souhaitez surveiller.

Remarque

Pour les pairs IPv6, vous devez configurer une adresse IP source ou une interface.

Exemple :

set protocols bfd peer 198.51.100.33
set protocols bfd peer <address> echo-mode

Activez le mode d'envoi d'écho BFD pour le pair à l'adresse IP spécifiée.

Exemple :

set protocols bfd peer 198.51.100.33 echo-mode
set protocols bfd peer <address> multihop

Configurez le pair à l'adresse IP spécifiée comme voisin multihop.

Note

Pour les pairs BFD multihop, vous devez configurer une adresse IP source locale.

Exemple :

set protocols bfd peer 198.51.100.33 multihop
set protocols bfd peer 198.51.100.33 source address 198.51.100.1
set protocols bfd peer <address> source address <address>

Configurez l'adresse IP source pour la session BFD avec le pair à l'adresse IP spécifiée.

Note

La configuration d'une adresse IP source ou d'une interface est obligatoire pour les pairs BFD IPv6.

Exemple :

set protocols bfd peer 198.51.100.33 source address 198.51.100.1
set protocols bfd peer <address> source interface <interface>

Configurez l'interface source pour la session BFD avec le pair à l'adresse IP spécifiée.

Note

La configuration d'une adresse IP source ou d'une interface est obligatoire pour les pairs BFD IPv6.

Exemple :

set protocols bfd peer 2001:db8::2 source interface eth0
set protocols bfd peer <address> interval echo-interval <10-60000>

Configurez l'intervalle minimum, en millisecondes, auquel le système local peut recevoir des paquets d'écho du pair à l'adresse IP spécifiée.

Exemple :

set protocols bfd peer 198.51.100.33 interval echo-interval 50
set protocols bfd peer <address> interval multiplier <2-255>

Configurez le multiplicateur de détection pour le pair à l'adresse IP spécifiée.

BFD multiplie l'intervalle négocié par cette valeur pour calculer le temps de détection — la période après laquelle il déclare la session comme tombée si aucun paquet de contrôle n'arrive.

Exemple :

set protocols bfd peer 192.0.2.1 interval multiplier 3
set protocols bfd peer <address> interval receive <10-60000>

Configurez l'intervalle, en millisecondes, auquel le système local peut recevoir des paquets de contrôle BFD du pair à l'adresse IP spécifiée.

Exemple :

set protocols bfd peer 192.0.2.1 interval receive 300
set protocols bfd peer <address> interval transmit <10-60000>

Configurez l'intervalle, en millisecondes, auquel vous souhaitez que le système local transmette des paquets de contrôle BFD au pair à l'adresse IP spécifiée.

Exemple :

set protocols bfd peer 192.0.2.1 interval transmit 300
set protocols bfd peer <address> shutdown

Désactivez la session BFD avec le pair à l'adresse IP spécifiée.

Exemple :

set protocols bfd peer 198.51.100.33 shutdown
set protocols bfd peer <address> minimum-ttl <1-254>

Configurez la valeur minimale de TTL que doivent avoir les paquets de contrôle BFD entrants pour être acceptés du pair à l'adresse IP spécifiée.

BFD supprime tout paquet dont le TTL est inférieur à cette limite.

Note

Cette configuration s'applique uniquement aux sessions multihop.

Exemple :

set protocols bfd peer 192.0.2.1 minimum-ttl 250
set protocols bfd peer <address> passive

Configurez la session BFD avec le pair à l'adresse IP spécifiée pour qu'elle fonctionne en mode passif.

En mode passif, le système local ne démarre pas la session BFD. Au lieu de cela, il attend de recevoir le premier paquet de contrôle BFD du pair distant.

Note

Au moins l'un des deux pairs doit rester en mode actif pour que la session puisse être établie. Si les deux pairs sont passifs, aucun ne démarre, et la session ne s'établit jamais.

Exemple :

set protocols bfd peer 198.51.100.33 passive
set protocols bfd peer <address> profile <profile>

Appliquez les paramètres d'un profil BFD désigné au pair à l'adresse IP spécifiée.

Exemple :

set protocols bfd peer 192.0.2.1 profile datacenter-fast
set protocols bfd peer <address> vrf <vrf>

Liez la session BFD avec le pair à l'adresse IP spécifiée à une instance spécifique de VRF.

Exemple :

set protocols bfd peer 192.0.2.1 vrf customer-a

Activer BFD dans BGP

set protocols bgp neighbor <neighbor> bfd

Activez la détection des pannes BFD pour la session BGP avec le voisin à l'adresse IP spécifiée.

Exemple :

set protocols bgp neighbor 192.0.2.1 bfd
set protocols bgp peer-group <neighbor> bfd

Activez la détection des pannes BFD pour tous les voisins du groupe de pairs BGP spécifié.

Exemple :

set protocols bgp peer-group INTERNAL-PEERS bfd

Activer BFD dans OSPF

set protocols ospf interface <interface> bfd

Activez la détection des pannes BFD pour les voisins OSPF découverts sur l'interface spécifiée.

Lorsque OSPF forme une adjacence avec un voisin sur cette interface, il demande à BFD d'établir une session avec ce voisin.

Exemple :

set protocols ospf interface eth0 bfd
set protocols ospfv3 interface <interface> bfd

Activez la détection des pannes BFD pour les voisins OSPFv3 découverts sur l'interface spécifiée.

Lorsque OSPFv3 forme une adjacence avec un voisin sur cette interface, il demande à BFD d'établir une session avec ce voisin.

Exemple :

set protocols ospfv3 interface eth0 bfd

Activer BFD dans IS-IS

set protocols isis interface <interface> bfd

Activez la détection des pannes BFD pour les voisins IS-IS découverts sur l'interface spécifiée.

Lorsque IS-IS forme une adjacence avec un voisin sur cette interface, il demande à BFD d'établir une session avec ce voisin.

Exemple :

set protocols isis interface eth0 bfd

Surveillance des routes statiques BFD

Une route statique surveillée est présente dans le RIB uniquement lorsque la session BFD est active. Si la session tombe, la route est supprimée.

set protocols static route <subnet> next-hop <address> bfd profile <profile>

Configurez la détection des pannes BFD pour une route statique à un saut.

BFD utilise l'adresse IP du prochain saut comme adresse IP du pair BFD et applique les paramètres du profil BFD spécifié.

Exemple :

set protocols static route 10.0.0.0/24 next-hop 192.0.2.1 bfd profile datacenter-fast
set protocols static route <subnet> next-hop <address> bfd multi-hop source-address <address>

Configurez la détection des pannes BFD pour une route statique à plusieurs sauts.

BFD utilise l'adresse IP du prochain saut comme adresse IP du pair BFD et l'adresse IP source multihop comme adresse source locale pour les paquets BFD sortants.

Exemple :

set protocols static route 10.0.0.0/24 next-hop 198.51.100.33 bfd multi-hop source-address 198.51.100.1
set protocols static route6 <subnet> next-hop <address> bfd profile <profile>

Configurez la détection des pannes BFD pour une route statique IPv6 à un saut.

BFD utilise l'adresse IPv6 du prochain saut comme adresse IPv6 du pair BFD et applique les paramètres du profil BFD spécifié.

Exemple :

set protocols static route6 2001:db8:1::/64 next-hop 2001:db8::1 bfd profile datacenter-fast
set protocols static route6 <subnet> next-hop <address> bfd multi-hop source-address <address>

Configurez la détection des pannes BFD pour une route statique IPv6 à plusieurs sauts.

BFD utilise l'adresse IPv6 du prochain saut comme adresse IPv6 du pair BFD et l'adresse IPv6 source multihop comme adresse source locale pour les paquets BFD sortants.

Exemple :

set protocols static route6 2001:db8:1::/64 next-hop 2001:db8:100::33 bfd multi-hop source-address 2001:db8::1
