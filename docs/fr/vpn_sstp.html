SSTP Server

SSTP est une forme de tunnel VPN qui fournit un mécanisme pour transporter le trafic PPP à travers un canal SSL/TLS. SSL/TLS fournit une sécurité au niveau du transport avec la négociation des clés, le chiffrement et le contrôle d'intégrité du trafic. L'utilisation de SSL/TLS sur le port TCP 443 permet au SSTP de passer à travers pratiquement tous les pare-feux et serveurs proxy, sauf les serveurs proxy web authentifiés.

SSTP est disponible pour Linux, BSD et Windows.

VyOS utilise accel-ppp pour fournir la fonctionnalité de serveur SSTP. Nous soutenons à la fois l'authentification locale et RADIUS.

Comme SSTP fournit PPP via un canal SSL/TLS, l'utilisation de certificats signés publiquement ou d'une PKI privée est requise.

Configuration du serveur SSTP

Certificats

Utilisez notre chapitre de documentation - PKI pour générer et installer le certificat CA et le certificat serveur

Configuration

set vpn sstp authentication local-users username test password 'test'
set vpn sstp authentication mode 'local'
set vpn sstp client-ip-pool SSTP-POOL range '10.0.0.2-10.0.0.100'
set vpn sstp default-pool 'SSTP-POOL'
set vpn sstp gateway-address '10.0.0.1'
set vpn sstp ssl ca-certificate 'CA1'
set vpn sstp ssl certificate 'Server'
set vpn sstp authentication mode <local | radius>

Définir le backend d'authentification. Le backend d'authentification configuré est utilisé pour toutes les requêtes.

  • radius: Toutes les requêtes d'authentification sont gérées par un serveur RADIUS configuré.

  • local: Toutes les requêtes d'authentification sont gérées localement.

set vpn sstp authentication local-users username <user> password <pass>

Créer <user> pour l'authentification locale sur ce système. Le mot de passe de l'utilisateur sera défini à <pass>.

set vpn sstp client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Utilisez cette commande pour définir la première adresse IP d'un pool d'adresses à attribuer aux clients SSTP. Si la notation x.x.x.x-x.x.x.x est utilisée, elle doit être dans un sous-réseau /24. Si la notation x.x.x.x/x est utilisée, il est possible de définir un hôte/masque réseau.

set vpn sstp default-pool <POOL-NAME>

Utilisez cette commande pour définir le nom du pool d'adresses par défaut.

set vpn sstp gateway-address <gateway>

Spécifie une seule adresse IP <gateway> à utiliser comme adresse locale des interfaces PPP.

set vpn sstp ssl ca-certificate <file>

Nom du certificat de l'autorité de certification installé.

set vpn sstp ssl certificate <file>

Nom du certificat serveur installé.

Configuration de l'authentification RADIUS

Pour activer l'authentification basée sur RADIUS, le mode d'authentification doit être modifié dans la configuration. Les paramètres précédents comme les utilisateurs locaux existent toujours dans la configuration, mais ils ne sont pas utilisés si le mode a été changé de local à radius. Une fois revenu à local, il utilisera à nouveau tous les comptes locaux.

set vpn sstp authentication mode radius
set vpn sstp authentication radius server <server> key <secret>

Configurer le serveur RADIUS <server> et sa clé partagée <secret> nécessaire pour communiquer avec le serveur RADIUS.

Étant donné que le serveur RADIUS serait un point de défaillance unique, plusieurs serveurs RADIUS peuvent être configurés et seront utilisés séquentiellement. Par exemple :

set vpn sstp authentication radius server 10.0.0.1 key 'foo'
set vpn sstp authentication radius server 10.0.0.2 key 'foo'

Note

Certains serveurs RADIUS utilisent une liste d'accès qui autorise ou refuse les requêtes, assurez-vous d'ajouter votre routeur VyOS à la liste des clients autorisés.

Adresse source RADIUS

Si vous utilisez OSPF comme votre IGP, utilisez l'interface connectée la plus proche du serveur RADIUS. Vous pouvez lier toutes les demandes RADIUS sortantes à une adresse IP source unique, par exemple l'interface boucle.

set vpn sstp authentication radius source-address <address>

Adresse IPv4 source utilisée dans toutes les requêtes du serveur RADIUS.

Note

La valeur source-address doit être configurée sur celle d'une interface. La pratique recommandée serait une interface boucle ou dummy.

Options avancées RADIUS

set vpn sstp authentication radius server <server> port <port>

Configurer le <server> RADIUS et son port requis pour les requêtes d'authentification.

set vpn sstp authentication radius server <server> fail-time <time>

Marquer le serveur RADIUS comme hors ligne pendant ce temps <time> en secondes.

set vpn sstp authentication radius server <server> disable

Désactiver temporairement ce serveur RADIUS.

Délai d'attente pour répondre aux paquets Interim-Update. (défaut 3 secondes)

set vpn sstp authentication radius dynamic-author server <address>

Spécifie l'adresse IP du serveur d'extension d'autorisation dynamique (DM/CoA). Cette adresse doit exister sur une interface VyOS ou peut être 0.0.0.0.

set vpn sstp authentication radius dynamic-author port <port>

Port UDP pour le serveur d'extension d'autorisation dynamique (DM/CoA)

set vpn sstp authentication radius dynamic-author key <secret>

Clé pour le serveur d'extension d'autorisation dynamique (DM/CoA)

set vpn sstp authentication radius max-try <number>

Nombre maximum de tentatives pour envoyer les requêtes Access-Request/Accounting-Request

set vpn sstp authentication radius timeout <timeout>

Délai d'attente pour la réponse du serveur (secondes)

set vpn sstp authentication radius nas-identifier <identifier>

Valeur à envoyer au serveur RADIUS dans l'attribut NAS-Identifier et à correspondre dans les requêtes DM/CoA.

set vpn sstp authentication radius nas-ip-address <address>

Valeur à envoyer au serveur RADIUS dans l'attribut NAS-IP-Address et à correspondre dans les requêtes DM/CoA. Le serveur DM/CoA se liera à cette adresse.

set vpn sstp authentication radius source-address <address>

Adresse IPv4 source utilisée dans toutes les requêtes du serveur RADIUS.

set vpn sstp authentication radius rate-limit attribute <attribute>

Spécifie quel attribut du serveur RADIUS contient les informations de limite de taux. La valeur par défaut est Filter-Id.

Note

Si vous définissez un attribut RADIUS personnalisé, vous devez le définir sur les deux dictionnaires du serveur RADIUS et du client.

set vpn sstp authentication radius rate-limit enable

Active le réglage de bande passante via RADIUS.

set vpn sstp authentication radius rate-limit vendor

Spécifie le dictionnaire fournisseur. Ce dictionnaire doit être présent dans /usr/share/accel-ppp/radius.

Les attributs RADIUS reçus ont une priorité plus élevée que les paramètres définis dans la configuration CLI, reportez-vous à l'explication ci-dessous.

Allouer des adresses IP clients par RADIUS

Si le serveur RADIUS envoie l'attribut Framed-IP-Address, cette adresse IP sera allouée au client et l'option default-pool dans la configuration CLI sera ignorée.

Si le serveur RADIUS envoie l'attribut Framed-Pool, l'adresse IP sera allouée à partir d'un pool d'adresses prédéfini dont le nom correspond à la valeur de l'attribut.

Si le serveur RADIUS envoie l'attribut Stateful-IPv6-Address-Pool, l'adresse IPv6 sera allouée à partir d'un pool IPv6 prédéfini prefix dont le nom correspond à la valeur de l'attribut.

Si le serveur RADIUS envoie l'attribut Delegated-IPv6-Prefix-Pool, un préfixe de délégation IPv6 sera alloué à partir d'un pool IPv6 prédéfini delegate dont le nom correspond à la valeur de l'attribut.

Note

Stateful-IPv6-Address-Pool et Delegated-IPv6-Prefix-Pool sont définis dans RFC6911. Si ces attributs ne sont pas définis sur votre serveur RADIUS, ajoutez un nouveau dictionnaire.

L'interface du client peut être placée dans un contexte VRF via un paquet Access-Accept RADIUS, ou modifiée via RADIUS CoA. Accel-VRF-Name est utilisé pour ces purposes. C'est un attribut ACCEL-PPP personnalisé. Définissez-le sur votre serveur RADIUS.

Renommer les interfaces clients par RADIUS

Si le serveur RADIUS utilise l'attribut NAS-Port-Id, les tunnels PPP seront renommés.

Note

La valeur de l'attribut NAS-Port-Id doit être inférieure à 16 caractères, sinon l'interface ne sera pas renommée.

IPv6

set vpn sstp ppp-options ipv6 <require | prefer | allow | deny>

Spécifie la préférence de négociation IPv6.

  • require - Exiger la négociation IPv6

  • prefer - Demander au client la négociation IPv6, ne pas échouer si il la refuse

  • allow - Négocier IPv6 uniquement si le client le demande (valeur par défaut)

  • deny - Ne pas négocier IPv6

set vpn sstp client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Utilisez cette commande pour définir le pool d'adresses IPv6 à partir duquel un client SSTP obtiendra un préfixe IPv6 de longueur définie (masque) pour terminer le point de terminaison SSTP côté client. La longueur du masque peut être définie entre 48 et 128 bits, la valeur par défaut est 64.

set vpn sstp client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Utilisez cette commande pour configurer la délégation de préfixe DHCPv6 (RFC3633) sur SSTP. Vous devrez définir votre pool IPv6 et la longueur du préfixe de délégation. À partir du pool IPv6 défini, vous distribuerez des réseaux de la longueur définie (préfixe de délégation). La longueur du préfixe de délégation peut être définie entre 32 et 64 bits.

set vpn sstp default-ipv6-pool <IPv6-POOL-NAME>

Utilisez cette commande pour définir le nom du pool d'adresses IPv6 par défaut.

set vpn sstp ppp-options ipv6 allow
set vpn sstp client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn sstp client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn sstp default-ipv6-pool IPv6-POOL

Options avancées IPv6

set vpn sstp ppp-options ipv6-accept-peer-interface-id

Accepter l'identifiant d'interface du pair. Par défaut, cela n'est pas défini.

set vpn sstp ppp-options ipv6-interface-id <random | x:x:x:x>

Spécifie si un identifiant d'interface fixe ou aléatoire est utilisé pour IPv6. La valeur par défaut est fixe.

  • random - Identifiant d'interface aléatoire pour IPv6

  • x:x:x:x - Spécifier l'identifiant d'interface pour IPv6

set vpn sstp ppp-options ipv6-interface-id <random | x:x:x:x>

Spécifie l'identifiant d'interface du pair pour IPv6. La valeur par défaut est fixe.

  • random - Identifiant d'interface aléatoire pour IPv6

  • x:x:x:x - Spécifier l'identifiant d'interface pour IPv6

  • ipv4-addr - Calculer l'identifiant d'interface à partir de l'adresse IPv4.

  • calling-sid - Calculer l'identifiant d'interface à partir de calling-station-id.

Options avancées PPP

set vpn sstp ppp-options disable-ccp

Désactiver le Protocole de Contrôle de Compression (CCP). CCP est activé par défaut.

set vpn sstp ppp-options interface-cache <number>

Spécifie le nombre d'interfaces à mettre en cache. Cela empêche les interfaces d'être supprimées une fois la session correspondante détruite. Au lieu de cela, les interfaces sont mises en cache pour une utilisation ultérieure dans de nouvelles sessions. Cela devrait réduire le taux de création/de suppression d'interfaces au niveau du noyau. La valeur par défaut est 0.

set vpn sstp ppp-options ipv4 <require | prefer | allow | deny>

Spécifie la préférence de négociation IPv4.

  • require - Exiger la négociation IPv4

  • prefer - Demander au client la négociation IPv4, ne pas échouer si il la refuse

  • allow - Négocier IPv4 uniquement si le client le demande (valeur par défaut)

  • deny - Ne pas négocier IPv4

set vpn sstp ppp-options lcp-echo-failure <number>

Définit le nombre maximal <number> de requêtes d'écho non répondues. Lorsque la valeur <number> est atteinte, la session sera réinitialisée. La valeur par défaut est 3.

set vpn sstp ppp-options lcp-echo-interval <interval>

Si cette option est spécifiée et supérieure à 0, le module PPP enverra des requêtes d'écho LCP toutes les <interval> secondes. La valeur par défaut est 30.

set vpn sstp ppp-options lcp-echo-timeout

Spécifie le délai d'attente en secondes pour attendre toute activité du pair. Si cette option est spécifiée, elle active la fonctionnalité d'écho LCP adaptatif et « lcp-echo-failure » n'est pas utilisé. La valeur par défaut est 0.

set vpn sstp ppp-options min-mtu <number>

Définit la MTU minimale acceptable. Si un client tente de négocier une MTU inférieure à celle-ci, elle sera NAKée, et la connexion sera interrompue si elle rejette une MTU plus grande. La valeur par défaut est 100.

set vpn sstp ppp-options mppe <require | prefer | deny>

Spécifie la préférence de négociation MPPE.

  • require - demander au client MPPE, si il le refuse, couper la connexion

  • prefer - demander au client MPPE, si il le refuse, ne pas échouer. (valeur par défaut)

  • deny - refuser MPPE

Comportement par défaut - ne pas demander au client MPPE, mais l'autoriser s'il le souhaite. Veuillez noter que RADIUS peut remplacer cette option par l'attribut MS-MPPE-Encryption-Policy.

set vpn sstp ppp-options mru <number>

Définit la MRU préférée. Par défaut, il n'est pas défini.

Options avancées globales

set vpn sstp description <description>

Définir la description.

set vpn sstp limits burst <value>

Nombre de pics

set vpn sstp limits connection-limit <value>

Nombre maximal de connexions acceptées (par exemple, 1/min, 60/sec)

set vpn sstp limits timeout <value>

Délai en secondes

set vpn sstp mtu

Unité de transmission maximale (MTU) (défaut : 1500)

set vpn sstp max-concurrent-sessions

Nombre maximal de tentatives de connexion simultanées

set vpn sstp name-server <address>

Les clients connectés doivent utiliser <address> comme serveur DNS. Cette commande accepte les adresses IPv4 et IPv6. Jusqu'à deux serveurs DNS peuvent être configurés pour IPv4, jusqu'à trois pour IPv6.

set vpn sstp shaper fwmark <1-2147483647>

Correspondance de la valeur de marque de pare-feu

set vpn sstp snmp master-agent

Activer SNMP

set vpn sstp wins-server <address>

Serveurs WINS propagés au client

set vpn sstp host-name <hostname>

Si cette option est donnée, seules les connexions SSTP vers l'hôte spécifié et avec le même SNI TLS seront autorisées.

Configuration du client SSTP

Une fois que vous avez configuré votre serveur SSTP, vient le moment de faire quelques tests basiques. Le client Linux utilisé pour les tests s'appelle sstpc. sstpc nécessite un fichier de configuration PPP/peer.

Si vous utilisez un certificat auto-signé, n'oubliez pas d'installer le CA côté client.

La configuration PPP suivante teste MSCHAP-v2 :

$ cat /etc/ppp/peers/vyos
usepeerdns
#require-mppe
#require-pap
require-mschap-v2
noauth
lock
refuse-pap
refuse-eap
refuse-chap
refuse-mschap
#refuse-mschap-v2
nobsdcomp
nodeflate
debug

Vous pouvez maintenant « appeler » le pair avec la commande suivante : sstpc --log-level 4 --log-stderr --user vyos --password vyos vpn.example.com -- call vyos.
