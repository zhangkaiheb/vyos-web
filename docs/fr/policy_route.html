Route et Route6 Policy

Les politiques de routage IPv4 et IPv6 sont définies dans cette section. Ces politiques de routage peuvent ensuite être associées aux interfaces.

Ensembles de règles

Un ensemble de règles est une collection nommée de règles pouvant être appliquée à une interface. Chaque règle est numérotée, a une action à appliquer si la règle est matchée, et la capacité à spécifier les critères de match. Les paquets de données passent par les règles de 1 à 999999, à la première correspondance l'action de la règle sera exécutée.

set policy route <name> description <text>
set policy route6 <name> description <text>

Fournir une description de l'ensemble de règles.

set policy route <name> default-log
set policy route6 <name> default-log

Option pour enregistrer les paquets touchant l'action par défaut.

set policy route <name> interface <interface>
set policy route6 <name> interface <interface>

Appliquer la politique de routage à l'interface

set policy route <name> rule <n> description <text>
set policy route6 <name> rule <n> description <text>

Fournir une description pour chaque règle.

set policy route <name> rule <n> log <enable|disable>
set policy route6 <name> rule <n> log <enable|disable>

Option pour activer ou désactiver le journal des règles correspondantes.

Critères de correspondance

Il existe de nombreuses options de critères de correspondance disponibles, à la fois pour policy route et policy route6. Ces options sont listées dans cette section.

set policy route <name> rule <n> connection-mark <1-2147483647>
set policy route6 <name> rule <n> connection-mark <1-2147483647>

Définir les critères de correspondance sur la marque de connexion.

set policy route <name> rule <n> mark <match_criteria>
set policy route6 <name> rule <n> mark <match_criteria>

Correspondre sur la marque du pare-feu (fwmark), où <match_criteria> peut être :

  • <0-2147483647> une seule fwmark

  • !<0-2147483647> tout sauf une seule fwmark

  • <start-end> une plage de marques

  • !<start-end> tout sauf la plage de marques

Note

Quand on utilise les commandes set table ou set vrf, les paramètres de marque sont ignorés et remplacés par une marque spécifique à la table qui est définie à 0x7FFFFFFF - l'id de la table/VRF.

set policy route <name> rule <n> source address <match_criteria>
set policy route <name> rule <n> destination address <match_criteria>
set policy route6 <name> rule <n> source address <match_criteria>
set policy route6 <name> rule <n> destination address <match_criteria>

Définir les critères de correspondance sur l'adresse IPv4/IPv6 source ou destination, où <match_criteria> pourrait être :

Pour IPv4 :

  • <x.x.x.x> : adresse IP à matcher.

  • <x.x.x.x/x> : sous-réseau à matcher.

  • <x.x.x.x>-<x.x.x.x> : plage d'adresses à matcher.

  • !<x.x.x.x> : matcher tout sauf l'adresse spécifiée.

  • !<x.x.x.x/x> : matcher tout sauf le sous-réseau spécifié.

  • !<x.x.x.x>-<x.x.x.x> : matcher tout sauf la plage spécifiée.

Et pour IPv6 :

  • <h:h:h:h:h:h:h:h> : adresse IPv6 à matcher.

  • <h:h:h:h:h:h:h:h/x> : préfixe IPv6 à matcher.

  • <h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h> : plage IPv6 à matcher.

  • !<h:h:h:h:h:h:h:h> : matcher tout sauf l'adresse spécifiée.

  • !<h:h:h:h:h:h:h:h/x> : matcher tout sauf le préfixe spécifié.

  • !<h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h> : matcher tout sauf la plage spécifiée.

set policy route <name> rule <n> source group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route <name> rule <n> destination group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route6 <name> rule <n> source group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route6 <name> rule <n> destination group <address-group|domain-group|mac-group|network-group|port-group> <text>

Définir les critères de correspondance sur les groupes source ou destination, où <text> serait le nom/identifiant du groupe. Préfixez le caractère ‘!’ pour une correspondance inversée.

set policy route <name> rule <n> destination port <match_criteria>
set policy route6 <name> rule <n> destination port <match_criteria>

Définir les critères de correspondance sur le port de destination, où <match_criteria> pourrait être :

  • <nom de port> : port nommé (n'importe quel nom dans /etc/services, par exemple http).

  • <1-65535> : port numéroté.

  • <start>-<end> : plage de ports numérotés (par exemple 1001-1005).

Plusieurs ports de destination peuvent être spécifiés comme une liste séparée par des virgules. La liste entière peut également être « négative » en utilisant « ! ». Par exemple : « !22,telnet,http,123,1001-1005 »

set policy route <name> rule <n> disable
set policy route6 <name> rule <n> disable

Option pour désactiver la règle.

set policy route <name> rule <n> dscp <text>
set policy route6 <name> rule <n> dscp <text>
set policy route <name> rule <n> dscp-exclude <text>
set policy route6 <name> rule <n> dscp-exclude <text>

Correspondre sur les critères de valeur DSCP. Plusieurs valeurs de 0 à 63 et plages sont prises en charge.

set policy route <name> rule <n> fragment <match-grag|match-non-frag>
set policy route6 <name> rule <n> fragment <match-grag|match-non-frag>

Définir la correspondance IP fragment, où :

  • match-frag : fragments secondaires ou ultérieurs des paquets fragmentés.

  • match-non-frag : fragments principaux ou paquets non fragmentés.

set policy route <name> rule <n> icmp <code | type>
set policy route6 <name> rule <n> icmpv6 <code | type>

Correspondre sur le code et le type ICMP|ICMPv6.

set policy route <name> rule <n> icmp type-name <text>
set policy route6 <name> rule <n> icmpv6 type-name <text>

Correspondre sur les critères de type-name ICMP|ICMPv6. Utilisez la touche Tab pour obtenir des informations sur les critères de type-name pris en charge.

set policy route <name> rule <n> ipsec <match-ipsec|match-none>
set policy route6 <name> rule <n> ipsec <match-ipsec|match-none>

Définir les critères de correspondance IPSec entrants, où :

  • match-ipsec : correspondre aux paquets IPSec entrants.

  • match-none : correspondre aux paquets non IPSec entrants.

set policy route <name> rule <n> limit burst <0-4294967295>
set policy route6 <name> rule <n> limit burst <0-4294967295>

Définir le nombre maximum de paquets autorisés en excès de débit.

set policy route <name> rule <n> limit rate <text>
set policy route6 <name> rule <n> limit rate <text>

Définir le taux moyen maximal correspondant. Format pour le taux : entier/unité de temps, où l'unité de temps peut être n'importe quelle unité parmi seconde, minute, heure ou jour. Par exemple 1/seconde implique que la règle soit correspondante à un taux moyen d'une fois par seconde.

set policy route <name> rule <n> protocol <text | 0-255 | tcp_udp | all >
set policy route6 <name> rule <n> protocol <text | 0-255 | tcp_udp | all >

Correspondre un critère de protocole. Un numéro de protocole ou un nom défini dans : /etc/protocols. Les noms spéciaux sont all pour tous les protocoles et tcp_udp pour les paquets TCP et UDP. Le ! inverse le protocole sélectionné.

set policy route <name> rule <n> packet-length <text>
set policy route6 <name> rule <n> packet-length <text>
set policy route <name> rule <n> packet-length-exclude <text>
set policy route6 <name> rule <n> packet-length-exclude <text>

Correspondre sur les critères de longueur de paquet. Plusieurs valeurs de 1 à 65535 et plages sont prises en charge.

set policy route <name> rule <n> packet-type [broadcast | host | multicast | other]
set policy route6 <name> rule <n> packet-type [broadcast | host | multicast | other]

Correspondre sur les critères de type de paquet.

set policy route <name> rule <n> recent count <1-255>
set policy route6 <name> rule <n> recent count <1-255>
set policy route <name> rule <n> recent time <1-4294967295>
set policy route6 <name> rule <n> recent time <1-4294967295>

Définir les paramètres pour correspondre aux sources récemment vues. Cette correspondance peut être utilisée en définissant count (adresse source vue plus de <1-255> fois) et/ou time (adresse source vue dans les dernières <0-4294967295> secondes).

set policy route <name> rule <n> state <established | invalid | new | related>
set policy route6 <name> rule <n> state <established | invalid | new | related>

Définir les critères de correspondance sur l'état de session.

set policy route <name> rule <n> tcp flags <text>
set policy route6 <name> rule <n> tcp flags <text>

Définir les critères de correspondance sur les drapeaux TCP. Valeurs autorisées pour les drapeaux TCP : SYN ACK FIN RST URG PSH ALL. Lorsque vous spécifiez plus d'un drapeau, les drapeaux doivent être séparés par des virgules. Par exemple : valeur de 'SYN,!ACK,!FIN,!RST' ne correspondra qu'aux paquets avec le drapeau SYN activé, et les drapeaux ACK, FIN et RST désactivés.

set policy route <name> rule <n> time monthdays <text>
set policy route6 <name> rule <n> time monthdays <text>
set policy route <name> rule <n> time startdate <text>
set policy route6 <name> rule <n> time startdate <text>
set policy route <name> rule <n> time starttime <text>
set policy route6 <name> rule <n> time starttime <text>
set policy route <name> rule <n> time stopdate <text>
set policy route6 <name> rule <n> time stopdate <text>
set policy route <name> rule <n> time stoptime <text>
set policy route6 <name> rule <n> time stoptime <text>
set policy route <name> rule <n> time weekdays <text>
set policy route6 <name> rule <n> time weekdays <text>
set policy route <name> rule <n> time utc
set policy route6 <name> rule <n> time utc

Heure pour correspondre à la règle définie.

set policy route rule <n> ttl <eq | gt | lt> <0-255>

Correspondre au paramètre TTL, où 'eq' signifie 'égal'; 'gt' signifie 'supérieur à', et 'lt' signifie 'inférieur à'.

set policy route6 rule <n> hop-limit <eq | gt | lt> <0-255>

Correspondre au paramètre de limite de saut, où 'eq' signifie 'égal'; 'gt' signifie 'supérieur à', et 'lt' signifie 'inférieur à'.

Actions

Lorsqu'un paquet correspond à tous les modèles définis dans une règle, différentes actions peuvent être effectuées. Cela inclut le rejet du paquet, la modification de certaines données, ou le réglage d'une table de routage différente.

set policy route <name> rule <n> action drop
set policy route6 <name> rule <n> action drop

Définir l'action de la règle sur drop.

set policy route <name> rule <n> set connection-mark <1-2147483647>
set policy route6 <name> rule <n> set connection-mark <1-2147483647>

Définir une marque de connexion spécifique.

set policy route <name> rule <n> set dscp <0-63>
set policy route6 <name> rule <n> set dscp <0-63>

Modifier le paquet : Codepoint de service différencié (DSCP)

set policy route <name> rule <n> set mark <1-2147483647>
set policy route6 <name> rule <n> set mark <1-2147483647>

Définir une marque de paquet spécifique.

set policy route <name> rule <n> set table <main | 1-200>
set policy route6 <name> rule <n> set table <main | 1-200>

Définir la table de routage à utiliser pour transmettre le paquet.

Note

Quand on utilise les commandes set table ou set vrf, il n'est pas possible de faire correspondre la marque, car elle est remplacée par une marque spécifique à la table qui est 0x7FFFFFFF - l'id de la table/VRF.

set policy route <name> rule <n> set tcp-mss <500-1460>
set policy route6 <name> rule <n> set tcp-mss <500-1460>

Modification des paquets : Définir explicitement la valeur de la taille maximale du segment TCP.

set policy route <name> rule <n> set vrf <default | text >
set policy route6 <name> rule <n> set vrf <default | text >

Définir le VRF à utiliser pour transmettre le paquet.

Note

Quand on utilise les commandes set table ou set vrf, il n'est pas possible de faire correspondre la marque, car elle est remplacée par une marque spécifique à la table qui est 0x7FFFFFFF - l'id de la table/VRF.
