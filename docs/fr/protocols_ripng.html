RIP

Développé dans les années 1970 au Xerox Labs, RIP est un protocole de routage à vecteur de distance basé sur l'algorithme de Bellman-Ford.

RIP détermine le meilleur chemin en fonction du nombre de sauts (nombre de routeurs traversés). Les routeurs activés avec RIP annoncent périodiquement leur table de routage complète à leurs voisins, ainsi que la métrique (nombre de sauts) pour chaque destination.

Versions prises en charge :

  • RIPv1 : tel que décrit dans RFC 1058

  • RIPv2 : tel que décrit dans RFC 2453

Configuration générale

set protocols rip network <A.B.C.D/M>

Activer RIP sur toutes les interfaces dont les adresses IP se trouvent dans le réseau spécifié.

Exemple :

set protocols rip network 192.0.2.0/24
set protocols rip interface <interface>

Activer RIP sur l'interface spécifiée.

Une fois appliqué, l'interface envoie et reçoit des paquets RIP.

Exemple :

set protocols rip interface eth0
set protocols rip neighbor <A.B.C.D>

Configurer un voisin RIP à l'aide de son adresse IP.

Utilisez cette commande lorsque un voisin ne peut pas traiter les mises à jour RIP multicast. Une fois configuré, le routeur local envoie les mises à jour directement au voisin spécifié sous forme de paquets unicast.

Exemple :

set protocols rip neighbor 192.0.2.2
set protocols rip passive-interface <interface>

Activer le mode passif pour l'interface spécifiée.

Cela empêche le routeur d'envoyer des mises à jour RIP sortantes sur l'interface, sauf vers les voisins configurés explicitement. Les mises à jour RIP entrantes sont toujours acceptées et traitées.

Exemple :

set protocols rip passive-interface eth0
set protocols rip passive-interface default

Activer le mode passif pour toutes les interfaces.

Cela empêche le routeur d'envoyer des mises à jour RIP sortantes sur toutes les interfaces, sauf vers les voisins configurés explicitement. Le routeur continue normalement de recevoir et de traiter les mises à jour RIP entrantes.

Exemple :

set protocols rip passive-interface default

Configuration facultative

set protocols rip default-distance <1-255>

Configurer la distance administrative pour toutes les routes apprises via RIP.

La distance administrative détermine comment les routes apprises via RIP sont priorisées par rapport aux routes apprises par d'autres sources (comme BGP, OSPF ou routes statiques) lorsqu'il existe plusieurs chemins vers la même destination.

Remarque

Les routes assignées à une distance de 255 sont désactivées et ne seront pas installées dans le tableau de routage du noyau.

Exemple :

set protocols rip default-distance 100
set protocols rip network-distance <A.B.C.D/M> distance <1-255>

Configurer une distance administrative pour les routes RIP dont l'adresse IP source se trouve dans le réseau spécifié.

Exemple :

set protocols rip network-distance 192.0.2.0/24 distance 80
set protocols rip network-distance <A.B.C.D/M> access-list <name>

Restreindre l'attribution des distances administratives aux routes RIP dont l'adresse IP source correspond au réseau spécifié et dont la route elle-même correspond à la liste d'accès spécifiée.

Exemple :

set protocols rip network-distance 192.0.2.0/24 distance 80
set protocols rip network-distance 192.0.2.0/24 access-list 10
set protocols rip default-information originate

Générer et annoncer une route par défaut (0.0.0.0/0) à tous les voisins RIP.

Exemple :

set protocols rip default-information originate
set protocols rip distribute-list access-list <in|out> <0-4294967295>

Appliquer une liste d'accès pour filtrer les routes RIP dans la direction entrante ou sortante.

  • in : Filtre les routes reçues des voisins RIP.

  • out : Filtre les routes annoncées aux voisins RIP.

Exemple :

set protocols rip distribute-list access-list in 20
set protocols rip distribute-list interface <interface> access-list <in|out> <0-4294967295>

Appliquer une liste d'accès pour filtrer les routes RIP dans la direction entrante ou sortante sur l'interface spécifiée.

  • in : Filtre les routes reçues des voisins RIP sur cette interface.

  • out : Filtre les routes annoncées aux voisins RIP sur cette interface.

Exemple :

set protocols rip distribute-list interface eth0 access-list in 20
set protocols rip distribute-list prefix-list <in|out> <name>

Appliquer une liste de préfixes pour filtrer les routes RIP dans la direction entrante ou sortante.

  • in : Filtre les routes reçues des voisins RIP.

  • out : Filtre les routes annoncées aux voisins RIP.

Exemple :

set protocols rip distribute-list prefix-list in INBOUND-FILTER
set protocols rip distribute-list interface <interface> prefix-list <in|out> <name>

Appliquer une liste de préfixes pour filtrer les routes RIP sur l'interface spécifiée dans la direction entrante ou sortante.

  • in : Filtre les routes reçues des voisins RIP sur cette interface.

  • out : Filtre les routes annoncées aux voisins RIP sur cette interface.

Exemple :

set protocols rip distribute-list interface eth0 prefix-list in RIP-IN
set protocols rip route <A.B.C.D/M>

Ajouter une route statique au processus de routage RIP.

La route est créée uniquement à l'intérieur de RIP.

Cette commande est spécifique à FRR et VyOS et ne doit être utilisée que par des utilisateurs avancés ayant une bonne compréhension du protocole RIP.

Pour la plupart des déploiements, l'approche recommandée est de créer une route statique standard et de la redistribuer dans RIP à l'aide de set protocols rip redistribute static.

Exemple :

set protocols rip route 192.0.2.0/24
set protocols rip timers update <5-2147483647>

Configurer le minuteur de mise à jour RIP, en secondes.

Le minuteur de mise à jour définit la fréquence à laquelle le routeur envoie des messages de réponse non sollicités à ses voisins RIP. Chaque réponse contient la table de routage RIP complète.

La valeur par défaut est de 30 secondes.

Exemple :

set protocols rip timers update 60
set protocols rip timers timeout <5-2147483647>

Configurer le minuteur de temporisation de la route RIP, en secondes.

Si une route n'est pas actualisée par une mise à jour entrante dans cet intervalle, elle devient invalide. Le routeur conserve temporairement la route invalide dans la table de routage RIP afin que les voisins sachent que la route a été supprimée.

La valeur par défaut est de 180 secondes.

Exemple :

set protocols rip timers timeout 300
set protocols rip timers garbage-collection <5-2147483647>

Configurer le minuteur de collecte des ordures pour RIP, en secondes.

Ce minuteur commence lorsque une route devient invalide. Lorsque le minuteur expire, la route est supprimée de la table de routage.

La valeur par défaut est de 120 secondes.

Exemple :

set protocols rip timers garbage-collection 60

Configuration de redistribution

set protocols rip redistribute <babel|bgp|connected|isis|kernel|nhrp|ospf|static>

Redistribuer les routes provenant de la source spécifiée vers RIP.

Les routes apprises à partir de la source choisie sont importées dans la table de routage RIP et annoncées aux voisins RIP comme si elles avaient été apprises via RIP elle-même.

Les sources prises en charge sont :

  • babel : Routes apprises via Babel.

  • bgp : Routes apprises via BGP.

  • connected : Routes directement connectées.

  • isis : Routes apprises via IS-IS.

  • kernel : Routes installées dans le tableau de routage du noyau.

  • nhrp : Routes apprises via NHRP.

  • ospf : Routes apprises via OSPF.

  • static : Routes configurées statiquement.

Exemple :

set protocols rip redistribute static
set protocols rip redistribute <babel|bgp|connected|isis|kernel|nhrp|ospf|static> metric <1-16>

Configurer la métrique pour les routes redistribuées depuis la source spécifiée.

Exemple :

set protocols rip redistribute static metric 5
set protocols rip redistribute <babel|bgp|connected|isis|kernel|nhrp|ospf|static> route-map <name>

Appliquer une route-map pour filtrer les routes redistribuées depuis la source spécifiée.

Exemple :

set protocols rip redistribute static route-map RIP-REDISTRIBUTE
set protocols rip default-metric <1-16>

Configurer la métrique par défaut (nombre de sauts) appliquée aux routes redistribuées.

La valeur par défaut est 1.

Note

Cette commande n'affecte pas les routes connectées redistribuées via set protocols rip redistribute connected. Pour configurer la métrique pour les routes connectées, utilisez set protocols rip redistribute connected metric explicitement.

Exemple :

set protocols rip default-metric 5

Configuration des interfaces

set protocols rip interface <interface> authentication plaintext-password <text>

Activer l'authentification simple mot de passe pour RIPv2 sur l'interface spécifiée et définir un mot de passe.

Le mot de passe ne doit pas dépasser 16 caractères.

Exemple :

set protocols rip interface eth0 authentication plaintext-password vyos-secret
set protocols rip interface <interface> authentication md5 <id> password <text>

Activer l'authentification MD5 pour RIPv2 sur l'interface spécifiée et définir la clé MD5.

La clé MD5 ne doit pas dépasser 16 caractères.

Exemple :

set protocols rip interface eth0 authentication md5 1 password vyos-secret
set protocols rip interface <interface> split-horizon disable

Désactiver le horizon séparé sur l'interface spécifiée.

Par défaut, VyOS n'annonce pas les routes RIP en arrière à travers l'interface sur laquelle elles ont été apprises (split horizon). Cette commande désactive cette configuration par défaut.

Exemple :

set protocols rip interface eth0 split-horizon disable
set protocols rip interface <interface> split-horizon poison-reverse

Activer le split horizon avec poison reverse sur l'interface spécifiée.

Si activé, le routeur annonce les routes apprises comme inaccessibles sur l'interface où elles ont été apprises.

Exemple :

set protocols rip interface eth0 split-horizon poison-reverse

Exemple

L'exemple suivant illustre une configuration de base RIP entre deux routeurs, où les réseaux directement connectés sont redistribués dans RIP.

Nœud 1 :

set interfaces ethernet eth0 address '198.51.100.1/24'
set interfaces loopback lo address '192.0.2.1/32'
set protocols rip network 198.51.100.0/24
set protocols rip redistribute connected

Nœud 2 :

set interfaces ethernet eth0 address '198.51.100.2/24'
set interfaces loopback lo address '192.0.2.2/32'
set protocols rip network 198.51.100.0/24
set protocols rip redistribute connected
