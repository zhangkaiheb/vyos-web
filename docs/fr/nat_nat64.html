NAT64

NAT64 est un composant critique dans les réseaux modernes, facilitant la communication entre les réseaux IPv6 et IPv4. Cette documentation présente la configuration, l'installation et l'utilisation de la fonction NAT64 dans votre projet. Que vous soyez en transition vers IPv6 ou que vous ayez besoin de connecter de manière transparente des appareils IPv4 et IPv6. NAT64 est un mécanisme de traduction étatique qui traduit les adresses IPv6 en adresses IPv4 et les adresses IPv4 en adresses IPv6. NAT64 est utilisé pour permettre aux clients uniquement IPv6 de contacter des serveurs IPv4 à l'aide de UDP, TCP ou ICMP unicast.

Types de NAT différents

SNAT64

SNAT64 est un mécanisme de traduction étatique qui traduit les adresses IPv6 en adresses IPv4.

64:ff9b::/96 est le préfixe bien connu pour les adresses IPv6 intégrant IPv4. Ce préfixe est utilisé pour représenter les adresses IPv4 au format d'une adresse IPv6. L'adresse IPv4 est encodée dans les 32 bits inférieurs de l'adresse IPv6. Les 32 bits supérieurs sont définis sur le préfixe bien connu 64:ff9b::/96.

Exemples de configuration

Les exemples suivants montrent comment configurer NAT64 sur un routeur VyOS. L'adresse 192.0.2.1 est utilisée comme adresse IPv4 pour la plage de traduction.

Configuration du serveur NAT64 :

set interfaces ethernet eth0 address '192.0.2.1/24'
set interfaces ethernet eth0 address '192.0.2.10/24'
set interfaces ethernet eth0 description 'WAN'
set interfaces ethernet eth1 address '2001:db8::1/64'
set interfaces ethernet eth1 description 'LAN'

set service dns forwarding allow-from '2001:db8::/64'
set service dns forwarding dns64-prefix '64:ff9b::/96'
set service dns forwarding listen-address '2001:db8::1'

set nat64 source rule 100 source prefix '64:ff9b::/96'
set nat64 source rule 100 translation pool 10 address '192.0.2.10'
set nat64 source rule 100 translation pool 10 port '1-65535'

Configuration du client NAT64 :

set interfaces ethernet eth1 address '2001:db8::2/64'
set protocols static route6 64:ff9b::/96 next-hop 2001:db8::1
set system name-server '2001:db8::1'
