Bridge

VyOS bridges connect Ethernet segments by grouping multiple interfaces into a single bridge interface, which acts as a virtual software switch. Unlike routers, which forward traffic based on Layer 3 IP addresses, bridges operate at Layer 2 and forward traffic based on MAC addresses. Operating at Layer 2, bridges are protocol-agnostic and transparently forward all Ethernet- encapsulated traffic, whether it is IPv4, IPv6, or specialized industrial protocols.

This implementation utilizes the Linux bridge subsystem to support a subset of the ANSI/IEEE 802.1d standard for transparent bridging and MAC address learning.

Note

STP est désactivé par défaut dans VyOS et doit être activé explicitement si nécessaire. Voir Configuration de STP pour plus de détails.

Configuration

Configuration commune des interfaces

set interfaces bridge <interface> address <address | dhcp | dhcpv6>

Configurez l'interface avec une ou plusieurs adresses IP.

Les options suivantes sont disponibles :

  • address: Attribuez une ou plusieurs adresses IPv4 ou IPv6 à l'interface. Par exemple, utilisez 192.0.2.1/24 pour IPv4 ou 2001:db8::1/64 pour IPv6.

  • dhcp: L'interface obtient une adresse IPv4 d'un serveur DHCP sur le même segment réseau.

  • dhcpv6: L'interface obtient une adresse IPv6 d'un serveur DHCPv6 sur le même segment réseau.

Note

Si l'interface obtient une adresse IPv4 via DHCP, et qu'il faut des ajustements spécifiques avant/après l'obtention de l'adresse IP, utilisez les scripts de raccordement fournis :

  • /config/scripts/dhcp-client/pre-hooks.d/

  • /config/scripts/dhcp-client/post-hooks.d/

Exemple :

set interfaces bridge br0 address 192.0.2.1/24
set interfaces bridge br0 address 2001:db8::1/64
set interfaces bridge br0 address dhcp
set interfaces bridge br0 address dhcpv6
set interfaces bridge <interface> description <description>

Configurez un alias clair et descriptif pour l'interface.

Cet alias apparaît dans la commande show interfaces et dans les outils de surveillance basés sur SNMP.

Exemple :

set interfaces bridge br0 description 'This is an interface running on VyOS.'
set interfaces bridge <interface> disable

Désactivez l'interface.

L'interface sera définie à l'état administrativement down (A/D).

Exemple :

set interfaces bridge br0 disable
set interfaces bridge <interface> disable-flow-control

Désactivez le contrôle de flux Ethernet (pauses IEEE 802.3x) sur l'interface.

Le contrôle de flux Ethernet, défini par la norme IEEE 802.3x, temporairement arrête la transmission de données pour éviter la perte de paquets lors de la congestion du réseau. Par exemple, lorsque l'émetteur transmet des données plus rapidement que le récepteur ne peut les traiter.
