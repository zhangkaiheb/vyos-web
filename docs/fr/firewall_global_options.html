Configuration des options globales du pare-feu

Aperçu

Certaines paramètres de pare-feu sont globaux et affectent l'ensemble du système. Cette section fournit des informations sur ces options globales que vous pouvez configurer à l'aide de la CLI VyOS.

Les commandes de configuration abordées dans cette section :

set firewall global-options …

Configuration

set firewall global-options all-ping [enable | disable]

Par défaut, lorsque VyOS reçoit un paquet de requête ICMP destiné à lui-même, il répond avec une réponse ICMP, sauf si votre pare-feu l'en empêche.

Vous pouvez définir des règles de pare-feu pour accepter, rejeter ou supprimer le trafic ICMP entrant, sortant ou local. Vous pouvez également utiliser la commande firewall global-options all-ping. Cette commande affecte uniquement le trafic local (paquets destinés à votre système VyOS), et non le trafic entrant ou sortant.

Remarque

firewall global-options all-ping affecte uniquement le trafic local et se comporte toujours de manière la plus restrictive

set firewall global-options all-ping enable

Lorsque vous activez cette commande, VyOS répond à chaque demande d'écho ICMP adressée à lui-même, mais cette réponse n'a lieu que si aucune autre règle ne supprime ou rejette les demandes d'écho locales. En cas de conflit, VyOS ne répond pas aux demandes d'écho ICMP.

set firewall global-options all-ping disable

Lorsque vous désactivez cette commande, VyOS ne répond à aucune demande d'écho ICMP adressée à lui-même, indépendamment de l'origine ou des règles spécifiques qui l'acceptent.

set firewall global-options apply-to-bridged-traffic [ipv4 | ipv6]

Appliquer les règles IPv4 ou IPv6 du pare-feu au trafic bridé.

set firewall global-options broadcast-ping [enable | disable]

Activer ou désactiver la réponse aux messages ICMP de diffusion. Le système modifie le paramètre suivant :

  • net.ipv4.icmp_echo_ignore_broadcasts

set firewall global-options ip-src-route [enable | disable]
set firewall global-options ipv6-src-route [enable | disable]

Définir si VyOS accepte les paquets avec une option de routage source. Les paramètres sysctl suivants seront modifiés :

  • net.ipv4.conf.all.accept_source_route

  • net.ipv6.conf.all.accept_source_route

set firewall global-options receive-redirects [enable | disable]
set firewall global-options ipv6-receive-redirects [enable | disable]

Permettre à VyOS d'accepter les messages de redirection ICMPv4 et ICMPv6. Les paramètres sysctl suivants seront modifiés :

  • net.ipv4.conf.all.accept_redirects

  • net.ipv6.conf.all.accept_redirects

set firewall global-options send-redirects [enable | disable]

Permettre à VyOS d'envoyer des messages de redirection ICMPv4. Le paramètre sysctl suivant sera modifié :

  • net.ipv4.conf.all.send_redirects

set firewall global-options log-martians [enable | disable]

Permettre à VyOS de journaliser les paquets IPv4 martiens. Le paramètre sysctl suivant sera modifié :

  • net.ipv4.conf.all.log_martians

set firewall global-options source-validation [strict | loose | disable]

Définir le mode de validation de la source IPv4. Le paramètre sysctl suivant sera modifié :

  • net.ipv4.conf.all.rp_filter

set firewall global-options syn-cookies [enable | disable]

Permettre à VyOS d'utiliser les cookies SYN IPv4. Le paramètre sysctl suivant sera modifié :

  • net.ipv4.tcp_syncookies

set firewall global-options twa-hazards-protection [enable | disable]

Activer ou désactiver la conformité de VyOS au RFC 1337. Le paramètre sysctl suivant sera modifié :

  • net.ipv4.tcp_rfc1337

set firewall global-options state-policy established action [accept | drop | reject]
set firewall global-options state-policy established log
set firewall global-options state-policy established log-level [emerg | alert | crit | err | warn | notice | info | debug]

Définir le paramètre global pour une connexion établie.

set firewall global-options state-policy invalid action [accept | drop | reject]
set firewall global-options state-policy invalid log
set firewall global-options state-policy invalid log-level [emerg | alert | crit | err | warn | notice | info | debug]

Définir le paramètre global pour les paquets invalides.

set firewall global-options state-policy related action [accept | drop | reject]
set firewall global-options state-policy related log
set firewall global-options state-policy related log-level [emerg | alert | crit | err | warn | notice | info | debug]

Définir le paramètre global pour les connexions associées.

VyOS permet de définir des durées d'attente pour les connexions par type de connexion. Vous pouvez définir des valeurs de délai pour les connexions génériques, les connexions ICMP, les connexions UDP ou les connexions TCP dans divers états.

set firewall global-options timeout icmp <1-21474836>
set firewall global-options timeout other <1-21474836>
set firewall global-options timeout tcp close <1-21474836>
set firewall global-options timeout tcp close-wait <1-21474836>
set firewall global-options timeout tcp established <1-21474836>
set firewall global-options timeout tcp fin-wait <1-21474836>
set firewall global-options timeout tcp last-ack <1-21474836>
set firewall global-options timeout tcp syn-recv <1-21474836>
set firewall global-options timeout tcp syn-sent <1-21474836>
set firewall global-options timeout tcp time-wait <1-21474836>
set firewall global-options timeout udp other <1-21474836>
set firewall global-options timeout udp stream <1-21474836>

Définir le délai en secondes pour un protocole ou un état.
