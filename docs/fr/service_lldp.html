LLDP

LLDP est un protocole de couche liaison indépendant du fournisseur dans le suite de protocoles Internet utilisé par les appareils réseau pour annoncer leur identité, leurs capacités et leurs voisins sur un réseau local IEEE 802, principalement Ethernet filaire. Le protocole est formellement désigné par l'IEEE comme la découverte de la connectivité des stations et des contrôles d'accès au média spécifiée dans l'IEEE 802.1AB et l'IEEE 802.3-2012 section 6 clause 79.

LLDP effectue des fonctions similaires à plusieurs protocoles propriétaires, tels que CDP, FDP, NDP et LLTD.

Les informations recueillies avec LLDP sont stockées dans l'appareil en tant que base de données d'informations de gestion (MIB) et peuvent être interrogées avec le protocole de gestion réseau simple (SNMP) tel que spécifié dans RFC 2922. La topologie d'un réseau LLDP activé peut être découverte en parcourant les hôtes et en interrogeant cette base de données. Les informations pouvant être récupérées incluent :

  • Nom et description du système

  • Nom et description du port

  • Nom du VLAN

  • Adresse de gestion IP

  • Capacités du système (commutation, routage, etc.)

  • Informations MAC/PHY

  • Puissance MDI

  • Regroupement de lien

Configuration

set service lldp

Activer le service LLDP

set service lldp management-address <address>

Définir l'adresse de gestion IPv4/IPv6 transmise via LLDP. Plusieurs adresses peuvent être définies. Seules les adresses connectées au système seront transmises.

set service lldp interface <interface>

Activer la transmission d'informations LLDP sur une interface donnée <interface>. Vous pouvez également dire all ici afin que LLDP soit activé sur chaque interface.

set service lldp interface <interface> mode [disable|rx-tx|rx|tx]

Configurer le statut administratif du port donné.

Par défaut, tous les ports sont configurés en mode rx-tx. Cela signifie qu'ils peuvent recevoir et transmettre des trames LLDP.

En mode rx, ils ne produisent aucune trame. En mode tx, ils ne reçoivent aucune trame. En mode désactivé, aucune trame ne sera envoyée et toute trame entrante sera supprimée.

set service lldp snmp

Activer les requêtes SNMP de la base de données LLDP

set service lldp legacy-protocols <cdp|edp|fdp|sonmp>

Activer le protocole hérité donné sur cette instance LLDP. Les protocoles hérités comprennent :

  • cdp - Écouter le CDP pour les routeurs/switches Cisco

  • edp - Écouter l'EDP pour les routeurs/switches Extreme

  • fdp - Écouter le FDP pour les routeurs/switches Foundry

  • sonmp - Écouter le SONMP pour les routeurs/switches Nortel
