Éthernet virtuel

Les interfaces Ethernet virtuelles (veth) sont des interfaces logicielles qui fonctionnent en paires, créant un tunnel entre elles. Le trafic transmis dans l'une des interfaces de la paire (par exemple, veth0) est livré directement à son interface pair (par exemple, veth1).

Les interfaces veth sont couramment utilisées pour connecter des espaces de noms réseau ou des VRF, mais elles peuvent également fonctionner comme des interfaces réseau virtuelles indépendantes.

Note

Les interfaces veth doivent être créées en paires, où chaque interface agit comme le pair de l'autre.

Configuration

Configuration commune des interfaces

set interfaces virtual-ethernet <interface> address <address | dhcp | dhcpv6>

Configurez l'interface avec une ou plusieurs adresses IP.

Les options suivantes sont disponibles :

  • address: Attribuez une ou plusieurs adresses IPv4 ou IPv6 à l'interface. Par exemple, utilisez 192.0.2.1/24 pour IPv4 ou 2001:db8::1/64 pour IPv6.

  • dhcp: L'interface obtient une adresse IPv4 d'un serveur DHCP sur le même segment réseau.

  • dhcpv6: L'interface obtient une adresse IPv6 d'un serveur DHCPv6 sur le même segment réseau.

Note

Si l'interface obtient une adresse IPv4 via DHCP, et qu'il est nécessaire d'apporter des ajustements avant/après l'obtention de l'adresse IP, utilisez les scripts de raccordement fournis :

  • /config/scripts/dhcp-client/pre-hooks.d/

  • /config/scripts/dhcp-client/post-hooks.d/

Exemple :

set interfaces virtual-ethernet veth0 address 192.0.2.1/24
set interfaces virtual-ethernet veth0 address 2001:db8::1/64
set interfaces virtual-ethernet veth0 address dhcp
set interfaces virtual-ethernet veth0 address dhcpv6
set interfaces virtual-ethernet <interface> description <description>

Configurez un alias clair et descriptif pour l'interface.

Cet alias apparaît dans la commande show interfaces et les outils de surveillance basés sur SNMP.

Exemple :

set interfaces virtual-ethernet veth0 description 'This is an interface running on VyOS.'

VLAN

VLAN réguliers (802.1q)

IEEE 802.1q, souvent appelé Dot1q, est la norme industrielle pour implémenter des VLAN sur les réseaux Ethernet. Elle définit le marquage des VLAN pour les trames Ethernet et décrit les procédures pour les ponts et commutateurs. La norme inclut également la priorisation du service qualité (IEEE 802.1p) et définit le protocole d'inscription des attributs généraux.

Les segments réseau VLAN (c'est-à-dire IEEE 802.1q conformes) utilisent des balises VLAN. Lorsqu'une trame entre dans un tel segment, une balise est ajoutée pour indiquer l'appartenance au VLAN. Chaque trame ne peut appartenir qu'à un seul VLAN. Si une trame arrive sans balise, elle est supposée faire partie du VLAN par défaut.

Le groupe de travail IEEE 802.1, membre du comité des normes IEEE 802, a développé la norme et continue de la réviser. Une révision notable est 802.1Q-2014, qui a intégré IEEE 802.1aq (Bridging court le plus court) et une grande partie de la norme IEEE 802.1d.

Dans VyOS, les interfaces VLAN 802.1q sont représentées comme des sous-interfaces virtuelles, appelées vif.

set interfaces virtual-ethernet <interface> vif <vlan-id>

Configurez une interface VLAN avec un identifiant VLAN unique.

L'identifiant VLAN identifie un VLAN spécifique et varie de 0 à 4094.

Vous pouvez configurer plusieurs interfaces VLAN sur une seule interface physique.

Note

Seules les trames 802.1Q étiquetées sont acceptées sur les vifs Ethernet.

set interfaces virtual-ethernet <interface> vif <vlan-id> address <address | dhcp | dhcpv6>

Configurez l'interface avec une ou plusieurs adresses IP.

Les options suivantes sont disponibles :

  • address: Attribuez une ou plusieurs adresses IPv4 ou IPv6 à l'interface. Par exemple, utilisez 192.0.2.1/24 pour IPv4 ou 2001:db8::1/64 pour IPv6.

  • dhcp: L'interface obtient une adresse IPv4 d'un serveur DHCP sur le même segment réseau.

  • dhcpv6: L'interface obtient une adresse IPv6 d'un serveur DHCPv6 sur le même segment réseau.

Note

Si l'interface obtient une adresse IPv4 via DHCP, et qu'il est nécessaire d'apporter des ajustements avant/après l'obtention de l'adresse IP, utilisez les scripts de raccordement fournis :

  • /config/scripts/dhcp-client/pre-hooks.d/

  • /config/scripts/dhcp-client/post-hooks.d/

Exemple :

set interfaces virtual-ethernet veth0 vif 10 address 192.0.2.1/24
set interfaces virtual-ethernet veth0 vif 10 address 2001:db8::1/64
set interfaces virtual-ethernet veth0 vif 10 address dhcp
set interfaces virtual-ethernet veth0 vif 10 address dhcpv6
set interfaces virtual-ethernet <interface> vif <vlan-id> description <description>

Configurez un alias clair et descriptif pour l'interface.

Cet alias apparaît dans la commande show interfaces et les outils de surveillance basés sur SNMP.

Exemple :

set interfaces virtual-ethernet veth0 vif 10 description 'This is an interface running on VyOS.'
set interfaces virtual-ethernet <interface> vif <vlan-id> disable

Désactivez l'interface.

L'interface sera définie sur l'état administrativement arrêté (A/D).

Exemple :

set interfaces virtual-ethernet veth0 vif 10 disable
set interfaces virtual-ethernet <interface> vif <vlan-id> disable-link-detect

Désactivez la détection des changements d'état physique sur l'interface, tels que lorsqu'un câble est débranché.

Par défaut, l'interface détecte les changements d'état physique.

Exemple :

set interfaces virtual-ethernet veth0
