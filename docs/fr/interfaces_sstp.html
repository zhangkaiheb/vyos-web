Client SSTP

SSTP transporte le trafic PPP sur un canal SSL/TLS, offrant une sécurité au niveau du transport par négociation de clés, chiffrement et vérification d'intégrité du trafic. L'utilisation de SSL/TLS sur le port TCP 443 (par défaut, ce port peut être modifié) permet à SSTP de traverser pratiquement tous les pare-feux et serveurs proxy, sauf les serveurs proxy authentifiés.

Note

VyOS inclut un serveur SSTP intégré. Pour plus d'informations, voir Serveur SSTP.

Configuration

Configuration commune de l'interface

set interfaces sstpc <interface> description <description>

Configurez un alias clair et descriptif pour l'interface.

Cet alias apparaît dans la commande show interfaces et les outils de surveillance basés sur SNMP.

Exemple :

set interfaces sstpc sstpc0 description 'This is an interface running on VyOS.'
set interfaces sstpc <interface> disable

Désactiver l'interface.

L'interface sera définie à l'état administrativement down (A/D).

Exemple :

set interfaces sstpc sstpc0 disable
set interfaces sstpc <interface> mtu <mtu>

Configurer le MTU sur l'interface.

Cette valeur définit la taille maximale du paquet, en octets, que l'interface transmet sans fragmentation.

Exemple :

set interfaces sstpc sstpc0 mtu 1600
set interfaces sstpc <interface> vrf <vrf>

Assigner l'interface à une instance spécifique VRF .

Voir aussi

Pour plus d'informations sur la configuration d'une VRF, consultez la section VRF.

Exemple :

set interfaces sstpc sstpc0 vrf red

Options du client SSTP

set interfaces sstpc <interface> no-default-route

Demander une adresse IP depuis le serveur SSTP sans installer une route par défaut.

Exemple :

set interfaces sstpc sstpc0 no-default-route

Note

Introduit avec VyOS 1.4, cette commande inverse la logique de l'option CLI précédente default-route.

set interfaces sstpc <interface> default-route-distance <distance>

Configurer la distance pour la passerelle par défaut fournie par le serveur SSTP.

Exemple :

set interfaces sstpc sstpc0 default-route-distance 220
set interfaces sstpc <interface> no-peer-dns

Désactiver l'installation des serveurs DNS annoncés sur le système local.

set interfaces sstpc <interface> server <address>

Configurer l'adresse du serveur SSTP distant pour la connexion client.

L'adresse peut être soit une adresse IP, soit un FQDN.

set interfaces sstpc <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

Configurer la taille maximale du segment (MSS) annoncée dans les paquets TCP SYN sortants sur l'interface spécifiée.

En limitant la valeur MSS dans les paquets TCP SYN, vous indiquez au côté distant de ne pas envoyer de paquets plus grands que la taille spécifiée. Cela aide à prévenir les problèmes de connexion si la découverte du MTU du chemin (PMTUD) échoue.

Les options suivantes sont disponibles :

  • mss : Définit le MSS à une valeur spécifique en octets.

  • clamp-mss-to-pmtu : Définit le MSS à la taille MTU de l'interface moins 40 octets pour le trafic IPv4 (20 octets pour l'en-tête IPv4 et 20 octets pour l'en-tête TCP). Cette option est recommandée pour définir automatiquement la bonne valeur.

Note

Introduit avec VyOS 1.4, cette commande remplace la syntaxe précédente set firewall options interface <name> adjust-mss <value>.

set interfaces sstpc <interface> ip disable-forwarding

Configurer l'interface pour un comportement d'hôte ou de routeur.

Si configuré, l'interface passe en mode hôte et le transfert IPv4 est désactivé sur celle-ci.

set interfaces sstpc <interface> ip source-validation <strict | loose | disable>

Configurer la validation de l'adresse IP source à l'aide de RPF sur cette interface, comme spécifié dans RFC 3704.

Les options suivantes sont disponibles :

  • strict : Chaque adresse IP source des paquets entrants est vérifiée contre la FIB. Si l'interface n'est pas le meilleur chemin vers cette source, la validation échoue et le paquet est supprimé.

  • loose : Chaque adresse IP source des paquets entrants est vérifiée contre la FIB. Si l'adresse IP source est inatteignable via n'importe quelle interface, la validation échoue.

  • disable : Aucune validation de l'adresse IP source n'est effectuée. Tous les paquets entrants sont acceptés.

RFC 3704 recommande d'activer le mode strict pour empêcher le spoofing d'IP, comme les attaques DDoS. Pour les scénarios de routage asynchrones ou autres complexes, utilisez le mode loose.

show interfaces sstpc <interface>

Afficher les informations détaillées sur l'interface spécifiée.

Connecter/déconnecter

disconnect interface <interface>

Déconnecter l'interface spécifiée.

connect interface <interface>

Initier une session sur l'interface spécifiée.
