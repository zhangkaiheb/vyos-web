L2TP

VyOS utilise accel-ppp pour fournir une fonctionnalité de serveur L2TP. Il peut être utilisé avec l'authentification locale ou un serveur RADIUS connecté.

Configuration du serveur L2TP

set vpn l2tp remote-access authentication mode local
set vpn l2tp remote-access authentication local-users username test password 'test'
set vpn l2tp remote-access client-ip-pool L2TP-POOL range 192.168.255.2-192.168.255.254
set vpn l2tp remote-access default-pool 'L2TP-POOL'
set vpn l2tp remote-access outside-address 192.0.2.2
set vpn l2tp remote-access gateway-address 192.168.255.1
set vpn l2tp remote-access authentication mode <local | radius>

Définir le backend d'authentification. Le backend d'authentification configuré est utilisé pour toutes les requêtes.

  • radius: Toutes les requêtes d'authentification sont gérées par un serveur RADIUS configuré.

  • local: Toutes les requêtes d'authentification sont gérées localement.

set vpn l2tp remote-access authentication local-users username <user> password <pass>

Créer <user> pour l'authentification locale sur ce système. Le mot de passe de l'utilisateur sera défini à <pass>.

set vpn l2tp remote-access client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Utilisez cette commande pour définir la première adresse IP d'un pool d'adresses à attribuer aux clients L2TP. Si la notation x.x.x.x-x.x.x.x, elle doit être dans un sous-réseau /24. Si la notation x.x.x.x/x est utilisée, il est possible de définir un hôte/masque réseau.

set vpn l2tp remote-access default-pool <POOL-NAME>

Utilisez cette commande pour définir le nom du pool d'adresses par défaut.

set vpn l2tp remote-access gateway-address <gateway>

Spécifie une seule adresse IP <gateway> à utiliser comme adresse locale des interfaces PPP.

Configuration de l'IPsec

set vpn ipsec interface eth0
set vpn l2tp remote-access ipsec-settings authentication mode pre-shared-secret
set vpn l2tp remote-access ipsec-settings authentication pre-shared-secret secret
set vpn ipsec interface <INTERFACE>

Utilisez cette commande pour définir l'interface IPsec.

set vpn l2tp remote-access ipsec-settings authentication mode <pre-shared-secret | x509>

Définir le mode d'authentification IPsec entre VyOS et les clients L2TP.

set vpn l2tp remote-access ipsec-settings authentication pre-shared-secret <secret>

Définir une phrase secrète partagée prédéfinie.

Si une politique de pare-feu locale est en place sur votre interface externe, vous devrez autoriser les ports suivants :

  • Port UDP 500 (IKE)

  • Numéro de protocole IP 50 (ESP)

  • Port UDP 1701 pour IPsec

Ainsi que les suivants pour permettre le traversement NAT (quand le client VPN détecte le NAT, ESP est encapsulé en UDP pour le traversement NAT) :

  • Port UDP 4500 (NAT-T)

Exemple :

set firewall ipv4 name OUTSIDE-LOCAL rule 40 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 40 protocol 'esp'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 destination port '500'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 protocol 'udp'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 destination port '4500'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 protocol 'udp'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 destination port '1701'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 ipsec 'match-ipsec'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 protocol 'udp'

Pour permettre aux clients VPN d'accéder via votre adresse externe, une règle NAT est nécessaire :

set nat source rule 110 outbound-interface name 'eth0'
set nat source rule 110 source address '192.168.255.0/24'
set nat source rule 110 translation address masquerade

Configuration de l'authentification RADIUS

Pour activer l'authentification basée sur RADIUS, le mode d'authentification doit être modifié dans la configuration. Les paramètres précédents comme les utilisateurs locaux, existent toujours dans la configuration, cependant ils ne sont pas utilisés si le mode a été changé de local à radius. Une fois changé de nouveau vers local, tous les comptes locaux seront utilisés à nouveau.

set vpn l2tp remote-access authentication mode radius
set vpn l2tp remote-access authentication radius server <server> key <secret>

Configurer le serveur RADIUS <server> et sa clé partagée <secret> requise pour communiquer avec le serveur RADIUS.

Comme le serveur RADIUS serait un point de défaillance unique, plusieurs serveurs RADIUS peuvent être configurés et utilisés séquentiellement. Par exemple :

set vpn l2tp remote-access authentication radius server 10.0.0.1 key 'foo'
set vpn l2tp remote-access authentication radius server 10.0.0.2 key 'foo'

Note

Certains serveurs RADIUS utilisent une liste de contrôle d'accès qui autorise ou refuse les requêtes, assurez-vous d'ajouter votre routeur VyOS à la liste des clients autorisés.

Adresse source RADIUS

Si vous utilisez OSPF comme IGP, utilisez l'interface connectée la plus proche du serveur RADIUS. Vous pouvez attacher toutes les demandes sortantes RADIUS à une adresse IP source unique, par exemple l'interface boucle.

set vpn l2tp remote-access authentication radius source-address <address>

Adresse IPv4 source utilisée dans toutes les requêtes au serveur RADIUS.

Note

La valeur source-address doit être configurée sur celle d'une interface. La pratique recommandée serait une interface boucle ou dummy.

Options avancées RADIUS

set vpn l2tp remote-access authentication radius server <server> port <port>

Configurer le <server> RADIUS et son port requis pour les requêtes d'authentification.

set vpn l2tp remote-access authentication radius server <server> fail-time <time>

Marquer le serveur RADIUS comme hors ligne pendant ce temps donné <time> en secondes.

set vpn l2tp remote-access authentication radius server <server> disable

Désactiver temporairement ce serveur RADIUS.

set vpn l2tp remote-access authentication radius acct-timeout <timeout>

Délai d'attente pour répondre aux paquets Interim-Update. (défaut 3 secondes)

set vpn l2tp remote-access authentication radius dynamic-author server <address>

Spécifie l'adresse IP pour le serveur d'authorisation dynamique (DM/CoA). Cette adresse IP doit exister sur n'importe quelle interface VyOS ou elle peut être 0.0.0.0.

set vpn l2tp remote-access authentication radius dynamic-author port <port>

Port UDP pour le serveur d'authorisation dynamique (DM/CoA)

set vpn l2tp remote-access authentication radius dynamic-author key <secret>

Clé pour le serveur d'authorisation dynamique (DM/CoA)

set vpn l2tp remote-access authentication radius max-try <number>

Nombre maximum de tentatives pour envoyer les requêtes Access-Request/Accounting-Request

set vpn l2tp remote-access authentication radius timeout <timeout>

Délai d'attente pour attendre une réponse du serveur (en secondes)

set vpn l2tp remote-access authentication radius nas-identifier <identifier>

Valeur à envoyer au serveur RADIUS dans l'attribut NAS-Identifier et à correspondre dans les requêtes DM/CoA.

set vpn l2tp remote-access authentication radius nas-ip-address <address>

Valeur à envoyer au serveur RADIUS dans l'attribut NAS-IP-Address et à correspondre dans les requêtes DM/CoA. Le serveur DM/CoA se liera également à cette adresse.

set vpn l2tp remote-access authentication radius source-address <address>

Adresse IPv4 source utilisée dans toutes les requêtes au serveur RADIUS.

set vpn l2tp remote-access authentication radius rate-limit attribute <attribute>

Spécifie quel attribut du serveur RADIUS contient les informations de limite de taux. L'attribut par défaut est Filter-Id.

Note

Si vous définissez un attribut RADIUS personnalisé, vous devez le définir sur les deux dictionnaires sur le serveur RADIUS et le client.

set vpn l2tp remote-access authentication radius rate-limit enable

Active le réglage de bande passante via RADIUS.

set vpn l2tp remote-access authentication radius rate-limit vendor

Spécifie le dictionnaire du fabricant. Ce dictionnaire doit être présent dans /usr/share/accel-ppp/radius.

Les attributs RADIUS reçus ont une priorité supérieure aux paramètres définis dans la configuration CLI, reportez-vous à l'explication ci-dessous.

Allouer les adresses IP des clients par RADIUS

Si le serveur RADIUS envoie l'attribut Framed-IP-Address, alors cette adresse IP sera allouée au client et l'option default-pool dans la configuration CLI sera ignorée.

Si le serveur RADIUS envoie l'attribut Framed-Pool, alors l'adresse IP sera allouée à partir d'un pool d'adresses prédéfini dont le nom correspond à la valeur de l'attribut.

Si le serveur RADIUS envoie l'attribut Stateful-IPv6-Address-Pool, l'IPv6 sera alloué à partir d'un pool d'IPv6 prédéfini prefix dont le nom correspond à la valeur de l'attribut.

Si le serveur RADIUS envoie l'attribut Delegated-IPv6-Prefix-Pool, un préfixe de délégation IPv6 sera alloué à partir d'un pool d'IPv6 prédéfini delegate dont le nom correspond à la valeur de l'attribut.

Note

Stateful-IPv6-Address-Pool et Delegated-IPv6-Prefix-Pool sont définis dans RFC6911. Si ces attributs ne sont pas définis sur votre serveur RADIUS, ajoutez un nouveau dictionnaire.

L'interface du client peut être placée dans un contexte VRF via un paquet Access-Accept RADIUS, ou modifiée via RADIUS CoA. Accel-VRF-Name est utilisé à ces fins. C'est un attribut ACCEL-PPP personnalisé. Définissez-le sur votre serveur RADIUS.

Renommer les interfaces des clients par RADIUS

Si le serveur RADIUS utilise l'attribut NAS-Port-Id, les tunnels PPP seront renommés.

Note

La valeur de l'attribut NAS-Port-Id doit être inférieure à 16 caractères, sinon l'interface ne sera pas renommée.

Configuration du LNS (serveur de réseau L2TP)

Les LNS sont souvent utilisés pour se connecter à un LAC (concentrateur d'accès L2TP).

set vpn l2tp remote-access lns host-name <hostname>

Envoyé au client (LAC) dans l'attribut Host-Name

set vpn l2tp remote-access lns shared-secret <secret>

Mot de passe du tunnel utilisé pour authentifier le client (LAC)

Pour expliquer l'utilisation du LNS, consultez notre modèle PPPoE sur L2TP.

IPv6

set vpn l2tp remote-access ppp-options ipv6 <require | prefer | allow | deny>

Spécifie la préférence de négociation IPv6.

  • require - Exiger la négociation IPv6

  • prefer - Demander au client de négocier IPv6, ne pas échouer si il refuse

  • allow - Négocier IPv6 uniquement si le client le demande (valeur par défaut)

  • deny - Ne pas négocier IPv6 (valeur par défaut)

set vpn l2tp remote-access client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Utilisez cette commande pour définir le pool d'adresses IPv6 à partir duquel un client L2TP obtiendra un préfixe IPv6 de longueur définie (masque) pour terminer le point de terminaison L2TP côté client. La longueur du masque peut être définie entre 48 et 128 bits, la valeur par défaut étant 64.

set vpn l2tp remote-access client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Utilisez cette commande pour configurer la délégation de préfixe DHCPv6 (RFC3633) sur L2TP. Vous devrez définir votre pool IPv6 et la longueur du préfixe de délégation. À partir du pool IPv6 défini, vous distribuerez des réseaux de la longueur définie (préfixe de délégation). La longueur du préfixe de délégation peut être comprise entre 32 et 64 bits.

set vpn l2tp remote-access default-ipv6-pool <IPv6-POOL-NAME>

Utilisez cette commande pour définir le nom du pool d'adresses IPv6 par défaut.

set vpn l2tp remote-access ppp-options ipv6 allow
set vpn l2tp remote-access client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn l2tp remote-access client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn l2tp remote-access default-ipv6-pool IPv6-POOL

Options avancées IPv6

set vpn l2tp remote-access ppp-options ipv6-accept-peer-interface-id

Accepter l'identifiant d'interface pair. Par défaut, cela n'est pas défini.

set vpn l2tp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Spécifie si un identifiant d'interface fixe ou aléatoire est utilisé pour IPv6. La valeur par défaut est fixe.

  • random - Identifiant d'interface aléatoire pour IPv6

  • x:x:x:x - Spécifier l'identifiant d'interface pour IPv6

set vpn l2tp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Spécifie l'identifiant d'interface pair pour IPv6. La valeur par défaut est fixe.

  • random - Identifiant d'interface aléatoire pour IPv6

  • x:x:x:x - Spécifier l'identifiant d'interface pour IPv6

  • ipv4-addr - Calculer l'identifiant d'interface à partir de l'adresse IPv4.

  • calling-sid - Calculer l'identifiant d'interface à partir de calling-station-id.

Script à exécuter lorsque l'interface de session est sur le point de se terminer

Options avancées PPP

set vpn l2tp remote-access ppp-options disable-ccp

Désactiver le protocole de contrôle de compression (CCP). CCP est activé par défaut.

set vpn l2tp remote-access ppp-options interface-cache <number>

Spécifie le nombre d'interfaces à mettre en cache. Cela empêche les interfaces d'être supprimées une fois la session correspondante détruite. Au lieu de cela, les interfaces sont mises en cache pour une utilisation ultérieure dans de nouvelles sessions. Cela devrait réduire le taux de création/de suppression d'interfaces au niveau du noyau. La valeur par défaut est 0.

set vpn l2tp remote-access ppp-options ipv4 <require | prefer | allow | deny>

Spécifie la préférence de négociation IPv4.

  • require - Exiger la négociation IPv4

  • prefer - Demander au client de négocier IPv4, ne pas échouer si il refuse

  • allow - Négocier IPv4 uniquement si le client le demande (valeur par défaut)

  • deny - Ne pas négocier IPv4

set vpn l2tp remote-access ppp-options lcp-echo-failure <number>

Définit le nombre maximum <number> de demandes d'écho non répondues. Lorsque la valeur <number> est atteinte, la session sera réinitialisée. La valeur par défaut est 3.

set vpn l2tp remote-access ppp-options lcp-echo-interval <interval>

Si cette option est spécifiée et supérieure à 0, le module PPP enverra des demandes d'écho LCP toutes les <interval> secondes. La valeur par défaut est 30.

set vpn l2tp remote-access ppp-options lcp-echo-timeout

Spécifie le délai en secondes pour attendre toute activité du pair. Si cette option est spécifiée, elle active la fonctionnalité d'écho LCP adaptatif et « lcp-echo-failure » n'est pas utilisé. La valeur par défaut est 0.

set vpn l2tp remote-access ppp-options min-mtu <number>

Définit la MTU minimale acceptable. Si un client tente de négocier une MTU inférieure à celle-ci, elle sera NAKée, et déconnectée si elle rejette une MTU plus grande. La valeur par défaut est 100.

set vpn l2tp remote-access ppp-options mppe <require | prefer | deny>

Spécifie la préférence de négociation MPPE.

  • require - demander au client MPPE, si il refuse, couper la connexion

  • prefer - demander au client MPPE, si il refuse, ne pas échouer. (valeur par défaut)

  • deny - refuser MPPE

Comportement par défaut - ne pas demander au client MPPE, mais l'autoriser si le client le souhaite. Veuillez noter que RADIUS peut remplacer cette option avec l'attribut MS-MPPE-Encryption-Policy.

set vpn l2tp remote-access ppp-options mru <number>

Définit la MRU préférée. Par défaut, il n'est pas défini.

Les clients connectés doivent utiliser <address> comme serveur DNS. Cette commande accepte à la fois les adresses IPv4 et IPv6. Jusqu'à deux serveurs de noms peuvent être configurés pour IPv4, jusqu'à trois pour IPv6.
