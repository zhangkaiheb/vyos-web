Serveur DHCP

VyOS utilise le serveur DHCP Kea pour l'attribution des adresses IPv4 et IPv6.

Serveur IPv4

La topologie réseau est déclarée par shared-network-name et les déclarations de sous-réseau. Le service DHCP peut servir plusieurs réseaux partagés, chacun ayant 1 ou plus de sous-réseaux. Chaque sous-réseau doit être présent sur une interface. Une plage peut être déclarée à l'intérieur d'un sous-réseau pour définir un pool d'adresses dynamiques. Plusieurs plages peuvent être définies et peuvent contenir des trous. Les mappages statiques peuvent être configurés pour assigner des « adresses statiques » aux clients en fonction de leur adresse MAC.

Configuration

set service dhcp-server hostfile-update

Créer une entrée DNS par location client, en ajoutant les clients au fichier /etc/hosts. L'entrée aura le format : <shared-network-name>_<hostname>.<domain-name>

Options du réseau partagé

Les options DHCP suivantes s'appliquent à un réseau partagé entier. Tous les sous-réseaux héritent de ces valeurs, sauf si la même option est définie localement.

set service dhcp-server shared-network-name <name> option bootfile-name <filename>

nom du fichier de démarrage (option DHCP 67).

set service dhcp-server shared-network-name <name> option bootfile-server <address>

serveur à partir duquel le fichier de démarrage initial doit être chargé (champ siaddr du DHCP).

set service dhcp-server shared-network-name <name> option bootfile-size <size>

Taille du fichier de démarrage en blocs de 512 octets (option DHCP 13).

set service dhcp-server shared-network-name <name> option captive-portal <url>

Point de terminaison API du portail captif (option DHCP 114).

set service dhcp-server shared-network-name <name> option capwap-controller <address>

Adresse IP du contrôleur CAPWAP (option DHCP 138).

set service dhcp-server shared-network-name <name> option client-prefix-length <prefix-length>

Spécifie le masque de sous-réseau du client selon le RFC 950. Si non défini, le déclaration de sous-réseau est utilisée (option DHCP 1).

set service dhcp-server shared-network-name <name> option default-router <address>

Adresse IP du routeur par défaut (option DHCP 3).

set service dhcp-server shared-network-name <name> option domain-name <domain-name>

Le paramètre domain-name devrait être le nom de domaine qui sera ajouté au nom d'hôte du client pour former un nom de domaine complet (FQDN) (option DHCP 15).

C'est le paramètre de configuration pour la définition du réseau partagé. Tous les sous-réseaux hériteront de cette configuration si elle n'est pas spécifiée localement.

set service dhcp-server shared-network-name <name> option domain-search <domain-name>

Le paramètre domain-name devrait être le nom de domaine utilisé lors de la complétion des requêtes DNS où aucun FQDN complet n'est passé. Cette option peut être donnée plusieurs fois si vous avez besoin de plusieurs domaines de recherche (option DHCP 119).

C'est le paramètre de configuration pour la définition du réseau partagé. Tous les sous-réseaux hériteront de cette configuration si elle n'est pas spécifiée localement.

set service dhcp-server shared-network-name <name> option interface-mtu <mtu>

MTU de l'interface client (option DHCP 26).

set service dhcp-server shared-network-name <name> option ip-forwarding

Activer le routage IP sur le client (option DHCP 19).

set service dhcp-server shared-network-name <name> option ipv6-only-preferred <seconds>

Désactiver IPv4 sur les hôtes IPv6 uniquement pendant le nombre de secondes spécifié (RFC 8925, option DHCP 108).
