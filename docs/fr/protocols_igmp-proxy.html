Proxy IGMP

Le IGMP proxy permet aux routeurs de transférer le trafic multicast, comme l'IPTV ou les flux vidéo, entre différents réseaux, tels que les réseaux domestiques et les fournisseurs d'accès Internet (FAI). Le proxy IGMP repose sur une interface en amont qui fait face aux sources multicast en amont, et une ou plusieurs interfaces en aval qui font face aux réseaux locaux ou aux hôtes et transmettent le trafic aux clients demandeurs.

La configuration du proxy IGMP nécessite exactement une interface en amont et au moins une interface en aval.

Configuration

set protocols igmp-proxy interface <interface> role <upstream | downstream>

Configurez le rôle opérationnel pour l'interface IGMP proxy spécifiée.

  • upstream: Communique avec les sources multicast en amont pour récupérer le trafic multicast. Une configuration valide nécessite exactement une interface en amont.

  • downstream: Communique avec les sous-réseaux locaux ou les hôtes en aval pour diffuser le trafic demandé. Une configuration valide nécessite au moins une interface en aval.

Exemple :

set protocols igmp-proxy interface eth0 role upstream
set protocols igmp-proxy interface eth1 role downstream
set protocols igmp-proxy interface <interface> alt-subnet <network>

Configurez un sous-réseau distant autorisé pour le trafic multicast entrant sur l'interface IGMP proxy spécifiée

Par défaut, le proxy IGMP accepte uniquement le trafic multicast provenant des sous-réseaux directement connectés. Si une source multicast se trouve sur un réseau distant, vous devez définir explicitement le sous-réseau distant autorisé pour permettre le trafic.

Vous pouvez configurer plusieurs sous-réseaux distants pour une interface IGMP proxy en amont.

Les interfaces en amont nécessitent souvent cette configuration car les sources multicast résident généralement sur des sous-réseaux externes.

Exemple :

set protocols igmp-proxy interface eth0 alt-subnet 10.0.0.0/8
set protocols igmp-proxy interface <interface> whitelist <network>

Configurez un réseau de destination autorisé pour les demandes de trafic multicast sur l'interface IGMP proxy spécifiée.

Par défaut, le proxy IGMP accepte les demandes pour tous les réseaux de destination multicast. Lorsque vous définissez une liste blanche, le proxy IGMP ne transfère les demandes que pour les réseaux multicast spécifiés.

Vous pouvez configurer plusieurs entrées de liste blanche par interface IGMP proxy en aval.

Exemple :

set protocols igmp-proxy interface eth1 whitelist 239.0.0.0/8
set protocols igmp-proxy interface <interface> threshold <1-255>

Configurez la limite TTL (Time-to-Live) pour l'interface IGMP proxy spécifiée.

Le proxy IGMP supprime tout paquet multicast ayant une valeur TTL inférieure à la limite configurée.

Exemple :

set protocols igmp-proxy interface eth0 threshold 5
set protocols igmp-proxy disable-quickleave

Désactivez le mode quickleave pour le proxy IGMP.

Si désactivé, le proxy IGMP ne transmet pas de message Leave en amont lorsqu'un message Leave en aval est reçu, empêchant ainsi la fin immédiate du trafic multicast en amont. Le proxy IGMP cesse également de interroger les interfaces en aval pour les rapports de membres. Si un client en aval soumet un nouveau rapport, le proxy IGMP ignore le message et ne reprend pas la distribution du trafic demandé.

Remarque

Désactiver le mode quickleave force le proxy IGMP à fonctionner exactement comme un client multicast standard sur l'interface en amont.

Remarque

Désactiver le mode quickleave augmente le risque de saturation de la bande passante du réseau.

Exemple :

set protocols igmp-proxy disable-quickleave
set protocols igmp-proxy disable

Désactivez le proxy IGMP sur le routeur.

Exemple :

set protocols igmp-proxy disable

Fonctionnement

restart igmp-proxy

Redémarrez le processus de proxy IGMP.

Exemple

Dans cet exemple, le LAN local sur l'interface eth1 fonctionne derrière un NAT. Pour permettre aux clients locaux de recevoir le trafic multicast provenant du réseau source 198.51.100.0/24 sur l'interface WAN (eth0), configurez le proxy IGMP comme suit :

set protocols igmp-proxy interface eth0 role upstream
set protocols igmp-proxy interface eth0 alt-subnet 198.51.100.0/24
set protocols igmp-proxy interface eth1 role downstream
