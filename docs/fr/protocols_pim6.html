PIMv6

VyOS prend en charge le routage multicast IPv6 via PIMv6 et MLD versions 1 et 2.

Le PIMv6 fonctionne de manière similaire à son homologue IPv4 : il utilise le tableau de routage unicast IPv6 existant pour les décisions de chemin, et le trafic des sources multicast est transmis vers un RP. Les récepteurs IPv6 multicast utilisent MLD pour signaler à leur routeur local les groupes qu'ils souhaitent recevoir, et le routeur utilise PIMv6 pour récupérer ce trafic depuis le RP via un arbre de distribution partagé.

Un déploiement PIMv6 fonctionnel nécessite :

  • L'activation du PIMv6 sur chaque interface participant au transfert multicast IPv6.

  • La déclaration de l'emplacement du point de rendez-vous (RP) identiquement sur chaque routeur du domaine PIMv6.

  • L'activation de MLD sur les interfaces face aux récepteurs multicast.

Commandes de base

Utilisez les commandes suivantes pour une configuration de base de PIMv6.

set protocols pim6 interface <interface-name>

Activer le PIMv6 sur l'interface PIMv6 spécifiée.

Cette commande active également MLD, permettant au routeur de traiter les requêtes et rapports MLD des récepteurs IPv6 multicast.

Exemple :

set protocols pim6 interface eth0
set protocols pim6 interface <interface-name> mld disable

Désactiver MLD sur l'interface PIMv6 spécifiée.

Cette commande désactive le traitement MLD sur l'interface tout en maintenant le PIMv6 activé.

Exemple :

set protocols pim6 interface eth0 mld disable

Commandes de réglage

Vous pouvez également configurer le multicast avec les commandes suivantes.

set protocols pim6 interface <interface-name> mld interval <1-65535>

Configurer l'intervalle des requêtes MLD, en secondes, sur l'interface spécifiée.

Cette configuration détermine la fréquence à laquelle le routeur envoie des requêtes MLD pour découvrir les groupes multicast IPv6 ayant des auditeurs actifs sur le réseau connecté.

La valeur par défaut est de 125 secondes.

Exemple :

set protocols pim6 interface eth0 mld interval 100
set protocols pim6 interface <interface-name> mld join <multicast-address>

Configurer l'interface pour rejoindre un groupe multicast IPv6 spécifique.

Exemple :

set protocols pim6 interface eth0 mld join ff0e::db8:0:1234
set protocols pim6 interface <interface-name> mld join <multicast-address> source <source-address>

Configurer l'interface pour rejoindre un canal (S,G) spécifique.

Un canal est identifié par la combinaison d'une adresse IPv6 source (S) et d'une adresse IPv6 multicast (G).

Exemple :

set protocols pim6 interface eth0 mld join ff3e::1234 source 2001:db8::1
set protocols pim6 interface <interface-name> mld last-member-query-count <1-255>

Configurer le nombre de requêtes Last Listener MLD envoyées par le routeur sur l'interface spécifiée après qu'un auditeur quitte un groupe multicast.

La valeur par défaut est de 2.

Exemple :

set protocols pim6 interface eth0 mld last-member-query-count 3
set protocols pim6 interface <interface-name> mld last-member-query-interval <100-6553500>

Configurer l'intervalle des requêtes Last Listener MLD, en millisecondes, sur l'interface spécifiée.

Cette configuration détermine la durée pendant laquelle le routeur attend entre les requêtes Last Listener.

La valeur par défaut est de 1000 millisecondes.

Exemple :

set protocols pim6 interface eth0 mld last-member-query-interval 500
set protocols pim6 interface <interface-name> mld max-response-time <100-6553500>

Configurer le délai maximum de réponse MLD, en millisecondes, sur l'interface spécifiée.

Cette valeur est insérée dans les requêtes MLD et spécifie le temps maximum que les hôtes ont pour répondre avec un rapport d'adhésion. Si aucun rapport n'est reçu dans la fenêtre spécifiée, PIMv6 suppose qu'il n'y a plus d'auditeurs locaux actifs et peut expirer l'état associé (*,G) ou (S,G).

Exemple :

set protocols pim6 interface eth0 mld max-response-time 5000
set protocols pim6 interface <interface-name> mld version <1-2>

Configurer la version MLD sur l'interface spécifiée.

La version par défaut est la version 2.

Exemple :

set protocols pim6 interface eth0 mld version 1

Exemple de configuration

Pour activer le PIMv6 sur les interfaces eth0 et eth1 (ce qui active automatiquement MLD, permettant au routeur de traiter les requêtes et rapports MLD des auditeurs IPv6 connectés) :

set protocols pim6 interface eth0
set protocols pim6 interface eth1

La configuration suivante rejoint explicitement le groupe multicast IPv6 ff0e::db8:0:1234 sur l'interface eth0, et le canal (S,G) (2001:db8::1, ff3e::5678) sur l'interface eth1 :

set protocols pim6 interface eth0 mld join ff0e::db8:0:1234
set protocols pim6 interface eth1 mld join ff3e::5678 source 2001:db8::1
