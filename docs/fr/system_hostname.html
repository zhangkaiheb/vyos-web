Informations sur l'hôte

Cette section décrit les informations système de l'hôte et comment les configurer, elle couvre les sujets suivants :

  • Nom d'hôte

  • Domaine

  • Adresse IP

  • Alias

Nom d'hôte

Un nom d'hôte est l'étiquette (nom) attribuée à un appareil réseau (un hôte) sur un réseau et est utilisé pour distinguer un appareil d'un autre sur des réseaux spécifiques ou sur Internet. D'autre part, ce sera le nom qui apparaît sur la ligne de commande.

set system host-name <hostname>

Le nom d'hôte peut avoir jusqu'à 63 caractères. Un nom d'hôte doit commencer et se terminer par une lettre ou un chiffre, et avoir comme caractères internes seulement des lettres, des chiffres ou un trait d'union.

Le nom d'hôte par défaut utilisé est vyos.

Nom de domaine

Un nom de domaine est l'étiquette (nom) attribuée à un réseau informatique et est donc unique. VyOS ajoute le nom de domaine en tant que suffixe à tout nom non qualifié. Par exemple, si vous définissez le nom de domaine example.com, et que vous essayez de faire un ping du nom non qualifié crux, alors VyOS qualifie le nom en crux.example.com.

set system domain-name <domain>

Configurer le nom de domaine du système. Un nom de domaine doit commencer et se terminer par une lettre ou un chiffre, et avoir comme caractères internes uniquement des lettres, des chiffres ou un trait d'union.

Mappage statique du nom d'hôte

Comment une adresse IP est attribuée à une interface dans Ethernet. Cette section montre comment mapper statiquement une adresse IP à un nom d'hôte pour la résolution de noms locale (c'est-à-dire sur cette instance VyOS). C'est l'équivalent VyOS des entrées du fichier /etc/hosts.

Remarque

Ne modifiez pas manuellement /etc/hosts. Ce fichier sera automatiquement régénéré au démarrage en fonction des paramètres de cette section, ce qui signifie que vous perdrez toutes vos modifications manuelles. Au lieu de cela, configurez les mappages d'hôte statiques comme suit.

set system static-host-mapping host-name <hostname> inet <address>

Créer un mappage de nom d'hôte statique qui résout toujours le nom <hostname> vers l'adresse IP <address>.

set system static-host-mapping host-name <hostname> alias <alias>

Créer un nom <alias> pour la carte statique configurée pour <hostname>. Ainsi, l'adresse configurée comme set system static-host-mapping host-name <hostname> inet <address> peut être atteinte via plusieurs noms.

Plusieurs alias peuvent être spécifiés par nom d'hôte.
