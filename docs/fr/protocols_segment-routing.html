Routing par segments

SR est une architecture réseau similaire au routage source. Le routeur d'entrée ajoute une liste de segments, connue sous le nom de SIDs, à chaque paquet lorsqu'il entre dans le réseau.

La liste de SIDs définit explicitement le chemin que la paquet suivra. À chaque nœud, le routeur lit le premier SID, exécute son instruction de routage, et supprime généralement celui-ci afin que le nœud suivant puisse traiter le SID suivant.

SR repose sur les IGPs tels que IS-IS ou OSPF pour annoncer les SIDs à travers le réseau.

Remarque

SR définit une architecture de plane de contrôle et peut être appliquée aux plans de données MPLS existants. Dans les réseaux MPLS, les segments sont encodés en tant qu'étiquettes MPLS et appliquées au routeur d'entrée. Ces étiquettes sont ensuite distribuées à travers le domaine de routage par des IGPs tels que IS-IS (comme décrit dans RFC 8667) ou OSPF.

SR pour le plan de données MPLS prend en charge IPv4, IPv6 et ECMP, et a été testé avec des routeurs Cisco et Juniper. Cependant, cette mise en œuvre reste expérimentale pour FRR.

Configuration SR IS-IS

Utilisez les commandes suivantes pour activer SR sur IS-IS.

Limitations connues :

  • Pas de prise en charge de la redistribution de niveau (L1 vers L2 ou L2 vers L1).

  • Pas de prise en charge du BSID.

  • Seul un seul SRGB et l'algorithme par défaut SPF sont pris en charge.

set protocols isis segment-routing global-block high-label-value <16-1048575>

Configurez la borne supérieure du Segment Routing Global Block (SRGB).

Le SRGB définit la plage d'étiquettes MPLS réservées pour mapper les segments globaux, tels que les Prefix-SIDs, aux entrées FIB.

La plage ne peut pas dépasser 65535 étiquettes.

Exemple :

set protocols isis segment-routing global-block high-label-value 23999
set protocols isis segment-routing global-block low-label-value <16-1048575>

Configurez la borne inférieure du Segment Routing Global Block (SRGB).

Le SRGB définit la plage d'étiquettes MPLS réservées pour mapper les segments globaux, tels que les Prefix-SIDs, aux entrées FIB.

La plage ne peut pas dépasser 65535 étiquettes.

Exemple :

set protocols isis segment-routing global-block low-label-value 16000
set protocols isis segment-routing local-block high-label-value <16-1048575>

Configurez la borne supérieure du Segment Routing Local Block (SRLB).

Le SRLB définit la plage d'étiquettes MPLS qu'un routeur réserve pour ses segments locaux, tels que les Adjacency-SIDs.

La plage ne peut pas dépasser 65535 étiquettes.

Exemple :

set protocols isis segment-routing local-block high-label-value 15999
set protocols isis segment-routing local-block low-label-value <16-1048575>

Configurez la borne inférieure du Segment Routing Local Block (SRLB).

Le SRLB définit la plage d'étiquettes MPLS qu'un routeur réserve pour ses segments locaux, tels que les Adjacency-SIDs.

La plage ne peut pas dépasser 65535 étiquettes.

Exemple :

set protocols isis segment-routing local-block low-label-value 15000

Note

Les blocs d'étiquettes SR ont les contraintes de configuration suivantes :

  • Les deux bornes (high-label-value et low-label-value) doivent être configurées. La suppression de l'une des bornes supprime également l'autre.

  • local-block nécessite que global-block soit configuré.

  • Les plages SRGB et SRLB ne doivent pas se chevaucher.

Violant l'une de ces règles provoque l'échec de la validation.

set protocols isis segment-routing maximum-label-depth <1-16>

Configurez le MSD pris en charge par le routeur.

La valeur dépend du plan de données MPLS.

Exemple :

set protocols isis segment-routing maximum-label-depth 10
set protocols isis segment-routing prefix <address> index value <0-65535>

Configurez un Prefix-SID avec une valeur d'index pour le préfixe IP spécifié.

Un Prefix-SID est un Identifiant de Segment associé à un préfixe IP et diffusé par l'IGP (IS-IS).

Exemple :

set protocols isis segment-routing prefix 192.0.2.1/32 index value 1
set protocols isis segment-routing prefix <address> index <no-php-flag | explicit-null>

Configurez un drapeau de traitement d'étiquette pour le Prefix-SID indexé associé au préfixe IP spécifié :

  • no-php-flag : Demande au voisin amont de ne pas retirer l'étiquette Prefix-SID avant de transmettre le paquet.

  • explicit-null : Demande au voisin amont de transmettre le paquet avec l'étiquette Explicit-Null.

Exemple :

set protocols isis segment-routing prefix 192.0.2.1/32 index no-php-flag
set protocols isis segment-routing prefix <address> absolute value <16-1048575>

Configurez un Prefix-SID avec une valeur absolue pour le préfixe IP spécifié

Un Prefix-SID est un Identifiant de Segment associé à un préfixe IP et diffusé par l'IGP (IS-IS).

Exemple :

set protocols isis segment-routing prefix 192.0.2.1/32 absolute value 16001
set protocols isis segment-routing prefix <address> absolute <no-php-flag | explicit-null>

Configurez un drapeau de traitement d'étiquette pour le Prefix-SID absolu associé au préfixe IP spécifié :

  • no-php-flag : Demande au voisin amont de ne pas retirer l'étiquette Prefix-SID avant de transmettre le paquet.

  • explicit-null : Demande au voisin amont de transmettre le paquet avec l'étiquette Explicit-Null.

Exemple :

set protocols isis segment-routing prefix 192.0.2.1/32 absolute no-php-flag

Commandes opérationnelles

show isis segment-routing node

Affichez tous les nœuds SR appris.

show isis route prefix-sid

Affichez tous les Prefix-SIDs appris et leurs étiquettes MPLS.

Note

Pour plus d'informations, voir IS-IS.

Configuration SR OSPF

Utilisez les commandes suivantes pour activer SR sur OSPF.

set protocols ospf parameters opaque-lsa

Activez Opaque LSA (RFC 2370) dans OSPF.

Les LSAs Opaque sont nécessaires pour transporter les étiquettes MPLS via OSPF.

Exemple :

set protocols ospf parameters opaque-lsa
set protocols ospf segment-routing global-block high-label-value <16-1048575>

Le SRGB définit la plage d'étiquettes MPLS réservées pour mapper les Prefix-SIDs aux entrées FIB.

Exemples

Activer SR sur IS-IS (expérimental)

L'exemple suivant montre une topologie SR basique à deux nœuds utilisant IS-IS.

Nœud 1 :

set interfaces loopback lo address '198.51.100.1/32'
set interfaces ethernet eth1 address '192.0.2.1/24'

set protocols isis interface eth1
set protocols isis interface lo
set protocols isis net '49.0001.1980.5110.0001.00'
set protocols isis segment-routing global-block high-label-value '599'
set protocols isis segment-routing global-block low-label-value '550'
set protocols isis segment-routing prefix 198.51.100.1/32 index value '1'
set protocols isis segment-routing prefix 198.51.100.1/32 index explicit-null
set protocols mpls interface 'eth1'

Nœud 2 :

set interfaces loopback lo address '198.51.100.2/32'
set interfaces ethernet eth1 address '192.0.2.2/24'

set protocols isis interface eth1
set protocols isis interface lo
set protocols isis net '49.0001.1980.5110.0002.00'
set protocols isis segment-routing global-block high-label-value '599'
set protocols isis segment-routing global-block low-label-value '550'
set protocols isis segment-routing prefix 198.51.100.2/32 index value '2'
set protocols isis segment-routing prefix 198.51.100.2/32 index explicit-null
set protocols mpls interface 'eth1'

Activer SR sur OSPF (expérimental)

L'exemple suivant montre une topologie SR basique à deux nœuds utilisant OSPF.

Nœud 1 :

set interfaces loopback lo address 198.51.100.1/32
set interfaces ethernet eth0 address 192.0.2.1/24
set protocols ospf area 0 network '192.0.2.0/24'
set protocols ospf area 0 network '198.51.100.1/32'
set protocols ospf parameters opaque-lsa
set protocols ospf parameters router-id '198.51.100.1'
set protocols ospf segment-routing global-block high-label-value '1100'
set protocols ospf segment-routing global-block low-label-value '1000'
set protocols ospf segment-routing prefix 198.51.100.1/32 index explicit-null
set protocols ospf segment-routing prefix 198.51.100.1/32 index value '1'

set interfaces loopback lo address 198.51.100.2/32
