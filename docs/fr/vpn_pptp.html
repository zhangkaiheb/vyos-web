Serveur PPTP

Le protocole de tunneling point à point (PPTP) a été implémenté dans VyOS uniquement pour la compatibilité descendante. Le PPTP présente de nombreux problèmes de sécurité connus et vous devriez utiliser l'une des nombreuses autres implementations de VPN récentes.

Configuration du serveur PPTP

set vpn pptp remote-access authentication mode local
set vpn pptp remote-access authentication local-users username test password 'test'
set vpn pptp remote-access client-ip-pool PPTP-POOL range 192.168.255.2-192.168.255.254
set vpn pptp remote-access default-pool 'PPTP-POOL'
set vpn pptp remote-access outside-address 192.0.2.2
set vpn pptp remote-access gateway-address 192.168.255.1
set vpn pptp remote-access authentication mode <local | radius>

Définir le backend d'authentification. Le backend d'authentification configuré est utilisé pour toutes les requêtes.

  • radius: Toutes les requêtes d'authentification sont gérées par un serveur RADIUS configuré.

  • local: Toutes les requêtes d'authentification sont gérées localement.

  • noauth: L'authentification désactivée.

set vpn pptp remote-access authentication local-users username <user> password <pass>

Créer <user> pour l'authentification locale sur ce système. Le mot de passe de l'utilisateur sera défini à <pass>.

set vpn pptp remote-access client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Utilisez cette commande pour définir la première adresse IP d'un pool de adresses à attribuer aux clients PPTP. Si la notation x.x.x.x-x.x.x.x, elle doit être dans un sous-réseau /24. Si la notation x.x.x.x/x est utilisée, il est possible de définir un hôte/netmask.

set vpn pptp remote-access default-pool <POOL-NAME>

Utilisez cette commande pour définir le nom du pool d'adresses par défaut.

set vpn pptp remote-access gateway-address <gateway>

Spécifie une seule adresse IP <gateway> à utiliser comme adresse locale des interfaces PPP.

Configuration de l'authentification RADIUS

Pour activer l'authentification basée sur RADIUS, le mode d'authentification doit être changé dans la configuration. Les paramètres précédents comme les utilisateurs locaux, existent toujours dans la configuration, mais ils ne sont pas utilisés si le mode a été changé de local à radius. Une fois remis à local, il utilisera à nouveau tous les comptes locaux.

set vpn pptp remote-access authentication mode radius
set vpn pptp remote-access authentication radius server <server> key <secret>

Configurer le serveur RADIUS <server> et sa clé partagée requise <secret> pour communiquer avec le serveur RADIUS.

Comme le serveur RADIUS serait un point de défaillance unique, plusieurs serveurs RADIUS peuvent être configurés et seront utilisés séquentiellement. Par exemple :

set vpn pptp remote-access authentication radius server 10.0.0.1 key 'foo'
set vpn pptp remote-access authentication radius server 10.0.0.2 key 'foo'

Remarque

Certains serveurs RADIUS utilisent une liste d'accès qui permet ou refuse les requêtes, assurez-vous d'ajouter votre routeur VyOS à la liste des clients autorisés.

Adresse source RADIUS

Si vous utilisez OSPF comme IGP, la plus proche interface connectée au serveur RADIUS est toujours utilisée. Vous pouvez lier toutes les demandes sortantes RADIUS à une adresse IP source unique, par exemple l'interface boucle.

set vpn pptp remote-access authentication radius source-address <address>

Adresse IPv4 source utilisée dans toutes les requêtes du serveur RADIUS.

Note

Certains serveurs RADIUS utilisent une liste d'accès qui permet ou refuse les requêtes, assurez-vous d'ajouter votre routeur VyOS à la liste des clients autorisés.

Options avancées RADIUS

set vpn pptp remote-access authentication radius server <server> port <port>

Configurer le serveur RADIUS <server> et son port requis pour les requêtes d'authentification.

set vpn pptp remote-access authentication radius server <server> fail-time <time>

Marquer le serveur RADIUS comme hors ligne pendant ce temps donné <time> en secondes.

set vpn pptp remote-access authentication radius server <server> disable

Désactiver temporairement ce serveur RADIUS.

set vpn pptp remote-access authentication radius acct-timeout <timeout>

Délai d'attente pour répondre aux paquets Interim-Update. (défaut 3 secondes)

set vpn pptp remote-access authentication radius dynamic-author server <address>

Spécifie l'adresse IP pour le serveur d'extension d'autorisation dynamique (DM/CoA). Cette adresse doit exister sur n'importe quelle interface VyOS ou elle peut être 0.0.0.0.

set vpn pptp remote-access authentication radius dynamic-author port <port>

Port UDP pour le serveur d'extension d'autorisation dynamique (DM/CoA)

set vpn pptp remote-access authentication radius dynamic-author key <secret>

Clé pour le serveur d'extension d'autorisation dynamique (DM/CoA)

set vpn pptp remote-access authentication radius max-try <number>

Nombre maximum de tentatives pour envoyer les requêtes Access-Request/Accounting-Request

set vpn pptp remote-access authentication radius timeout <timeout>

Délai d'attente pour répondre au serveur (secondes)

set vpn pptp remote-access authentication radius nas-identifier <identifier>

Valeur à envoyer au serveur RADIUS dans l'attribut NAS-Identifier et à correspondre dans les requêtes DM/CoA.

set vpn pptp remote-access authentication radius nas-ip-address <address>

Valeur à envoyer au serveur RADIUS dans l'attribut NAS-IP-Address et à correspondre dans les requêtes DM/CoA. Le serveur DM/CoA se liera à cette adresse.

set vpn pptp remote-access authentication radius source-address <address>

Adresse IPv4 source utilisée dans toutes les requêtes du serveur RADIUS.

set vpn pptp remote-access authentication radius rate-limit attribute <attribute>

Spécifie quel attribut du serveur RADIUS contient les informations de limite de taux. La valeur par défaut est Filter-Id.

Note

Si vous définissez un attribut RADIUS personnalisé, vous devez le définir sur les deux dictionnaires sur le serveur RADIUS et le client.

set vpn pptp remote-access authentication radius rate-limit enable

Active le contrôle de bande passante via RADIUS.

set vpn pptp remote-access authentication radius rate-limit vendor

Spécifie le dictionnaire fournisseur, le dictionnaire doit être dans /usr/share/accel-ppp/radius.

Les attributs RADIUS reçus ont une priorité plus élevée que les paramètres définis dans la configuration CLI, se référer à l'explication ci-dessous.

Allouer des adresses IP aux clients par RADIUS

Si le serveur RADIUS envoie l'attribut Framed-IP-Address, cette adresse IP sera allouée au client et l'option default-pool dans la configuration CLI est ignorée.

Si le serveur RADIUS envoie l'attribut Framed-Pool, l'adresse IP sera allouée d'un pool d'adresses prédéfini dont le nom correspond à la valeur de l'attribut.

Si le serveur RADIUS envoie l'attribut Stateful-IPv6-Address-Pool, l'adresse IPv6 sera allouée à partir d'un pool IPv6 prédéfini prefix dont le nom correspond à la valeur de l'attribut.

Si le serveur RADIUS envoie l'attribut Delegated-IPv6-Prefix-Pool, le préfixe de délégation IPv6 sera alloué à partir d'un pool IPv6 prédéfini delegate dont le nom correspond à la valeur de l'attribut.

Note

Stateful-IPv6-Address-Pool et Delegated-IPv6-Prefix-Pool sont définis dans RFC6911. Si ces attributs ne sont pas définis sur votre serveur RADIUS, ajoutez un nouveau dictionnaire.

L'interface utilisateur peut être placée dans un contexte VRF via un paquet RADIUS Access-Accept, ou changer via RADIUS CoA. Accel-VRF-Name est utilisé à ces fins. C'est un attribut ACCEL-PPP personnalisé. Définissez-le sur votre serveur RADIUS.

Renommer les interfaces des clients par RADIUS

Si le serveur RADIUS utilise l'attribut NAS-Port-Id, les tunnels PPP seront renommer.

Note

La valeur de l'attribut NAS-Port-Id doit être inférieure à 16 caractères, sinon l'interface ne sera pas renommée.

IPv6

set vpn pptp remote-access ppp-options ipv6 <require | prefer | allow | deny>

Spécifie la préférence de négociation IPv6.

  • require - Exiger la négociation IPv6

  • prefer - Demander au client la négociation IPv6, ne pas échouer si il rejette

  • allow - Négocier IPv6 uniquement si le client le demande (valeur par défaut)

  • deny - Ne pas négocier IPv6 (valeur par défaut)

set vpn pptp remote-access client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Utilisez cette commande pour définir le pool d'adresses IPv6 à partir duquel un client PPTP obtiendra un préfixe IPv6 de longueur définie par vous (masque). La longueur du masque peut être définie de 48 à 128 bits, la valeur par défaut est 64.

set vpn pptp remote-access client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Utilisez cette commande pour configurer la délégation de préfixe DHCPv6 (RFC3633) sur PPTP. Vous devrez définir votre pool IPv6 et la longueur du préfixe de délégation. À partir du pool IPv6 défini, vous distribuerez des réseaux de longueur définie (préfixe de délégation). La longueur du préfixe de délégation peut être définie de 32 à 64 bits.

set vpn pptp remote-access default-ipv6-pool <IPv6-POOL-NAME>

Utilisez cette commande pour définir le nom du pool d'adresses IPv6 par défaut.

set vpn pptp remote-access ppp-options ipv6 allow
set vpn pptp remote-access client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn pptp remote-access client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn pptp remote-access default-ipv6-pool IPv6-POOL

Options avancées IPv6

set vpn pptp remote-access ppp-options ipv6-accept-peer-interface-id

Accepter l'identifiant d'interface du pair. Par défaut, il n'est pas défini.

set vpn pptp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Spécifie l'identifiant d'interface fixe ou aléatoire pour IPv6. Par défaut, c'est fixe.

  • random - Identifiant d'interface aléatoire pour IPv6

  • x:x:x:x - Spécifier l'identifiant d'interface pour IPv6

set vpn pptp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Spécifie l'identifiant d'interface du pair pour IPv6. Par défaut, c'est fixe.

  • random - Identifiant d'interface aléatoire pour IPv6

  • x:x:x:x - Spécifier l'identifiant d'interface pour IPv6

  • ipv4-addr - Calculer l'identifiant d'interface à partir de l'adresse IPv4.

  • calling-sid - Calculer l'identifiant d'interface à partir de calling-station-id.

Script à exécuter lorsque l'interface de session est complètement configurée et lancée

Options avancées PPP

set vpn pptp remote-access ppp-options disable-ccp

Désactiver le protocole de contrôle de compression (CCP). CCP est activé par défaut.

set vpn pptp remote-access ppp-options interface-cache <number>

Spécifie le nombre d'interfaces à garder en cache. Cela signifie que nous ne détruisons pas l'interface après que la session correspondante soit détruite, mais on la place dans le cache et on l'utilise ultérieurement pour les nouvelles sessions. Cela devrait réduire le taux de création/de suppression d'interfaces au niveau du noyau. La valeur par défaut est 0.

set vpn pptp remote-access ppp-options ipv4 <require | prefer | allow | deny>

Spécifie la préférence de négociation IPv4.

  • require - Exiger la négociation IPv4

  • prefer - Demander au client la négociation IPv4, ne pas échouer si il rejette

  • allow - Négocier IPv4 uniquement si le client le demande (valeur par défaut)

  • deny - Ne pas négocier IPv4

set vpn pptp remote-access ppp-options lcp-echo-failure <number>

Définit le nombre maximum <number> de demandes d'écho non répondues. Lorsque la valeur <number> est atteinte, la session sera réinitialisée. La valeur par défaut est 3.

set vpn pptp remote-access ppp-options lcp-echo-interval <interval>

Si cette option est spécifiée et supérieure à 0, le module PPP enverra des ping LCP de type echo toutes les <interval> secondes. La valeur par défaut est 30.

set vpn pptp remote-access ppp-options lcp-echo-timeout

Spécifie le délai en secondes pour attendre toute activité du pair. Si cette option est spécifiée, cela active la fonctionnalité adaptative d'écho LCP et « lcp-echo-failure » n'est pas utilisé. La valeur par défaut est 0.

set vpn pptp remote-access ppp-options min-mtu <number>

Définit la MTU acceptable minimale. Si le client essaie de négocier moins que la MTU spécifiée, elle sera NAKée ou déconnectée si elle rejette une MTU plus grande. La valeur par défaut est 100.

set vpn pptp remote-access ppp-options mppe <require | prefer | deny>

Spécifie la préférence de négociation MPPE.

  • require - demander au client MPPE, si il refuse, couper la connexion

  • prefer - demander au client MPPE, si il refuse, ne pas échouer. (valeur par défaut)

  • deny - refuser MPPE

Comportement par défaut - ne pas demander au client MPPE, mais permettre s'il veut. Veuillez noter que RADIUS peut remplacer cette option par l'attribut MS-MPPE-Encryption-Policy.

set vpn pptp remote-access ppp-options mru <number>

Définit la MRU préférée. Par défaut, elle n'est pas définie.
