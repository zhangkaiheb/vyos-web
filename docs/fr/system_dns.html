Configuration DNS du système

Avertissement

Si vous configurez un VRF à des fins de gestion, il n’existe actuellement aucun moyen de forcer le trafic DNS du système via un VRF spécifique.

Cette section décrit la configuration du DNS sur le système, à savoir :

  • Serveurs de noms DNS

  • Ordre de recherche de domaine

Serveurs de noms DNS

set system name-server <address>

Utilisez cette commande pour spécifier un serveur DNS pour le système à utiliser pour les recherches DNS. Plusieurs serveurs DNS peuvent être ajoutés, en configurant un à la fois. Les adresses IPv4 et IPv6 sont prises en charge.

Exemple

Dans cet exemple, certains serveurs OpenNIC sont utilisés, deux adresses IPv4 et deux adresses IPv6 :

set system name-server 176.9.37.132
set system name-server 195.10.195.195
set system name-server 2a01:4f8:161:3441::1
set system name-server 2a00:f826:8:2::195

Ordre de recherche de domaine

Afin que le système puisse utiliser et compléter les noms d’hôtes non qualifiés, une liste peut être définie qui sera utilisée pour les recherches de domaines.

set system domain-search <domain>

Utilisez cette commande pour définir des domaines, un à la fois, afin que le système les utilise pour compléter les noms d’hôtes non qualifiés. Maximum : 6 entrées.

Note

Les noms de domaine peuvent inclure des lettres, des chiffres, des tirets et des points avec une longueur maximale de 253 caractères.

Exemple

Le système est configuré pour tenter la complétion des domaines dans l’ordre suivant : vyos.io (premier), vyos.net (deuxième) et vyos.network (dernier) :

set system domain-search vyos.io
set system domain-search vyos.net
set system domain-search vyos.network
