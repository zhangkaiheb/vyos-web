Politique de carte de routage

La carte de routage est une commande puissante qui offre aux administrateurs réseau un outil très utile et flexible pour la manipulation du trafic.

Configuration

Carte de routage

set policy route-map <text>

Cette commande crée une nouvelle politique de carte de routage, identifiée par <text>.

set policy route-map <text> description <text>

Définir la description de la politique de carte de routage.

set policy route-map <text> rule <1-65535> action <permit|deny>

Définir l'action pour la politique de carte de routage.

set policy route-map <text> rule <1-65535> call <text>

Appeler une autre politique de carte de routage en cas de correspondance.

set policy route-map <text> rule <1-65535> continue <1-65535>

Passer à une règle différente dans cette carte de routage en cas de correspondance.

set policy route-map <text> rule <1-65535> description <text>

Définir la description de la règle dans la politique de carte de routage.

set policy route-map <text> rule <1-65535> match as-path <text>

Liste d'as-path BGP à matcher.

set policy route-map <text> rule <1-65535> match community community-list <text>

Liste de communauté BGP à matcher.

set policy route-map <text> rule <1-65535> match community exact-match

Définir la liste de communauté BGP pour une correspondance exacte.

set policy route-map <text> rule <1-65535> match extcommunity <text>

Communauté étendue BGP à matcher.

set policy route-map <text> rule <1-65535> match interface <text>

Interface de saut initial d'une route à matcher.

set policy route-map <text> rule <1-65535> match ip address access-list <1-2699>

Adresse IP de la route à matcher, basée sur la liste d'accès.

set policy route-map <text> rule <1-65535> match ip address prefix-list <text>

Adresse IP de la route à matcher, basée sur la liste de préfixe.

set policy route-map <text> rule <1-65535> match ip address prefix-len <0-32>

Adresse IP de la route à matcher, basée sur la longueur de préfixe spécifiée. Remarque : cela ne peut être utilisé que pour les routes du noyau. Ne pas appliquer aux routes des protocoles de routage dynamique (par exemple, BGP, RIP, OSPF), car cela peut entraîner des résultats inattendus.

set policy route-map <text> rule <1-65535> match ip nexthop access-list <1-2699>

Prochain saut IP de la route à matcher, basé sur la liste d'accès.

set policy route-map <text> rule <1-65535> match ip nexthop address <x.x.x.x>

Prochain saut IP de la route à matcher, basé sur l'adresse IP.

set policy route-map <text> rule <1-65535> match ip nexthop prefix-len <0-32>

Prochain saut IP de la route à matcher, basé sur la longueur de préfixe.

set policy route-map <text> rule <1-65535> match ip nexthop prefix-list <text>

Prochain saut IP de la route à matcher, basé sur la liste de préfixe.

set policy route-map <text> rule <1-65535> match ip nexthop type <blackhole>

Prochain saut IP de la route à matcher, basé sur le type.

set policy route-map <text> rule <1-65535> match ip route-source access-list <1-2699>

Source IP de la route à matcher, basée sur la liste d'accès.

set policy route-map <text> rule <1-65535> match ip route-source prefix-list <text>

Source IP de la route à matcher, basée sur la liste de préfixe.

set policy route-map <text> rule <1-65535> match ipv6 address access-list <text>

Adresse IPv6 de la route à matcher, basée sur la liste d'accès IPv6.

set policy route-map <text> rule <1-65535> match ipv6 address prefix-list <text>

Adresse IPv6 de la route à matcher, basée sur la liste de préfixe IPv6.

set policy route-map <text> rule <1-65535> match ipv6 address prefix-len <0-128>

Adresse IPv6 de la route à matcher, basée sur la longueur de préfixe spécifiée. Remarque : cela ne peut être utilisé que pour les routes du noyau. Ne pas appliquer aux routes des protocoles de routage dynamique (par exemple, BGP, RIP, OSPF), car cela peut entraîner des résultats inattendus.

set policy route-map <text> rule <1-65535> match ipv6 nexthop <h:h:h:h:h:h:h:h>

Adresse IPv6 du prochain saut à matcher.

set policy route-map <text> rule <1-65535> match large-community large-community-list <text>

Correspondre aux grandes communautés BGP.

set policy route-map <text> rule <1-65535> match local-preference <0-4294967295>

Correspondre à la préférence locale.

set policy route-map <text> rule <1-65535> match metric <1-65535>

Correspondre à la métrique de la route.

set policy route-map <text> rule <1-65535> match origin <egp|igp|incomplete>

Code d'origine du protocole de passerelle bord (BGP) à matcher.

set policy route-map <text> rule <1-65535> match peer <x.x.x.x>

Adresse IP du pair à matcher.

set policy route-map <text> rule <1-65535> match protocol <protocol>
Protocole source à matcher.

  • babel - Protocole de routage Babel (Babel)

  • bgp - Protocole de passerelle bord (BGP)

  • connected - Routes connectées (sous-réseau ou hôte directement attaché)

  • isis - Système intermédiaire à système intermédiaire (IS-IS)

  • kernel - Routes du noyau

  • ospf - Premier chemin le plus court (OSPFv2)

  • ospfv3 - Premier chemin le plus court (IPv6) (OSPFv3)

  • rip - Protocole de information de routage (RIP)

  • ripng - Protocole de information de routage de génération suivante (IPv6) (RIPng)

  • static - Routes configurées statiquement

  • table - Table de routage du noyau non principale

  • vnc - Contrôle de réseau virtuel (VNC)

set policy route-map <text> rule <1-65535> match rpki <invalid|notfound|valid>

Correspondre au résultat de validation RPKI.

set policy route-map <text> rule <1-65535> match source-vrf <text>

VRF source à matcher.

set policy route-map <text> rule <1-65535> match tag <1-65535>

Étiquette de route à matcher.

set policy route-map <text> rule <1-65535> on-match goto <1-65535>

Sortie de la politique en cas de correspondance : aller à la règle <1-65535>

set policy route-map <text> rule <1-65535> on-match next

Sortie de la politique en cas de correspondance : passer à la prochaine séquence.

set policy route-map <text> rule <1-65535> set aggregator <as|ip> <1-4294967295|x.x.x.x>

Attribut d'agrégateur BGP : numéro AS ou adresse IP d'une agrégation.

set policy route-map <text> rule <1-65535> set as-path exclude <1-4294967295 | all>

Supprimer le numéro AS de l'AS path BGP.

Si all est spécifié, supprimez tous les numéros AS de l'AS_PATH de l'NLRI du chemin BGP.

set policy route-map <text> rule <1-65535> set as-path prepend <1-4294967295>

Ajouter la chaîne spécifiée de numéros AS au AS_PATH de l'NLRI du chemin BGP.

set policy route-map <text> rule <1-65535> set as-path prepend-last-as <n>

Ajouter le dernier numéro AS existant (le premier ASN) au AS_PATH.

set policy route-map <text> rule <1-65535> set atomic-aggregate

Attribut d'agrégat atomique BGP.

set policy route-map <text> rule <1-65535> set community <add|replace> <community>

Ajouter ou remplacer l'attribut de communauté BGP au format <0-65535:0-65535> ou à partir d'une liste de communautés connues

set policy route-map <text> rule <1-65535> set community none

Supprimer toutes les communautés BGP

set policy route-map <text> rule <1-65535> set community delete <text>

Supprimer les communautés BGP correspondant à la liste de communauté.

set policy route-map <text> rule <1-65535> set large-community <add|replace> <GA:LDP1:LDP2>

Ajouter ou remplacer l'attribut de grande communauté BGP au format <0-4294967295:0-4294967295:0-4294967295>

set policy route-map <text> rule <1-65535> set large-community none

Supprimer toutes les grandes communautés BGP

set policy route-map <text> rule <1-65535> set large-community delete <text>

Supprimer les communautés BGP correspondant à la liste de grandes communautés.

set policy route-map <text> rule <1-65535> set extcommunity bandwidth <1-25600|cumulative|num-multipaths>

Définir la bande passante de la communauté étendue

set policy route-map <text> rule <1-65535> set extcommunity bandwidth-non-transitive

La communauté de bande passante étendue est encodée de manière non transitive

set policy route-map <text> rule <1-65535> set extcommunity rt <text>

Définir la valeur de cible de routage au format <0-65535:0-4294967295> ou <IP:0-65535>.

set policy route-map <text> rule <1-65535> set extcommunity soo <text>

Définir la valeur de site d'origine au format <0-65535:0-4294967295> ou <IP:0-65535>.

set policy route-map <text> rule <1-65535> set extcommunity none

Effacer toutes les extcommunities BGP.

set policy route-map <text> rule <1-65535> set distance <0-255>

Distance administrative significative localement.

set policy route-map <text> rule <1-65535> set ip-next-hop <x.x.x.x>

Adresse IP du prochain saut.

set policy route-map <text> rule <1-65535> set ip-next-hop unchanged

Définir le prochain saut comme inchangé. Passer à travers la carte de routage sans changer sa valeur

set policy route-map <text> rule <1-65535> set ip-next-hop peer-address

Définir l'adresse du prochain saut BGP sur l'adresse du pair. Pour une carte de routage entrante, cela signifie que l'adresse IP de notre pair est utilisée. Pour une carte de routage sortante, cela signifie que l'adresse IP de notre propre appareil est utilisée pour établir le pair avec notre voisin.

set policy route-map <text> rule <1-65535> set ipv6-next-hop <global|local> <h:h:h:h:h:h:h:h>

Adresse IPv6 du prochain saut.

set policy route-map <text> rule <1-65535> set ipv6-next-hop peer-address

Définir l'adresse du prochain saut BGP sur l'adresse du pair. Pour une carte de routage entrante, cela signifie que l'adresse IP de notre pair est utilisée. Pour une carte de routage sortante, cela signifie que l'adresse IP de notre propre appareil est utilisée pour établir le pair avec notre voisin.

set policy route-map <text> rule <1-65535> set ipv6-next-hop prefer-global

Pour les cartes de routage entrantes et d'importation, si nous recevons une adresse v6 globale et une adresse v6 LL pour la route, préférons utiliser l'adresse globale comme prochain saut.

set policy route-map <text> rule <1-65535> set local-preference <0-4294967295>

Définir l'attribut de préférence locale BGP.

set policy route-map <text> rule <1-65535> set metric <+/-metric|0-4294967295|rtt|+rtt|-rtt>

Définir la métrique de la route. Lorsqu'elle est utilisée avec BGP, définir l'attribut MED à une valeur spécifique. Utilisez +/- pour ajouter ou soustraire la valeur spécifiée à/from la métrique/MED existante. Utilisez rtt pour définir la MED sur le temps de trajet aller-retour ou +rtt/-rtt pour ajouter/soustraire le temps de trajet aller-retour à/from la MED.

set policy route-map <text> rule <1-65535> set metric-type <type-1|type-2>

Définir le type de métrique OSPF externe.

set policy route-map <text> rule <1-65535> set origin <igp|egp|incomplete>

Définir le code d'origine BGP.

set policy route-map <text> rule <1-65535> set originator-id <x.x.x.x>

Définir l'attribut ID d'originateur BGP.

set policy route-map <text> rule <1-65535> set src <x.x.x.x|h:h:h:h:h:h:h:h>

Définir l'adresse IP/IPv6 source pour la route.

set policy route-map <text> rule <1-65535> set table <1-200>

Définir les préfixes vers le tableau.

set policy route-map <text> rule <1-65535> set tag <1-65535>

Définir la valeur d'étiquette pour le protocole de routage.

set policy route-map <text> rule <1-65535> set weight <0-4294967295>

Définir l'attribut de poids BGP
