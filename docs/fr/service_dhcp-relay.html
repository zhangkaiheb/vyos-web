Relai DHCP

Un agent de relai DHCP permet à un seul serveur DHCP de servir des clients sur des sous-réseaux distants, éliminant ainsi le besoin d'un serveur séparé sur chaque sous-réseau.

L'agent de relai DHCP reçoit les demandes des clients sur une interface, les transmet en tant que unicasts vers le serveur désigné sur un autre réseau, et livre les réponses du serveur aux clients originaux.

VyOS propose deux services de relai DHCP indépendants :

  • service dhcp-relay : Relaie les messages entre les clients et les serveurs IPv4.

  • service dhcpv6-relay : Relaie les messages entre les clients et les serveurs IPv6.

Les deux services sont configurés séparément et ne partagent aucun paramètre. Sur un réseau dual-stack où les clients des deux familles d'adresses ont besoin de DHCP, configurez les deux.

Relai IPv4

Configuration

set service dhcp-relay listen-interface <interface>

Configurez une interface d'écoute sur laquelle le relai DHCPv4 reçoit les demandes de broadcast des clients.

Répétez la commande pour configurer plusieurs interfaces d'écoute.

Remarque

Au moins une listen-interface et une upstream-interface doivent être configurées pour un commit réussi.

Exemple :

set service dhcp-relay listen-interface eth1
set service dhcp-relay upstream-interface <interface>

Configurez une interface amont par laquelle le relai DHCPv4 transmet les demandes des clients vers le serveur DHCP.

Répétez la commande pour configurer plusieurs interfaces amont.

Note

Au moins une listen-interface et une upstream-interface doivent être configurées pour un commit réussi.

Exemple :

set service dhcp-relay upstream-interface eth2
set service dhcp-relay server <ipv4-address>

Configurez l'adresse IPv4 d'un serveur DHCPv4 vers lequel le relai transmet les demandes des clients.

Répétez la commande pour transmettre les demandes des clients vers plusieurs serveurs DHCPv4.

Note

Au moins un serveur DHCPv4 doit être configuré pour un commit réussi.

Exemple :

set service dhcp-relay server 203.0.113.4
set service dhcp-relay interface <interface>

Configurez une interface qui participe au relai DHCPv4.

Les interfaces configurées avec cette commande héritée fonctionnent bidirectionnellement, recevant les broadcasts DHCPv4 clients et transmettant les demandes vers le serveur.

Avertissement

Cette commande est obsolète et reste disponible uniquement pour soutenir les configurations existantes. Les nouveaux déploiements devraient utiliser listen-interface et upstream-interface, qui ne peuvent pas être combinés avec cette commande. Un avertissement d'obsolescence apparaît lors du commit.

Note

L'interface loopback (lo) n'est pas acceptée comme valeur valide pour cette commande.

Exemple :

set service dhcp-relay interface eth1
set service dhcp-relay interface eth2
set service dhcp-relay disable

Désactivez administrativement le service de relai DHCPv4 sans supprimer sa configuration.

Exemple :

set service dhcp-relay disable

Options de relai

set service dhcp-relay relay-options hop-count <1-255>

Configurez le nombre de sauts DHCPv4 à partir duquel les paquets relais sont supprimés.

Un relai DHCPv4 qui reçoit un message client définit le nombre de sauts à 0. Chaque relai DHCPv4 suivant le long du chemin du paquet l'augmente. Les paquets dont le nombre de sauts a atteint la valeur spécifiée sont silencieusement supprimés.

La valeur par défaut est 10.

Exemple :

set service dhcp-relay relay-options hop-count 4
set service dhcp-relay relay-options max-size <64-1400>

Configurez la taille maximale, en octets, qu'un paquet DHCPv4 peut atteindre avec l'option Informations du Relai Ajouté.

Si le paquet avec l'option ajoutée dépasse cette taille, l'option est omise et le paquet est transmis sans elle.

La valeur par défaut est 576.

Exemple :

set service dhcp-relay relay-options max-size 1400
set service dhcp-relay relay-options relay-agents-packets <append | discard | forward | replace>

Configurez la politique appliquée aux paquets DHCPv4 entrants qui portent déjà une option Informations du Relai :

  • append : Ajoute l'option Informations du Relai local tout en préservant l'option Informations du Relai existante.

  • discard : Supprime les paquets portant une option Informations du Relai.

  • forward : Transmet les paquets avec leur option Informations du Relai existante inchangée.

  • replace : Supprime l'option Informations du Relai existante et insère l'option Informations du Relai local.

La valeur par défaut est forward.

Exemple :

set service dhcp-relay relay-options relay-agents-packets discard

Fonctionnement

restart dhcp relay-agent

Redémarrez le service de relai DHCPv4.

Exemple

La configuration suivante redirige les demandes de client DHCP reçues sur eth1 (l'interface client) via eth2 (l'interface serveur) vers un serveur DHCP à 203.0.113.4. Les paquets qui contiennent déjà des Informations du Relai sont supprimés, afin que seules les demandes originales provenant directement des clients soient transmises.

set interfaces ethernet eth1 address '192.0.2.1/24'
set interfaces ethernet eth2 address '198.51.100.1/24'
set service dhcp-relay listen-interface 'eth1'
set service dhcp-relay upstream-interface 'eth2'
set service dhcp-relay server '203.0.113.4'
set service dhcp-relay relay-options relay-agents-packets discard

La configuration équivalente utilisant la syntaxe dépréciée interface, conservée uniquement pour la compatibilité descendante, est :

set interfaces ethernet eth1 address '192.0.2.1/24'
set interfaces ethernet eth2 address '198.51.100.1/24'
set service dhcp-relay interface 'eth1'
set service dhcp-relay interface 'eth2'
set service dhcp-relay server '203.0.113.4'
set service dhcp-relay relay-options relay-agents-packets discard

Relai IPv6

Configuration

set service dhcpv6-relay listen-interface <interface>

Configurez une interface d'écoute sur laquelle le relai DHCPv6 reçoit les demandes multicast des clients.

L'interface doit déjà avoir une adresse IPv6 unicast globale assignée.

Répétez la commande pour configurer plusieurs interfaces d'écoute.

Note

Au moins une listen-interface et une upstream-interface doivent être configurées pour un commit réussi.

Exemple :

set service dhcpv6-relay listen-interface eth1
set service dhcpv6-relay listen-interface <interface> address <ipv6-address>

Configurez l'adresse IPv6 que le relai DHCPv6 utilise pour identifier le réseau client au serveur DHCPv6.

L'adresse doit être une adresse IPv6 non link-local déjà assignée à l'interface d'écoute spécifiée.

Si l'adresse n'est pas définie, le relai DHCPv6 utilise la première adresse IPv6 non link-local trouvée sur cette interface d'écoute.

Exemple :

set service dhcpv6-relay listen-interface eth1 address 2001:db8:1::1
set service dhcpv6-relay upstream-interface <interface> address <ipv6-address>

Configurez l'adresse IPv6 d'un serveur DHCPv6 (ou d'un autre relai) vers lequel le relai DHCPv6 transmet les messages des clients via l'interface amont spécifiée.

Répétez la commande pour transmettre les messages des clients vers plusieurs serveurs (ou relais).

Note

Au moins une adresse de serveur (ou de relai) doit être configurée pour chaque interface amont pour un commit réussi.

Exemple :

set service dhcpv6-relay upstream-interface eth2 address 2001:db8:2::4
set service dhcpv6-relay disable

Désactivez administrativement le service de relai DHCPv6 sans supprimer sa configuration.

Exemple :

set service dhcpv6-relay disable

Options de relai

set service dhcpv6-relay max-hop-count <1-255>

Configurez le nombre de sauts DHCPv6 à partir duquel les paquets relais sont supprimés.

Un relai DHCPv6 qui reçoit un message client définit le nombre de sauts à 0. Chaque relai DHCPv6 suivant le long du chemin du paquet l'augmente. Les paquets dont le nombre de sauts a atteint la valeur spécifiée sont silencieusement supprimés.

La valeur par défaut est 10.

Exemple :

set service dhcpv6-relay max-hop-count 4
set service dhcpv6-relay use-interface-id-option

Activez l'insertion de l'option ID d'interface dans chaque message Relay-forward.

L'option ID d'interface est insérée automatiquement chaque fois qu'il y a plus d'une interface d'écoute configurée sur un relai, indépendamment de cette configuration.

Exemple :

set service dhcpv6-relay use-interface-id-option

Fonctionnement

restart dhcpv6 relay-agent

Redémarrez le service de relai DHCPv6.

Exemple

La configuration suivante redirige les demandes de client DHCPv6 reçues sur eth1 (l'interface client) via eth2 (l'interface serveur) vers un serveur DHCPv6 à 2001:db8:2::4.

set interfaces ethernet eth1 address '2001:db8:1::1/64'
set interfaces ethernet eth2 address '2001:db8:2::1/64'
set service dhcpv6-relay listen-interface 'eth1'
set service dhcpv6-relay upstream-interface 'eth2' address '2001:db8:2::4'
