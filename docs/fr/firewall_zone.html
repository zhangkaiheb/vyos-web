Firewall basé sur les zones

Aperçu

Remarque

Toutes les versions de VyOS construites après le 22 octobre 2023 (VyOS 1.4 et 1.5) prennent en charge cette fonctionnalité.

Cette section fournit des informations sur la configuration du pare-feu pour le pare-feu basé sur les zones. Cette section couvre les commandes de configuration suivantes :

set firewall zone …

Pour en savoir plus sur le flux général du trafic dans les pare-feux VyOS, voir Pare-feu.

- set firewall
    * zone
         - custom_zone_name
            + ...

Dans une politique basée sur les zones, vous attribuez des interfaces aux zones et appliquez une politique d'inspection au trafic se déplaçant entre les zones. Le pare-feu agit sur le trafic selon les règles. Une zone est un groupe d'interfaces ayant des fonctions ou des caractéristiques similaires. Elle établit les frontières de sécurité d'un réseau. Une zone définit une limite où le système soumet le trafic à des restrictions de politique lorsqu'il traverse vers une autre région du réseau.

Points clés :

  • Une zone doit être configurée avant d'attribuer une interface à celle-ci, et vous ne pouvez attribuer une interface qu'à une seule zone.

  • Tout le trafic entrant et sortant d'une interface au sein d'une zone circule librement.

  • Les politiques existantes affectent tout le trafic entre les zones.

  • Le trafic ne peut pas circuler entre une interface membre d'une zone et toute interface qui n'est pas membre d'une zone.

  • Vous devez définir 2 pare-feux distincts pour définir le trafic : un pour chaque direction.

Note

Dans T2199, la syntaxe de la configuration de la zone a été modifiée. La configuration de la zone a été passée de zone-policy zone <name> à firewall zone <name>.

Configuration

En tant qu'alternative à l'application de la politique à une interface directement, vous pouvez créer un pare-feu basé sur les zones pour simplifier la configuration lorsqu'il y a plusieurs interfaces appartenant à la même zone de sécurité. Au lieu d'appliquer des jeux de règles aux interfaces, vous les appliquez aux paires source-destination de zones.

Vous trouverez une introduction de base aux pare-feux basés sur les zones dans la Base de connaissances VyOS, et un exemple à Exemple de politique de zone.

Les étapes suivantes sont nécessaires pour créer un pare-feu basé sur les zones :

  1. Définir à la fois les zones source et destination

  2. Définir le jeu de règles

  3. Appliquer le jeu de règles aux zones

Définir une zone

Pour définir une zone, configurez soit une avec des interfaces, soit comme la zone locale.

set firewall zone <name> interface <interface>

Attribuez des interfaces en tant que membre d'une zone.

Note

  • Une interface ne peut être membre qu'une seule zone.

  • Vous pouvez avoir plusieurs interfaces dans une zone. Le trafic entre les interfaces de la même zone suit la politique de filtrage inter-zone (autorisée par défaut).

set firewall zone <name> local-zone

Définissez la zone comme la zone locale pour le trafic provenant ou destiné à la propre passerelle.

Note

  • Une zone locale ne peut pas avoir d'interfaces membres

  • Vous ne pouvez pas avoir plusieurs zones locales

set firewall zone <name> default-action [drop | reject]

Modifiez l'action par défaut de la zone, qui s'applique au trafic destiné à cette zone qui ne correspond à aucun des jeux de règles source appliqués.

set firewall zone <name> default-log

Activez la journalisation des paquets correspondant à l'action par défaut de cette zone (désactivée par défaut).

set firewall zone <name> description

Ajoutez une description pertinente.

Définition d'un jeu de règles

Les jeux de règles du pare-feu basé sur les zones définissent le trafic provenant d'une zone source vers une zone de destination.

Vous créez des jeux de règles en tant que chaîne de pare-feu personnalisée en utilisant les commandes ci-dessous (référez-vous aux sections IPv4/IPv6 du pare-feu pour la syntaxe complète) :

  • Pour IPv4 : set firewall ipv4 name <name> ...

  • Pour IPv6 : set firewall ipv6 name <name> ...

Il est utile de nommer les jeux de règles au format <Source Zone>-<Destination Zone>-<v4 | v6> pour les rendre facilement identifiables.

Application d'un jeu de règles à une zone

Après avoir défini un jeu de règles, appliquez-le aux zones source et destination. La syntaxe de configuration s'ancrée à la zone de destination, avec chaque jeu de règles source listé contre la destination.

set firewall zone <Destination Zone> from <Source Zone> firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> from <Source Zone> firewall ipv6-name <ipv6-rule-set-name>

Vous devriez créer deux jeux de règles pour chaque paire de zones source-destination.

set firewall zone DMZ from LAN firewall name LAN-DMZ-v4
set firewall zone LAN from DMZ firewall name DMZ-LAN-v4

Application d'un jeu de règles par défaut à une zone

Lorsqu'une zone de destination partage un jeu de règles commun pour plusieurs zones sources, ou lorsque vous avez besoin d'un ensemble complexe de politiques par défaut, vous pouvez appliquer un jeu de règles par défaut optionnel. Le jeu de règles par défaut s'applique à toutes les zones qui ne disposent pas d'un jeu de règles configuré tel que défini dans IPv4

set firewall zone <Destination Zone> default-firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> default-firewall ipv6-name <ipv6-rule-set-name>

Mode d'opération

show firewall zone-policy

Affiche un résumé de base de la configuration de la zone.

vyos@vyos:~$ show firewall zone-policy
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LAN     eth1          WAN          WAN-LAN-v4
eth2
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
show firewall zone-policy zone <zone>

Affiche un résumé de base d'une zone particulière.

vyos@vyos:~$ show firewall zone-policy zone WAN
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
vyos@vyos:~$ show firewall zone-policy zone LOCAL
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
