Loopback

Интерфейс loopback — это виртуальный, программный сетевой интерфейс. Все трафик, отправленный на него, возвращается и направлен только на службы локальной машины.

Примечание

В одной операционной системе разрешено использовать только один интерфейс lo. Если вам нужны несколько виртуальных интерфейсов, используйте тип интерфейса Dummy.

Конфигурация

Общая конфигурация интерфейса

set interfaces loopback <interface> address <address>

Настройте одно или несколько IP-адресов интерфейса.

<address> поддерживает IPv4 и IPv6 в формате CIDR. Например, используйте 192.0.2.1/24 для IPv4 или 2001:db8::1/64 для IPv6.

Пример:

set interfaces loopback lo address 192.0.2.1/24
set interfaces loopback lo address 2001:db8::1/64
set interfaces loopback <interface> description <description>

Настройте понятное, описательное имя интерфейса.

Это имя появляется в команде show interfaces и в средствах мониторинга на основе SNMP.

Пример:

set interfaces loopback lo description 'This is an interface running on VyOS.'

Работа

show interfaces loopback

Показать краткую информацию об интерфейсе.

vyos@vyos:~$ show interfaces loopback
Codes: S - State, L - Link, u - Up, D - Down, A - Admin Down
Interface        IP Address                        S/L  Description
---------        ----------                        ---  -----------
lo               127.0.0.1/8                       u/u
                 ::1/128
show interfaces loopback lo

Показать подробную информацию об интерфейсе.
