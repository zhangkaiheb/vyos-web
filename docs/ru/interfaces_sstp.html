SSTP клиент

SSTP передает трафик PPP через канал SSL/TLS, обеспечивая защиту на уровне транспорта за счет обмена ключами, шифрования и проверки целостности трафика. Использование SSL/TLS через порт TCP 443 (по умолчанию, порт можно изменить) позволяет SSTP проходить практически через все брандмауэры и прокси-серверы, за исключением аутентифицированных веб-прокси.

Примечание

VyOS включает встроенный сервер SSTP. Для получения дополнительной информации см. Сервер SSTP.

Конфигурация

Общая конфигурация интерфейса

set interfaces sstpc <interface> description <description>

Настройте понятное описание для интерфейса.

Это описание появляется в команде show interfaces и инструментах мониторинга на основе SNMP.

Пример:

set interfaces sstpc sstpc0 description 'This is an interface running on VyOS.'
set interfaces sstpc <interface> disable

Отключите интерфейс.

Интерфейс будет установлен в состояние административно выключен (A/D).

Пример:

set interfaces sstpc sstpc0 disable
set interfaces sstpc <interface> mtu <mtu>

Настройте MTU на интерфейсе.

Это значение определяет максимальный размер пакета, в байтах, который интерфейс передает без фрагментации.

Пример:

set interfaces sstpc sstpc0 mtu 1600
set interfaces sstpc <interface> vrf <vrf>

Назначьте интерфейс конкретному экземпляру VRF .

См. также

Для информации о настройке VRF обратитесь к разделу VRF.

Пример:

set interfaces sstpc sstpc0 vrf red

Параметры клиента SSTP

set interfaces sstpc <interface> no-default-route

Запросите IP-адрес от сервера SSTP без установки маршрута по умолчанию.

Пример:

set interfaces sstpc sstpc0 no-default-route

Примечание

Введено в VyOS 1.4, эта команда меняет логику предыдущего параметра CLI default-route.

set interfaces sstpc <interface> default-route-distance <distance>

Настройте расстояние для маршрута по умолчанию, предоставляемого сервером SSTP.

Пример:

set interfaces sstpc sstpc0 default-route-distance 220
set interfaces sstpc <interface> no-peer-dns

Отключите установку объявленных DNS-серверов на локальной системе.

set interfaces sstpc <interface> server <address>

Настройте адрес удаленного сервера SSTP для подключения клиента.

Адрес может быть либо IP-адресом, либо FQDN.

set interfaces sstpc <interface> ip adjust-mss <mss | clamp-mss-to-pmtu>

Настройте MSS , объявляемый в исходящих пакетах TCP SYN на указанном интерфейсе.

При ограничении значения MSS в пакетах TCP SYN вы указываете удаленной стороне не отправлять пакеты большего размера, чем указано. Это помогает избежать проблем с соединением, если PMTUD не работает.

Доступны следующие варианты:

  • mss: Устанавливает MSS в конкретное значение в байтах.

  • clamp-mss-to-pmtu: Устанавливает MSS в размер MTU интерфейса минус 40 байт для трафика IPv4 (20 байт для заголовка IPv4 и 20 байт для заголовка TCP). Этот вариант рекомендуется для автоматической установки правильного значения.

Примечание

Введено в VyOS 1.4, эта команда заменяет более старую синтаксическую конструкцию set firewall options interface <name> adjust-mss <value>.

set interfaces sstpc <interface> ip disable-forwarding

Настройте интерфейс на работу в режиме хоста или роутера.

Если настроен, интерфейс переключается в режим хоста, и IPv4-пересылка отключается на нем.

set interfaces sstpc <interface> ip source-validation <strict | loose | disable>

Настройте проверку исходного IP-адреса с использованием RPF на этом интерфейсе, как указано в RFC 3704.

Доступны следующие варианты:

  • strict: Каждый входящий пакет проверяется на соответствие FIB. Если интерфейс не является лучшим маршрутом обратно к этому источнику, проверка завершается неудачей, и пакет удаляется.

  • loose: Каждый входящий пакет проверяется на соответствие FIB. Если исходный IP-адрес недоступен через любой интерфейс, проверка завершается неудачей.

  • disable: Проверка исходного IP-адреса не выполняется. Все входящие пакеты принимаются.

RFC 3704 рекомендует включить режим strict, чтобы предотвратить спуфинг IP-адресов, например, DDoS-атаки. Для асимметричных или других сложных сценариев маршрутизации используйте режим loose.

Подключение/отключение

disconnect interface <interface>

Отключить указанный интерфейс.

connect interface <interface>

Инициировать сессию на указанном интерфейсе.
