L2TP

VyOS использует accel-ppp, чтобы предоставить функции сервера L2TP. Он может использоваться с локальной аутентификацией или подключенным сервером RADIUS.

Настройка сервера L2TP

set vpn l2tp remote-access authentication mode local
set vpn l2tp remote-access authentication local-users username test password 'test'
set vpn l2tp remote-access client-ip-pool L2TP-POOL range 192.168.255.2-192.168.255.254
set vpn l2tp remote-access default-pool 'L2TP-POOL'
set vpn l2tp remote-access outside-address 192.0.2.2
set vpn l2tp remote-access gateway-address 192.168.255.1
set vpn l2tp remote-access authentication mode <local | radius>

Установите систему аутентификации. Настроенный механизм аутентификации используется для всех запросов.

  • radius: Все запросы аутентификации обрабатываются конфигурированным сервером RADIUS.

  • local: Все запросы аутентификации обрабатываются локально.

set vpn l2tp remote-access authentication local-users username <user> password <pass>

Создайте <user> для локальной аутентификации на этом компьютере. Пароль пользователя будет установлен на <pass>.

set vpn l2tp remote-access client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Используйте эту команду, чтобы определить первый IP-адрес пула адресов, которые будут предоставлены клиентам L2TP. Если используется обозначение x.x.x.x-x.x.x.x, он должен находиться в подсети /24. Если используется обозначение x.x.x.x/x, возможно установить хост/сетевой маску.

set vpn l2tp remote-access default-pool <POOL-NAME>

Используйте эту команду, чтобы определить имя пула адресов по умолчанию.

set vpn l2tp remote-access gateway-address <gateway>

Указывает единственный <gateway> IP-адрес, который будет использоваться как локальный адрес интерфейсов PPP.

Настройка IPsec

set vpn ipsec interface eth0
set vpn l2tp remote-access ipsec-settings authentication mode pre-shared-secret
set vpn l2tp remote-access ipsec-settings authentication pre-shared-secret secret
set vpn ipsec interface <INTERFACE>

Используйте эту команду, чтобы определить интерфейс IPsec.

set vpn l2tp remote-access ipsec-settings authentication mode <pre-shared-secret | x509>

Установите режим аутентификации IPsec между VyOS и клиентами L2TP.

set vpn l2tp remote-access ipsec-settings authentication pre-shared-secret <secret>

Установите предопределенную общую секретную фразу.

Если на вашем внешнем интерфейсе есть политика локального брандмауэра, вам нужно разрешить следующие порты:

  • UDP порт 500 (IKE)

  • Номер протокола IP 50 (ESP)

  • UDP порт 1701 для IPsec

Также необходимо разрешить следующее, чтобы позволить NAT-проход (когда NAT обнаруживается клиентом VPN, ESP инкапсулируется в UDP для NAT-прохода):

  • UDP порт 4500 (NAT-T)

Пример:

set firewall ipv4 name OUTSIDE-LOCAL rule 40 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 40 protocol 'esp'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 destination port '500'
set firewall ipv4 name OUTSIDE-LOCAL rule 41 protocol 'udp'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 destination port '4500'
set firewall ipv4 name OUTSIDE-LOCAL rule 42 protocol 'udp'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 action 'accept'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 destination port '1701'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 ipsec 'match-ipsec'
set firewall ipv4 name OUTSIDE-LOCAL rule 43 protocol 'udp'

Чтобы разрешить доступ к клиентам VPN через ваш внешний адрес, требуется правило NAT:

set nat source rule 110 outbound-interface name 'eth0'
set nat source rule 110 source address '192.168.255.0/24'
set nat source rule 110 translation address masquerade

Настройка аутентификации RADIUS

Для включения аутентификации на основе RADIUS, режим аутентификации должен быть изменен в конфигурации. Предыдущие настройки, такие как локальные пользователи, все еще существуют в конфигурации, однако они не используются, если режим был изменен с локального на RADIUS. После изменения обратно на локальный, он снова будет использовать все локальные учетные записи.

set vpn l2tp remote-access authentication mode radius
set vpn l2tp remote-access authentication radius server <server> key <secret>

Настройте RADIUS <server> и его необходимый общий <secret> для обмена данными с сервером RADIUS.

Поскольку сервер RADIUS является единственной точкой отказа, можно настроить несколько серверов RADIUS, которые будут использоваться последовательно. Например:

set vpn l2tp remote-access authentication radius server 10.0.0.1 key 'foo'
set vpn l2tp remote-access authentication radius server 10.0.0.2 key 'foo'

Примечание

Некоторые серверы RADIUS используют список контроля доступа, который разрешает или запрещает запросы, убедитесь, что добавили ваш маршрутизатор VyOS в список разрешенных клиентов.

IP-адрес источника RADIUS

Если вы используете OSPF в качестве вашего IGP, используйте интерфейс, наиболее близкий к серверу RADIUS. Вы можете привязать все исходящие запросы RADIUS к одному исходному IP-адресу, например, к интерфейсу loopback.

set vpn l2tp remote-access authentication radius source-address <address>

Исходный IPv4-адрес, используемый во всех запросах к серверу RADIUS.

Примечание

Параметр source-address должен быть настроен на IP-адрес интерфейса. Лучшей практикой будет использование loopback или dummy интерфейса.

Дополнительные параметры RADIUS

set vpn l2tp remote-access authentication radius server <server> port <port>

Настройте RADIUS <server> и его необходимый порт для запросов аутентификации.

set vpn l2tp remote-access authentication radius server <server> fail-time <time>

Пометьте сервер RADIUS как недоступный на заданное количество <time> секунд.

set vpn l2tp remote-access authentication radius server <server> disable

Временно отключите этот сервер RADIUS.

set vpn l2tp remote-access authentication radius acct-timeout <timeout>

Время ожидания ответа для пакетов Interim-Update. (по умолчанию 3 секунды)

set vpn l2tp remote-access authentication radius dynamic-author server <address>

Указывает IP-адрес сервера расширения динамической авторизации (DM/CoA). Этот IP-адрес должен существовать на любом интерфейсе VyOS или может быть 0.0.0.0.

set vpn l2tp remote-access authentication radius dynamic-author port <port>

UDP-порт для сервера расширения динамической авторизации (DM/CoA)

set vpn l2tp remote-access authentication radius dynamic-author key <secret>

Секрет для сервера расширения динамической авторизации (DM/CoA)

set vpn l2tp remote-access authentication radius max-try <number>

Максимальное количество попыток отправить запросы Access-Request/Accounting-Request

set vpn l2tp remote-access authentication radius timeout <timeout>

Время ожидания ответа от сервера (секунды)

set vpn l2tp remote-access authentication radius nas-identifier <identifier>

Значение, отправляемое серверу RADIUS в атрибуте NAS-Identifier и совпадающее в запросах DM/CoA.

set vpn l2tp remote-access authentication radius nas-ip-address <address>

Значение, отправляемое серверу RADIUS в атрибуте NAS-IP-Address и совпадающее в запросах DM/CoA. Также сервер DM/CoA будет привязан к этому адресу.

set vpn l2tp remote-access authentication radius source-address <address>

Исходный IPv4-адрес, используемый во всех запросах к серверу RADIUS.

set vpn l2tp remote-access authentication radius rate-limit attribute <attribute>

Указывает, какой атрибут сервера RADIUS содержит информацию о ограничении скорости. По умолчанию атрибут — Filter-Id.

Примечание

Если вы установите пользовательский атрибут RADIUS, вы должны определить его на обоих словарях на сервере RADIUS и клиенте.

set vpn l2tp remote-access authentication radius rate-limit enable

Включает регулирование пропускной способности через RADIUS.

set vpn l2tp remote-access authentication radius rate-limit vendor

Указывает словарь производителя. Этот словарь должен присутствовать в /usr/share/accel-ppp/radius.

Полученные атрибуты RADIUS имеют более высокий приоритет, чем параметры, определенные в конфигурации CLI, см. объяснение ниже.

Выделение IP-адресов клиентам через RADIUS

Если сервер RADIUS отправляет атрибут Framed-IP-Address, то этот IP-адрес будет выделен клиенту, и параметр default-pool в конфигурации CLI будет проигнорирован.

Если сервер RADIUS отправляет атрибут Framed-Pool, то IP-адрес будет выделен из заранее определенного пула IP-адресов, имя которого равно значению атрибута.

Если сервер RADIUS отправляет атрибут Stateful-IPv6-Address-Pool, то IPv6-адрес будет выделен из заранее определенного пула IPv6 prefix, имя которого равно значению атрибута.

Если сервер RADIUS отправляет атрибут Delegated-IPv6-Prefix-Pool, то префикс делегирования IPv6 будет выделен из заранее определенного пула IPv6 delegate, имя которого равно значению атрибута.

Примечание

Stateful-IPv6-Address-Pool и Delegated-IPv6-Prefix-Pool определены в RFC6911. Если они не определены на вашем сервере RADIUS, добавьте новый словарь.

Интерфейс клиента может быть помещен в контекст VRF через пакет Access-Accept RADIUS, или изменен через RADIUS CoA. Accel-VRF-Name используется для этих целей. Это является пользовательским атрибутом ACCEL-PPP. Определите его на вашем сервере RADIUS.

Переименование интерфейсов клиентов через RADIUS

Если сервер RADIUS использует атрибут NAS-Port-Id, то туннели ppp будут переименованы.

Примечание

Значение атрибута NAS-Port-Id должно быть меньше 16 символов, иначе интерфейс не будет переименован.

set vpn l2tp remote-access lns host-name <hostname>

set vpn l2tp remote-access lns shared-secret <secret>

IPv6

set vpn l2tp remote-access ppp-options ipv6 <require | prefer | allow | deny>

Указывает предпочтение согласования IPv6.

  • require - Требуется согласование IPv6

  • prefer - Запросить клиента о согласовании IPv6, не завершать, если он отклоняет

  • allow - Согласование IPv6 только если клиент запрашивает (значение по умолчанию)

  • deny - Не согласовывать IPv6 (значение по умолчанию)

set vpn l2tp remote-access client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Используйте эту команду, чтобы установить пул IPv6, из которого клиент L2TP получит префикс IPv6 заданной длины (маски), чтобы завершить точку подключения L2TP на их стороне. Длина маски может быть установлена между 48 и 128 битами, значение по умолчанию — 64.

set vpn l2tp remote-access client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Используйте эту команду, чтобы настроить делегирование префикса DHCPv6 (RFC3633) на L2TP. Вам нужно будет установить ваш пул IPv6 и длину префикса делегирования. Из определенного пула IPv6 вы будете выдавать сети заданной длины (префикс делегирования). Длина префикса делегирования может быть установлена между 32 и 64 битами.

set vpn l2tp remote-access default-ipv6-pool <IPv6-POOL-NAME>

Используйте эту команду, чтобы определить имя пула IPv6 по умолчанию.

set vpn l2tp remote-access ppp-options ipv6 allow
set vpn l2tp remote-access client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn l2tp remote-access client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn l2tp remote-access default-ipv6-pool IPv6-POOL

Дополнительные параметры IPv6

set vpn l2tp remote-access ppp-options ipv6-accept-peer-interface-id

Принять идентификатор интерфейса партнера. По умолчанию это не определено.

set vpn l2tp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Определяет, используется ли фиксированный или случайный идентификатор интерфейса для IPv6. По умолчанию используется фиксированный.

  • random - Случайный идентификатор интерфейса для IPv6

  • x:x:x:x - Указать идентификатор интерфейса для IPv6

set vpn l2tp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Определяет идентификатор интерфейса партнера для IPv6. По умолчанию используется фиксированный.

  • random - Случайный идентификатор интерфейса для IPv6

  • x:x:x:x - Указать идентификатор интерфейса для IPv6

  • ipv4-addr - Вычислить идентификатор интерфейса из IPv4-адреса.

  • calling-sid - Вычислить идентификатор интерфейса из вызывающего станционного идентификатора.

Требуется, чтобы абонент аутентифицировался, используя один из следующих протоколов: pap, chap, mschap, mschap-v2.

Дополнительные параметры PPP

set vpn l2tp remote-access ppp-options disable-ccp

Отключить протокол управления сжатием (CCP). CCP включен по умолчанию.

set vpn l2tp remote-access ppp-options interface-cache <number>

Определяет количество интерфейсов, которые будут кэшироваться. Это предотвращает удаление интерфейсов после уничтожения соответствующей сессии. Вместо этого интерфейсы будут кэшироваться для использования в новых сессиях. Это должно снизить частоту создания/удаления интерфейсов на уровне ядра. Значение по умолчанию — 0.

set vpn l2tp remote-access ppp-options ipv4 <require | prefer | allow | deny>

Указывает предпочтение согласования IPv4.

  • require - Требуется согласование IPv4

  • prefer - Запросить клиента о согласовании IPv4, не завершать, если он отклоняет

  • allow - Согласование IPv4 только если клиент запрашивает (значение по умолчанию)

  • deny - Не согласовывать IPv4

set vpn l2tp remote-access ppp-options lcp-echo-failure <number>

Определяет максимальное количество <number> неподтвержденных эхо-запросов. При достижении значения <number>, сессия будет перезапущена. Значение по умолчанию — 3.

set vpn l2tp remote-access ppp-options lcp-echo-interval <interval>

Если эта опция указана и больше 0, то модуль PPP будет отправлять запросы LCP echo каждые <interval> секунд. Значение по умолчанию — 30.

set vpn l2tp remote-access ppp-options lcp-echo-timeout

Указывает время ожидания в секундах для любого активного действия партнера. Если эта опция указана, она включает адаптивную функцию эха LCP и «lcp-echo-failure» не используется. Значение по умолчанию — 0.

set vpn l2tp remote-access ppp-options min-mtu <number>

Определяет минимально допустимый MTU. Если клиент пытается согласовать MTU меньше этого, он будет NAKed, и отключен, если он отклоняет больший MTU. Значение по умолчанию — 100.

set vpn l2tp remote-access ppp-options mppe <require | prefer | deny>

Указывает предпочтение согласования MPPE.

  • require - запросить клиента о mppe, если он отклоняет, завершить соединение

  • prefer - запросить клиента о mppe, если он отклоняет, не завершать. (Значение по умолчанию)

  • deny - запретить mppe

Поведение по умолчанию — не запрашивать клиента о mppe, но разрешить, если клиент хочет. Обратите внимание, что RADIUS может переопределить этот параметр с помощью атрибута MS-MPPE-Encryption-Policy.

set vpn l2tp remote-access ppp-options mru <number>

Определяет предпочитаемый MRU. По умолчанию не определено.
