Ограждение на основе зон

Обзор

Примечание

Все версии VyOS, созданные после 2023-10-22 (VyOS 1.4 и 1.5), поддерживают эту функцию.

Этот раздел предоставляет информацию о настройке брандмауэра для ограждения на основе зон. Этот раздел охватывает следующие команды конфигурации:

set firewall zone …

Чтобы узнать о общем потоке трафика в брандмауэрах VyOS, см. Брандмауэр.

- set firewall
    * zone
         - custom_zone_name
            + ...

В политике на основе зоны вы присваиваете интерфейсы зонам и применяете политику проверки трафика, движущегося между зонами. Брандмауэр действует на трафик в соответствии с правилами. Зона — это группа интерфейсов, имеющих похожие функции или особенности. Она устанавливает границы безопасности сети. Зона определяет границу, где система подвергает трафик политике ограничений при пересечении другой области сети.

Основные моменты:

  • Зона должна быть настроена до того, как вы присвоите интерфейс ей, и вы можете присвоить интерфейс только одной зоне.

  • Все трафик к и от интерфейса внутри зоны свободно проходит.

  • Существующие политики влияют на весь трафик между зонами.

  • Трафик не может проходить между интерфейсом-членом зоны и любым интерфейсом, который не является членом зоны.

  • Вы должны определить 2 отдельных брандмауэра, чтобы определить трафик: один для каждого направления.

Примечание

В T2199 синтаксис конфигурации зоны был изменен. Конфигурация зоны была перемещена из zone-policy zone <name> в firewall zone <name>.

Конфигурация

Вместо применения политики напрямую к интерфейсу, вы можете создать брандмауэр на основе зон, чтобы упростить настройку, когда несколько интерфейсов принадлежат одной и той же зоне безопасности. Вместо применения наборов правил к интерфейсам, вы применяете их к парам источника-назначения зон.

Вы можете найти основное введение в брандмауэры на основе зон в Базе знаний VyOS, и пример в Примере политики зоны.

Следующие шаги необходимы для создания брандмауэра на основе зон:

  1. Определите как исходную, так и целевую зону

  2. Определите набор правил

  3. Примените набор правил к зонам

Определение зоны

Чтобы определить зону, установите либо одну с интерфейсами, либо локальную зону.

set firewall zone <name> interface <interface>

Назначьте интерфейсы как членов зоны.

Примечание

  • Интерфейс может быть членом только одной зоны.

  • Вы можете иметь несколько интерфейсов в зоне. Трафик между интерфейсами в одной и той же зоне следует политике внутренней фильтрации (разрешено по умолчанию).

set firewall zone <name> local-zone

Определите зону как локальную зону для трафика, который исходит из маршрутизатора или предназначен для него.

Примечание

  • Локальная зона не может иметь никаких членов интерфейсов

  • Вы не можете иметь несколько локальных зон

set firewall zone <name> default-action [drop | reject]

Измените действие по умолчанию для зоны, которое применяется к трафику, направленному в эту зону, который не соответствует ни одному из правил, примененных к исходной зоне.

set firewall zone <name> default-log

Включите логирование пакетов, соответствующих действию по умолчанию этой зоны (по умолчанию отключено).

set firewall zone <name> description

Добавьте значимое описание.

Определение набора правил

Наборы правил брандмауэра на основе зон определяют трафик от Исходной зоны до Целевой зоны.

Вы создаете наборы правил как пользовательскую цепочку брандмауэра, используя команды ниже (обратитесь к разделам брандмауэра IPv4/IPv6 для полного синтаксиса):

  • Для IPv4: set firewall ipv4 name <name> ...

  • Для IPv6: set firewall ipv6 name <name> ...

Полезно называть наборы правил в формате <Исходная зона>-<Целевая зона>-<v4 | v6>, чтобы легко их идентифицировать.

Применение набора правил к зоне

После определения набора правил, примените его к исходной и целевой зонам. Синтаксис конфигурации привязывается к целевой зоне, с каждым из исходных наборов правил, перечисленных против целевой.

set firewall zone <Destination Zone> from <Source Zone> firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> from <Source Zone> firewall ipv6-name <ipv6-rule-set-name>

Вы должны создать два набора правил для каждой пары исходной-целевой зоны.

set firewall zone DMZ from LAN firewall name LAN-DMZ-v4
set firewall zone LAN from DMZ firewall name DMZ-LAN-v4

Применение набора правил по умолчанию к зоне

Когда целевая зона имеет общий набор правил для нескольких исходных зон, или когда вам требуется сложный набор правил по умолчанию, вы можете применить опциональный набор правил по умолчанию. Набор правил по умолчанию применяется ко всем зонам, которые не имеют набора правил, определенного в IPv4

set firewall zone <Destination Zone> default-firewall name <ipv4-rule-set-name>
set firewall zone <Destination Zone> default-firewall ipv6-name <ipv6-rule-set-name>

Режим работы

show firewall zone-policy

Показать краткое резюме конфигурации зоны.

vyos@vyos:~$ show firewall zone-policy
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LAN     eth1          WAN          WAN-LAN-v4
eth2
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
show firewall zone-policy zone <zone>

Показать краткое резюме конкретной зоны.

vyos@vyos:~$ show firewall zone-policy zone WAN
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
WAN     eth3          LAN          LAN-WAN-v4
eth0          LOCAL        LOCAL-WAN-v4
vyos@vyos:~$ show firewall zone-policy zone LOCAL
Zone    Interfaces    From Zone    Firewall IPv4    Firewall IPv6
------  ------------  -----------  ---------------  ---------------
LOCAL   LOCAL         LAN          LAN-LOCAL-v4
WAN          WAN-LOCAL-v4     WAN-LOCAL-v6
