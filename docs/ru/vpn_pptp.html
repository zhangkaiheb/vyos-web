PPTP-сервер

Протокол туннелирования точка-точка (PPTP) был реализован в VyOS только для обеспечения обратной совместимости. У PPTP много хорошо известных проблем безопасности, и вы должны использовать один из многих новых реализаций VPN.

Настройка PPTP сервера

set vpn pptp remote-access authentication mode local
set vpn pptp remote-access authentication local-users username test password 'test'
set vpn pptp remote-access client-ip-pool PPTP-POOL range 192.168.255.2-192.168.255.254
set vpn pptp remote-access default-pool 'PPTP-POOL'
set vpn pptp remote-access outside-address 192.0.2.2
set vpn pptp remote-access gateway-address 192.168.255.1
set vpn pptp remote-access authentication mode <local | radius>

Установите систему аутентификации. Используемая система аутентификации используется для всех запросов.

  • radius: Все запросы аутентификации обрабатываются сервером RADIUS.

  • local: Все запросы аутентификации обрабатываются локально.

  • noauth: Аутентификация отключена.

set vpn pptp remote-access authentication local-users username <user> password <pass>

Создайте <user> для локальной аутентификации на этом компьютере. Пароль пользователя будет установлен на <pass>.

set vpn pptp remote-access client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Используйте эту команду для определения первого IP-адреса пула адресов, которые будут предоставлены клиентам PPTP. Если используется обозначение x.x.x.x-x.x.x.x, оно должно находиться в подсети /24. Если используется обозначение x.x.x.x/x, возможно установить хост/сетевой маску.

set vpn pptp remote-access default-pool <POOL-NAME>

Используйте эту команду для определения имени пула адресов по умолчанию.

set vpn pptp remote-access gateway-address <gateway>

Указывает единственный IP-адрес <gateway>, который будет использоваться как локальный адрес интерфейсов PPP.

Настройка аутентификации RADIUS

Для включения аутентификации на основе RADIUS необходимо изменить режим аутентификации в конфигурации. Предыдущие настройки, такие как локальные пользователи, все еще существуют в конфигурации, однако они не используются, если режим был изменен с локального на RADIUS. При возврате к локальному режиму будут использоваться все локальные учетные записи.

set vpn pptp remote-access authentication mode radius
set vpn pptp remote-access authentication radius server <server> key <secret>

Настройте RADIUS <server> и его необходимый общий <secret> для обмена сообщениями с сервером RADIUS.

Поскольку сервер RADIUS является единственной точкой отказа, можно настроить несколько серверов RADIUS, которые будут использоваться последовательно. Например:

set vpn pptp remote-access authentication radius server 10.0.0.1 key 'foo'
set vpn pptp remote-access authentication radius server 10.0.0.2 key 'foo'

Примечание

Некоторые серверы RADIUS используют список контроля доступа, разрешающий или запрещающий запросы, убедитесь, что ваш роутер VyOS добавлен в список разрешенных клиентов.

Исходный адрес RADIUS

Если вы используете OSPF как IGP, всегда используется ближайший интерфейс, подключенный к серверу RADIUS. Вы можете привязать все исходящие запросы RADIUS к одному исходному IP-адресу, например, к интерфейсу loopback.

set vpn pptp remote-access authentication radius source-address <address>

Исходный IPv4-адрес, используемый во всех запросах к серверу RADIUS.

Примечание

Некоторые серверы RADIUS используют список контроля доступа, разрешающий или запрещающий запросы, убедитесь, что ваш роутер VyOS добавлен в список разрешенных клиентов.

set vpn pptp remote-access authentication radius timeout <timeout>

Время ожидания ответа от сервера (в секундах)

set vpn pptp remote-access authentication radius nas-identifier <identifier>

Значение, отправляемое на сервер RADIUS в атрибуте NAS-Identifier и соответствующее запросам DM/CoA.

set vpn pptp remote-access authentication radius nas-ip-address <address>

Значение, отправляемое на сервер RADIUS в атрибуте NAS-IP-Address и соответствующее запросам DM/CoA. Также сервер DM/CoA будет привязан к этому адресу.

Исходный IPv4-адрес, используемый во всех запросах к серверу RADIUS.

set vpn pptp remote-access authentication radius rate-limit attribute <attribute>

Указывает, какой атрибут сервера RADIUS содержит информацию о скорости ограничения. По умолчанию используется атрибут Filter-Id.

Примечание

Если вы установили пользовательский атрибут RADIUS, вы должны определить его на обоих словарях на сервере RADIUS и клиенте.

set vpn pptp remote-access authentication radius rate-limit enable

Включает регулирование пропускной способности через RADIUS.

set vpn pptp remote-access authentication radius rate-limit vendor

Указывает словарь производителя, словарь должен находиться в /usr/share/accel-ppp/radius.

Полученные атрибуты RADIUS имеют более высокий приоритет, чем параметры, определенные в конфигурации CLI, см. объяснение ниже.

Выделение IP-адресов клиентам по RADIUS

Если сервер RADIUS отправляет атрибут Framed-IP-Address, то этот IP-адрес будет выделен клиенту, а параметр default-pool в конфигурации CLI игнорируется.

Если сервер RADIUS отправляет атрибут Framed-Pool, IP-адрес будет выделен из предопределенного пула IP-адресов, имя которого равно значению атрибута.

Если сервер RADIUS отправляет атрибут Stateful-IPv6-Address-Pool, IPv6-адрес будет выделен из предопределенного пула IPv6 prefix, имя которого равно значению атрибута.

Если сервер RADIUS отправляет атрибут Delegated-IPv6-Prefix-Pool, префикс делегирования IPv6 будет выделен из предопределенного пула IPv6 delegate, имя которого равно значению атрибута.

Примечание

Stateful-IPv6-Address-Pool и Delegated-IPv6-Prefix-Pool определены в RFC6911. Если они не определены на вашем сервере RADIUS, добавьте новый словарь.

Интерфейс пользователя может быть помещен в контекст VRF через пакет Access-Accept RADIUS, или изменен через RADIUS CoA. Accel-VRF-Name используется для этих целей. Это пользовательский атрибут ACCEL-PPP. Определите его на вашем сервере RADIUS.

Переименование интерфейсов клиентов по RADIUS

Если сервер RADIUS использует атрибут NAS-Port-Id, то туннели ppp будут переименованы.

Примечание

Значение атрибута NAS-Port-Id должно быть меньше 16 символов, иначе интерфейс не будет переименован.

IPv6

set vpn pptp remote-access ppp-options ipv6 <require | prefer | allow | deny>

Указывает предпочтение согласования IPv6.

  • require - Требуется согласование IPv6

  • prefer - Запросить клиента о согласовании IPv6, не завершать, если он отклоняет

  • allow - Согласование IPv6 только в том случае, если клиент запрашивает (значение по умолчанию)

  • deny - Не согласовывать IPv6 (значение по умолчанию)

set vpn pptp remote-access client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Используйте эту команду для установки пула IPv6, из которого клиент PPTP получит префикс IPv6 вашего определенного размера (маска), чтобы завершить точку PPTP на их стороне. Длина маски может быть установлена от 48 до 128 бит, значение по умолчанию — 64.

set vpn pptp remote-access client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Используйте эту команду для настройки передачи префикса DHCPv6 (RFC3633) на PPTP. Вам нужно установить ваш пул IPv6 и длину префикса делегирования. Из определенного пула IPv6 вы будете выдавать сети заданной длины (префикс делегирования). Длина префикса делегирования может быть установлена от 32 до 64 бит.

set vpn pptp remote-access default-ipv6-pool <IPv6-POOL-NAME>

Используйте эту команду для определения имени пула IPv6 по умолчанию.

set vpn pptp remote-access ppp-options ipv6 allow
set vpn pptp remote-access client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn pptp remote-access client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn pptp remote-access default-ipv6-pool IPv6-POOL

Дополнительные параметры IPv6

set vpn pptp remote-access ppp-options ipv6-accept-peer-interface-id

Принять идентификатор интерфейса абонента. По умолчанию не определено.

set vpn pptp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Указывает фиксированный или случайный идентификатор интерфейса IPv6. По умолчанию фиксированный.

  • random - Случайный идентификатор интерфейса IPv6

  • x:x:x:x - Указать идентификатор интерфейса IPv6

set vpn pptp remote-access ppp-options ipv6-interface-id <random | x:x:x:x>

Указывает идентификатор интерфейса абонента для IPv6. По умолчанию фиксированный.

  • random - Случайный идентификатор интерфейса IPv6

  • x:x:x:x - Указать идентификатор интерфейса IPv6

  • ipv4-addr - Вычислить идентификатор интерфейса из IPv4-адреса.

  • calling-sid - Вычислить идентификатор интерфейса из вызывающего станции-идентификатора.

Дополнительные параметры PPP

set vpn pptp remote-access ppp-options disable-ccp

Отключить протокол сжатия контроля (CCP). CCP включен по умолчанию.

set vpn pptp remote-access ppp-options interface-cache <number>

Указывает количество интерфейсов, которые следует сохранить в кэше. Это означает, что не уничтожать интерфейс после уничтожения соответствующей сессии, а поместить его в кэш и использовать его позже для повторного создания новых сессий. Это должно снизить частоту создания/удаления интерфейсов на уровне ядра. Значение по умолчанию — 0.

set vpn pptp remote-access ppp-options ipv4 <require | prefer | allow | deny>

Указывает предпочтение согласования IPv4.

  • require - Требуется согласование IPv4

  • prefer - Запросить клиента о согласовании IPv4, не завершать, если он отклоняет

  • allow - Согласование IPv4 только в том случае, если клиент запрашивает (значение по умолчанию)

  • deny - Не согласовывать IPv4

set vpn pptp remote-access ppp-options lcp-echo-failure <number>

Определяет максимальное количество <number> неотвеченных эхо-запросов. При достижении значения <number>, сессия будет сброшена. Значение по умолчанию — 3.

set vpn pptp remote-access ppp-options lcp-echo-interval <interval>

Если эта опция указана и больше 0, модуль PPP будет отправлять эхо-запросы LCP каждые <interval> секунд. Значение по умолчанию — 30.

set vpn pptp remote-access ppp-options lcp-echo-timeout

Указывает время ожидания в секундах для любого активного взаимодействия со стороны абонента. Если эта опция указана, включается адаптивная функция эхо-запроса LCP и «lcp-echo-failure» не используется. Значение по умолчанию — 0.

set vpn pptp remote-access ppp-options min-mtu <number>

Определяет минимально допустимый MTU. Если клиент попытается согласовать меньше указанного MTU, он будет NAKed или отключен, если отклоняет больший MTU. Значение по умолчанию — 100.

set vpn pptp remote-access ppp-options mppe <require | prefer | deny>

Указывает предпочтение согласования MPPE.

  • require - запросить клиента о mppe, если он отклоняет, отключить соединение

  • prefer - запросить клиента о mppe, если он отклоняет, не завершать. (значение по умолчанию)

  • deny - запретить mppe

По умолчанию — не запрашивать клиента о mppe, но разрешить, если клиент хочет. Обратите внимание, что RADIUS может перезаписать этот параметр атрибутом MS-MPPE-Encryption-Policy.

set vpn pptp remote-access ppp-options mru <number>

Определяет предпочитаемый MRU. По умолчанию не определено.
