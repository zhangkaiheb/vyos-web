Веб-прокси

Сервис прокси в VyOS основан на Squid и некоторых связанных модулях.

Squid — это кэширующий и перенаправляющий HTTP-веб-прокси. У него есть широкий спектр применения, включая ускорение веб-сервера за счет кэширования повторяющихся запросов, кэширование веб-ресурсов, DNS и других компьютерных сетевых запросов для группы людей, разделяющих ресурсы сети, а также помощь в обеспечении безопасности за счет фильтрации трафика. Хотя он в основном используется для HTTP и FTP, Squid имеет ограниченную поддержку нескольких других протоколов, включая Internet Gopher, SSL,[6] TLS и HTTPS. Squid не поддерживает протокол SOCKS.

Фильтрация URL предоставляется SquidGuard.

Конфигурация

set service webproxy append-domain <domain>

Используйте эту команду, чтобы указать имя домена, которое будет добавлено к именам доменов в URL, которые не содержат точку . домен добавляется.

Пример: если установлено значение vyos.net, а полученный URL — www/foo.html, система будет использовать сгенерированный окончательный URL www.vyos.net/foo.html.

set service webproxy append-domain vyos.net
set service webproxy cache-size <size>

Размер дискового кэша прокси можно настроить пользователем. По умолчанию размер кэша прокси составляет 100 МБ.

Единица измерения этой команды — МБ.

set service webproxy cache-size 1024
set service webproxy default-port <port>

Укажите порт, на котором служба прокси слушает запросы. Этот порт — это порт по умолчанию, используемый для указанного адреса прослушивания.

Порт по умолчанию — 3128.

set service webproxy default-port 8080
set service webproxy domain-block <domain>

Используется для блокировки определенных доменов прокси. Указание «vyos.net» заблокирует все доступы к vyos.net, а указание «.xxx» заблокирует все доступы к URL, оканчивающимся на .xxx.

set service webproxy domain-block vyos.net
set service webproxy domain-noncache <domain>

Позволяет получить доступ к сайтам в домене без получения их из кэша прокси. Указание «vyos.net» позволит получить доступ к vyos.net, но страницы, которые были доступны, не будут кэшироваться. Это полезно для обхода проблем с проверкой «If-Modified-Since» на определенных сайтах.

set service webproxy domain-noncache vyos.net
set service webproxy listen-address <address>

Указывает адрес прослушивания службы прокси. Адрес прослушивания — это IP-адрес, на котором служба веб-прокси слушает клиентские запросы.

Для безопасности адрес прослушивания должен использоваться только на внутренних/доверенных сетях!

set service webproxy listen-address 192.0.2.1
set service webproxy listen-address <address> disable-transparent

Отключает прозрачный режим веб-прокси на адресе прослушивания.

В прозрачном режиме прокси все трафик, приходящий на порт 80 и предназначенный для интернета, автоматически перенаправляется через прокси. Это позволяет немедленное перенаправление прокси без настройки браузеров клиентов.

Непрозрачное перенаправление требует, чтобы браузеры клиентов были настроены с помощью настроек прокси до того, как запросы будут перенаправлены. Преимущество этого в том, что клиентский веб-браузер может обнаружить, что используется прокси, и вести себя соответственно. Кроме того, веб-малварь иногда может быть заблокирована непрозрачным веб-прокси, так как они не знают о настройках прокси.

set service webproxy listen-address 192.0.2.1 disable-transparent
set service webproxy listen-address <address> port <port>

Устанавливает порт прослушивания для адреса прослушивания. Это переопределяет порт по умолчанию 3128 на конкретном адресе прослушивания.

set service webproxy listen-address 192.0.2.1 port 8080
set service webproxy reply-block-mime <mime>

Используется для блокировки определенного типа MIME.

# блокировка всех PDF
set service webproxy reply-block-mime application/pdf
set service webproxy reply-body-max-size <size>

Указывает максимальный размер тела ответа в КБ, используется для ограничения размера ответа.

По умолчанию принимаются все размеры ответов.

set service webproxy reply-body-max-size 2048
set service webproxy safe-ports <port>

Добавляет новый порт в ACL Safe-ports. Порты, включенные по умолчанию в ACL Safe-ports: 21, 70, 80, 210, 280, 443, 488, 591, 777, 873, 1025-65535

set service webproxy ssl-safe-ports <port>

Добавляет новый порт в ACL SSL-ports. Порты, включенные по умолчанию в ACL SSL-ports: 443

Аутентификация

Встроенный прокси Squid может использовать LDAP для аутентификации пользователей против корпоративной директории. Ниже приведен пример того, как использовать Active Directory как бэкенд для аутентификации. Запросы выполняются через LDAP.

set service webproxy authentication children <number>

Максимальное количество процессов аутентификатора, которые будут запущены. Если вы запустите слишком мало, Squid будет вынужден ждать их для обработки очереди проверок учетных данных, что замедлит его. Когда проверка паролей выполняется через (медленную) сеть, вероятно, потребуется много процессов аутентификатора.

По умолчанию 5.

set service webproxy authentication children 10
set service webproxy authentication credentials-ttl <time>

Указывает, как долго Squid считает, что пара username:password, проверенная внешним образом, действительна — другими словами, как часто вызывается программа-помощник для этого пользователя. Установите это низкое, чтобы заставить перепроверять с краткосрочными паролями.

Время в минутах, по умолчанию 60.

set service webproxy authentication credentials-ttl 120
set service webproxy authentication method <ldap>

Метод аутентификации прокси, в настоящее время поддерживается только LDAP.

set service webproxy authentication method ldap
set service webproxy authentication realm

Указывает область защиты (также называемое именем области), которая будет сообщена клиенту для схемы аутентификации. Обычно это часть текста, который пользователь увидит при запросе имени пользователя и пароля.

set service webproxy authentication realm "VyOS proxy auth"

LDAP

set service webproxy authentication ldap base-dn <base-dn>

Указывает базовый DN, под которым находятся пользователи.

set service webproxy authentication ldap base-dn DC=vyos,DC=net
set service webproxy authentication ldap bind-dn <bind-dn>

DN и пароль для привязки при выполнении поисков.

set service webproxy authentication ldap bind-dn CN=proxyuser,CN=Users,DC=vyos,DC=net
set service webproxy authentication ldap filter-expression <expr>

Фильтр поиска LDAP для поиска DN пользователя. Требуется, если пользователи находятся ниже базового DN или если имя входа не является тем, что строит специфичную часть DN пользователя.

Фильтр поиска может содержать до 15 вхождений %s, которые будут заменены именем пользователя, как в «uid=%s» для RFC 2037 каталогов. Для подробного описания синтаксиса фильтра поиска LDAP см. RFC 2254.

set service webproxy authentication ldap filter-expression (cn=%s)
set service webproxy authentication ldap password <password>

DN и пароль для привязки при выполнении поисков. Так как пароль должен быть напечатан в виде обычного текста в вашем конфигурационном файле Squid, настоятельно рекомендуется использовать аккаунт с минимальными связанными привилегиями. Это для ограничения ущерба в случае, если кто-то получит копию вашего файла конфигурации Squid.

set service webproxy authentication ldap password vyos
set service webproxy authentication ldap persistent-connection

Использовать постоянное соединение LDAP. Обычно соединение LDAP открыто только во время проверки имени пользователя для сохранения ресурсов на сервере LDAP. Эта опция заставляет соединение LDAP оставаться открытым, позволяя использовать его для дальнейшей проверки пользователей.

Рекомендуется для крупных установок.

set service webproxy authentication ldap persistent-connection
set service webproxy authentication ldap port <port>

Укажите альтернативный TCP-порт, на котором слушает сервер LDAP, если не является стандартным портом LDAP 389.

set service webproxy authentication ldap port 389
set service webproxy authentication ldap server <server>

Указывает сервер LDAP для подключения.

set service webproxy authentication ldap server ldap.vyos.net
set service webproxy authentication ldap use-ssl

Использовать шифрование TLS.

set service webproxy authentication ldap use-ssl
set service webproxy authentication ldap username-attribute <attr>

Указывает имя атрибута DN, содержащего имя пользователя/логин. Комбинируется с базовым DN для построения DN пользователя, когда фильтр поиска не указан (filter-expression).

По умолчанию «uid»

Примечание

Это можно сделать только в том случае, если все ваши пользователи расположены прямо под одним и тем же местоположением в дереве LDAP и имя входа используется для именования каждого объекта пользователя. Если ваша структура LDAP не соответствует этим критериям или если вы хотите отфильтровать, кто являются действительными пользователями, то вам нужно использовать фильтр поиска для поиска DN ваших пользователей (filter-expression).

set service webproxy authentication ldap username-attribute uid
set service webproxy authentication ldap version <2 | 3>

Версия протокола LDAP. По умолчанию 3, если не указано.

set service webproxy authentication ldap version 2

Некоторые службы не работают правильно, когда обрабатываются через веб-прокси. Поэтому иногда полезно обойти прозрачный прокси:

  • Чтобы обойти прокси для каждого запроса, направленного на определенное назначение:

    set service webproxy whitelist destination-address 198.51.100.33

    set service webproxy whitelist destination-address 192.0.2.0/24

  • Чтобы обойти прокси для каждого запроса, поступающего с определенного источника:

    set service webproxy whitelist source-address 192.168.1.2

    set service webproxy whitelist source-address 192.168.2.0/24

    (Это может быть полезно, когда вызываемая служба имеет множество и/или часто меняющихся адресов назначения — например, Netflix.)
