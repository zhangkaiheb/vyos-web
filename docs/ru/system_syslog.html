Syslog

Обзор

По умолчанию, VyOS предоставляет минимальную конфигурацию журналирования с локальным хранением и циклическим вращением журналов. Все ошибки, включая сообщения local7, сохраняются в локальный файл. Чрезвычайные оповещения отправляются на консоль.

Чтобы изменить эти настройки, войдите в режим конфигурации.

Конфигурация syslog

Syslog поддерживает запись в несколько назначений: локальный файл, консоль или удаленный сервер syslog через UDP или TCP.

Конфигурация syslog организована в следующие категории:

  • Глобальные настройки

  • Локальное журналирование

  • Журналирование на консоли

  • Удаленное журналирование

  • Шифрованное удаленное журналирование по TLS

Глобальные настройки

Настройте общее поведение службы syslog.

set system syslog marker interval <number>

Настройте интервал, в секундах, для отправки сообщений маркера syslog.

Сообщения маркера syslog подтверждают, что служба журналирования работает.

По умолчанию: 1200 секунд.

set system syslog marker disable

Отключить отправку сообщений маркера syslog.

set system syslog preserve-fqdn

Настройте, как имя хоста устройства отображается в сообщениях журнала, отправляемых на удаленный сервер syslog.

Если настроено, устройство включает свой FQDN в сообщения журнала, даже если сервер syslog находится в той же доменной зоне.

Локальное журналирование

Настройте, какие сообщения журнала сохранять в локальный файл журнала.

set system syslog local <filename> facility <keyword> level <keyword>

Настройте syslog для сохранения сообщений журнала для определенного типа и уровня серьезности в ``/var/log/messages``.

См. таблицы ниже для получения допустимых вариантов типа и уровня серьезности.

Журналирование на консоли

Настройте, какие сообщения журнала отправлять на /dev/console.

set system syslog console facility <keyword> level <keyword>

Настройте syslog для отправки сообщений журнала для определенного типа и уровня серьезности на консоль устройства.

См. таблицы ниже для получения допустимых вариантов типа и уровня серьезности.

Удаленное журналирование

Настройте удаленное журналирование для отправки сообщений журнала на удаленный сервер syslog.

Удаленное журналирование не влияет ни на локальное, ни на журналирование на консоли и работает параллельно с ними. Удаленное журналирование поддерживает отправку сообщений журнала на несколько хостов.

set system syslog remote <address> facility <keyword> level <keyword>

Настройте передачу сообщений журнала на удаленный сервер syslog для определенного типа и уровня серьезности.

Адрес сервера можно указать с помощью либо FQDN, либо IP-адреса.

См. таблицы ниже для получения допустимых вариантов типа и уровня серьезности.

set system syslog remote <address> protocol <udp | tcp>

Настройте протокол для передачи сообщений журнала.

Протокол может быть UDP или TCP. По умолчанию сообщения журнала отправляются через UDP.

set system syslog remote <address> port <port>

Настройте порт для передачи сообщений журнала.

По умолчанию используется стандартный порт 514.

set system syslog remote <address> format include-timezone

Настройте передачу сообщений журнала в формате RFC 5424.

Формат RFC 5424 включает часовой пояс в метку времени. Например:

<34>1 2003-10-11T22:14:15.003-07:00 mymachine.example.com su - ID47 - BOM’su root’ failed for lonvick on /dev/pts/8.

По умолчанию сообщения журнала отправляются в формате RFC 3164. Например:

<34>Oct 11 22:14:15 mymachine su: ‘su root’ failed for lonvick on /dev/pts/8
set system syslog remote <address> format octet-counted

Включите фрейминг по количеству октетов для передачи сообщений журнала.

При включении, многострочные сообщения журнала отправляются без разделения. Убедитесь, что удаленный сервер поддерживает фрейминг по количеству октетов, чтобы избежать ошибок при разборе.

Фрейминг по количеству октетов недоступен для протокола UDP.

set system syslog remote <address> vrf <name>

Настройте экземпляр VRF для передачи сообщений журнала.

set system syslog remote <address> source-address <address>

Настройте исходный IP-адрес (IPv4 или IPv6) для передачи сообщений журнала.

TLS-зашифрованное удалённое журналирование

VyOS поддерживает TLS-зашифрованное удалённое журналирование по TCP для обеспечения безопасной передачи данных syslog на удалённые серверы syslog.

Требования: Перед настройкой TLS-зашифрованного удалённого журналирования убедитесь, что у вас есть:

  • Действительный адрес удалённого сервера syslog.

  • Действительные сертификаты CA и клиента, загруженные в локальное хранилище PKI.

  • Протокол передачи удалённого syslog установлен на TCP:

    set system syslog remote <address> protocol tcp

Примечание

TLS-зашифрованное удалённое журналирование не поддерживается по UDP.

set system syslog remote <address> tls

Включить TLS-зашифрованное удалённое журналирование.

set system syslog remote <address> tls ca-certificate <ca_name>

Настройте сертификат CA .

Клиент syslog использует сертификат CA, чтобы проверить идентичность удалённого сервера syslog.

Сертификат CA требуется для всех режимов аутентификации, кроме anon.

set system syslog remote <address> tls certificate <cert_name>

Настройте клиентский сертификат.

Удалённый сервер syslog использует клиентский сертификат для проверки идентичности клиента syslog.

Клиентский сертификат необходим, если удалённый сервер syslog требует проверки клиентского сертификата.

set system syslog remote <address> tls auth-mode <anon | fingerprint | certvalid | name>

Настройте режим аутентификации.

Режим аутентификации определяет, как клиент syslog проверяет идентичность сервера syslog.

Доступны следующие режимы аутентификации:

  • anon (по умолчанию): Позволяет зашифрованные соединения без проверки идентичности сервера syslog. Этот режим не рекомендуется, так как он уязвим к атакам MITM.

  • fingerprint: Проверяет хэш сертификата сервера против значения, предварительно настроенного с помощью:

    set system syslog remote <address> tls permitted-peer <peer>

  • certvalid: Проверяет, что сертификат сервера подписан доверенным CA, пропуская проверку CN.

  • name: Проверяет, что:

    • Сертификат сервера подписан доверенным CA.

    • Значение CN в сертификате совпадает со значением, предварительно настроенным с помощью:

    set system syslog remote <address> tls permitted-peer <peer>

    Это рекомендуемый безопасный режим для производственных сред.

set system syslog remote <address> tls permitted-peer <peer>

Настройте идентификаторы сертификатов peer.

Формат идентификатора сертификата зависит от режима аутентификации:

  • fingerprint: Введите ожидаемые хэши сертификатов (SHA-1 или SHA-256).

  • name: Введите ожидаемые имена сертификатов CNs.

Для режимов аутентификации anon и certvalid идентификаторы сертификатов не требуются.

Примеры:

# Пример режима аутентификации 'anon'
set system syslog remote 10.10.2.3 facility all level debug
set system syslog remote 10.10.2.3 port 6514
set system syslog remote 10.10.2.3 protocol tcp
set system syslog remote 10.10.2.3 tls auth-mode anon
# или просто используйте 'set system syslog remote 10.10.2.3 tls'

# Пример режима аутентификации 'certvalid'
set system syslog remote elk.example.com facility all level debug
set system syslog remote elk.example.com port 6514
set system syslog remote elk.example.com protocol tcp
set system syslog remote elk.example.com tls ca-certificate my-ca
set system syslog remote elk.example.com tls auth-mode certvalid

# Пример режима аутентификации 'fingerprint'
set system syslog remote syslog.example.com facility all level debug
set system syslog remote syslog.example.com port 6514
set system syslog remote syslog.example.com protocol tcp
set system syslog remote syslog.example.com tls ca-certificate my-ca
set system syslog remote syslog.example.com tls auth-mode fingerprint
set system syslog remote syslog.example.com tls permitted-peers 'SHA1:10:C4:26:...,SHA256:7B:4B:10:...'

# Пример режима аутентификации 'name'
set system syslog remote graylog.example.com facility all level debug
set system syslog remote graylog.example.com port 6514
set system syslog remote graylog.example.com protocol tcp
set system syslog remote graylog.example.com tls ca-certificate my-ca
set system syslog remote graylog.example.com tls certificate syslog-client
set system syslog remote graylog.example.com tls auth-mode name
set system syslog remote graylog.example.com tls permitted-peers 'graylog.example.com'

Рекомендации по безопасности

  • Для безопасных развертываний всегда используйте режим аутентификации name. Это гарантирует, что сервер проверен доверенным CA и что имя хоста совпадает с сертификатом.

  • Используйте режим аутентификации anon только в тестовых средах, так как он не обеспечивает аутентификацию сервера.

  • Убедитесь, что закрытые ключи генерируются, хранятся и поддерживаются исключительно внутри системы PKI.

Службы syslog

Этот раздел перечисляет службы, используемые syslog. Большинство имен служб самосогласованы. Службы local0–local7 используются для пользовательских целей, например, для журналирования с сетевых узлов и оборудования. Назначение службы гибкое и должно быть адаптировано под потребности вашей компании. Рассматривайте службы как инструменты категоризации, а не строгие директивы.

Показать журналы

show log [all | authorization | cluster | conntrack-sync | …]

Показать журналы для определенной категории на консоли.

Используйте завершение табуляции, чтобы увидеть список доступных категорий.

Если категория не указана, будут показаны все журналы.

show log image <name> [all | authorization | directory | file <file name> | tail <lines>]

Показать журналы для определенного образа на консоли.

Доступные категории журналов:

all

Отображает содержимое системных файлов журнала указанного образа.

authorization

Отображает попытки авторизации указанного образа.

directory

Отображает пользовательские файлы журнала указанного образа.

file <file name>

Отображает содержимое указанного пользовательского файла журнала указанного образа.

tail

Отображает последние строки системного журнала указанного образа.

<lines>

Количество строк, которые должны быть отображены, по умолчанию 10.

Если категория не указана, будет отображаться содержимое основного файла syslog.

Совет

Используйте show log | strip-private, чтобы скрыть частные данные при отображении ваших журналов.
