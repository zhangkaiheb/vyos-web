BFD

BFD — это сетевой протокол, который обнаруживает сбои в коммуникации между двумя подключенными маршрутизирующими устройствами за доли секунды — гораздо быстрее, чем традиционные маршрутизирующие протоколы. BFD сам по себе не передает трафик. Вместо этого он обеспечивает быстрое обнаружение сбоев для других протоколов, таких как BGP, OSPF и статические маршруты.

BFD описан и расширен следующими RFC: RFC 5880, RFC 5881 и RFC 5883.

Как работает BFD

BFD устанавливает сессию между двумя узлами и обменивается быстро UDP управляющими пакетами с согласованным интервалом (например, 300 мс между последовательными пакетами). Если узел не получает эти пакеты в течение времени обнаружения (согласованный интервал, умноженный на коэффициент обнаружения), BFD предполагает сбой соединения и информирует маршрутизирующие протоколы.

Конфигурация

set protocols bfd peer <address>

Настройте IPv4 или IPv6 адрес BFD-узла.

Вы можете настроить несколько BFD-узлов, указав разный IP-адрес для каждого соседа, которого вы хотите отслеживать.

Примечание

Для IPv6-узлов необходимо настроить исходный IP-адрес или интерфейс.

Пример:

set protocols bfd peer 198.51.100.33
set protocols bfd peer <address> echo-mode

Включите режим передачи эхо-сообщений BFD для узла с указанным IP-адресом.

Пример:

set protocols bfd peer 198.51.100.33 echo-mode
set protocols bfd peer <address> multihop

Настройте узел с указанным IP-адресом как многопрозвонный сосед.

Примечание

Для BFD-узлов многопрозвонки необходимо настроить локальный исходный IP-адрес.

Пример:

set protocols bfd peer 198.51.100.33 multihop
set protocols bfd peer 198.51.100.33 source address 198.51.100.1
set protocols bfd peer <address> source address <address>

Настройте исходный IP-адрес для сессии BFD с узлом, указанным IP-адресом.

Примечание

Настройка исходного IP-адреса или интерфейса обязательна для IPv6 BFD-узлов.

Пример:

set protocols bfd peer 198.51.100.33 source address 198.51.100.1
set protocols bfd peer <address> source interface <interface>

Настройте исходный интерфейс для сессии BFD с узлом, указанным IP-адресом.

Примечание

Настройка исходного IP-адреса или интерфейса обязательна для IPv6 BFD-узлов.

Пример:

set protocols bfd peer 2001:db8::2 source interface eth0
set protocols bfd peer <address> interval echo-interval <10-60000>

Настройте минимальный интервал, в миллисекундах, с которым локальная система может принимать эхо-пакеты от узла с указанным IP-адресом.

Пример:

set protocols bfd peer 198.51.100.33 interval echo-interval 50
set protocols bfd peer <address> interval multiplier <2-255>

Настройте коэффициент обнаружения для узла с указанным IP-адресом.

BFD умножает согласованный интервал на это значение, чтобы рассчитать время обнаружения — период, после которого он объявляет сессию недоступной, если не приходят управляющие пакеты.

Пример:

set protocols bfd peer 192.0.2.1 interval multiplier 3
set protocols bfd peer <address> interval receive <10-60000>

Настройте интервал, в миллисекундах, с которым локальная система может принимать пакеты BFD от узла с указанным IP-адресом.

Пример:

set protocols bfd peer 192.0.2.1 interval receive 300
set protocols bfd peer <address> interval transmit <10-60000>

Настройте интервал, в миллисекундах, с которым вы хотите, чтобы локальная система отправляла управляющие пакеты BFD на узел с указанным IP-адресом.

Пример:

set protocols bfd peer 192.0.2.1 interval transmit 300
set protocols bfd peer <address> shutdown

Отключите сессию BFD с узлом с указанным IP-адресом.

Пример:

set protocols bfd peer 198.51.100.33 shutdown
set protocols bfd peer <address> minimum-ttl <1-254>

Настройте минимальное значение TTL, которое должны иметь входящие пакеты BFD управляющих сообщений, чтобы быть принятыми от узла с указанным IP-адресом.

BFD отбрасывает любой пакет, у которого TTL ниже этого порога.

Примечание

Это настройка применяется только к сессиям многопрозвонки.

Пример:

set protocols bfd peer 192.0.2.1 minimum-ttl 250
set protocols bfd peer <address> passive

Настройте сессию BFD с узлом с указанным IP-адресом на работу в пассивном режиме.

В пассивном режиме локальная система не инициирует сессию BFD. Вместо этого она ждет получения первого управляющего пакета BFD от удаленного узла.

Примечание

Хотя бы один из двух узлов должен оставаться в активном режиме для установления сессии. Если оба узла находятся в пассивном режиме, ни один из них не инициирует, и сессия никогда не будет установлена.

Пример:

set protocols bfd peer 198.51.100.33 passive
set protocols bfd peer <address> profile <profile>

Примените настройки из указанного профиля BFD к узлу с указанным IP-адресом.

Пример:

set protocols bfd peer 192.0.2.1 profile datacenter-fast
set protocols bfd peer <address> vrf <vrf>

Свяжите сессию BFD с узлом с указанным IP-адресом с конкретным экземпляром VRF.

Пример:

set protocols bfd peer 192.0.2.1 vrf customer-a

Включение BFD в BGP

set protocols bgp neighbor <neighbor> bfd

Включите обнаружение сбоев BFD для сессии BGP с соседом с указанным IP-адресом.

Пример:

set protocols bgp neighbor 192.0.2.1 bfd
set protocols bgp peer-group <neighbor> bfd

Включите обнаружение сбоев BFD для всех соседей в указанной группе BGP.

Пример:

set protocols bgp peer-group INTERNAL-PEERS bfd

Включение BFD в OSPF

set protocols ospf interface <interface> bfd

Включите обнаружение сбоев BFD для соседей OSPF, найденных на указанном интерфейсе.

Когда OSPF формирует соседство с соседом на этом интерфейсе, он запрашивает BFD для установления сессии с этим соседом.

Пример:

set protocols ospf interface eth0 bfd
set protocols ospfv3 interface <interface> bfd

Включите обнаружение сбоев BFD для соседей OSPFv3, найденных на указанном интерфейсе.

Когда OSPFv3 формирует соседство с соседом на этом интерфейсе, он запрашивает BFD для установления сессии с этим соседом.

Пример:

set protocols ospfv3 interface eth0 bfd

Включение BFD в IS-IS

set protocols isis interface <interface> bfd

Включите обнаружение сбоев BFD для соседей IS-IS, найденных на указанном интерфейсе.

Когда IS-IS формирует соседство с соседом на этом интерфейсе, он запрашивает BFD для установления сессии с этим соседом.

Пример:

set protocols isis interface eth0 bfd

Мониторинг статических маршрутов BFD

Мониторируемый статический маршрут присутствует в RIB только тогда, когда сессия BFD активна. Если сессия завершена, маршрут удаляется.

set protocols static route <subnet> next-hop <address> bfd profile <profile>

Настройте обнаружение сбоев BFD для однопрозвонного статического маршрута.

BFD использует IP-адрес следующего прыжка как IP-адрес узла BFD и применяет настройки из указанного профиля BFD.

Пример:

set protocols static route 10.0.0.0/24 next-hop 192.0.2.1 bfd profile datacenter-fast
set protocols static route <subnet> next-hop <address> bfd multi-hop source-address <address>

Настройте обнаружение сбоев BFD для многопрозвонного статического маршрута.

BFD использует IP-адрес следующего прыжка как IP-адрес узла BFD и IP-адрес источника многопрозвонки как локальный исходный IP для исходящих пакетов BFD.

Пример:

set protocols static route 10.0.0.0/24 next-hop 198.51.100.33 bfd multi-hop source-address 198.51.100.1
set protocols static route6 <subnet> next-hop <address> bfd profile <profile>

Настройте обнаружение сбоев BFD для однопрозвонного IPv6 статического маршрута.

BFD использует IPv6-адрес следующего прыжка как IPv6-адрес узла BFD и применяет настройки из указанного профиля BFD.

Пример:

set protocols static route6 2001:db8:1::/64 next-hop 2001:db8::1 bfd profile datacenter-fast
set protocols static route6 <subnet> next-hop <address> bfd multi-hop source-address <address>

Настройте обнаружение сбоев BFD для многопрозвонного IPv6 статического маршрута.

BFD использует IPv6-адрес следующего прыжка как IPv6-адрес узла BFD и IPv6-адрес источника многопрозвонки как локальный исходный IPv6-адрес для исходящих пакетов BFD.

Пример:

set protocols static route6 2001:db8:1::/64 next-hop 2001:db8:100::33 bfd multi-hop source-address 2001:db8::1
