PIMv6

VyOS поддерживает мультикаст-маршрутизацию IPv6 через PIMv6 и MLD версии 1 и 2.

PIMv6 работает аналогично его IPv4-аналогу: он использует существующую таблицу маршрутизации IPv6 для принятия решений о пути, а трафик от мультикаст-источников передается к RP. IPv6-приемники используют MLD для сообщения локальному маршрутизатору, к каким группам они хотят получать данные, и маршрутизатор использует PIMv6 для получения этого трафика от RP через общее распределительное дерево.

Работающая конфигурация PIMv6 требует:

  • Включения PIMv6 на каждом интерфейсе, участвующем в мультикаст-пересылке IPv6.

  • Однозначного указания местоположения точки привязки (RP) на всех маршрутизаторах в домене PIMv6.

  • Включения MLD на интерфейсах, направленных к мультикаст-приемникам.

Основные команды

Используйте следующие команды для базовой настройки PIMv6.

set protocols pim6 interface <interface-name>

Включить PIMv6 на указанном интерфейсе PIMv6.

Эта команда также включает MLD, позволяя маршрутизатору обрабатывать запросы и отчеты MLD от IPv6-приемников.

Пример:

set protocols pim6 interface eth0
set protocols pim6 interface <interface-name> mld disable

Отключить MLD на указанном интерфейсе PIMv6.

Эта команда отключает обработку MLD на интерфейсе, оставляя PIMv6 включенным.

Пример:

set protocols pim6 interface eth0 mld disable

Команды настройки

Вы также можете настроить мультикаст с помощью следующих команд.

set protocols pim6 interface <interface-name> mld interval <1-65535>

Настроить интервал запросов MLD, в секундах, на указанном интерфейсе.

Это значение определяет, как часто маршрутизатор отправляет запросы MLD для выявления активных слушателей в подключенной сети.

Значение по умолчанию — 125 секунд.

Пример:

set protocols pim6 interface eth0 mld interval 100
set protocols pim6 interface <interface-name> mld join <multicast-address>

Настроить интерфейс на присоединение к определенной группе IPv6-мультикаста.

Пример:

set protocols pim6 interface eth0 mld join ff0e::db8:0:1234
set protocols pim6 interface <interface-name> mld join <multicast-address> source <source-address>

Настроить интерфейс на присоединение к определенному каналу (S,G).

Канал определяется комбинацией адреса источника IPv6 (S) и адреса мультикаста IPv6 (G).

Пример:

set protocols pim6 interface eth0 mld join ff3e::1234 source 2001:db8::1
set protocols pim6 interface <interface-name> mld last-member-query-count <1-255>

Настроить количество запросов последнего слушателя, которые маршрутизатор отправляет на указанном интерфейсе после того, как слушатель покидает группу мультикаста.

Значение по умолчанию — 2.

Пример:

set protocols pim6 interface eth0 mld last-member-query-count 3
set protocols pim6 interface <interface-name> mld last-member-query-interval <100-6553500>

Настроить интервал запроса последнего слушателя MLD, в миллисекундах, на указанном интерфейсе.

Это значение определяет, как долго маршрутизатор ждет между запросами последнего слушателя.

Значение по умолчанию — 1000 миллисекунд.

Пример:

set protocols pim6 interface eth0 mld last-member-query-interval 500
set protocols pim6 interface <interface-name> mld max-response-time <100-6553500>

Настроить максимальное время ответа MLD, в миллисекундах, на указанном интерфейсе.

Это значение вставляется в запросы MLD и указывает максимальное время, в течение которого хосты могут ответить отчетом о подписке. Если отчет не получен в течение заданного времени, PIMv6 предполагает, что больше нет активных локальных получателей, и может истечь срок действия связанного состояния (*,G) или (S,G).

Пример:

set protocols pim6 interface eth0 mld max-response-time 5000
set protocols pim6 interface <interface-name> mld version <1-2>

Настроить версию MLD на указанном интерфейсе.

По умолчанию используется версия 2.

Пример:

set protocols pim6 interface eth0 mld version 1

Пример конфигурации

Чтобы включить PIMv6 на интерфейсах eth0 и eth1 (что также автоматически включает MLD, позволяя маршрутизатору обрабатывать запросы MLD и отчеты от подключенных IPv6-приемников):

set protocols pim6 interface eth0
set protocols pim6 interface eth1

Следующая конфигурация явно присоединяет IPv6-мультикаст-группу ff0e::db8:0:1234 на интерфейсе eth0, и канал (S,G) (2001:db8::1, ff3e::5678) на интерфейсе eth1:

set protocols pim6 interface eth0 mld join ff0e::db8:0:1234
set protocols pim6 interface eth1 mld join ff3e::5678 source 2001:db8::1
