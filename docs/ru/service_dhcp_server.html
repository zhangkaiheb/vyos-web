Сервер DHCP

VyOS использует сервер DHCP Kea для назначения IPv4 и IPv6 адресов.

Сервер IPv4

Топология сети определяется с помощью shared-network-name и объявлений подсетей. Служба DHCP может обслуживать несколько общих сетей, каждая из которых может иметь одну или более подсетей. Каждая подсеть должна быть на интерфейсе. Внутри подсети можно объявить диапазон для определения пула динамических адресов. Можно объявить несколько диапазонов, которые могут содержать промежутки. Статические сопоставления могут быть установлены для назначения «статических» адресов клиентам на основе их MAC-адреса.

Конфигурация

set service dhcp-server hostfile-update

Создание записей DNS для каждого клиента при аренде, добавляя клиентов в файл /etc/hosts. Запись будет иметь формат: <shared-network-name>_<hostname>.<domain-name>

Параметры общей сети

Следующие параметры DHCP применяются ко всей общей сети. Все подсети наследуют эти значения, если не указано локально.

set service dhcp-server shared-network-name <name> option bootfile-name <filename>

Имя файла загрузки (DHCP Option 67).

set service dhcp-server shared-network-name <name> option bootfile-server <address>

Сервер, с которого загружается начальный файл загрузки (поле siaddr DHCP).

set service dhcp-server shared-network-name <name> option bootfile-size <size>

Размер загрузочного файла в блоках по 512 октетов (DHCP Option 13).

set service dhcp-server shared-network-name <name> option captive-portal <url>

API-конечная точка для захвата (DHCP Option 114).

set service dhcp-server shared-network-name <name> option capwap-controller <address>

IP-адрес контроллера CAPWAP (DHCP Option 138).

set service dhcp-server shared-network-name <name> option client-prefix-length <prefix-length>

Указывает маску подсети клиента в соответствии с RFC 950. Если не указано, используется объявление подсети (DHCP Option 1).

set service dhcp-server shared-network-name <name> option default-router <address>

IP-адрес шлюза по умолчанию (DHCP Option 3).

set service dhcp-server shared-network-name <name> option domain-name <domain-name>

Параметр domain-name должен быть доменным именем, которое будет добавлено к имени хоста клиента для формирования полного доменного имени (FQDN) (DHCP Option 15).

Это параметр конфигурации для всей общей сети. Все подсети будут наследовать этот параметр, если он не указан локально.

set service dhcp-server shared-network-name <name> option domain-search <domain-name>

Параметр domain-name должен быть доменным именем, используемым при завершении запроса DNS, где не передается полное FQDN. Этот параметр можно указать несколько раз, если вам нужно несколько доменных имен для поиска (DHCP Option 119).

Это параметр конфигурации для всей общей сети. Все подсети будут наследовать этот параметр, если он не указан локально.

set service dhcp-server shared-network-name <name> option interface-mtu <mtu>

MTU интерфейса клиента (DHCP Option 26).

set service dhcp-server shared-network-name <name> option ip-forwarding

Включить маршрутизацию IP на клиенте (DHCP Option 19).

set service dhcp-server shared-network-name <name> option ipv6-only-preferred <seconds>

Отключить IPv4 на хостах только с IPv6 на указанное количество секунд (RFC 8925, DHCP Option 108).
