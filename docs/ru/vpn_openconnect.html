Функция сервера, совместимого с OpenConnect, доступна с версии Equuleus (1.3). Openconnect VPN поддерживает SSL-соединение и предоставляет полный доступ к сети. Сетевое расширение SSL-VPN соединяет конечную систему с корпоративной сетью с контролем доступа, основанным только на информации уровня сети, например, на адресе назначения IP и номере порта. Таким образом, он обеспечивает безопасную связь для всех типов трафика устройств по общественным и частным сетям, а также шифрует трафик с использованием протокола SSL.

Удаленный пользователь будет использовать клиент openconnect для подключения к роутеру и получит IP-адрес из пула VPN, что позволит полный доступ к сети.

Конфигурация

SSL-сертификаты

Нам нужно создать сертификат, который аутентифицирует пользователей, пытающихся получить доступ к сетевым ресурсам через SSL-VPN-туннели. Ниже приведены команды, которые создадут самозаверяющиеся сертификаты и сохранят их в конфигурации:

run generate pki ca install <CA name>
run generate pki certificate sign <CA name> install <Server name>

Мы также можем создать сертификаты с помощью Certbot, который является простым в использовании клиентом, получающим сертификат с Let’s Encrypt, открытой авторитетной центра сертификации, запущенной EFF, Mozilla и другими, и размещает его на веб-сервере.

sudo certbot certonly --standalone --preferred-challenges http -d <domain name>

Настройка сервера

set vpn openconnect authentication local-users username <user> password <pass>
set vpn openconnect authentication mode <local password|radius|certificate>
set vpn openconnect network-settings client-ip-settings subnet <subnet>
set vpn openconnect network-settings name-server <address>
set vpn openconnect network-settings name-server <address>
set vpn openconnect ssl ca-certificate <pki-ca-name>
set vpn openconnect ssl certificate <pki-cert-name>
set vpn openconnect ssl passphrase <pki-password>

Поддержка 2FA OTP

Вместо аутентификации только паролем можно использовать аутентификацию пароля + ключа OTP. Альтернативно, можно использовать только аутентификацию OTP без пароля. Для этого необходимо добавить конфигурацию OTP в приведенную выше конфигурацию:

set vpn openconnect authentication mode local <password-otp|otp>
set vpn openconnect authentication local-users username <user> otp <key>
set vpn openconnect authentication local-users username <user> interval <interval (optional)>
set vpn openconnect authentication local-users username <user> otp-length <otp-length (optional)>
set vpn openconnect authentication local-users username <user> token-type <token-type (optional)>

Для генерации ключа OTP в VyOS можно использовать команду CLI (режим оперативного режима):

generate openconnect username <user> otp-key hotp-time

Аутентификация пользователя по сертификату

Вы можете настроить пользователей на аутентификацию по сертификату, установив режим аутентификации в certificate, и определив, какой поле (по OID) в сертификате будет использоваться для идентификации имени пользователя. Два предопределенных

сокращения для Common Name (OID 2.5.4.3) и User ID (OID 0.9.2342.19200300.100.1.1) предоставлены как cn или uid.

В противном случае необходимо указать конкретное значение OID.

Сертификат пользователя должен быть подписан центром сертификации, определенным в конфигурации, чтобы он мог быть проверен для аутентификации.

set vpn openconnect authentication mode certificate
set vpn openconnect authentication mode certificate user-identifier-field cn
set vpn openconnect ssl ca-certificate <cert>

Конфигурация Openconnect

Простая настройка с одним пользователем и аутентификацией по паролю:

set vpn openconnect authentication local-users username tst password 'OC_bad_Secret'
set vpn openconnect authentication mode local password
set vpn openconnect network-settings client-ip-settings subnet '172.20.20.0/24'
set vpn openconnect network-settings name-server '10.1.1.1'
set vpn openconnect network-settings name-server '10.1.1.2'
set vpn openconnect ssl ca-certificate 'ca-ocserv'
set vpn openconnect ssl certificate 'srv-ocserv'

Чтобы включить HTTP-заголовки безопасности в конфигурационном файле, используйте команду:

set vpn openconnect http-security-headers

Конфигурация на основе идентичности

OpenConnect поддерживает подмножество своих параметров конфигурации, которые могут применяться на основе пользователя/группы, для целей конфигурации мы относим эту функциональность как «конфигурацию на основе идентичности». Ниже приведены руководство по серверу OpenConnect, которое описывает набор параметров конфигурации, которые разрешены. Это можно использовать для применения различных наборов конфигураций разным пользователям или группам пользователей.

sudo mkdir -p /config/auth/ocserv/config-per-user
sudo touch /config/auth/ocserv/default-user.conf

set vpn openconnect authentication identity-based-config mode user
set vpn openconnect authentication identity-based-config directory /config/auth/ocserv/config-per-user
set vpn openconnect authentication identity-based-config default-config /config/auth/ocserv/default-user.conf

Предупреждение

Указанный выше каталог и default-config должны быть дочерним каталогом /config/auth, так как файлы вне этого каталога не сохраняются после обновления образа.

После того как вы примете вышеуказанные изменения, вы можете создать файл конфигурации в каталоге /config/auth/ocserv/config-per-user, который соответствует имени пользователя, которого вы создали, например, «tst». Теперь, когда вы входите с пользователем «tst», параметры конфигурации, которые вы установили в этом файле, будут загружены.

Убедитесь, что в файле по умолчанию задано разумное значение конфигурации, это будет загружено в случае, если пользователь аутентифицирован, но файл не найден в указанном каталоге, соответствующем имени пользователя/группе.

sudo nano /config/auth/ocserv/config-per-user/tst

Тот же набор параметров конфигурации применяется, когда конфигурация на основе идентичности настроена в режиме группы, за исключением того, что режим группы может использоваться только с аутентификацией RADIUS.

Предупреждение

Сервер OpenConnect сопоставляет имя файла в чувствительном к регистру порядке, убедитесь, что имя пользователя/группы, которое вы настраиваете, точно совпадает с именем файла.

Настройка учета RADIUS

OpenConnect можно настроить так, чтобы отправлять информацию об учете в RADIUS-сервер для захвата данных сессии пользователя, таких как время подключения/отключения, переданные данные и т. д.

Настройте сервер учета и включите учет с помощью:

set vpn openconnect accounting mode radius
set vpn openconnect accounting radius server 172.20.20.10
set vpn openconnect accounting radius server 172.20.20.10 port 1813
set vpn openconnect accounting radius server 172.20.20.10 key your_radius_secret

Предупреждение

Функция учета RADIUS должна использоваться с режимом аутентификации OpenConnect RADIUS. Ее нельзя использовать с локальной аутентификацией. Вы должны настроить режим аутентификации OpenConnect на «radius».
