SSTP сервер

SSTP — это форма VPN туннеля, которая предоставляет механизм для транспортировки PPP-трафика через канал SSL/TLS. SSL/TLS обеспечивает транспортный уровень безопасности с согласованием ключей, шифрованием и проверкой целостности трафика. Использование SSL/TLS на TCP-порт 443 позволяет SSTP проходить практически через все брандмауэры и прокси-серверы, за исключением аутентифицированных веб-прокси.

SSTP доступен для Linux, BSD и Windows.

VyOS использует accel-ppp, чтобы предоставить функциональность сервера SSTP. Мы поддерживаем как локальную, так и RADIUS-аутентификацию.

Поскольку SSTP предоставляет PPP через канал SSL/TLS, требуется использование либо сертификатов, подписанных публично, либо частной PKI.

Настройка SSTP сервера

Сертификаты

Используйте наш раздел документации — PKI чтобы создать и установить CA и серверный сертификат

vyos@vyos:~$ generate pki ca install CA

vyos@vyos:~$ generate pki certificate sign CA install Server

Конфигурация

set vpn sstp authentication local-users username test password 'test'
set vpn sstp authentication mode 'local'
set vpn sstp client-ip-pool SSTP-POOL range '10.0.0.2-10.0.0.100'
set vpn sstp default-pool 'SSTP-POOL'
set vpn sstp gateway-address '10.0.0.1'
set vpn sstp ssl ca-certificate 'CA1'
set vpn sstp ssl certificate 'Server'
set vpn sstp authentication mode <local | radius>

Установите backend-авторизацию. Настроенный backend-авторизации используется для всех запросов.

  • radius: Все запросы на аутентификацию обрабатываются конфигурированным сервером RADIUS.

  • local: Все запросы на аутентификацию обрабатываются локально.

set vpn sstp authentication local-users username <user> password <pass>

Создайте <user> для локальной аутентификации на этом устройстве. Пароль пользователя будет установлен на <pass>.

set vpn sstp client-ip-pool <POOL-NAME> range <x.x.x.x-x.x.x.x | x.x.x.x/x>

Используйте эту команду, чтобы определить первый IP-адрес пула адресов, которые будут предоставлены клиентам SSTP. Если используется обозначение x.x.x.x-x.x.x.x, оно должно находиться в подсети /24. Если используется обозначение x.x.x.x/x, возможно задание хоста/сетевого маски.

set vpn sstp default-pool <POOL-NAME>

Используйте эту команду, чтобы определить имя пула адресов по умолчанию.

set vpn sstp gateway-address <gateway>

Указывает единственный <gateway> IP-адрес, который будет использоваться как локальный адрес интерфейсов PPP.

set vpn sstp ssl ca-certificate <file>

Имя сертификата авторитета, установленного.

set vpn sstp ssl certificate <file>

Имя установленного серверного сертификата.

Настройка RADIUS-аутентификации

Для включения аутентификации на основе RADIUS необходимо изменить режим аутентификации в конфигурации. Предыдущие настройки, такие как локальные пользователи, все еще существуют в конфигурации, однако они не используются, если режим был изменен с локального на RADIUS. После возврата к локальному режиму будут использоваться все локальные учетные записи.

set vpn sstp authentication mode radius
set vpn sstp authentication radius server <server> key <secret>

Настройте RADIUS <server> и его необходимый общий <secret> для общения с сервером RADIUS.

Поскольку RADIUS-сервер является точкой отказа, можно настроить несколько RADIUS-серверов, которые будут использоваться последовательно. Например:

set vpn sstp authentication radius server 10.0.0.1 key 'foo'
set vpn sstp authentication radius server 10.0.0.2 key 'foo'

Примечание

Некоторые RADIUS-серверы используют список контроля доступа, который разрешает или запрещает запросы, убедитесь, что ваш роутер VyOS добавлен в список разрешенных клиентов.

Исходный адрес RADIUS

Если вы используете OSPF как ваш IGP, используйте интерфейс, наиболее близкий к RADIUS-серверу. Вы можете привязать все исходящие запросы RADIUS к одному исходному IP-адресу, например, к циклическому интерфейсу.

set vpn sstp authentication radius source-address <address>

Исходный IPv4-адрес, используемый во всех запросах к серверу RADIUS.

Примечание

Параметр source-address должен быть настроен на интерфейсе. Лучшей практикой будет использование циклического или фиктивного интерфейса.

Дополнительные параметры RADIUS

set vpn sstp authentication radius server <server> port <port>

Настройте RADIUS <server> и его необходимый порт для запросов аутентификации.

set vpn sstp authentication radius server <server> fail-time <time>

Отметьте RADIUS-сервер как недоступный на заданное количество <time> секунд.

set vpn sstp authentication radius server <server> disable

Временно отключите этот RADIUS-сервер.

set vpn sstp authentication radius acct-timeout <timeout>

Время ожидания ответа для пакетов Interim-Update. (по умолчанию 3 секунды)

set vpn sstp authentication radius dynamic-author server <address>

Указывает IP-адрес сервера расширения динамической авторизации (DM/CoA). Этот IP-адрес должен существовать на любом интерфейсе VyOS или может быть 0.0.0.0.

set vpn sstp authentication radius dynamic-author port <port>

UDP-порт для сервера расширения динамической авторизации (DM/CoA)

set vpn sstp authentication radius dynamic-author key <secret>

Секрет для сервера расширения динамической авторизации (DM/CoA)

set vpn sstp authentication radius max-try <number>

Максимальное количество попыток отправить запросы Access-Request/Accounting-Request

set vpn sstp authentication radius timeout <timeout>

Время ожидания ответа от сервера (в секундах)

set vpn sstp authentication radius nas-identifier <identifier>

Значение, отправляемое на RADIUS-сервер в атрибуте NAS-Identifier и которое должно совпадать в запросах DM/CoA.

set vpn sstp authentication radius nas-ip-address <address>

Значение, отправляемое на RADIUS-сервер в атрибуте NAS-IP-Address и которое должно совпадать в запросах DM/CoA. Также сервер DM/CoA будет привязан к этому адресу.

set vpn sstp authentication radius source-address <address>

Исходный IPv4-адрес, используемый во всех запросах к серверу RADIUS.

set vpn sstp authentication radius rate-limit attribute <attribute>

Указывает, какой атрибут сервера RADIUS содержит информацию о скорости ограничения. По умолчанию используется атрибут Filter-Id.

Примечание

Если вы установите пользовательский атрибут RADIUS, вы должны определить его как на сервере RADIUS, так и на клиенте.

set vpn sstp authentication radius rate-limit enable

Включает регулирование пропускной способности через RADIUS.

set vpn sstp authentication radius rate-limit vendor

Указывает словарь производителя. Этот словарь должен быть присутствующим в /usr/share/accel-ppp/radius.

Полученные атрибуты RADIUS имеют более высокий приоритет, чем параметры, определенные в конфигурации CLI, см. объяснение ниже.

Выделение клиентских IP-адресов через RADIUS

Если RADIUS-сервер отправляет атрибут Framed-IP-Address, то этот IP-адрес будет выделен клиенту, а параметр default-pool в конфигурации CLI будет игнорироваться.

Если RADIUS-сервер отправляет атрибут Framed-Pool, то IP-адрес будет выделен из предопределенного пула адресов, имя которого равно значению атрибута.

Если RADIUS-сервер отправляет атрибут Stateful-IPv6-Address-Pool, то IPv6-адрес будет выделен из предопределенного пула IPv6 prefix, имя которого равно значению атрибута.

Если RADIUS-сервер отправляет атрибут Delegated-IPv6-Prefix-Pool, то префикс делегирования IPv6 будет выделен из предопределенного пула IPv6 delegate, имя которого равно значению атрибута.

Примечание

Stateful-IPv6-Address-Pool и Delegated-IPv6-Prefix-Pool определены в RFC6911. Если они не определены на вашем RADIUS-сервере, добавьте новый словарь.

Интерфейс клиента может быть помещен в контекст VRF через пакет Access-Accept RADIUS или изменен через RADIUS CoA. Accel-VRF-Name используется для этих целей. Это является пользовательским атрибутом ACCEL-PPP. Определите его на вашем RADIUS-сервере.

Переименование интерфейсов клиентов через RADIUS

Если RADIUS-сервер использует атрибут NAS-Port-Id, то туннели PPP будут переименованы.

Примечание

Значение атрибута NAS-Port-Id должно быть меньше 16 символов, иначе интерфейс не будет переименован.

IPv6

set vpn sstp ppp-options ipv6 <require | prefer | allow | deny>

Указывает предпочтение согласования IPv6.

  • require - Требуется согласование IPv6

  • prefer - Запросите клиента о согласовании IPv6, не завершайте, если он отклоняет

  • allow - Согласование IPv6 только при запросе клиента (значение по умолчанию)

  • deny - Не согласовывать IPv6

set vpn sstp client-ipv6-pool <IPv6-POOL-NAME> prefix <address> mask <number-of-bits>

Используйте эту команду, чтобы установить пул IPv6, из которого клиент SSTP получит префикс IPv6 вашего определенного размера (маска), чтобы завершить точку подключения SSTP на их стороне. Длина маски может быть установлена между 48 и 128 битами, значение по умолчанию — 64.

set vpn sstp client-ipv6-pool <IPv6-POOL-NAME> delegate <address> delegation-prefix <number-of-bits>

Используйте эту команду, чтобы настроить DHCPv6 Prefix Delegation (RFC3633) на SSTP. Вам нужно будет установить ваш пул IPv6 и длину префикса делегирования. Из определенного пула IPv6 вы будете выдавать сети заданной длины (префикс делегирования). Длина префикса делегирования может быть установлена между 32 и 64 битами.

set vpn sstp default-ipv6-pool <IPv6-POOL-NAME>

Используйте эту команду, чтобы определить имя пула IPv6 по умолчанию.

set vpn sstp ppp-options ipv6 allow
set vpn sstp client-ipv6-pool IPv6-POOL delegate '2001:db8:8003::/48' delegation-prefix '56'
set vpn sstp client-ipv6-pool IPv6-POOL prefix '2001:db8:8002::/48' mask '64'
set vpn sstp default-ipv6-pool IPv6-POOL

Дополнительные параметры IPv6

set vpn sstp ppp-options ipv6-accept-peer-interface-id

Принять идентификатор интерфейса абонента. По умолчанию это не определено.

set vpn sstp ppp-options ipv6-interface-id <random | x:x:x:x>

Определяет, используется ли фиксированный или случайный идентификатор интерфейса для IPv6. По умолчанию используется фиксированный.

  • random - Случайный идентификатор интерфейса для IPv6

  • x:x:x:x - Укажите идентификатор интерфейса для IPv6

set vpn sstp ppp-options ipv6-interface-id <random | x:x:x:x>

Определяет идентификатор интерфейса абонента для IPv6. По умолчанию используется фиксированный.

  • random - Случайный идентификатор интерфейса для IPv6

  • x:x:x:x - Укажите идентификатор интерфейса для IPv6

  • ipv4-addr - Рассчитайте идентификатор интерфейса из IPv4-адреса.

  • calling-sid - Рассчитайте идентификатор интерфейса из вызывающего станционного идентификатора.

Дополнительные параметры PPP

set vpn sstp ppp-options disable-ccp

Отключить протокол управления сжатием (CCP). CCP включен по умолчанию.

set vpn sstp ppp-options interface-cache <number>

Указывает количество интерфейсов, которые нужно кэшировать. Это предотвращает удаление интерфейсов после уничтожения соответствующей сессии. Вместо этого интерфейсы кэшируются для использования в новых сессиях. Это должно снизить частоту создания/удаления интерфейсов на уровне ядра. Значение по умолчанию — 0.

set vpn sstp ppp-options ipv4 <require | prefer | allow | deny>

Указывает предпочтение согласования IPv4.

  • require - Требуется согласование IPv4

  • prefer - Запросите клиента о согласовании IPv4, не завершайте, если он отклоняет

  • allow - Согласование IPv4 только при запросе клиента (значение по умолчанию)

  • deny - Не согласовывать IPv4

set vpn sstp ppp-options lcp-echo-failure <number>

Определяет максимальное количество <number> неподтвержденных эхо-запросов. При достижении значения <number>, сессия будет перезапущена. Значение по умолчанию — 3.

set vpn sstp ppp-options lcp-echo-interval <interval>

Если эта опция указана и больше 0, модуль PPP будет отправлять эхо-запросы LCP каждые <interval> секунд. Значение по умолчанию — 30.

set vpn sstp ppp-options lcp-echo-timeout

Указывает время ожидания в секундах для любого активности со стороны абонента. Если эта опция указана, она включает адаптивную функцию эхо-запроса LCP и «lcp-echo-failure» не используется. Значение по умолчанию — 0.

set vpn sstp ppp-options min-mtu <number>

Определяет минимально допустимый MTU. Если клиент пытается согласовать MTU ниже этого, он будет NAKed, и отключен, если он отклоняет больший MTU. Значение по умолчанию — 100.

set vpn sstp ppp-options mppe <require | prefer | deny>

Указывает предпочтение согласования MPPE.

  • require - Запросите клиента о MPPE, если он отклоняет, завершите соединение

  • prefer - Запросите клиента о MPPE, если он отклоняет, не завершайте. (Значение по умолчанию)

  • deny - Отказаться от MPPE

По умолчанию — не запрашивать клиента о MPPE, но разрешить, если клиент хочет. Обратите внимание, что RADIUS может переопределить этот параметр атрибутом MS-MPPE-Encryption-Policy.

set vpn sstp ppp-options mru <number>

Определяет предпочитаемый MRU. По умолчанию не определен.

Настройка клиента SSTP

После настройки вашего сервера SSTP наступает время основного тестирования. Клиент Linux, используемый для тестирования, называется sstpc. sstpc требует файла конфигурации PPP/peer.

Если вы используете самоподписанный сертификат, не забудьте установить CA на стороне клиента.

Следующая конфигурация PPP тестирует MSCHAP-v2:

$ cat /etc/ppp/peers/vyos
usepeerdns
#require-mppe
#require-pap
require-mschap-v2
noauth
lock
refuse-pap
refuse-eap
refuse-chap
refuse-mschap
#refuse-mschap-v2
nobsdcomp
nodeflate
debug

Теперь вы можете «дial» peer следующей командой: sstpc --log-level 4 --log-stderr --user vyos --password vyos vpn.example.com -- call vyos.

Попытка подключения будет отображаться следующим образом:
