Политика карты маршрутов

Карта маршрутов — это мощная команда, которая предоставляет сетевым администраторам очень полезный и гибкий инструмент для манипуляции трафиком.

Конфигурация

Карта маршрутов

set policy route-map <text>

Эта команда создает новую политику карты маршрутов, идентифицируемую как <text>.

set policy route-map <text> description <text>

Задать описание для политики карты маршрутов.

set policy route-map <text> rule <1-65535> action <permit|deny>

Установить действие для политики карты маршрутов.

set policy route-map <text> rule <1-65535> call <text>

Вызов другой политики карты маршрутов при совпадении.

set policy route-map <text> rule <1-65535> continue <1-65535>

Перейти к другому правилу в этой карте маршрутов при совпадении.

set policy route-map <text> rule <1-65535> description <text>

Установить описание для правила в политике карты маршрутов.

set policy route-map <text> rule <1-65535> match as-path <text>

BGP список as-path для совпадения.

set policy route-map <text> rule <1-65535> match community community-list <text>

BGP список сообщества для совпадения.

set policy route-map <text> rule <1-65535> match community exact-match

Установить BGP список сообщества для точного совпадения.

set policy route-map <text> rule <1-65535> match extcommunity <text>

BGP расширенное сообщество для совпадения.

set policy route-map <text> rule <1-65535> match interface <text>

Первый интерфейс маршрута для совпадения.

set policy route-map <text> rule <1-65535> match ip address access-list <1-2699>

IP-адрес маршрута для совпадения, основанный на списке доступа.

set policy route-map <text> rule <1-65535> match ip address prefix-list <text>

IP-адрес маршрута для совпадения, основанный на префиксном списке.

set policy route-map <text> rule <1-65535> match ip address prefix-len <0-32>

IP-адрес маршрута для совпадения, основанный на указанной длине префикса. Обратите внимание, что это может использоваться только для маршрутов ядра. Не применяйте к маршрутам динамических протоколов маршрутизации (например, BGP, RIP, OSFP), так как это может привести к неожиданным результатам.

set policy route-map <text> rule <1-65535> match ip nexthop access-list <1-2699>

IP-адрес следующего узла маршрута для совпадения, основанный на списке доступа.

set policy route-map <text> rule <1-65535> match ip nexthop address <x.x.x.x>

IP-адрес следующего узла маршрута для совпадения, основанный на IP-адресе.

set policy route-map <text> rule <1-65535> match ip nexthop prefix-len <0-32>

IP-адрес следующего узла маршрута для совпадения, основанный на длине префикса.

set policy route-map <text> rule <1-65535> match ip nexthop prefix-list <text>

IP-адрес следующего узла маршрута для совпадения, основанный на префиксном списке.

set policy route-map <text> rule <1-65535> match ip nexthop type <blackhole>

IP-адрес следующего узла маршрута для совпадения, основанный на типе.

set policy route-map <text> rule <1-65535> match ip route-source access-list <1-2699>

Исходный IP-адрес маршрута для совпадения, основанный на списке доступа.

set policy route-map <text> rule <1-65535> match ip route-source prefix-list <text>

Исходный IP-адрес маршрута для совпадения, основанный на префиксном списке.

set policy route-map <text> rule <1-65535> match ipv6 address access-list <text>

IPv6-адрес маршрута для совпадения, основанный на IPv6-списке доступа.

set policy route-map <text> rule <1-65535> match ipv6 address prefix-list <text>

IPv6-адрес маршрута для совпадения, основанный на IPv6-префиксном списке.

set policy route-map <text> rule <1-65535> match ipv6 address prefix-len <0-128>

IPv6-адрес маршрута для совпадения, основанный на указанной длине префикса. Обратите внимание, что это может использоваться только для маршрутов ядра. Не применяйте к маршрутам динамических протоколов маршрутизации (например, BGP, RIP, OSFP), так как это может привести к неожиданным результатам.

set policy route-map <text> rule <1-65535> match ipv6 nexthop <h:h:h:h:h:h:h:h>

IPv6-адрес следующего узла для совпадения.

set policy route-map <text> rule <1-65535> match large-community large-community-list <text>

Совпадение с большими сообществами BGP.

set policy route-map <text> rule <1-65535> match local-preference <0-4294967295>

Совпадение с локальной предпочтительностью.

set policy route-map <text> rule <1-65535> match metric <1-65535>

Совпадение с метрикой маршрута.

set policy route-map <text> rule <1-65535> match origin <egp|igp|incomplete>

Код источника границы шлюза (BGP) для совпадения.

set policy route-map <text> rule <1-65535> match peer <x.x.x.x>

IP-адрес соседа для совпадения.

set policy route-map <text> rule <1-65535> match protocol <protocol>
Исходный протокол для совпадения.

  • babel - Протокол маршрутизации Babel (Babel)

  • bgp - Граница шлюза (BGP)

  • connected - Связанные маршруты (непосредственно подключенные подсеть или хост)

  • isis - Промежуточные системы (IS-IS)

  • kernel - Маршруты ядра

  • ospf - Открытый кратчайший путь (OSPFv2)

  • ospfv3 - Открытый кратчайший путь (IPv6) (OSPFv3)

  • rip - Протокол информационных маршрутов (RIP)

  • ripng - Новое поколение протокола информационных маршрутов (IPv6) (RIPng)

  • static - Статически настроенные маршруты

  • table - Неглавная таблица маршрутизации ядра

  • vnc - Виртуальное управление сетью (VNC)

set policy route-map <text> rule <1-65535> match rpki <invalid|notfound|valid>

Совпадение с результатом проверки RPKI.

set policy route-map <text> rule <1-65535> match source-vrf <text>

Исходный VRF для совпадения.

set policy route-map <text> rule <1-65535> match tag <1-65535>

Тег маршрута для совпадения.

set policy route-map <text> rule <1-65535> on-match goto <1-65535>

Выход из политики при совпадении: перейти к правилу <1-65535>

set policy route-map <text> rule <1-65535> on-match next

Выход из политики при совпадении: перейти к следующему номеру последовательности.

set policy route-map <text> rule <1-65535> set aggregator <as|ip> <1-4294967295|x.x.x.x>

Атрибут агрегатора BGP: номер AS или IP-адрес агрегации.

set policy route-map <text> rule <1-65535> set as-path exclude <1-4294967295 | all>

Удалить AS-NUMBER из BGP AS path.

Если указано all, удалите все номера AS из AS_PATH BGP пути NLRI.

set policy route-map <text> rule <1-65535> set as-path prepend <1-4294967295>

Добавьте заданный набор номеров AS в AS_PATH BGP пути NLRI.

set policy route-map <text> rule <1-65535> set as-path prepend-last-as <n>

Добавьте существующий последний номер AS (левый ASN) в AS_PATH.

set policy route-map <text> rule <1-65535> set atomic-aggregate

Атрибут атомарного агрегата BGP.

set policy route-map <text> rule <1-65535> set community <add|replace> <community>

Добавить или заменить атрибут сообщества BGP в формате <0-65535:0-65535> или из списка известных сообществ

set policy route-map <text> rule <1-65535> set community none

Удалить все сообщества BGP

set policy route-map <text> rule <1-65535> set community delete <text>

Удалить сообщества BGP, совпадающие со списком сообществ.

set policy route-map <text> rule <1-65535> set large-community <add|replace> <GA:LDP1:LDP2>

Добавить или заменить атрибут больших сообществ BGP в формате <0-4294967295:0-4294967295:0-4294967295>

set policy route-map <text> rule <1-65535> set large-community none

Удалить все большие сообщества BGP

set policy route-map <text> rule <1-65535> set large-community delete <text>

Удалить сообщества BGP, совпадающие со списком больших сообществ.

set policy route-map <text> rule <1-65535> set extcommunity bandwidth <1-25600|cumulative|num-multipaths>

Установить расширенное сообщество полосы пропускания

set policy route-map <text> rule <1-65535> set extcommunity bandwidth-non-transitive

Расширенное сообщество полосы пропускания кодируется как непередаваемое

set policy route-map <text> rule <1-65535> set extcommunity rt <text>

Установить значение маршрута в формате <0-65535:0-4294967295> или <IP:0-65535>.

set policy route-map <text> rule <1-65535> set extcommunity soo <text>

Установить значение места происхождения в формате <0-65535:0-4294967295> или <IP:0-65535>.

set policy route-map <text> rule <1-65535> set extcommunity none

Очистить все BGP extcommunities.

set policy route-map <text> rule <1-65535> set distance <0-255>

Локально значимое административное расстояние.

set policy route-map <text> rule <1-65535> set ip-next-hop <x.x.x.x>

IP-адрес следующего узла.

set policy route-map <text> rule <1-65535> set ip-next-hop unchanged

Установить следующий узел без изменений. Пройти через карту маршрутов без изменения его значения

set policy route-map <text> rule <1-65535> set ip-next-hop peer-address

Установить адрес следующего узла BGP в адрес соседа. Для входящей карты маршрутов это означает использование IP-адреса нашего соседа. Для исходящей карты маршрутов это означает использование IP-адреса нашего собственного устройства для установления связи с нашим соседом.

set policy route-map <text> rule <1-65535> set ipv6-next-hop <global|local> <h:h:h:h:h:h:h:h>

IPv6-адрес следующего узла.

set policy route-map <text> rule <1-65535> set ipv6-next-hop peer-address

Установить адрес следующего узла BGP в адрес соседа. Для входящей карты маршрутов это означает использование IP-адреса нашего соседа. Для исходящей карты маршрутов это означает использование IP-адреса нашего собственного устройства для установления связи с нашим соседом.

set policy route-map <text> rule <1-65535> set ipv6-next-hop prefer-global

Для входящих и импортированных карт маршрутов, если мы получаем v6 глобальный и v6 LL адрес для маршрута, то предпочтительно использовать глобальный адрес как следующий узел.

set policy route-map <text> rule <1-65535> set local-preference <0-4294967295>

Установить атрибут локальной предпочтительности BGP.

set policy route-map <text> rule <1-65535> set metric <+/-metric|0-4294967295|rtt|+rtt|-rtt>

Установить метрику маршрута. При использовании с BGP установите атрибут MED в конкретное значение. Используйте +/-, чтобы добавить или вычесть указанное значение из существующего/MED. Используйте rtt, чтобы установить MED в время обратного прохода или +rtt/-rtt, чтобы добавить/вычесть время обратного прохода из MED.

set policy route-map <text> rule <1-65535> set metric-type <type-1|type-2>

Установить тип внешней метрики OSPF.

set policy route-map <text> rule <1-65535> set origin <igp|egp|incomplete>

Установить код источника BGP.

set policy route-map <text> rule <1-65535> set originator-id <x.x.x.x>

Атрибут идентификатора создателя BGP.

set policy route-map <text> rule <1-65535> set src <x.x.x.x|h:h:h:h:h:h:h:h>

Установить исходный IP/IPv6-адрес для маршрута.

set policy route-map <text> rule <1-65535> set table <1-200>

Установить префиксы в таблицу.

set policy route-map <text> rule <1-65535> set tag <1-65535>

Установить значение тега для протокола маршрутизации.

set policy route-map <text> rule <1-65535> set weight <0-4294967295>
