Разделение маршрутов

SR — это архитектура сети, похожая на исходный маршрут. Входной маршрутизатор прикрепляет список сегментов, известных как SIDs, к каждому пакету при его входе в сеть.

Список SIDs явно определяет путь, который будет следовать пакет. На каждом узле маршрутизатор читает первый SID, выполняет инструкцию о пересылке, и обычно удаляет его, чтобы следующий узел мог обработать последующий SID.

SR зависит от IGPs, таких как IS-IS или OSPF для рекламы SIDs по всей сети.

Примечание

SR определяет архитектуру плоскости управления и может быть применен к существующим MPLS-сетям. В сетях MPLS сегменты кодируются как метки MPLS и применяются на входном маршрутизаторе. Эти метки затем распространяются по домену маршрутизации IGPs, такими как IS-IS (как описано в RFC 8667) или OSPF.

SR для плоскости данных MPLS поддерживает IPv4, IPv6 и ECMP, и был протестирован с маршрутизаторами Cisco и Juniper. Однако эта реализация все еще экспериментальна для FRR.

Конфигурация SR IS-IS

Используйте следующие команды, чтобы включить SR в IS-IS.

Известные ограничения:

  • Нет поддержки перераспределения уровней (L1 к L2 или L2 к L1).

  • Нет поддержки BSID.

  • Поддерживается только один SRGB и стандартный SPF алгоритм.

set protocols isis segment-routing global-block high-label-value <16-1048575>

Настройте верхнюю границу Segment Routing Global Block (SRGB).

SRGB определяет диапазон меток MPLS, зарезервированный для сопоставления глобальных сегментов, таких как Prefix-SIDs, с записями FIB.

Диапазон не может превышать 65535 меток.

Пример:

set protocols isis segment-routing global-block high-label-value 23999
set protocols isis segment-routing global-block low-label-value <16-1048575>

Настройте нижнюю границу Segment Routing Global Block (SRGB).

SRGB определяет диапазон меток MPLS, зарезервированный для сопоставления глобальных сегментов, таких как Prefix-SIDs, с записями FIB.

Диапазон не может превышать 65535 меток.

Пример:

set protocols isis segment-routing global-block low-label-value 16000
set protocols isis segment-routing local-block high-label-value <16-1048575>

Настройте верхнюю границу Segment Routing Local Block (SRLB).

SRLB определяет диапазон меток MPLS, которые маршрутизатор резервирует для своих локальных сегментов, таких как Adjacency-SIDs.

Диапазон не может превышать 65535 меток.

Пример:

set protocols isis segment-routing local-block high-label-value 15999
set protocols isis segment-routing local-block low-label-value <16-1048575>

Настройте нижнюю границу Segment Routing Local Block (SRLB).

SRLB определяет диапазон меток MPLS, которые маршрутизатор резервирует для своих локальных сегментов, таких как Adjacency-SIDs.

Диапазон не может превышать 65535 меток.

Пример:

set protocols isis segment-routing local-block low-label-value 15000

Примечание

Установка блоков меток SR имеет следующие ограничения конфигурации:

  • Обе границы (high-label-value и low-label-value) должны быть установлены. Удаление любой из границ также удаляет другую.

  • local-block требует, чтобы global-block был настроен.

  • Диапазоны SRGB и SRLB не должны пересекаться.

Нарушение любого из этих условий приведет к неудаче коммита.

set protocols isis segment-routing maximum-label-depth <1-16>

Настройте максимальную глубину SID (MSD), поддерживаемую маршрутизатором.

Значение зависит от плоскости данных MPLS.

Пример:

set protocols isis segment-routing maximum-label-depth 10
set protocols isis segment-routing prefix <address> index value <0-65535>

Настройте Prefix-SID с числовым значением для указанного IP-префикса.

Prefix-SID — это идентификатор сегмента, связанный с IP-префиксом и распространяемый IGP (IS-IS).

Пример:

set protocols isis segment-routing prefix 192.0.2.1/32 index value 1
set protocols isis segment-routing prefix <address> index <no-php-flag | explicit-null>

Настройте флаг обработки метки для индексированного Prefix-SID, связанного с указанным IP-префиксом:

  • no-php-flag: Запрашивает у upstream-соседа не удалять метку Prefix-SID перед передачей пакета.

  • explicit-null: Запрашивает у upstream-соседа передать пакет с меткой Explicit-Null.

Пример:

set protocols isis segment-routing prefix 192.0.2.1/32 index no-php-flag
set protocols isis segment-routing prefix <address> absolute value <16-1048575>

Настройте Prefix-SID с абсолютным значением для указанного IP-префикса

Prefix-SID — это идентификатор сегмента, связанный с IP-префиксом и распространяемый IGP (IS-IS).

Пример:

set protocols isis segment-routing prefix 192.0.2.1/32 absolute value 16001
set protocols isis segment-routing prefix <address> absolute <no-php-flag | explicit-null>

Настройте флаг обработки метки для абсолютного Prefix-SID, связанного с указанным IP-префиксом:

  • no-php-flag: Запрашивает у upstream-соседа не удалять метку Prefix-SID перед передачей пакета.

  • explicit-null: Запрашивает у upstream-соседа передать пакет с меткой Explicit-Null.

Пример:

set protocols isis segment-routing prefix 192.0.2.1/32 absolute no-php-flag

Операционные команды

show isis segment-routing node

Показать все изученные узлы SR.

show isis route prefix-sid

Показать все изученные Prefix-SIDs и их метки MPLS.

Примечание

Для получения дополнительной информации см. IS-IS.

Конфигурация SR OSPF

Используйте следующие команды, чтобы включить SR в OSPF.

set protocols ospf parameters opaque-lsa

Включите Opaque LSA (RFC 2370) в OSPF.

Opaque LSAs необходимы для транспортировки меток MPLS через OSPF.

Пример:

set protocols ospf parameters opaque-lsa
set protocols ospf segment-routing global-block high-label-value <16-1048575>

Включение SR на IS-IS (экспериментально)

В следующем примере показано базовое двухузловое топологию SR с использованием IS-IS.

Узел 1:

set interfaces loopback lo address '198.51.100.1/32'
set interfaces ethernet eth1 address '192.0.2.1/24'

set protocols isis interface eth1
set protocols isis interface lo
set protocols isis net '49.0001.1980.5110.0001.00'
set protocols isis segment-routing global-block high-label-value '599'
set protocols isis segment-routing global-block low-label-value '550'
set protocols isis segment-routing prefix 198.51.100.1/32 index value '1'
set protocols isis segment-routing prefix 198.51.100.1/32 index explicit-null
set protocols mpls interface 'eth1'

Узел 2:

set interfaces loopback lo address '198.51.100.2/32'
set interfaces ethernet eth1 address '192.0.2.2/24'

set protocols isis interface eth1
set protocols isis interface lo
set protocols isis net '49.0001.1980.5110.0002.00'
set protocols isis segment-routing global-block high-label-value '599'
set protocols isis segment-routing global-block low-label-value '550'
