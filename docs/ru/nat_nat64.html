NAT64

NAT64 — критически важный компонент современных сетей, обеспечивающий обмен данными между сетями IPv6 и IPv4. Это руководство описывает настройку, конфигурацию и использование функции NAT64 в вашем проекте. Независимо от того, переходите ли вы на IPv6 или вам нужно без проблем соединить устройства IPv4 и IPv6. NAT64 — это механизм состояния, который переводит адреса IPv6 в адреса IPv4 и наоборот. NAT64 используется для того, чтобы клиенты, использующие только IPv6, могли обращаться к серверам IPv4 с помощью унICAST UDP, TCP или ICMP.

Обзор

Разные типы NAT

SNAT64

SNAT64 — это механизм состояния, который переводит адреса IPv6 в адреса IPv4.

64:ff9b::/96 — это известный префикс для IPv6-адресов, содержащих IPv4-адреса. Этот префикс используется для представления IPv4-адресов в формате IPv6. IPv4-адрес кодируется в младших 32 битах IPv6-адреса. Старшие 32 бита устанавливаются в известный префикс 64:ff9b::/96.

Примеры конфигурации

Следующие примеры показывают, как настроить NAT64 на маршрутизаторе VyOS. Адрес 192.0.2.1 используется как IPv4-адрес для пула перевода.

Конфигурация сервера NAT64:

set interfaces ethernet eth0 address '192.0.2.1/24'
set interfaces ethernet eth0 address '192.0.2.10/24'
set interfaces ethernet eth0 description 'WAN'
set interfaces ethernet eth1 address '2001:db8::1/64'
set interfaces ethernet eth1 description 'LAN'

set service dns forwarding allow-from '2001:db8::/64'
set service dns forwarding dns64-prefix '64:ff9b::/96'
set service dns forwarding listen-address '2001:db8::1'

set nat64 source rule 100 source prefix '64:ff9b::/96'
set nat64 source rule 100 translation pool 10 address '192.0.2.10'
set nat64 source rule 100 translation pool 10 port '1-65535'

Конфигурация клиента NAT64:

set interfaces ethernet eth1 address '2001:db8::2/64'
set protocols static route6 64:ff9b::/96 next-hop 2001:db8::1
set system name-server '2001:db8::1'
