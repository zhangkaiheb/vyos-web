HTTP API

VyOS предоставляет HTTP API. Вы можете использовать его для выполнения команд в режиме операций или для изменения или удаления конфигурации. API доступен как REST API, так и как GraphQL API.

Для примеров запросов REST API, конечных точек и деталей аутентификации, см. VyOS API.

Примечание

Если для сервиса не настроены сертификаты PKI, VyOS автоматически генерирует самоподписанный сертификат. Это не рекомендуется для использования в производственной среде.

Конфигурация

HTTPS-слушатель

set service https listen-address <address>

Настройте локальный IPv4 или IPv6 адрес, на котором HTTPS-слушатель принимает входящие соединения.

IP-адрес должен уже быть назначен локальному интерфейсу. Повторите команду, чтобы настроить несколько IP-адресов.

При отсутствии настройки слушатель принимает входящие соединения на всех локальных IP-адресах.

Пример:

set service https listen-address 192.0.2.1
set service https listen-address 2001:db8::1
set service https port <1-65535>

Настройте TCP-порт, на котором HTTPS-слушатель принимает входящие соединения.

По умолчанию используется 443.

Примечание

Если выбранный порт уже используется другим сервисом, коммит завершится ошибкой.

Пример:

set service https port 8443
set service https vrf <name>

Привязать HTTPS-слушатель к указанному экземпляру VRF.

VRF должен уже быть настроен под set vrf name <name>.

Пример:

set service https vrf mgmt
set service https allow-client address <address>

Ограничьте доступ к конечным точкам API HTTPS указанным IPv4 или IPv6 адресом или префиксом.

Повторите команду, чтобы разрешить несколько IP-адресов или префиксов.

При отсутствии настройки API принимает соединения с любого IP-адреса.

Пример:

set service https allow-client address 192.0.2.0/24
set service https allow-client address 2001:db8::/32
set service https enable-http-redirect

Включить перенаправление входящих HTTP-запросов (порт 80) на HTTPS.

Перенаправление отправляет трафик на стандартный HTTPS-порт (443). Если вы изменили HTTPS-порт, перенаправление не будет работать.

Пример:

set service https enable-http-redirect
set service https request-body-size-limit <1-256>

Настройте максимальный размер, в мегабайтах, тела HTTP-запроса, принимаемого слушателем.

Запросы, превышающие этот лимит, отклоняются.

По умолчанию установлено значение 1.

Пример:

set service https request-body-size-limit 10

TLS

set service https tls-version <1.2 | 1.3>

Включить конкретную версию протокола TLS для HTTPS-слушателя.

Повторите команду, чтобы включить несколько версий протокола.

По умолчанию включены TLS 1.2 и TLS 1.3.

Пример:

set service https tls-version 1.3
set service https certificates certificate <name>

Привязать сертификат TLS из подсистемы PKI к HTTPS-слушателю.

Сертификат должен уже быть определен под set pki certificate <name> с сертификатом и частным ключом.

Пример:

set service https certificates certificate my-server-cert
set service https certificates ca-certificate <name>

Привязать сертификат CA из подсистемы PKI к HTTPS-слушателю.

CA должен уже быть определен под set pki ca <name>. Сертификат CA добавляется к TLS-сертификату, чтобы сформировать полную цепочку, представленную клиентам во время TLS-рукопожатия.

Пример:

set service https certificates ca-certificate my-internal-ca
set service https certificates dh-params <name>

Выберите параметры Диффи-Хеллмана из подсистемы PKI для HTTPS-слушателя.

Параметры должны уже быть определены под set pki dh <name> с размером ключа не менее 2048 бит. Параметры используются DHE-шифрами в TLS 1.2. TLS 1.3 не использует их.

Пример:

set service https certificates dh-params my-dh-2048

Аутентификация API

set service https api keys id <name> key <apikey>

Настройте ключ HTTP API для аутентификации запросов REST и запросов GraphQL, если GraphQL не переключен на аутентификацию JWT-токеном.

Ключ указывается в виде обычного текста и предоставляет полный доступ к API.

Для использования REST API необходимо настроить хотя бы один ключ. GraphQL может работать без ключей, если включен JWT-токен аутентификации.

Пример:

set service https api keys id MY-HTTPS-API-ID key 'MY-HTTPS-API-PLAINTEXT-KEY'

REST

set service https api rest

Включить REST API для управления VyOS через HTTPS.

Пример:

set service https api rest
set service https api rest strict

Отказывать в запросах удаления на конечной точке /configure, когда целевой путь конфигурации не существует.

Без этого флага такие запросы завершаются успешно без сообщений.

Пример:

set service https api rest strict
set service https api rest debug

Записывать подробные сообщения об ошибках в журнал systemd при неудаче запросов конфигурации API.

Без этого флага записываются только короткие сообщения об ошибках.

Пример:

set service https api rest debug

GraphQL

set service https api graphql introspection

Включить интроспекцию графа GraphQL.

Авторизованные клиенты могут затем запросить конечную точку для получения полной схемы. По умолчанию отключено, и обычно остается отключенным в производственной среде из-за проблем безопасности.

Пример:

set service https api graphql introspection
set service https api graphql authentication type <key | token>

Настройте тип аутентификации для запросов GraphQL:

  • key: Использует API-ключи, настроенные в service https api keys.

  • token: Использует JWT токены.

По умолчанию установлено значение key.

Пример:

set service https api graphql authentication type token
set service https api graphql authentication expiration <60-31536000>

Настройте продолжительность жизни JWT-токена, в секундах.

По умолчанию установлено значение 3600.

Пример:

set service https api graphql authentication expiration 86400
set service https api graphql authentication secret-length <16-65535>

Настройте длину, в байтах, общего секрета, используемого для подписания JWT-токенов.

По умолчанию установлено значение 32.

Пример:

set service https api graphql authentication secret-length 64
set service https api graphql cors allow-origin <origin>

Настройте, какие сайты (источники) могут читать ответы от GraphQL API в браузере, используя CORS.

Повторите команду, чтобы разрешить несколько источников.

Пример:

set service https api graphql cors allow-origin https://app.example.com

Пример

Минимальная конфигурация для работы REST API требует включения REST и настройки хотя бы одного API-ключа:

set service https api keys id MY-HTTPS-API-ID key MY-HTTPS-API-PLAINTEXT-KEY
set service https api rest
