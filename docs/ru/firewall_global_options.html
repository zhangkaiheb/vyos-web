Конфигурация глобальных параметров брандмауэра

Обзор

Некоторые настройки брандмауэра являются глобальными и влияют на всю систему. В этом разделе предоставляется информация о этих глобальных параметрах, которые вы можете настроить с помощью CLI VyOS.

Команды конфигурации, охватываемые этим разделом:

set firewall global-options …

Конфигурация

set firewall global-options all-ping [enable | disable]

По умолчанию, когда VyOS получает пакет запроса ICMP echo, предназначенный для него самого, он отвечает пакетом ICMP echo reply, если только ваш брандмауэр не запрещает это.

Вы можете настроить правила брандмауэра, чтобы принимать, блокировать или отклонять ICMP в, выхлоп или локальный трафик. Вы также можете использовать команду firewall global-options all-ping. Эта команда влияет только на локальный трафик (пакеты, предназначенные для вашей системы VyOS), а не на входящий или исходящий трафик.

Примечание

firewall global-options all-ping влияет только на локальный трафик и всегда действует самым строгим образом

set firewall global-options all-ping enable

При установке этой команды VyOS отвечает на каждый пакет ICMP echo, адресованный ему самому, но этот ответ происходит только в том случае, если нет других правил, которые блокируют или отклоняют локальные запросы echo. В случае конфликта VyOS не отвечает на пакеты ICMP echo.

set firewall global-options all-ping disable

При установке этой команды VyOS не отвечает на пакеты ICMP echo, адресованные ему самому, независимо от того, откуда они приходят или какие конкретные правила их принимают.

set firewall global-options apply-to-bridged-traffic [ipv4 | ipv6]

Применение правил IPv4 или IPv6 брандмауэра к мостовому трафику.

set firewall global-options broadcast-ping [enable | disable]

Включить или отключить ответ на сообщения ICMP broadcast. Система изменяет следующий параметр:

  • net.ipv4.icmp_echo_ignore_broadcasts

set firewall global-options ip-src-route [enable | disable]
set firewall global-options ipv6-src-route [enable | disable]

Установите, принимает ли VyOS пакеты с опцией source route. Следующие параметры sysctl будут изменены:

  • net.ipv4.conf.all.accept_source_route

  • net.ipv6.conf.all.accept_source_route

set firewall global-options receive-redirects [enable | disable]
set firewall global-options ipv6-receive-redirects [enable | disable]

Разрешить VyOS принимать сообщения redirect ICMPv4 и ICMPv6. Следующие параметры sysctl будут изменены:

  • net.ipv4.conf.all.accept_redirects

  • net.ipv6.conf.all.accept_redirects

set firewall global-options send-redirects [enable | disable]

Разрешить VyOS отправлять сообщения redirect ICMPv4. Следующий параметр sysctl будет изменен:

  • net.ipv4.conf.all.send_redirects

set firewall global-options log-martians [enable | disable]

Разрешить VyOS записывать пакеты IPv4, которые являются мартианами. Следующий параметр sysctl будет изменен:

  • net.ipv4.conf.all.log_martians

set firewall global-options source-validation [strict | loose | disable]

Установите режим проверки источника IPv4. Следующий параметр sysctl будет изменен:

  • net.ipv4.conf.all.rp_filter

set firewall global-options syn-cookies [enable | disable]

Разрешить VyOS использовать TCP SYN Cookies IPv4. Следующий параметр sysctl будет изменен:

  • net.ipv4.tcp_syncookies

set firewall global-options twa-hazards-protection [enable | disable]

Включить или отключить соответствие VyOS стандарту RFC 1337. Следующий параметр sysctl будет изменен:

  • net.ipv4.tcp_rfc1337

set firewall global-options state-policy established action [accept | drop | reject]
set firewall global-options state-policy established log
set firewall global-options state-policy established log-level [emerg | alert | crit | err | warn | notice | info | debug]

Установите глобальные настройки для установленного соединения.

set firewall global-options state-policy invalid action [accept | drop | reject]
set firewall global-options state-policy invalid log
set firewall global-options state-policy invalid log-level [emerg | alert | crit | err | warn | notice | info | debug]

Установите глобальные настройки для недействительных пакетов.

set firewall global-options state-policy related action [accept | drop | reject]
set firewall global-options state-policy related log
set firewall global-options state-policy related log-level [emerg | alert | crit | err | warn | notice | info | debug]

Установите глобальные настройки для связанных соединений.

VyOS поддерживает установку таймаутов для соединений по типу соединения. Вы можете установить значения таймаута для общих соединений, соединений ICMP, UDP или TCP в различных состояниях.

set firewall global-options timeout icmp <1-21474836>
set firewall global-options timeout other <1-21474836>
set firewall global-options timeout tcp close <1-21474836>
set firewall global-options timeout tcp close-wait <1-21474836>
set firewall global-options timeout tcp established <1-21474836>
set firewall global-options timeout tcp fin-wait <1-21474836>
set firewall global-options timeout tcp last-ack <1-21474836>
set firewall global-options timeout tcp syn-recv <1-21474836>
set firewall global-options timeout tcp syn-sent <1-21474836>
set firewall global-options timeout tcp time-wait <1-21474836>
set firewall global-options timeout udp other <1-21474836>
set firewall global-options timeout udp stream <1-21474836>

Установите таймаут в секундах для протокола или состояния.
