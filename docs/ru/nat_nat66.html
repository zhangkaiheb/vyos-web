NAT66(NPTv6)

Задача

Преобразовать блоки команд в этом файле в директивы cfgcmd/opcmd для отслеживания покрытия команд.

NPTv6 - это технология перевода адресов, основанная на сетях IPv6, используемая для преобразования префикса IPv6 в сообщении IPv6 в другой префикс IPv6. Мы называем этот метод перевода адресов NAT66. Устройства, поддерживающие функцию NAT66, называются устройствами NAT66, которые могут предоставлять функции перевода исходного и целевого адреса NAT66.

Обзор

Различные типы NAT

SNAT66

SNPTv6 Функция преобразования используется в следующих сценариях:

  • Одна внутренняя сеть и внешняя сеть. Используйте устройство NAT66 для подключения одной внутренней сети и публичной сети, а хосты в внутренней сети используют префиксы IPv6, которые поддерживают маршрутизацию только внутри локального диапазона. Когда хост в внутренней сети обращается к внешней сети, исходный префикс IPv6 в сообщении будет преобразован в глобальный одноранговый префикс IPv6 устройством NAT66.

  • Резервирование и распределение нагрузки. На границе IPv6-сети к другой IPv6-сети имеется несколько устройств NAT66. Путь через устройство NAT66 к другой IPv6-сети формирует эквивалентный маршрут, и трафик может распределяться между этими устройствами NAT66. В этом случае вы можете настроить одинаковые правила перевода исходных адресов на этих устройствах NAT66, чтобы любое устройство NAT66 могло обрабатывать IPv6-трафик между разными сайтами.

  • Мульти-хомед. В многохомедной сетевой среде устройство NAT66 подключается к внутренней сети и одновременно подключается к разным внешним сетям. На интерфейсе внешней сети устройства NAT66 можно настроить перевод адресов, чтобы преобразовать один и тот же внутренний адрес в различные внешние адреса и реализовать соответствие одного внутреннего адреса нескольким внешним адресам.

DNAT66

Функция перевода целевого адреса DNPTv6 используется в сценариях, где сервер в внутренней сети предоставляет услуги внешней сети, например, предоставляет веб-сервисы или FTP-сервисы внешней сети. На интерфейсе внешней сети устройства NAT66 можно настроить соотношение между внутренним сервером и внешним сетевым адресом, чтобы пользователи внешней сети могли получить доступ к серверу внутренней сети через заданный внешний сетевой адрес.

Преобразование префиксов

Исходный префикс

Каждое правило SNAT66 имеет определенную команду перевода. Префикс, определенный для перевода, используется при замене информации о адресе в пакете.

SNAT66 правило заменяет исходный адрес пакета и рассчитывает преобразованный адрес с использованием префикса, указанного в правиле.

Пример:

  • Преобразование префикса адреса единственной сети fc01::/64 в fc00::/64

  • Выход через сеть eth0

set nat66 source rule 1 outbound-interface name 'eth0'
set nat66 source rule 1 source prefix 'fc01::/64'
set nat66 source rule 1 translation address 'fc00::/64'

Целевой префикс

Для правила DNAT66, целевой адрес пакета заменяется на адрес, рассчитанный из указанного адреса или префикса в команде translation address.

Пример:

  • Преобразование префикса адреса единственной сети fc00::/64 в fc01::/64

  • Вход через сеть eth0

set nat66 destination rule 1 inbound-interface name 'eth0'
set nat66 destination rule 1 destination address 'fc00::/64'
set nat66 destination rule 1 translation address 'fc01::/64'

Для назначения также можно использовать группы вместо адреса.

Пример:

set firewall group ipv6-address-group ADR-INSIDE-v6 address fc00::1

set nat66 destination rule 1 inbound-interface name 'eth0'
set nat66 destination rule 1 destination group address-group ADR-INSIDE-v6
set nat66 destination rule 1 translation address 'fc01::/64'

Примеры конфигурации

Используйте следующую топологию для создания изолированной сети на основе NAT66 между внутренней и внешней сетями (динамические префиксы не поддерживаются):

R1:

set interfaces ethernet eth0 ipv6 address autoconf
set interfaces ethernet eth1 address 'fc01::1/64'
set nat66 destination rule 1 destination address 'fc00:470:f1cd:101::/64'
set nat66 destination rule 1 inbound-interface name 'eth0'
set nat66 destination rule 1 translation address 'fc01::/64'
set nat66 source rule 1 outbound-interface name 'eth0'
set nat66 source rule 1 source prefix 'fc01::/64'
set nat66 source rule 1 translation address 'fc00:470:f1cd:101::/64'

R2:

set interfaces bridge br1 address 'fc01::2/64'
set interfaces bridge br1 member interface eth0
set interfaces bridge br1 member interface eth1
set protocols static route6 ::/0 next-hop fc01::1
set service router-advert interface br1 prefix ::/0

Используйте следующую топологию для перевода локальных адресов внутренних пользователей (fc::/7) в префиксы, предоставленные ISP через VyOS HA-пару, с использованием виртуального интерфейса.

Настройте оба маршрутизатора (a и b) для DHCPv6-PD через виртуальный интерфейс:

set interfaces bonding bond0 vif 20 dhcpv6-options pd 1 interface dum1 address '0'
set interfaces bonding bond0 vif 20 dhcpv6-options pd 2 interface dum1 address '0'
set interfaces bonding bond0 vif 20 dhcpv6-options pd 3 interface dum1 address '0'
set interfaces bonding bond0 vif 20 dhcpv6-options rapid-commit
commit
