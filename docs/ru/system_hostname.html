Информация о хосте

Этот раздел описывает системную информацию о хосте и как ее настроить, он охватывает следующие темы:

  • Имя хоста

  • Домен

  • IP-адрес

  • Псевдонимы

Имя хоста

Имя хоста — это метка (имя), присвоенная сетевому устройству (хосту) в сети и используется для различения одного устройства от другого в определенных сетях или по интернету. С другой стороны, это имя будет отображаться в командной строке.

set system host-name <hostname>

Имя хоста может состоять до 63 символов. Имя хоста должно начинаться и заканчиваться буквой или цифрой, а внутренние символы могут быть только буквами, цифрами или дефисом.

По умолчанию используется имя хоста vyos.

Имя домена

Имя домена — это метка (имя), присвоенная компьютерной сети и поэтому уникальное. VyOS добавляет имя домена как суффикс к любому неполному имени. Например, если вы установите имя домена example.com, и вы попытаетесь пинговать неполное имя crux, то VyOS приведет имя к виду crux.example.com.

set system domain-name <domain>

Настройка имени домена системы. Имя домена должно начинаться и заканчиваться буквой или цифрой, а внутренние символы могут быть только буквами, цифрами или дефисом.

Статическое сопоставление имен хостов

Как IP-адрес назначается интерфейсу в Ethernet. Этот раздел показывает, как статически сопоставить IP-адрес с именем хоста для локального (то есть на этом экземпляре VyOS) разрешения имен. Это эквивалентно записям файла /etc/hosts в VyOS.

Примечание

Не редактируйте вручную /etc/hosts. Этот файл будет автоматически пересоздан при запуске на основе настроек этого раздела, что означает, что вы потеряете все свои ручные изменения. Вместо этого настройте статические сопоставления имен следующим образом.

set system static-host-mapping host-name <hostname> inet <address>

Создайте статическое сопоставление имен хостов, которое всегда будет разрешать имя <hostname> в IP-адрес <address>.

set system static-host-mapping host-name <hostname> alias <alias>

Создайте именованный <alias> для настроенного статического сопоставления для <hostname>. Таким образом, адрес, настроенный как set system static-host-mapping host-name <hostname> inet <address>, можно достичь через несколько имен.

Можно указать несколько псевдонимов для одного имени хоста.
