Suricata

Suricata — это открытая система обнаружения сетевых угроз, которая выполняет обнаружение вторжений (IDS), встроенный предотвращение вторжений (IPS) и мониторинг безопасности сети (NSM) путем сопоставления живого трафика с набором правил, также называемых сигнатурами. Каждое событие записывается в журнал событий EVE в формате JSON.

VyOS интегрирует Suricata как управляемую службу, настраиваемую под разделом service suricata. При применении конфигурации VyOS генерирует конфигурацию Suricata из этих настроек и запускает службу.

Под разделом service suricata вы можете настроить следующее:

  • Мониторируемые интерфейсы: один или несколько интерфейсов, на которых Suricata захватывает трафик.

  • Группы адресов: именованные списки IPv4/IPv6 адресов или префиксов, используемые вместо буквальных IP-адресов в правилах Suricata.

  • Группы портов: именованные списки портов или диапазонов портов, используемые вместо буквальных портов в правилах Suricata.

  • Журнал EVE: назначение (обычный файл или syslog), имя файла или путь, типы событий для журналирования.

Правила загружаются отдельно при выполнении команды update suricata в режиме операционного режима. Пока эта команда не будет выполнена, служба не будет иметь правил для сопоставления.

Примечание

Конфигурация Suricata может быть сохранена только при наличии хотя бы одного интерфейса, одной группы адресов и одной группы портов. В противном случае, сохранение завершится ошибкой.

Конфигурация

Мониторируемые интерфейсы

Используйте следующую команду для настройки интерфейсов, которые Suricata мониторит.

set service suricata interface <interface>

Настройте интерфейс, на котором Suricata захватывает и анализирует трафик.

Повторите команду, чтобы мониторить несколько интерфейсов. Для успешного сохранения необходимо настроить хотя бы один интерфейс.

Пример:

set service suricata interface eth1

Группы адресов

Используйте следующие команды для настройки групп адресов.

Примечание

Имена групп должны состоять из строчных букв, цифр или дефисов.

Примечание

Правила Suricata ссылаются на обычный набор имен групп, таких как home-net, external-net, http-servers и другие. Определение группы с нестандартным именем разрешено, но ни одно из поставляемых правил не будет на нее ссылаться. Типичные группы адресов включают:

  • home-net: сети, которые Suricata должен рассматривать как внутренние (например, 192.0.2.0/24 и 2001:db8::/32).

  • external-net: все, что не входит в home-net.

  • http-servers, sql-servers, dns-servers: хосты, запускающие соответствующие службы.

set service suricata address-group <name> address <address>

Настройте IPv4 или IPv6 адрес или префикс как члена указанной группы адресов.

<address> принимает IPv4 или IPv6 адрес, IPv4 или IPv6 префикс, или любой из них с префиксом ! для исключения его из совпадений.

Повторите команду, чтобы добавить больше адресов или префиксов в ту же группу.

Пример:

set service suricata address-group home-net address 192.0.2.0/24
set service suricata address-group home-net address 2001:db8::/32
set service suricata address-group home-net address !192.0.2.5
set service suricata address-group <name> group <name>

Настройте другую группу адресов как члена указанной группы адресов.

Предварите имя ссылки символом !, чтобы исключить членов этой группы из совпадений. Указанная группа должна быть определена к моменту сохранения, и циклические ссылки между группами отклоняются.

Повторите команду, чтобы добавить больше групп в ту же родительскую группу.

Пример:

set service suricata address-group home-net address 192.0.2.0/24
set service suricata address-group external-net group !home-net

Группы портов

Используйте следующие команды для настройки групп портов.

Примечание

Имена групп должны состоять из строчных букв, цифр или дефисов.

Примечание

Правила Suricata ссылаются на обычный набор имен групп портов, таких как http-ports, ssh-ports, oracle-ports, shellcode-ports и другие. Определение группы портов с нестандартным именем разрешено, но ни одно из поставляемых правил не будет на нее ссылаться. Типичные группы портов включают:

  • http-ports: порты, где работают службы HTTP.

  • ssh-ports: порты, где слушают службы SSH.

  • oracle-ports: порты, используемые службами базы данных Oracle.

  • shellcode-ports: порты, проверяемые правилами обнаружения shellcode.

set service suricata port-group <name> port <port>

Настройте порт или диапазон портов как члена указанной группы портов.

<port> принимает отдельный порт (1–65535), числовой диапазон в формате start-end (например, 1001-1005), или любую из этих форм с префиксом ! для исключения из совпадений.

Повторите команду, чтобы добавить больше портов или диапазонов портов в ту же группу.

Пример:

set service suricata port-group http-ports port 80
set service suricata port-group http-ports port 443
set service suricata port-group http-ports port 8000-8999
set service suricata port-group http-ports port !8080
set service suricata port-group <name> group <name>

Настройте другую группу портов как члена указанной группы портов.

Предварите имя ссылки символом !, чтобы исключить членов этой группы из совпадений. Указанная группа должна быть определена к моменту сохранения, и циклические ссылки между группами отклоняются.

Повторите команду, чтобы добавить несколько групп в ту же родительскую группу.

Пример:

set service suricata port-group http-ports port 80
set service suricata port-group shellcode-ports group !http-ports

Журнал EVE

Используйте следующие команды для настройки журнала EVE.

set service suricata log eve filename <filename>

Настройте имя файла или путь для журнала Suricata EVE.

Чистое имя файла (например, eve.json) размещает журнал в каталоге по умолчанию Suricata, /var/log/suricata/. Абсолютный путь используется как есть.

По умолчанию eve.json.

Пример:

set service suricata log eve filename eve.json
set service suricata log eve filename /var/log/custom/suricata-eve.json
set service suricata log eve filetype <regular | syslog>

Настройте назначение для журнала Suricata EVE:

  • regular: Записывает журнал EVE в файл, указанный командой set service suricata log eve filename.

  • syslog: Отправляет журнал EVE в syslog.

По умолчанию regular.

Пример:

set service suricata log eve filetype syslog
set service suricata log eve type <type>

Настройте, какие типы событий EVE будут записываться.

Допустимые значения:

  • Общие типы событий: alert, anomaly, drop, files, flow, netflow.

  • Типы событий по протоколам: http, http2, dns, tls, smtp, ftp, smb, ssh, dhcp, tftp, nfs, rdp, sip, snmp, ikev2, krb5, dcerpc, dnp3, rfb, mqtt.

Повторите команду, чтобы записать несколько типов событий.

Пример:

set service suricata log eve type alert
set service suricata log eve type flow
set service suricata log eve type http

Работа

update suricata

Получите текущий набор правил с помощью suricata-update и перезапустите службу Suricata, чтобы загрузить его.

Если service suricata не настроен, команда выводит сообщение об ошибке и завершается.

Пример:

update suricata
restart suricata

Перезапустите службу Suricata.

Если служба не настроена (не существует конфигурации service suricata), или происходит сохранение конфигурации, команда выводит сообщение об ошибке и завершается.

Пример:

restart suricata
