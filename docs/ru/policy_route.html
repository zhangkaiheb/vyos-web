Политики маршрутизации и маршрутизации IPv6

Политики маршрутизации IPv4 и IPv6 определяются в этом разделе. Эти политики маршрутизации могут быть связаны с интерфейсами.

Наборы правил

Набор правил — это именованный набор правил, которые могут быть применены к интерфейсу. Каждое правило имеет номер, действие, которое применяется, если правило совпадает, и возможность указать критерии для совпадения. Пакеты проходят через правила от 1 до 999999, и при первом совпадении действие правила будет выполнено.

set policy route <name> description <text>
set policy route6 <name> description <text>

Укажите описание набора правил.

set policy route <name> default-log
set policy route6 <name> default-log

Опция для ведения журнала пакетов, попадающих под действие по умолчанию.

set policy route <name> interface <interface>
set policy route6 <name> interface <interface>

Применить политику маршрутизации к интерфейсу

set policy route <name> rule <n> description <text>
set policy route6 <name> rule <n> description <text>

Укажите описание каждого правила.

set policy route <name> rule <n> log <enable|disable>
set policy route6 <name> rule <n> log <enable|disable>

Опция для включения или отключения журналирования совпадающего правила.

Критерии совпадения

Доступно множество вариантов критериев совпадения как для policy route, так и для policy route6. Эти параметры перечислены в этом разделе.

set policy route <name> rule <n> connection-mark <1-2147483647>
set policy route6 <name> rule <n> connection-mark <1-2147483647>

Установите критерии совпадения на основе маркировки соединения.

set policy route <name> rule <n> mark <match_criteria>
set policy route6 <name> rule <n> mark <match_criteria>

Совпадение на основе маркировки огневой стены (fwmark), где <match_criteria> может быть:

  • <0-2147483647> — отдельная маркировка fwmark

  • !<0-2147483647> — все, кроме отдельной маркировки fwmark

  • <start-end> — диапазон маркировок

  • !<start-end> — все, кроме диапазона маркировок

Примечание

При использовании команд set table или set vrf настройки маркировки игнорируются и заменяются маркировкой, специфичной для таблицы, которая устанавливается в 0x7FFFFFFF — идентификатор таблицы/VRF.

set policy route <name> rule <n> source address <match_criteria>
set policy route <name> rule <n> destination address <match_criteria>
set policy route6 <name> rule <n> source address <match_criteria>
set policy route6 <name> rule <n> destination address <match_criteria>

Установите критерии совпадения на основе исходного или целевого адреса IPv4/IPv6, где <match_criteria> может быть:

Для IPv4:

  • <x.x.x.x>: IP-адрес для совпадения.

  • <x.x.x.x/x>: Подсеть для совпадения.

  • <x.x.x.x>-<x.x.x.x>: Диапазон IP-адресов для совпадения.

  • !<x.x.x.x>: Совпадение со всем, кроме указанного адреса.

  • !<x.x.x.x/x>: Совпадение со всем, кроме указанной подсети.

  • !<x.x.x.x>-<x.x.x.x>: Совпадение со всем, кроме указанного диапазона.

И для IPv6:

  • <h:h:h:h:h:h:h:h>: IPv6-адрес для совпадения.

  • <h:h:h:h:h:h:h:h/x>: Префикс IPv6 для совпадения.

  • <h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>: Диапазон IPv6 для совпадения.

  • !<h:h:h:h:h:h:h:h>: Совпадение со всем, кроме указанного адреса.

  • !<h:h:h:h:h:h:h:h/x>: Совпадение со всем, кроме указанного префикса.

  • !<h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>: Совпадение со всем, кроме указанного диапазона.

set policy route <name> rule <n> source group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route <name> rule <n> destination group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route6 <name> rule <n> source group <address-group|domain-group|mac-group|network-group|port-group> <text>
set policy route6 <name> rule <n> destination group <address-group|domain-group|mac-group|network-group|port-group> <text>

Установите критерии совпадения на основе исходного или целевого групп, где <text> будет именем группы/идентификатором. Добавьте символ «!» перед критерием для инвертирования совпадения.

set policy route <name> rule <n> destination port <match_criteria>
set policy route6 <name> rule <n> destination port <match_criteria>

Установите критерии совпадения на основе порта назначения, где <match_criteria> может быть:

  • <имя порта>: Именованный порт (любое имя в /etc/services, например, http).

  • <1-65535>: Номер порта.

  • <start>-<end>: Диапазон номеров портов (например, 1001-1005).

Можно указать несколько портов назначения в виде списка, разделенного запятыми. Целый список также можно «инвертировать», используя «!». Например: «!22,telnet,http,123,1001-1005»

set policy route <name> rule <n> disable
set policy route6 <name> rule <n> disable

Опция для отключения правила.

set policy route <name> rule <n> dscp <text>
set policy route6 <name> rule <n> dscp <text>
set policy route <name> rule <n> dscp-exclude <text>
set policy route6 <name> rule <n> dscp-exclude <text>

Совпадение на основе критериев значения DSCP. Поддерживаются несколько значений от 0 до 63 и диапазоны.

set policy route <name> rule <n> fragment <match-grag|match-non-frag>
set policy route6 <name> rule <n> fragment <match-grag|match-non-frag>

Установите совпадение фрагментов IP, где:

  • match-frag: Вторые и последующие фрагменты фрагментированных пакетов.

  • match-non-frag: Головные фрагменты или нефрагментированные пакеты.

set policy route <name> rule <n> icmp <code | type>
set policy route6 <name> rule <n> icmpv6 <code | type>

Совпадение на основе кода и типа ICMP/ICMPv6.

set policy route <name> rule <n> icmp type-name <text>
set policy route6 <name> rule <n> icmpv6 type-name <text>

Совпадение на основе критериев типа ICMP/ICMPv6. Используйте клавишу Tab для получения информации о том, какие критерии типа поддерживаются.

set policy route <name> rule <n> ipsec <match-ipsec|match-none>
set policy route6 <name> rule <n> ipsec <match-ipsec|match-none>

Установите критерии совпадения входящих IPSec-пакетов, где:

  • match-ipsec: совпадение входящих IPSec-пакетов.

  • match-none: совпадение входящих не-IPSec-пакетов.

set policy route <name> rule <n> limit burst <0-4294967295>
set policy route6 <name> rule <n> limit burst <0-4294967295>

Установите максимальное количество пакетов, разрешенных сверх скорости.

set policy route <name> rule <n> limit rate <text>
set policy route6 <name> rule <n> limit rate <text>

Установите максимальную среднюю скорость совпадения. Формат скорости: целое число/единица времени, где единица времени может быть любой из: секунда, минута, час или день. Например, 1/секунда означает, что правило должно совпадать в среднем один раз в секунду.

set policy route <name> rule <n> protocol <text | 0-255 | tcp_udp | all >
set policy route6 <name> rule <n> protocol <text | 0-255 | tcp_udp | all >

Совпадение по критериям протокола. Номер протокола или имя, определенное в: /etc/protocols. Специальные имена: all для всех протоколов и tcp_udp для пакетов TCP и UDP. Символ ! инвертирует выбранный протокол.

set policy route <name> rule <n> packet-length <text>
set policy route6 <name> rule <n> packet-length <text>
set policy route <name> rule <n> packet-length-exclude <text>
set policy route6 <name> rule <n> packet-length-exclude <text>

Совпадение на основе критериев длины пакета. Поддерживаются несколько значений от 1 до 65535 и диапазоны.

set policy route <name> rule <n> packet-type [broadcast | host | multicast | other]
set policy route6 <name> rule <n> packet-type [broadcast | host | multicast | other]

Совпадение на основе критериев типа пакета.

set policy route <name> rule <n> recent count <1-255>
set policy route6 <name> rule <n> recent count <1-255>
set policy route <name> rule <n> recent time <1-4294967295>
set policy route6 <name> rule <n> recent time <1-4294967295>

Установите параметры для совпадения недавно обнаруженных источников. Это совпадение может быть использовано, установив счет (адрес источника, видимый более чем <1-255> раз) и/или время (адрес источника, видимый за последние <0-4294967295> секунд).

set policy route <name> rule <n> state <established | invalid | new | related>
set policy route6 <name> rule <n> state <established | invalid | new | related>

Установите критерии совпадения на основе состояния сессии.

set policy route <name> rule <n> tcp flags <text>
set policy route6 <name> rule <n> tcp flags <text>

Установите критерии совпадения на основе флагов TCP. Допустимые значения для флагов TCP: SYN ACK FIN RST URG PSH ALL. При указании более одного флага флаги должны быть разделены запятой. Например: значение 'SYN,!ACK,!FIN,!RST' будет совпадать только с пакетами, у которых установлен флаг SYN, а флаги ACK, FIN и RST не установлены.

set policy route <name> rule <n> time monthdays <text>
set policy route6 <name> rule <n> time monthdays <text>
set policy route <name> rule <n> time startdate <text>
set policy route6 <name> rule <n> time startdate <text>
set policy route <name> rule <n> time starttime <text>
set policy route6 <name> rule <n> time starttime <text>
set policy route <name> rule <n> time stopdate <text>
set policy route6 <name> rule <n> time stopdate <text>
set policy route <name> rule <n> time stoptime <text>
set policy route6 <name> rule <n> time stoptime <text>
set policy route <name> rule <n> time weekdays <text>
set policy route6 <name> rule <n> time weekdays <text>
set policy route <name> rule <n> time utc
set policy route6 <name> rule <n> time utc

Время для совпадения определенного правила.

set policy route <name> rule <n> ttl <eq | gt | lt> <0-255>

Совпадение параметра времени жизни, где «eq» означает «равно»; «gt» означает «больше чем», а «lt» означает «меньше чем».

set policy route6 <name> rule <n> hop-limit <eq | gt | lt> <0-255>

Совпадение параметра ограничения количества хопов, где «eq» означает «равно»; «gt» означает «больше чем», а «lt» означает «меньше чем».

Действия

При совпадении всех шаблонов, определенных в правиле, можно выполнить различные действия. Это включает в себя отбрасывание пакета, модификацию определенных данных или установку другой таблицы маршрутизации.

set policy route <name> rule <n> action drop
set policy route6 <name> rule <n> action drop

Установите действие правила как «отбросить».

set policy route <name> rule <n> set connection-mark <1-2147483647>
set policy route6 <name> rule <n> set connection-mark <1-2147483647>

Установите конкретную маркировку соединения.

set policy route <name> rule <n> set dscp <0-63>
set policy route6 <name> rule <n> set dscp <0-63>

Установите модификации пакета: Различимый сервисный кодпункт (DSCP)

set policy route <name> rule <n> set mark <1-2147483647>
set policy route6 <name> rule <n> set mark <1-2147483647>

Установите конкретную маркировку пакета.

set policy route <name> rule <n> set table <main | 1-200>
set policy route6 <name> rule <n> set table <main | 1-200>

Установите таблицу маршрутизации для передачи пакета.

Примечание

При использовании команд set table или set vrf совпадение по марке невозможно, потому что оно перезаписывается специфичной для таблицы маркой, равной 0x7FFFFFFF — идентификатору таблицы/VRF.

set policy route <name> rule <n> set tcp-mss <500-1460>
set policy route6 <name> rule <n> set tcp-mss <500-1460>

Установите модификации пакета: явно установите значение максимального размера сегмента TCP.

set policy route <name> rule <n> set vrf <default | text >
set policy route6 <name> rule <n> set vrf <default | text >

Установите VRF для передачи пакета.

Примечание

При использовании команд set table или set vrf совпадение по марке невозможно, потому что оно перезаписывается специфичной для таблицы маркой, равной 0x7FFFFFFF — идентификатору таблицы/VRF.
