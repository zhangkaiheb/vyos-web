Ретрансляция DHCP

Агент ретрансляции DHCP позволяет одному серверу DHCP обслуживать клиентов на удаленных подсетях, что исключает необходимость в отдельном сервере на каждой подсети.

Агент ретрансляции DHCP получает запросы клиентов на одном интерфейсе, передает их как одноадресные сообщения на указанный сервер на другом сетевом интерфейсе и доставляет ответы сервера обратно исходным клиентам.

VyOS предоставляет две независимые службы ретрансляции DHCP:

  • service dhcp-relay: Ретранслирует сообщения между клиентами и серверами IPv4.

  • service dhcpv6-relay: Ретранслирует сообщения между клиентами и серверами IPv6.

Эти две службы настраиваются отдельно и не делят настройки. На двойной стековой сети, где клиенты обоих адресных семей нуждаются в DHCP, необходимо настроить обе.

Ретрансляция IPv4

Настройка

set service dhcp-relay listen-interface <interface>

Настройте интерфейс прослушивания, на котором DHCPv4 ретранслятор получает запросы клиентов в виде широковещательных сообщений.

Повторите команду для настройки нескольких интерфейсов прослушивания.

Примечание

Для успешного применения конфигурации необходимо настроить хотя бы один listen-interface и один upstream-interface.

Пример:

set service dhcp-relay listen-interface eth1
set service dhcp-relay upstream-interface <interface>

Настройте верхний интерфейс, через который DHCPv4 ретранслятор передает запросы клиентов к DHCP-серверу.

Повторите команду для настройки нескольких верхних интерфейсов.

Примечание

Для успешного применения конфигурации необходимо настроить хотя бы один listen-interface и один upstream-interface.

Пример:

set service dhcp-relay upstream-interface eth2
set service dhcp-relay server <ipv4-address>

Настройте IPv4-адрес DHCPv4-сервера, к которому ретранслятор перенаправляет запросы клиентов.

Повторите команду, чтобы перенаправить запросы клиентов на несколько DHCPv4-серверов.

Примечание

Для успешного применения конфигурации необходимо настроить хотя бы один DHCPv4-сервер.

Пример:

set service dhcp-relay server 203.0.113.4
set service dhcp-relay interface <interface>

Настройте интерфейс, участвующий в ретрансляции DHCPv4.

Интерфейсы, настроенные с помощью этой устаревшей команды, работают в двух направлениях, получая широковещательные сообщения DHCPv4 от клиентов и перенаправляя запросы на сервер.

Предупреждение

Эта команда устарела и доступна только для поддержки существующих конфигураций. Новые развертывания должны использовать listen-interface и upstream-interface, которые не могут быть использованы вместе с этой командой. При применении появляется предупреждение о прекращении поддержки.

Примечание

Циклический интерфейс (lo) не принимается в качестве допустимого значения для этой команды.

Пример:

set service dhcp-relay interface eth1
set service dhcp-relay interface eth2
set service dhcp-relay disable

Административно отключите службу ретрансляции DHCPv4 без удаления ее конфигурации.

Пример:

set service dhcp-relay disable

Параметры ретрансляции

set service dhcp-relay relay-options hop-count <1-255>

Настройте количество промежутков (hop count), при котором ретранслируемые пакеты будут отбрасываться.

Ретранслятор DHCPv4, получающий сообщение клиента, устанавливает количество промежутков в 0. Каждый последующий ретранслятор DHCPv4 вдоль пути увеличивает его. Пакеты, чей счетчик промежутков достиг указанного значения, будут беззвучно отброшены.

По умолчанию установлено значение 10.

Пример:

set service dhcp-relay relay-options hop-count 4
set service dhcp-relay relay-options max-size <64-1400>

Настройте максимальный размер, в байтах, который может достигнуть пакет DHCPv4 с добавленным опцией информации агента ретрансляции.

Если пакет с добавленной опцией превышает этот размер, опция будет опущена, и пакет будет передан без нее.

По умолчанию установлено значение 576.

Пример:

set service dhcp-relay relay-options max-size 1400
set service dhcp-relay relay-options relay-agents-packets <append | discard | forward | replace>

Настройте политику, применяемую к входящим пакетам DHCPv4, которые уже содержат опцию информации агента ретрансляции:

  • append: Добавляет локальную опцию информации агента ретрансляции, сохранив существующую опцию информации агента ретрансляции.

  • discard: Отбрасывает пакеты, содержащие опцию информации агента ретрансляции.

  • forward: Передает пакеты без изменений в существующей опции информации агента ретрансляции.

  • replace: Удаляет существующую опцию информации агента ретрансляции и вставляет локальную опцию информации агента ретрансляции.

По умолчанию установлено значение forward.

Пример:

set service dhcp-relay relay-options relay-agents-packets discard

Работа

restart dhcp relay-agent

Перезапустите службу ретрансляции DHCPv4.

Пример

Следующая конфигурация перенаправляет запросы клиентов DHCP, полученные на eth1 (интерфейс, обращенный к клиенту), через eth2 (интерфейс, обращенный к серверу), к DHCP-серверу по адресу 203.0.113.4. Пакеты, содержащие информацию о ретрансляторе, будут отброшены, поэтому будут перенаправлены только запросы, исходящие непосредственно от клиентов.

set interfaces ethernet eth1 address '192.0.2.1/24'
set interfaces ethernet eth2 address '198.51.100.1/24'
set service dhcp-relay listen-interface 'eth1'
set service dhcp-relay upstream-interface 'eth2'
set service dhcp-relay server '203.0.113.4'
set service dhcp-relay relay-options relay-agents-packets discard

Эквивалентная конфигурация с использованием устаревшего синтаксиса interface, сохраненного только для обеспечения обратной совместимости, выглядит так:

set interfaces ethernet eth1 address '192.0.2.1/24'
set interfaces ethernet eth2 address '198.51.100.1/24'
set service dhcp-relay interface 'eth1'
set service dhcp-relay interface 'eth2'
set service dhcp-relay server '203.0.113.4'
set service dhcp-relay relay-options relay-agents-packets discard

Ретрансляция IPv6

Настройка

set service dhcpv6-relay listen-interface <interface>

Настройте интерфейс прослушивания, на котором DHCPv6 ретранслятор получает запросы клиентов в виде многоадресных сообщений.

Интерфейс должен уже иметь назначенный глобальный одноранговый IPv6-адрес.

Повторите команду для настройки нескольких интерфейсов прослушивания.

Примечание

Для успешного применения конфигурации необходимо настроить хотя бы один listen-interface и один upstream-interface.

Пример:

set service dhcpv6-relay listen-interface eth1
set service dhcpv6-relay listen-interface <interface> address <ipv6-address>

Настройте IPv6-адрес, который использует DHCPv6 ретранслятор для идентификации клиентского сетевого интерфейса для DHCPv6-сервера.

Адрес должен быть нелокальным IPv6-адресом, уже назначенным указанному интерфейсу прослушивания.

Если адрес не задан, DHCPv6 ретранслятор использует первый нелокальный IPv6-адрес, найденный на этом интерфейсе прослушивания.

Пример:

set service dhcpv6-relay listen-interface eth1 address 2001:db8:1::1
set service dhcpv6-relay upstream-interface <interface> address <ipv6-address>

Настройте IPv6-адрес DHCPv6-сервера (или другого ретранслятора), к которому DHCPv6 ретранслятор перенаправляет сообщения клиентов через указанный верхний интерфейс.

Повторите команду, чтобы перенаправить сообщения клиентов на несколько серверов (или ретрансляторов).

Примечание

Для успешного применения конфигурации необходимо настроить адрес сервера (или ретранслятора) для каждого верхнего интерфейса.

Пример:

set service dhcpv6-relay upstream-interface eth2 address 2001:db8:2::4
set service dhcpv6-relay disable

Административно отключите службу ретрансляции DHCPv6 без удаления ее конфигурации.

Пример:

set service dhcpv6-relay disable

Параметры ретрансляции

set service dhcpv6-relay max-hop-count <1-255>

Настройте количество промежутков (hop count), при котором ретранслируемые пакеты будут отбрасываться.

Ретранслятор DHCPv6, получающий сообщение клиента, устанавливает количество промежутков в 0. Каждый последующий ретранслятор DHCPv6 вдоль пути увеличивает его. Пакеты, чей счетчик промежутков достиг указанного значения, будут беззвучно отброшены.

По умолчанию установлено значение 10.

Пример:

set service dhcpv6-relay max-hop-count 4
set service dhcpv6-relay use-interface-id-option

Включите вставку опции идентификатора интерфейса в каждое сообщение Relay-forward.

Опция идентификатора интерфейса вставляется автоматически каждый раз, когда на ретрансляторе настроено более одного интерфейса прослушивания, независимо от этого параметра.

Пример:

set service dhcpv6-relay use-interface-id-option

Работа

restart dhcpv6 relay-agent

Перезапустите службу ретрансляции DHCPv6.

Пример

Следующая конфигурация перенаправляет запросы клиентов DHCPv6, полученные на eth1 (интерфейс, обращающийся к клиенту), через eth2 (интерфейс, обращающийся к серверу), к DHCPv6-серверу по адресу 2001:db8:2::4.

set interfaces ethernet eth1 address '2001:db8:1::1/64'
set interfaces ethernet eth2 address '2001:db8:2::1/64'
set service dhcpv6-relay listen-interface 'eth1'
set service dhcpv6-relay upstream-interface 'eth2' address '2001:db8:2::4'
