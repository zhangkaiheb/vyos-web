Conntrack

VyOS может быть настроено для отслеживания соединений с использованием подсистемы отслеживания соединений. Отслеживание соединений становится активным, как только будет настроено состояние фаервола или NAT.

Настройка

set system conntrack table-size <1-50000000>

Таблица отслеживания соединений содержит одну запись для каждого соединения, отслеживаемого системой.

set system conntrack expect-table-size <1-50000000>

Таблица ожидаемых соединений отслеживает одно значение для каждого ожидаемого соединения, связанного с существующим соединением. Эти значения обычно используются модулями «помощника по отслеживанию соединений», такими как FTP. Размер таблицы ожиданий по умолчанию составляет 2048 записей.

set system conntrack hash-size <1-50000000>

Установите размер хэш-таблицы. Хэш-таблица отслеживания соединений делает поиск в таблице отслеживания соединений быстрее. Хэш-таблица использует «карманы» для записи записей в таблице отслеживания соединений.

set system conntrack modules ftp
set system conntrack modules h323
set system conntrack modules nfs
set system conntrack modules pptp
set system conntrack modules sip
set system conntrack modules sqlnet
set system conntrack modules tftp

Настройте модули помощников протокола отслеживания соединений. Все модули включены по умолчанию.

Используйте delete system conntrack modules, чтобы деактивировать все модули.
Или, например, ftp, delete system conntrack modules ftp.
set system conntrack tcp half-open-connections <1-21474836>

Установите максимальное количество TCP-соединений в состоянии полуготовности.

set system conntrack tcp loose <enable | disable>

Политика отслеживания ранее установленных соединений.

set system conntrack tcp max-retrans <1-2147483647>

Установите количество максимальных попыток повторной передачи TCP.

Время ожидания Conntrack

Вы можете определить пользовательские значения времени ожидания, чтобы применить их к определенному подмножеству соединений, на основе селектора пакетов и потока. Для этого вам нужно создать правило, определяющее селектор пакетов и потока.

set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> description <test>

Установите описание правила.

set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> destination address <ip-address>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> source address <ip-address>

Установите адрес назначения и/или отправителя. Допустимый ввод для IPv4:

set system conntrack timeout custom ipv4 rule <1-999999> [source | destination] address
Возможные завершения:
   <x.x.x.x>            IPv4 адрес для совпадения
   <x.x.x.x/x>          IPv4 префикс для совпадения
   <x.x.x.x>-<x.x.x.x>  IPv4 диапазон адресов для совпадения
   !<x.x.x.x>           Совпадение со всем, кроме указанного адреса
   !<x.x.x.x/x>         Совпадение со всем, кроме указанного префикса
   !<x.x.x.x>-<x.x.x.x> Совпадение со всем, кроме указанного диапазона

set system conntrack timeout custom ipv6 rule <1-999999> [source | destination] address
Возможные завершения:
   <h:h:h:h:h:h:h:h>    IP адрес для совпадения
   <h:h:h:h:h:h:h:h/x>  Подсеть для совпадения
   <h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>
                        IP диапазон для совпадения
   !<h:h:h:h:h:h:h:h>   Совпадение со всем, кроме указанного адреса
   !<h:h:h:h:h:h:h:h/x> Совпадение со всем, кроме указанного префикса
   !<h:h:h:h:h:h:h:h>-<h:h:h:h:h:h:h:h>
                        Совпадение со всем, кроме указанного диапазона
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> destination port <value>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> source port <value>

Установите порт назначения и/или отправителя. Допустимый ввод:

<port name>    Именованный порт (любое имя в /etc/services, например, http)
<1-65535>      Номер порта
<start>-<end>  Номер диапазона портов (например, 1001-1005)

Можно указать несколько портов назначения в виде списка, разделенного запятыми. Целый список также можно «отрицать» с помощью ‘!’ Например: !22,telnet,http,123,1001-1005`

set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp close <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp close-wait <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp established <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp fin-wait <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp last-ack <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp syn-recv <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp syn-sent <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol tcp time-wait <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol udp replied <1-21474836>
set system conntrack timeout custom [ipv4 | ipv6] rule <1-999999> protocol udp unreplied <1-21474836>

Установите время ожидания в секундах для протокола или состояния в пользовательском правиле.

Правила игнорирования Conntrack

Примечание

Важное примечание о правилах игнорирования conntrack: Начиная с vyos-1.5-rolling-202406120020, правила игнорирования могут быть определены в set firewall [ipv4 | ipv6] prerouting raw .... Ожидается, что в будущем правила игнорирования conntrack будут удалены.

Пользовательские правила игнорирования, основанные на селекторе пакетов и потока.

set system conntrack ignore [ipv4 | ipv6] rule <1-999999> description <text>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> destination address <ip-address>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> destination port <port>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> inbound-interface <interface>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> protocol <protocol>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> source address <ip-address>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> source port <port>
set system conntrack ignore [ipv4 | ipv6] rule <1-999999> tcp flags [not] <text>

Допустимые значения для флагов TCP: ack, cwr, ecn, fin, psh, rst, syn и urg. Поддерживаются несколько значений, а для обратного выбора используйте not, как показано в примере.

Журнал Conntrack

set system conntrack log event destroy
set system conntrack log event new
set system conntrack log event update

Записывать события отслеживания соединений по типу.

set system conntrack log event destroy icmp
set system conntrack log event destroy other
set system conntrack log event destroy tcp
set system conntrack log event destroy udp
set system conntrack log event new icmp
set system conntrack log event new other
set system conntrack log event new tcp
set system conntrack log event new udp
set system conntrack log event update icmp
set system conntrack log event update other
set system conntrack log event update tcp
set system conntrack log event update udp

Записывать события отслеживания соединений по протоколу.

set system conntrack log timestamp

Включить расширение временной метки на основе потока.

set system conntrack log queue-size <100-999999>

Управлять размером внутренней очереди, по умолчанию размер составляет 4096 событий.

set system conntrack log log-level <info | debug>
