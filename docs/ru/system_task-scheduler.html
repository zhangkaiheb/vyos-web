Планировщик задач

Планировщик задач позволяет запускать задачи по заданному расписанию. Он использует UNIX cron.

Примечание

Все скрипты, выполняемые таким образом, запускаются от пользователя root — это может быть опасно. Вместе с Сценарии команд это может использоваться для автоматизации (пере)настройки.

set system task-scheduler task <task> interval <interval>

Укажите временной интервал, когда <task> должно быть выполнено. Интервал указывается как число с одним из следующих суффиксов:

  • none - Интервал выполнения в минутах

  • m - Интервал выполнения в минутах

  • h - Интервал выполнения в часах

  • d - Интервал выполнения в днях

Примечание

Если суффикс опущен, предполагается минуты.

set system task-scheduler task <task> crontab-spec <spec>

Установите время выполнения в обычном формате cron. Спецификация cron <spec> вида 30 */6 * * * будет выполнять <task> в 30-й минуте каждого 6-го часа.

set system task-scheduler task <task> executable path <path>

Укажите абсолютный <path> к скрипту, который будет запущен при выполнении <task>.

set system task-scheduler task <task> executable arguments <args>

Аргументы, которые будут переданы исполняемому файлу.
