Конфигурация IPv6 брандмауэра

Обзор

Этот раздел охватывает полезную информацию о конфигурации брандмауэра IPv6 и соответствующие команды режима работы.

Этот раздел описывает следующие команды конфигурации:

set firewall ipv6 …

Чтобы узнать о общем потоке трафика в брандмауерах VyOS, см. Брандмауэр.

- set firewall
    * ipv6
         - forward
            + filter
         - input
            + filter
         - output
            + filter
            + raw
         - prerouting
            + raw
         - name
            + custom_name

Роутер сначала получает весь трафик и обрабатывает его в разделе prerouting.

Этот этап включает:

  • IPv6 Prerouting: команды, найденные под set firewall ipv6 prerouting raw ...

  • Conntrack Ignore: set system conntrack ignore ipv6...

  • Policy Route: команды, найденные под set policy route6 ...

  • Destination NAT: команды, найденные под set nat66 destination ...

Для трафика, который роутер получает и передает, базовая цепочка — это forward. Ниже приведена упрощенная диаграмма потока пакетов для транзитного трафика:

Используйте set firewall ipv6 forward filter ..., чтобы настроить правила фильтрации для транзитного трафика. Эта команда соответствует этапу 5 и выделена красным на диаграмме.

Для трафика, предназначенного для роутера, используйте цепочку input. Для трафика, который генерирует роутер, используйте цепочку output. Ниже представлена диаграмма потока пакетов для трафика, предназначенного роутеру, и трафика, который генерирует роутер (начиная с круга номер 6):

Используйте set firewall ipv6 input filter ..., чтобы настроить трафик, предназначенный роутеру.

Используйте set firewall ipv6 output ..., чтобы настроить трафик, который генерирует роутер. Доступны две подцепочки: filter и raw:

  • Output Prerouting: set firewall ipv6 output raw .... Как описано в разделе Prerouting, брандмауэр обрабатывает правила в этом разделе до подсистемы отслеживания соединений.

  • Output Filter: set firewall ipv6 output filter .... Брандмауэр обрабатывает правила в этом разделе после подсистемы отслеживания соединений.

Примечание

Важное примечание о действиях по умолчанию: Если вы не определите действие по умолчанию для базовой цепочки, система установит действие по умолчанию как accept для этой цепочки. Для пользовательских цепочек, если вы не определили действие по умолчанию, система установит действие по умолчанию как drop

Создайте пользовательские цепочки брандмауэра с помощью команд set firewall ipv6 name <name> .... Чтобы использовать пользовательскую цепочку, определите правило с action jump и соответствующим target в базовой цепочке.

Брандмауэр - Правила IPv6

Создайте правила фильтрации брандмауэра. Каждое правило имеет номер и действие, которое применяется при совпадении правила. Вы можете указать несколько критериев совпадения. Пакеты проходят через правила от 1 до 999999, поэтому порядок важен. Брандмауэр выполняет действие первого совпадающего правила.

Действия

Если вы определяете правило, вы должны определить действие для него. Действие говорит брандмауэру, что делать, когда все критерии для этого правила выполнены.

Действие может быть :

  • accept: принять пакет.

  • continue: продолжить анализ следующего правила.

  • drop: отбросить пакет.

  • reject: отклонить пакет.

  • jump: перейти к другой пользовательской цепочке.

  • return: вернуться из текущей цепочки и продолжить с следующего правила последней цепочки.

  • queue: добавить пакет в очередь в пространстве пользователя.

  • synproxy: синпрокси пакет.

set firewall ipv6 forward filter rule <1-999999> action [accept | continue | drop | jump | queue | reject | return | synproxy]
set firewall ipv6 input filter rule <1-999999> action [accept | continue | drop | jump | queue | reject | return | synproxy]
set firewall ipv6 output filter rule <1-999999> action [accept | continue | drop | jump | queue | reject | return]
set firewall ipv6 name <name> rule <1-999999> action [accept | continue | drop | jump | queue | reject | return]

Это обязательное настройка определяет действие текущего правила. Если вы установите действие на jump, вы также должны определить целевую точку прыжка.

set firewall ipv6 forward filter rule <1-999999> jump-target <text>
set firewall ipv6 input filter rule <1-999999> jump-target <text>
set firewall ipv6 output filter rule <1-999999> jump-target <text>
set firewall ipv6 name <name> rule <1-999999> jump-target <text>

Используйте эту команду только при действии, установленном на jump. Укажите целевую точку прыжка.

set firewall ipv6 forward filter rule <1-999999> queue <0-65535>
set firewall ipv6 input filter rule <1-999999> queue <0-65535>
set firewall ipv6 output filter rule <1-999999> queue <0-65535>
set firewall ipv6 name <name> rule <1-999999> queue <0-65535>

Используйте эту команду только при действии, установленном на queue. Укажите целевую очередь. Также поддерживаются диапазоны очередей.

set firewall ipv6 forward filter rule <1-999999> queue-options bypass
set firewall ipv6 input filter rule <1-999999> queue-options bypass
set firewall ipv6 output filter rule <1-999999> queue-options bypass
set firewall ipv6 name <name> rule <1-999999> queue-options bypass

Используйте эту команду только при действии, установленном на queue. Эта команда позволяет пакету пройти через брандмауэр, когда ни одно программное обеспечение пользовательского пространства не подключено к очереди.

set firewall ipv6 forward filter rule <1-999999> queue-options fanout
set firewall ipv6 input filter rule <1-999999> queue-options fanout
set firewall ipv6 output filter rule <1-999999> queue-options fanout
set firewall ipv6 name <name> rule <1-999999> queue-options fanout

Используйте эту команду только при действии, установленном на queue. Эта команда распределяет пакеты между несколькими очередями.

Также default-action — это действие, которое происходит, когда пакет не соответствует никакому правилу в своей цепочке. Для базовых цепочек возможные варианты для default-action — это accept или drop.

set firewall ipv6 forward filter default-action [accept | drop]
set firewall ipv6 input filter default-action [accept | drop]
set firewall ipv6 output filter default-action [accept | drop]
set firewall ipv6 name <name> default-action [accept | drop | jump | queue | reject | return]

Установите действие по умолчанию для набора правил, если пакет не соответствует критериям любого правила. Если вы установите default-action на jump, вы также должны определить default-jump-target. Для базовых цепочек вы можете установить действие по умолчанию только на accept или drop. Для пользовательских цепочек доступно больше действий.

set firewall ipv6 name <name> default-jump-target <text>

Используется только тогда, когда default-action установлено на jump. Используйте эту команду, чтобы указать целевую точку прыжка для правила по умолчанию.

Примечание

Важное примечание о действиях по умолчанию: Если вы не определите действие по умолчанию для базовой цепочки, система устанавливает действие по умолчанию как accept для этой цепочки. Для пользовательских цепочек, если вы не определили действие по умолчанию, система устанавливает действие по умолчанию как drop.

Журналы брандмауэра

Вы можете включить журналирование для каждого правила брандмауэра. При включении можно также определить другие параметры журнала.

set firewall ipv6 forward filter rule <1-999999> log
set firewall ipv6 input filter rule <1-999999> log
set firewall ipv6 output filter rule <1-999999> log
set firewall ipv6 name <name> rule <1-999999> log

Включить логирование для совпадающих пакетов. Если эта конфигурационная команда отсутствует, логирование отключено.

set firewall ipv6 forward filter default-log
set firewall ipv6 input filter default-log
set firewall ipv6 output filter default-log
set firewall ipv6 name <name> default-log

Используйте эту команду, чтобы включить логирование действия по умолчанию на указанной цепочке.

set firewall ipv6 forward filter rule <1-999999> log-options level [emerg | alert | crit | err | warn | notice | info | debug]
set firewall ipv6 input filter rule <1-999999> log-options level [emerg | alert | crit | err | warn | notice | info | debug]
set firewall ipv6 output filter rule <1-999999> log-options level [emerg | alert | crit | err | warn | notice | info | debug]
set firewall ipv6 name <name> rule <1-999999> log-options level [emerg | alert | crit | err | warn | notice | info | debug]

Определите уровень журнала. Действует только при активированном журнале правила.

set firewall ipv6 forward filter rule <1-999999> log-options group <0-65535>
set firewall ipv6 input filter rule <1-999999> log-options group <0-65535>
set firewall ipv6 output filter rule <1-999999> log-options group <0-65535>
set firewall ipv6 name <name> rule <1-999999> log-options group <0-65535>

Определите группу журнала для отправки сообщений. Действует только при активированном журнале правила.

set firewall ipv6 forward filter rule <1-999999> log-options snapshot-length <0-9000>
set firewall ipv6 input filter rule <1-999999> log-options snapshot-length <0-9000>
set firewall ipv6 output filter rule <1-999999> log-options snapshot-length <0-9000>
set firewall ipv6 name <name> rule <1-999999> log-options snapshot-length <0-9000>

Определите длину заголовка пакетов, которые будут включаться в сообщение netlink. Действует только при активированном журнале правила и определенной группе журнала.

set firewall ipv6 forward filter rule <1-999999> log-options queue-threshold <0-65535>
set firewall ipv6 input filter rule <1-999999> log-options queue-threshold <0-65535>
set firewall ipv6 output filter rule <1-999999> log-options queue-threshold <0-65535>
set firewall ipv6 name <name> rule <1-999999> log-options queue-threshold <0-65535>

Определите количество пакетов, которые нужно сохранить в ядре, прежде чем отправить их в пространство пользователя. Действует только при активированном журнале правила и определенной группе журнала.

Описание брандмауэра

Для справки вы можете определить описание для каждого правила и пользовательской цепочки.

set firewall ipv6 name <name> description <text>

Укажите описание для пользовательской цепочки брандмауэра.

set firewall ipv6 forward filter rule <1-999999> description <text>
set firewall ipv6 input filter rule <1-999999> description <text>
set firewall ipv6 output filter rule <1-999999> description <text>
set firewall ipv6 name <name> rule <1-999999> description <text>

Укажите описание для каждого правила.

Статус правила

Новые правила включены по умолчанию. В некоторых случаях вы можете захотеть отключить правило вместо того, чтобы удалить его.

Критерии совпадения

Существует множество критериев, по которым можно протестировать пакет.

Изменения пакетов

Брандмауэр может изменять пакеты перед их отправкой. Эта функция предоставляет большую гибкость для обработки пакетов.

Synproxy

Синхронизация соединений

set firewall ipv6 [input | forward] filter rule <1-999999> action synproxy
set firewall ipv6 [input | forward] filter rule <1-999999> protocol tcp
set firewall ipv6 [input | forward] filter rule <1-999999> synproxy tcp mss <501-65535>

Установите максимальный размер сегмента TCP для соединения.

set firewall ipv6 [input | forward] filter rule <1-999999> synproxy tcp window-scale <1-14>

Установите коэффициент масштабирования окна для масштабирования окна TCP.

Пример Synproxy

Требования для включения Synproxy:

  • Трафик должен быть симметричным

  • Синпроцесс зависит от синкоуков и временных меток TCP, убедитесь, что они включены

  • Отключите опцию loose track в conntrack

set system sysctl parameter net.ipv4.tcp_timestamps value '1'


set system conntrack tcp loose disable

set system conntrack ignore ipv6 rule 10 destination port '8080'

set system conntrack ignore ipv6 rule 10 protocol 'tcp'

set system conntrack ignore ipv6 rule 10 tcp flags syn


set firewall global-options syn-cookies 'enable'

set firewall ipv6 input filter rule 10 action 'synproxy'

set firewall ipv6 input filter rule 10 destination port '8080'

set firewall ipv6 input filter rule 10 inbound-interface name 'eth1'

set firewall ipv6 input filter rule 10 protocol 'tcp'

set firewall ipv6 input filter rule 10 synproxy tcp mss '1460'

set firewall ipv6 input filter rule 10 synproxy tcp window-scale '7'

set firewall ipv6 input filter rule 1000 action 'drop'

set firewall ipv6 input filter rule 1000 state invalid

Пример частичной конфигурации

<
firewall {
    ipv6 {
        input {
            filter {
                rule 10 {
                    action jump
                    inbound-interface {
                        name eth1
                    }
                    jump-target INP-ETH1
                }
                rule 20 {
                    action accept
                    inbound-interface {
                        name eth0
                    }
                    log
                    protocol ipv6-icmp
                }
            }
        }
        name INP-ETH1 {
            default-action drop
            default-log
            rule 10 {
                action accept
                protocol tcp_udp
            }
        }
    }
}
