# 内存监控

## 概述

内存监控页面显示系统内存使用情况，包括物理内存、交换空间和缓存使用情况。

## 监控指标

### 物理内存
- **总计（Total）**：系统总物理内存
- **已用（Used）**：已使用的内存
- **空闲（Free）**：完全未使用的内存
- **可用（Available）**：可用于新进程的内存（包括可回收的缓存）

### 交换空间
- **总计（Total）**：交换空间总量
- **已用（Used）**：已使用的交换空间
- **空闲（Free）**：未使用的交换空间

### 缓存
- **缓冲区（Buffers）**：块设备缓存
- **缓存（Cached）**：文件系统缓存
- **Slab**：内核数据结构缓存

## 操作命令

```bash
# 查看内存使用情况
show system memory

# 查看进程内存使用
show system processes memory
```

## 注意事项

- 可用内存比空闲内存更能反映实际可用资源
- 交换空间使用率过高可能表示物理内存不足
- 建议保持可用内存占总内存的 20% 以上
