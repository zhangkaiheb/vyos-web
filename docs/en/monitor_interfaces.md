# 接口流量监控

## 概述

接口流量监控页面显示网络接口的实时流量统计信息，帮助您了解网络带宽使用情况。

## 监控指标

### 流量统计
- **接收字节数（RX Bytes）**：接口接收的总字节数
- **发送字节数（TX Bytes）**：接口发送的总字节数
- **接收包数（RX Packets）**：接口接收的数据包数量
- **发送包数（TX Packets）**：接口发送的数据包数量

### 错误统计
- **接收错误（RX Errors）**：接收时的错误数
- **发送错误（TX Errors）**：发送时的错误数
- **丢弃包（Drops）**：丢弃的数据包数量
- **冲突（Collisions）**：以太网冲突数

### 速率
- **接收速率（RX Rate）**：当前接收速率（bps/pps）
- **发送速率（TX Rate）**：当前发送速率（bps/pps）

## 操作命令

```bash
# 查看接口统计
show interfaces

# 查看接口详细统计
show interfaces ethernet eth0

# 实时监控接口流量
monitor interface ethernet eth0
```

## 注意事项

- 持续高错误率可能表示硬件或电缆问题
- 高丢弃率可能表示缓冲区不足或拥塞
- 建议监控接口利用率，避免超过 80%
