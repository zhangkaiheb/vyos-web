# CPU 监控

## 概述

CPU 监控页面显示系统 CPU 使用率统计信息，帮助您了解系统的计算资源使用情况。

## 监控指标

### CPU 使用率
- **用户态（User）**：用户进程使用的 CPU 时间百分比
- **系统态（System）**：内核进程使用的 CPU 时间百分比
- **空闲（Idle）**：CPU 空闲时间百分比
- **等待 I/O（IOWait）**：CPU 等待 I/O 操作完成的时间百分比

### 负载平均值
- **1 分钟负载**：过去 1 分钟的平均负载
- **5 分钟负载**：过去 5 分钟的平均负载
- **15 分钟负载**：过去 15 分钟的平均负载

## 操作命令

```bash
# 查看 CPU 使用率
show system cpu

# 查看进程 CPU 使用情况
show system processes cpu
```

## 注意事项

- 负载平均值超过 CPU 核心数表示系统过载
- 持续高 IOWait 可能表示磁盘或网络瓶颈
- 建议保持 CPU 使用率在 70% 以下以确保稳定运行
