# VyOS Web

Веб-система конфигурации для VyOS, предназначенная для визуального управления распространёнными настройками командной строки с сохранением согласованности с нативной структурой команд VyOS.

## Обзор проекта

VyOS Web Config предоставляет полную реализацию фронтенда и бэкенда:
- Фронтенд на базе Vue 3 (нативный ESM в браузере)
- Бэкенд на базе Python WSGI (Apache + mod_wsgi в продакшене)
- Чтение и запись конфигурации через нативные механизмы VyOS
- Поддержка контроля доступа, аудита и логирования, справочной документации, онлайн-обновлений и др.

Проект развёртывается в отдельном каталоге, чтобы не изменять основные системные файлы.

## Основные возможности

- Меню и пути конфигурации соответствуют иерархии VyOS
- Охватывает управление системой, сеть, маршрутизацию, межсетевой экран, NAT, сервисы, VPN, логирование и другие модули
- Сессии конфигурации: commit, confirm commit, rollback, compare, import/export
- Управление пользователями и доступом (видимость страниц, права чтения/записи)
- Мониторинг и логирование (включая SSE и потоковую передачу в реальном времени)
- Локальная справочная документация и многоязычные ресурсы
- Управление версиями веб-приложения и API обновлений

## Технологический стек

### Фронтенд
- Vue 3
- Vue Router 4
- Vue I18n 9
- Axios
- Нативная загрузка модулей (без сборщика)

### Бэкенд
- Python 3
- WSGI-приложение
- Apache + mod_wsgi (продакшен)
- Ключевые зависимости: PyJWT, paramiko, cryptography, requests, openpyxl, vyos

## Архитектура

- Точка входа фронтенда: `frontend/index.html` + `frontend/src/main.js`
- Точка входа бэкенда: `backend/app.py`
- Точка входа WSGI: `backend/app.wsgi`
- Сервер разработки: `scripts/run_server.py`
- Сервис мониторинга: `backend/websocket_server.py`
- Генерация меню: `backend/data/generate_menu.py`

Бэкенд разделён на сервисы (`backend/services/`) с единым API-маршрутизацией;
фронтенд построен на компонентах страниц и общих компонентах форм/модальных окон.

## Быстрый старт

> Рекомендуется использовать на VyOS или в среде с зависимостями VyOS.

### 1) Установка (продакшен)

```bash
cd /opt/vyos-web-config
sudo bash scripts/install.sh
```

Скрипт установки выполнит:
- Инициализацию каталогов
- Установку Python venv и зависимостей
- Настройку сайта Apache и mod_wsgi
- Генерацию самоподписанных сертификатов (при отсутствии)
- Инициализацию базы данных

После установки доступ по адресу:
- `https://<vyos-ip>/`

### 2) Режим разработки

Терминал 1: запуск веб-сервера

```bash
cd /opt/vyos-web-config
python3 scripts/run_server.py --host 0.0.0.0 --port 8080
```

Терминал 2: запуск WebSocket-сервиса мониторинга

```bash
cd /opt/vyos-web-config
python3 backend/websocket_server.py
```

Или используйте флаг разработки установочного скрипта:

```bash
cd /opt/vyos-web-config
sudo bash scripts/install.sh --dev
```

## Структура каталогов

```text
/opt/vyos-web-config
─ frontend/                # Фронтенд: страницы и компоненты
│  ├─ index.html
│  └─ src/
├─ backend/                 # Бэкенд: WSGI-приложение
│  ├─ app.py
│  ├─ app.wsgi
│  ├─ services/
│  ├─ routes/
│  ├─ utils/
│  ├─ tests/
│  └─ data/
├─ scripts/                 # Скрипты установки, запуска, маппинга документации
├─ docs/                    # Локальная справка (многоязычная)
├─ apache/                  # Конфигурация Apache и сертификаты
└─ config/                  # Конфигурационные файлы проекта
```

## Рекомендации по разработке

- После изменения структуры меню синхронизируйте скрипт генерации и данные меню
- При добавлении новых страниц также заполняйте:
  - Маршруты меню
  - Настройки видимости и прав доступа
  - Справочную документацию
  - Локализацию (китайский и английский)
- API конфигурации бэкенда работают с C-расширениями VyOS; избегайте параллельного чтения/записи во время разработки

## Безопасность

- Замените самоподписанные сертификаты в продакшене
- Аутентификация опирается на системных пользователей; используйте принцип минимальных привилегий
- Рекомендуется ограничивать доступ к интерфейсу управления через ACL/межсетевой экран
